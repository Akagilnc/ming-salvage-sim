## 核心

**国策 = 「当下旨意的具体后果」，不是玩家点的进度树/科技树面板。**

真护栏 = **皇帝角色保真**——这是模拟皇帝的模拟器，皇帝面前不该有能点的科技树/进度面板。同根原则：不亲手换兵种、皇帝无表（见 P4：DB 有数皇帝无表）、**actor 博弈 > 资源按钮**。

国策的落点 = **建军 / 人物去向 / 营建 / 财政 / 局势**这些**此刻的实体后果**，不是面板上的解锁项。

## feel：不是钦定悲剧

feel **非钦定悲剧**，是《冰汽时代 1》式的**高压绝境求生 + 硬取舍 + 破局可真**（「越努力越难、但出路恒在」）。结局开放，破局可真。

## 长线发展/科技：不是禁区，但「合理」须两轴都过

长线发展、科技**不是禁区**。但要「合理」，**两根轴都得过**：

1. **形态轴 —— 必须 diegetic（世界观叙事内）涌现**
   - ✅ 经旨意 / 召对 / 奏报涌现：徐光启奏对「能从澳门葡人搞红夷炮练兵」。
   - ❌ 面板话术：大臣嘴里冒「先点 A 解锁 B」。

2. **尺度轴 —— 史实合理范围一点点**
   - ✅ 红夷炮 / 燧发枪（史实合理范围）。
   - ❌ 蒸汽机 / 化肥 / 火车 / 飞机（跨几百年文明阶梯＝越界）。

**禁的是「面板形态 + 越界尺度」，不是发展/出路本身。**

**判据** = 「皇帝会不会坐这面板前点它」，**不是**「它给不给出路」（出路本就该有）。
