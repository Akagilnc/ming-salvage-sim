# 圣意备忘 — 本局关键决策 / 待议 / 伏笔

> 配合 data/probe.db（盘面存档）一起构成"游戏进度"。上下文会压缩、记忆不可靠，重要的记这里。当前：崇祯二年二月。

## 💡 待议 / 想法（尚未正式下旨）
- **宗室从军**：开宗室四民之禁后，皇帝联想到——许宗室子弟从军报国（军籍亦是一条"自谋生计"的出路），既补兵源、又多给宗室一条路。可与卢象升练兵、四民之禁并案。**待与韩爌、兵部议。**（崇祯二年二月，因起用卢象升练天雄军而起意）

## ⚔️ 必须盯住的伏笔（能臣内耗 / 党争——韩爌警告过）
- **温体仁(皇党) vs 东林**：东林参温"附阉"，皇帝以"看罪不看派"驳回、保温。温记仇（退朝眼底阴翳）。史上温反扑东林、专权八年。→ 靠韩爌持平、皇帝盯防。
- **杨嗣昌(主和) vs 卢象升(主战)**：和战路线水火不容。史上杨掣肘卢、致其巨鹿殉国。起用卢象升后须防这对内耗。
- **杨嗣昌 vs 清流(倪黄)**：清丈分化时已有细缝。

## 🎯 进行中大政（issue 系统在跟，此处记要点）
- **备己巳之变**（崇祯二年十月）：孙承宗抚蒙喀喇沁/束不的、断后金借道（关键先手，月月汇报）
- **治本长策**：屯田番薯（杨徐，3年）、清丈（推山东河南）、宗室四民之禁+整禄米、九边整饷裁冗
- **复辽**：袁崇焕务实固辽（不以五年苛之）
- **反间**：魏忠贤撬八旗（阿敏离心，内讧苗头）
