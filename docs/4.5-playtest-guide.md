# ⛳4.5 试玩指引（#548 / #478 S13 族尾）

**核对日期：2026-08-28（本地日期 Asia/Tokyo；HEAD 点核）**

## 本指引是什么 / 不是什么

- **4.5 = 持续校准点，不是开工闸、停车闸、准入闸。**  
  排程真源见 #486：试玩只影响实现微调，不决定家族是否开跑、是否放行。  
  本文件是试玩者读物，不是进度板。
- **已知债 = 现象 + 归属 issue**。进度真源仍是各 issue 与 #486 评论。  
  **不得**在本文件加状态列、优先级、排期、勾选框。
- **doc-only**：本片不改渲染 / 引擎 / 测试代码。比对中新发现的 P4 漏点只记债、归 #347（或另开 issue），不在本指引里「顺手修」。

## 怎么用

1. 开一局 web 主路径（夜流卷轴召对），可选再对照 CLI。
2. 按下方 **beat 分母** 逐条比：北极星长什么样 ↔ 现游戏长什么样。
3. 不符时先查「已知债」是否已覆盖；未覆盖 → 记真问题（带截图/原文），勿把已知债误诊成新回归。
4. 对照所依北极星：
   - 总览与索引：[`docs/AUDIENCE_NORTH_STAR.md`](AUDIENCE_NORTH_STAR.md)

## 逐 beat 对照

格式固定：**北极星此处长什么样 ↔ 现游戏此处长什么样 ↔ 若不符 = 已知债 | 真问题**。

### opening

| 维 | 内容 |
| --- | --- |
| 北极星 | 开场先立局势与悬念，不剧透结局。越次召对开篇点出「太仓只剩三百二十万两，新君威信未立」；乾清宫一夜开篇点出魏忠贤爪牙仍在、少年天子敢不敢动（`archive/越次召对-杨嗣昌.md` 首段；`乾清宫一夜-…` 首段；北极星 US#11 / ADR 0044）。 |
| 现游戏 | 开夜框架账 → scroll `beat: "opening"`（`audience_night.py` 对 `TAG_OPEN_NIGHT`）；无 generator 时为空 typed 垫位且不投影。opening 成色走既有 LLM materials / scene-registry seam（`attach_chat_turn_to_night` → `generate_open_beat_body`），无确定性 opening fallback。已有显式非空 opening 时仍可叠加尚未迁走 #1571 的 due/urge `scene_text`。有非空正文时卷轴 `role: "scene"` 段落呈现。 |
| 若不符 | **真问题**（开场空/模板腔/剧透结果）→ 记 #478/#503 呈现声音或编排；**已知债**若只是国势数字在旁白里被念成裸分 → 归 #347（见债清单）。 |

### entrance

| 维 | 内容 |
| --- | --- |
| 北极星 | 「宣 X」口令后，应召者入殿有舞台感：叩首、神态、越次惊奋等（杨嗣昌「应召入殿，叩首…」；毕自严「应召入京陛见…眼眶发红」）。口令层与入殿层用词分层（北极星「召对流程·用词」；US#10）。 |
| 现游戏 | 入殿口令/在场 ENTER → `beat: "entrance"`；body 可由 `generate_enter_beat_body` 填充。直播左栏/锚点认 `entrance`（与 `divider`）切换当前奏对者（`chatModal.tsx`）。 |
| 若不符 | 入殿无戏、或变成灰色系统小字 → **真问题**（#478 戏内 scene）。人名错位/不入殿 → **真问题**（#470 在场账）。 |

### dialogue

| 维 | 内容 |
| --- | --- |
| 北极星 | 朕 / 大臣长卷奏对：利害权衡、分策、可数实物（银两/兵/年月）自然入话；大臣气泡可有神态行（action）与承重句（如「太仓与内库俱要见底」）。连场中殿侧老臣可插话，speaker 可辨（乾清宫一夜）。 |
| 现游戏 | 持久对话轮 → `beat: "dialogue"`（user/minister）；高亮清单挂大臣气泡（#544）；organic `**` 剥离；流式时 pending dialogue 可临时插入。 |
| 若不符 | 长奏对扁成公文条、人格无差 → 先排除通道/模型；**不得**再写「0033 改写未落」（见债清单勘误）。高亮缺失且非超时静默 → **真问题**（#544）。人物抽象裸分出戏 → 角色轴归既有 P4/0122；**国势/地区抽象裸分** → #347。 |

### aside

| 维 | 内容 |
| --- | --- |
| 北极星 | 王承恩（近臣）凑近御座低声：把裁判式点评化成在场读心/补刀，与殿上公开分层（越次召对多段「欠身，凑近御座低声」；乾清宫一夜同构；US#8）。 |
| 现游戏 | 两条生产路投影为 `beat: "aside"`：① 对话轮 `list_mindreading_records` 读心旁白（#491 → `ming_sim/mindreading.py` / `audience_pipeline.py`）；② 故事账 `audibility` 私 → attendant/aside。壳：`scrollMessages` 对「御前低语」加 aside 样式与近臣头像。回奏内容通道 #492（`ming_sim/intelligence.py`）已 CLOSED，与读心同属近臣层供给。 |
| 若不符 | **不得**写「aside 待 #491/#492」——两票均已 CLOSED（2026-07-18）。成色/精度/漏触发对照北极星落差 → **真问题**（内容归 #472 族后续；壳/分层归 #478）。旁白念出国势/地区抽象裸分 → #347。 |

### scene

| 维 | 内容 |
| --- | --- |
| 北极星 | 非对话的戏内旁白：局势、退侍殿侧、场面描写等，读起来是戏而不是系统日志（乾清宫一夜场间叙述；US#10）。 |
| 现游戏 | 故事账非命令、且非 private → `beat: "scene"`，`role: "scene"`，正文段落渲染。 |
| 若不符 | 旁白出戏/空/与对话重复（应用对话承载却双渲）→ **真问题**（scroll 投影/账标签）。 |

### exit

| 维 | 内容 |
| --- | --- |
| 北极星 | 告退或退侍殿侧是戏的一部分；连场时前人可留殿侧，不「关掉对话框就蒸发」（乾清宫一夜毕自严等；US#2–3）。 |
| 现游戏 | EXIT 命令账或 `presence_effect` EXIT → `beat: "exit"`。 |
| 若不符 | 退下无文案、或人从舞台上硬切消失且无退侍语义 → **真问题**（#470 在场 / #478 多臣同殿）。 |

### divider

| 维 | 内容 |
| --- | --- |
| 北极星 | 场与场之间软段分幕，带下一位人名钩子，长卷可跳读（US#6；海报分场感）。 |
| 现游戏 | `read_night_scroll` 从交接事实或显式 EXIT 派生 `beat: "divider"`：前臣留殿时为 handoff → divider(B) → entrance(B)，显式退场时为 exit → divider(B) → entrance(B)；交接旁白落定前不提前投影 divider。`speaker` = 下一位 entrance 人名（无则空）；前端 `scene-divider` 横线 + 强名。 |
| 若不符 | 连场无分幕、或幕名错人 → **真问题**（投影推导）。 |

### closing

| 维 | 内容 |
| --- | --- |
| 北极星 | 退朝有收束：气氛即史实，一场有落幕（越次召对尾声史笔；乾清宫一夜收在老臣深夜；US#12）。 |
| 现游戏 | 收夜框架账 `TAG_CLOSE_NIGHT` → `beat: "closing"`；收夜 scene 可经 close beat 编排生成后落账。 |
| 若不符 | 收夜无文/断在半场 → **真问题**（#503 收夜 beat / 夜状态机）。 |

### coda

| 维 | 内容 |
| --- | --- |
| 本轮 | **本轮不比，OOS。** PRD #534：coda 只建空插槽；生成侧归 #466，素材源在关系账等更后序。生产：`read_night_scroll` 末条 `beat: "coda"` 且 `content: ""`（`audience_night.py` 留位，无非测试产出方）。试玩见到空 coda **不算缺陷**。 |

## 已知债清单（试玩者读物）

> 每条：现象 + 归属 + 证据锚。无状态/排期/勾选。  
> 点核日：2026-08-18（本地日期 Asia/Tokyo）。  
> 覆盖面：下列债条对齐 [`347-score-seam-enumeration.md`](347-score-seam-enumeration.md) 入库回流面（含 HUD/地区/效果/CLI/报告变化句/扮演 context）；枚举真源若增面，本清单同步补现象+归属，不另开第二套口径。

### 1. 顶栏国势抽象分仍是裸数字

- **现象**：主界面顶栏「民心」「皇威」直接显示 0–100 整数（扫一眼是现代 HUD 分，不是奏报口吻）。
- **归属**：#347
- **证据**：`web/src/components/gameHud.tsx:139-142`（`state.metrics["民心"]` / `["皇威"]`）；数据缝 `web_app.py` `state_payload` → `"metrics": display_metrics`。

### 2. 地区抽象分在地图/省份抽屉仍是裸数字

- **现象**：点省或开省份抽屉，见「民心 50 / 动乱 20」及同族「士绅阻力 / 边防压力」整数；列表行还有「动乱{n}」meta。
- **归属**：#347
- **证据**：`web/src/components/map.tsx:785`；`web/src/components/drawers.tsx:399`、`:414-416`；payload `ming_sim/db.py` `region_payload`（`public_support`/`unrest`/… 裸 int）。  
  完整面集与插槽形态见 [`docs/347-score-seam-enumeration.md`](347-score-seam-enumeration.md)（本仓该主题唯一枚举真源）。

### 3. 局势/结案/帝国修正效果文案里的国势·地区抽象增量裸号

- **现象**：局势 tip、结案卡、帝国修正条出现「民心+3」「皇威-2」「某省·民心+5%」这类抽象分增量，而非定性措辞。
- **归属**：#347
- **证据**：`web/src/format.ts` `formatEffectSummary` metrics 循环（约 :97-102）、`formatLegacyEffect`（约 :268-271）；消费点 `situation.tsx` / `closedIssues.tsx` / `hud.tsx` `LegacyBar`；服务端 `_humanize_legacy_effect`（`web_app.py` 约 :327-346）同构。

### 4. CLI 回合头国势条仍是 n/100

- **现象**：CLI 打印 `民心:  55/100 █████░░░░░` 形式，抽象分裸露。
- **归属**：#347
- **证据**：`ming_sim/report.py:25-27`（`SCORE_METRICS` 循环 + `metric_bar`）；入口 `ming_sim/cli/terminal.py` `_print_header`。

### 5. CLI/报告/时间线里的国势·地区变化句仍是裸增量

- **现象**：回合变化报告、章节/时间线效果句出现 `民心+N` / `〔省〕民心+N` / `皇威-N` 等抽象分裸增量（非钱粮键未走定性）。
- **归属**：#347
- **证据**：`ming_sim/context.py:181-191` `format_metric_delta`；`ming_sim/report.py:35-48` `format_region_changes`；`ming_sim/memories.py:109-120` `effect_brief`。对应枚举面 #12–#14。

### 6. 扮演路径国势 context 仍裸拼抽象分

- **现象**：大臣/近臣等 agent 输入里的国势摘要把非钱粮 metrics 拼成 `民心55`、`皇威40` 一类裸串；回话可把抽象分原样念回皇帝耳目（角色扮演回流，不只 HUD）。
- **归属**：#347
- **证据**：`ming_sim/context.py:155-162` `state_context`（`f"{key}{value}"` 分支）；消费 `ming_sim/tools.py` 组 context。对应枚举面 #15。
