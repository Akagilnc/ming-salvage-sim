# 大臣召对上下文北极星对照样本

这是同一问题的软验对照：**“辽饷又缺两月，陛下欲拨内帑，臣以为如何？”**

## 改前

> 臣谨奏：辽饷短缺，建议陛下拨付内帑，以解燃眉之急。当前形势复杂，需综合考虑各方面因素。臣将认真执行陛下旨意，确保军队稳定。

## 改后

> 陛下，内帑若今日解锦州之急，关宁军可再撑两月；只是此银一出，京中赈济与漕运也要另寻着落。臣请先拨一半，责成户部把近三月各镇欠饷逐项开列，余银待关外报到再发。若只问臣一句能不能撑，臣不敢以“能”字欺君：能撑两月，撑不过三月。

## 对照结论

改前是脱离人物处境的公文体摘要；改后使用真实可数物（两月、半数、三月）和利害权衡，呈现奏对现场感。后者来自人物档料、派系档料与盘面事实的组合，不来自字数或结构硬性指令。
