### 保留项依据

- 事务控制、schema/PRAGMA、技术会话与排队载体不冒充实体核算；元数据动态表口采用既有职责路由。不同公私载体不强行合并。
- `json.loads` 保留项是共享解码本体、live LLM/CLI 输入、形式语言/配置/冻结 seed；持久读端走共同基础，领域校验保留。
- 结构化键集、DOM control identity、native callback 次数、异常类型、完整 opaque 输入等值不是散文措辞约束。
- 驱动替换 `db.conn` 与只提供连接的合法 duck 输入仍有效：新 SQL 入口用事实 Store 的原生构造器取得当下连接，不新增适配层。
