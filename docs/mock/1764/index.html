已授权目标只到体验层：提交一道旨之后，皇帝能在拟诏台辨明这道旨是否已收下、现在去了哪。 留桌 / 离桌 / 状态字样均为待审方案。本页五画面按票面五个审读问题展开； 状态 chip 为呈现层特征化示意（P7：生产不写死模板句）；不给数值（P4）；不加确认弹窗/新按钮层级（0047）。

数据只读既有接缝：turn_directives（候选）+ decree_dossiers 诏令账（0051 成案后）+ 本地在飞（请求未返回，非持久）。不另立事实源。详见 PROPOSAL.md。

0048 边界（两案共通）

  • 不在成案卡上放准 / 驳 / 改 / 删（改删仅限尚未成案的 draft 候选）。
  • 成案事实来自 decree_dossiers（0051），桌面只投影「已收下 → 待颁/已颁…」，不另立第二账。
  • 案甲：卡留桌但工具区失效/隐藏，chip 说去向；案乙：卡离桌，顶一条只读收据，避免「0 道草案」空桌误读。
  • 待 owner 拍：甲留桌 vs 乙离桌（或甲乙折中：刚成案短暂留桌再收折进收据）。

数据来源

  • 未成案：list_directives → pending/draft 且无 dossier
  • 已成案：既有 get_dossier_for_directive / 诏令账 status（proposed 等）
