## 为什么它是北极星（一场好召对长什么样）
同时满足这五条，才算达到北极星：

1. **actor 博弈，不是资源面板**：杨嗣昌不是一个「+盐课」按钮，是一个有谋略、有立场、会权衡阉党风险的人。皇帝透过奏对读到的是「这个人」。（呼应 P3 品味护栏；actor 博弈优于资源按钮）
2. **人物保真、史实合理尺度**：口吻与术语（窝本/盐引/考成法/诡寄/骨鲠）、政治现实（崔呈秀把关都察院、九千岁未倒、袁可立罢居睢州需起复）都在史实合理范围；性格与其历史轨迹咬合（十余年后「四正六隅、十面张网」督师天下）。
3. **定性叙事、不见裸数值**：财政窘境靠「不出半年，太仓与内库俱要见底」这类话呈现，不是甩「国库 320 万」。（呼应 P4 铁律，见 no-raw-numbers）
4. **近臣递话作为信息层**：王承恩在御座侧低声补白——替皇帝读人、点破杨没敢说尽的话、提示反扑将至。这是「皇帝透过奏对/传闻读人」的载体，UI 上与系统旁白/画外音区分开（虚线气泡 + 头像）。
5. **高压求生里的真破局感**：皇帝在钱荒 + 威信未立下，试图撬动「本朝积年动不得的死结」，且路径真的可行、代价真的存在。（呼应冰汽时代式高压 + 破局可真）

## 携带出来的机制方向：召 = 喊人来（近即时 / 远旅行）
这场召对暴露出一个可统一的原语——**「召见」本质是「派人去喊人来」**，一个动作，延迟随距离走：

- **近的**（已在殿外候着，如本场杨嗣昌）→ 宣入殿，几乎即时，喊完就召对。
- **远的**（罢居在外 / 在边镇 / 需起复：袁可立在睢州、袁崇焕、徐光启）→ 传召 / 起复，人得走一段路才到（「得些时日」），到了才能召对。

本场文本自己就摆了两极：王承恩「倪、黄二位倒是**现成**，一道钦差关防即可」（近/即时）对「袁可立**要起复才动得了**……得些时日」（远/有延迟）。

**方向**：把**召对系统**（ADR 0028）与**起复远人 / 可用人才池**（ADR 0009；CONTEXT「人才池」「起复」）统一成同一个「召」原语，差别只是**到人的旅行时间**——近人零延迟直接召对，远人排队旅行后入场。⚠️ 这是设计**方向**、未拍成决定；真正设计时另立 ADR，勿当既定实现。

## 用词分层（本场确立的惯例）
- **事件 / 标题 / 旁白层**：用「召对 / 召见」——描述这场君臣相见。
- **皇帝口令层**：用「宣 X」（如「宣杨嗣昌」）——宫里的话；「召见」当口令偏叙述口语。
- **大臣应答层**：「应召入殿」承接「宣」，一「宣」一「应召」，首尾咬合。
