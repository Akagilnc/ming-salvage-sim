# 0046: 消息形态契约 = 四类戏内 role + 系统层瘦身

Status: Accepted（2026-07-03 随 PR #554 合入 90c7a70a；决策：2026-07-03 #478 grill Q2 用户拍）

召对消息的形态契约定为**四类戏内 role**：朕 / 大臣 / 递话（可闻性=御前私，两层跟 ADR 0035 不许塌）/ scene（旁白：开场/入殿/退下/分幕/收夜/coda）——视觉样式的权威是北极星实物（archive/ 卡片），样式细节不进本 ADR。现状 role 仅 user/minister，扩展属实现。**「已传X入殿/X已退下」类在场事件从系统提示行升格为 scene 戏内旁白**（内容特征化长出、非模板句——入殿/收夜 beat 在 0035/CONTEXT 已钉为一等流程 beat，正好由 scene 承载；scene 文案与大臣回话同属本轮玩家可见内容，轮内与其他无依赖的 LLM 调用并行，整轮汇合完成后玩家才继续交互）；系统提示行瘦身为只装真系统事务（失败/重试/恢复，循 0036/0041 系统层口径），密令回执维持已定低噪音口径不动。全戏内化（失败也让王承恩戏内说）被否：戏内低语承载不了显眼+可重试的 affordance。
