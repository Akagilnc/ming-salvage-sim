# 0039: 皇帝动词表统一在语义层、机械上三档分层

Status: Proposed（2026-07-02，#471 grill Q1 用户拍）

皇帝动作语法的动词表是一张语义层统一词表，机械身份按档分三层：**口令档**（宣召/收夜类）走引擎常量封闭集、确定性落账（沿 ADR 0035 分线）；**动作档**（准驳/密授/任免类，有机械消费方）进召对动作分类器枚举，走「确定性 > LLM 软判尽力」既有分层（ADR 0028）；**对话档**（追问/压问类话术棋）不设机械表示、只作词表特征化进组装链（ADR 0037「不预建」：无消费方不预付结构）。玩家始终自由文本说话——词表的词是引擎给话语打的标签，不是玩家须念出的咒语；各词条归哪档是词条必填属性，逐词分配归 PRD/子 issue，不在本 ADR。
