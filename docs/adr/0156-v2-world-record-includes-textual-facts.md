# 重构：文字也可以是世界实况的记录形式

Status: proposed（2026-09-09；owner 已拍方向，设计待评审，未实施；本次游戏重构，非独立版本）

世界账本同时容纳需要精确核算的数值记录，以及没有专用字段、但需要后续记住和演绎的文字事实，避免每出现一种伤势或特殊处境就必须先开发一套字段与机制。
文字事实与人物说法、传闻按 [0153](0153-v2-world-record-and-two-way-mediation.md) 区分，其后续变化与剧情影响仍由 LLM 演绎，不由代码从句子推导固定效果。
owner 已认可 [孙传庭伤臂例及账本形态](../design/game-v2-architecture.md#文字事实依据)，本决定不规定存储格式（更新与归属见下段），也不以文字替代银两、欠饷、兵员等所需的精确核算。
更新与归属（2026-09-09，决策票 [#1818](https://github.com/Akagilnc/ming-salvage-sim/issues/1818) owner 拍）：文字事实只追加、不覆盖，每条带发生月份，读时按时间顺序全部提供、由 LLM 自行判断当前，不预建作废或整理机制（同 [0155](0155-v2-single-scene-llm-with-complete-perspectives.md) 不做整理）；文字事实挂在它描述的对象（人物、军队、地区）上，关于事务本身进展的文字挂在事务上、即事务的当前情况，不设挂不到对象的杂项桶。未选：覆盖式单值、追加加显式作废。
