# 0053: 参与人分主办、协办、知情三档，主办可多人，所遣之人办砸全权者背锅

Status: Accepted（2026-07-04 随 PR #573 合入；决策：2026-07-03 #474 设计闸 grill 用户拍，北极星实录校正「主办一定单一吗」）

一件差事的参与人分三档：主办、协办、知情。

- **主办可多人**（北极星实证：倪元璐＋黄道周合力试点清丈畿辅）。
- **协办**含跨衙门接应（杨嗣昌「户部接应钱粮、账目盯着」）与大臣自遣之人。
- **知情**只知道这件事（参与即知，#485/#489），不进追责链。
- **所遣之人办砸，全权者背锅**：大臣自己派出去的人（徐光启「门生听调」所点学生、毕自严遣门生张缙彦持密令押解）办砸了，连坐与责任上溯到派他的人；走样时分得清是主办自砸还是所遣人砸。
- 参与人可追加：皇帝未点名而大臣自行拉人的，也算进来，记明是谁拉的。
- 每人在本案的职分（「监军」「参赞机务」）是给人读的戏文；三档管账，职分管戏。师徒、门生故吏、座主同年这张网属于人物关系，不长在差事上。
