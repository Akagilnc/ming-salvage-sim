# 0122: 大臣侧 P4 定性词带＋扮演 prompt 裸值泄漏收口

Status: Proposed（决策：2026-07-08 #89 大臣系统设计闸 grill 块⑤ 用户拍板；承 0010 决定 2/3 读端双变体、0023 D10、F16、0102 identity、0108 阴谋轴；#89/#555）

本闸的**搭车收口件**：把 [ADR 0010](0010-presentation-adapter-read-contract.md) 决定 2/3 已钉的读端契约（全档两变体——**带数值版**喂机面 `inspect_*`/simulator payload、**定性版**喂扮演 agent，因 agent 回话会到皇帝面前、给裸数值＝它照念）在**大臣六轴**上落地。军队侧已有先例：`_ARMY_QUALITATIVE_WORDS`（`ming_sim/db.py:148`，`Dict[str, Tuple[str,str,str,str,str]]` 五档词带）＋ `_qualitative_army_stat`（`db.py:158`，按 ≥80/60/40/20/else 五档投影）。本 ADR 为大臣**六轴各配同形定性档表**：`loyalty`/`ability`/`integrity`/`courage`（`db.py:543-546` 现成列）＋ `identity`（0102/0011-2 真源，动态承重值）＋ `阴谋`（0108 成色/阴谋轴真源）——每轴一组档位词＋切点，**凡进扮演 agent 上下文、召对回话、邸报、HUD 等玩家输出边界的六轴属性一律喂档位词**（「军事能力优良」不是「92」；范围＝六轴本身——家产大概数放行与机面量例外见后文各自条款，勿把词带过度铺到非六轴字段，CodeRabbit R1 勘正）；机面（`inspect_*` 工具、simulator payload、判官带数值上下文）仍走带数值版，双变体由呈现适配器出、不混。落 prompt 用**正向表述**（P4 铁律：写「以奏疏口吻定性描述人物」，不写「不要显示数值」——负向句会让 LLM 拎出数值/念 meta）。各轴档位切点与词面**首版随 playtest**（0011-4 D4-6 先例；军队侧五档词带即校准起点）、归切片验收。**占位期口径**：identity/阴谋两列落地（#690/#693）前，扮演路径对这两轴输出**占位定性词**（「立场深浅未著」类），**绝不输出 int 或空值**——P4 守门 sentinel 断言对六轴在占位期同步生效，列到位后换真档投影、断言不变。

**现存违规面（本闸须堵）**：`character_context`（`ming_sim/context.py:153`）第 159–160 行把 `忠诚{loyalty}，能力{ability}，清廉{integrity}，胆略{courage}` 四个**裸 int** 直接拼进人物串，经 `character_context_with_db`（`context.py:164`）灌入 `registry.py:512` 的「你当前扮演」大臣 prompt → 回话回流皇帝（F16 触发实例：召对王承恩议任洪承畴，太监回话「民心三十八、动乱七十」式念裸 stat、出戏，playtest-findings.md F16）。**修复方向一句**：扮演路径（`registry.py:512` 走的 `character_context`）改喂六轴定性档投影，机面路径保留带数值版（0010 决定 3 的横切保证）；**实现编码细节归切片验收**。**呈现边界（细化 F16/0023 D10）**：`characters.wealth` 家产**报大概数放行**——判据＝F16「明朝人会不会自然用数字报」（银两/家产＝会，同 0023 D10「财政钱数是真钱、非抽象 stat」），故「国丈家赀约数十万两」式奏报口吻数放行、不出裸数值表；**表报进度**（大臣自陈的差务进展）＝玩家面 diegetic 叙事；**实进度/暴露度/意愿底档带**（#89 双轴机面账）＝机面 only，永不入玩家边界。**毙案**：把六轴裸 int 留在扮演 prompt、靠 prompt 叮嘱「别念数字」压制＝违 P4 正向铁律且实证压不住（F16 即此漏路照念），毙。

**净新契约仅两条**：(a) 大臣六轴定性档表（六轴 × 五档词带＋切点，形状复用 `_ARMY_QUALITATIVE_WORDS`）；(b) 扮演路径读端从裸值改喂定性档投影的一条修复方向。**无新机制、无新数据轴**——六轴列（`db.py:543-546` ＋ 0102 identity ＋ 0108 阴谋轴）全现成，仅补读端定性化与泄漏收口。
