# 0051: 案卷=收夜准旨记录本身——无月末二次切分

Status: Accepted（2026-07-04 随 PR #573 合入；决策：2026-07-03 #474 设计闸 grill Q2 用户拍）

收夜落库的每条准旨记录（政令/任免/交办/拨款/密令等，密令为应允即落地的既有例外）即「**案卷**」——唯一可寻址的 action 一等实体，带状态机（**准旨→已颁→执行中→结案**——「打回」不在主链：它是颁布格值＋批红待抉择的旁路组合态，cmr R8 统一表示法；迁移规则：结案直达仅限**效果落地即终局、无执行判定面**的案卷（如内库直发恩赏）；凡带执行判定面者——**任免（就任/称病/辞不拜）、在途拨款（押解对账，S12）、军令状/护行/工程**——已颁→执行中，执行格填值后结案（任免辞不拜的官位后果=后续 office_changes 记录走推演-extractor 既有链，物化不回滚；各动词类型执行判定面之有无随 S5 对照表逐聚类落定——cmr R11 补任免归类，防「结构化载荷=一次性」误读关死执行格）；案卷记录诞生于**成案点**＝收夜提交**或**结束回合默认同意〔0049 成案路——默认同意者同样建案卷、同批入判，cmr R8 补两路〕，即准旨；「已应允」属 pending_actions 暂存域的前置概念态，**不入案卷枚举**，0038 夜内直写白名单不动，cmr R3 校正死状态；密令案卷应允即落地、始态即已颁）与时间戳（含军令状期限）、**中旨标记字段**（含缘由，append-only 标记/判决流水——schema 归本条，写入归 0055/0056 批红与判官路径，0052 的 STIGMA 存放引用即此，cmr R5 补 ADR 级定义）；**不存在月末第二次切分层**，旨意的粒度=召对内拆分（#519 一句多旨，归 #471）后皇帝逐条应允的粒度。#150 由「新建 decree_text→action[] 转换层」收敛为「给收夜记录补齐案卷字段」的契约（判决两格 0052／参与人 0053／关联与回指 0054）——其 body 前提写于暂存管线（0028/0038/#502）之前，按本条改写。月末推演改吃案卷列表而非合并文本 blob（decree.py 现状），定向改造细节归 PRD（0057）。案卷粒度即撤回成命（0041）、否决网（#473）、到期复核（#476）的作用单位——皇帝指得着「朕收回派李若琏那道旨」。不给对话档发言立案卷（0037 不预建）；案卷不是 delta 之上的平行第二真源——它是 delta 各效果记录的溯源锚（0054 回指）。三条边界条款（cmr R1 补）：①**物化载荷（cmr R3 细化适用面）**——**结构化载荷类**案卷（任免/定额拨帑/授权等 payload 可机械导出**且经外廷受判**者——**密令不在此列**：应允即物化的 0038 白名单例外、豁免判决 gating，案卷仅单向引用其行，cmr R8 除内矛盾）继承暂存候选的机械载荷（0006 暂存表 payload_json 既有形态），判决后（顺颁/批红强颁/留中跨月后强颁）效果自案卷载荷物化、同源可重放，打回零效果不需要任何回填；**叙事性政令**（新政/工程/改革，无结构化 payload）效果经推演-extractor 链涌现，已颁出才进推演正文（顺颁当月、批红强颁次月 T+1——0055 cmr R12）、打回受硬约束零效果（0055 分工线）。载荷是物化**输入**，非 0054 所禁的效果清单副本（那是落库**输出**的复制）。②**留中态**——批红留中=回「准旨（待判）」态、下月重入判决（0055）；**留中保持同一案卷 id（非新建记录），重判即同案再判**；「打回」即批红 DECISION 块期间的持有态，三选是迁出转移而非新增枚举（强颁→已颁、收回→结案、留中→准旨待判——cmr R3 钉同一性与持有态语义）；**DB status 列枚举恰四值｛准旨/已颁/执行中/结案｝**（中文为概念名——实际存储常量命名循仓库既有英文惯例、S1 落定；「（待判）」为准旨态的注解、非枚举后缀，cmr R9）——「打回」不入 status 列，其表达=颁布格值「打回」＋案卷停留在批红待抉择（组合态），迁移测试断言组合态而非裸枚举（cmr R7 钉 schema 表示）；颁布格存最新判决，历次判决进 append-only 判决流水（0057 判官读的强颁标记流水同源）。③**密令双轴划界**——密令案卷以**单向外键**指向 secret_orders 行（案卷.secret_order_id，新指旧、secret_orders 老表零改列；反查由案卷侧查询发起——cmr R3 改判「互指」措辞，遵 0054 引用纪律）：核议生命周期（active→pending_review→done/failed 结案——实码枚举，cmr R2 校准）真源仍在 secret_orders 既有链（0011-5 D5-7 隔离原则），判决格/参与人/关联/月度进展归案卷；结案时执行格与 result 由同一 extractor 步同写（单写入方）；**非月末的异常终态迁移**（承办人死亡/被罢/密令提前取消等致 secret_orders 直接转 done/failed 的入口）经同一结案函数**同步案卷结案＋执行格中断说明**（复用单写入方，防两轴撕裂留幽灵在途案卷——cmr R4）；两轴不重叠、restore 不漂移。
