# 0051: 案卷=收夜准旨记录本身——无月末二次切分

Status: Proposed（决策：2026-07-03 #474 设计闸 grill Q2 用户拍）

收夜落库的每条准旨记录（政令/任免/交办/拨款/密令等，密令为应允即落地的既有例外）即「**案卷**」——唯一可寻址的 action 一等实体，带状态机（已应允→准旨→已颁/打回→执行中→结案）与时间戳（含军令状期限）；**不存在月末第二次切分层**，旨意的粒度=召对内拆分（#519 一句多旨，归 #471）后皇帝逐条应允的粒度。#150 由「新建 decree_text→action[] 转换层」收敛为「给收夜记录补齐案卷字段」的契约（判决两格 0052／参与人 0053／关联与回指 0054）——其 body 前提写于暂存管线（0028/0038/#502）之前，按本条改写。月末推演改吃案卷列表而非合并文本 blob（decree.py 现状），定向改造细节归 PRD（0057）。案卷粒度即撤回成命（0041）、否决网（#473）、到期复核（#476）的作用单位——皇帝指得着「朕收回派李若琏那道旨」。不给对话档发言立案卷（0037 不预建）；案卷不是 delta 之上的平行第二真源——它是 delta 各效果记录的溯源锚（0054 回指）。三条边界条款（cmr R1 补）：①**物化载荷**——案卷继承暂存候选的机械载荷（ADR 0006 暂存表 payload_json 既有形态），判决后（顺颁/批红强颁/留中跨月后强颁）效果一律自案卷载荷物化、同源可重放，打回零效果不需要任何回填；载荷是物化**输入**，非 0054 所禁的效果清单副本（那是落库**输出**的复制）。②**留中态**——批红留中=回「准旨（待判）」态、下月重入判决（0055）；颁布格存最新判决，历次判决进 append-only 判决流水（0057 判官读的强颁标记流水同源）。③**密令双轴划界**——密令案卷与 secret_orders 行一一映射（外键互指）：核议生命周期（active→pending_review→done/failed 结案——实码枚举，cmr R2 校准）真源仍在 secret_orders 既有链（0011-5 D5-7 隔离原则），判决格/参与人/关联/月度进展归案卷；结案时执行格与 result 由同一 extractor 步同写（单写入方），两轴不重叠、restore 不漂移。
