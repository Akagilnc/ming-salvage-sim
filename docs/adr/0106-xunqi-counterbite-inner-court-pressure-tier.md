# 0106: 勋戚外戚收编反咬——抓手京营/内廷、上限内廷施压档

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G6 用户拍；承 #555/#87/#89）

勋戚外戚（勋臣/外戚）被打击时的反制**全走收编、零新层**——不建新派、不建新阶级、不建颁布否决层（守 0065 红线：场外阶层不进颁布关、不为其建任何新数据轴）。打击勋戚**并入 0101 反咬三档评估**（resolve 判打击类动作时同步评估目标反制能力）：抓手 = **京营职位 + 内廷耳目网络**（全 `characters`/`office_type`/`faction` DB 现成，是 0101 宫变档「要害抓手」口径的勋戚版；勋戚 tag 机制已由 0011-4 D4-2〔`office_type==后宫` ∨ 爵位正则派生 → 既得轴 +8 + 代理人保险丝薛国观锚〕钉死，本 ADR 不重建 tag）；个体恨记落 **#479 君臣边**（0081 有向边引擎：勋戚→皇帝的辜负/恨边，与大臣边同构，跨年回声 coda 素材从此长）。

**净新契约只两条**：**①勋戚反咬上限 = 「内廷施压档」、不设 0101 宫变档**（＝0101 目标类别 cap 表第②行、两处同源——勋戚**即使持京营职**也按类别封顶，通用三量评估不得越 cap）——勋戚无造反牙（法统全系皇权、造反自毁根基〔同宗室双命门逻辑〕，史实无勋戚政变），故 0101 宫变档第一连续量「要害抓手」对勋戚够不到「提督东厂/掌批红/净军」那种存亡级、封顶在内廷施压；内廷施压档**走事件涌现**——结构化触发源＝**反咬评估的内廷施压 signal 本身**（ResolveResult 反咬列表当回合落库〔P1〕后作 `auto_trigger_seed_issues` 的候选输入，0037「入账即入机制」：signal 即账；**cmr 勘正：勋戚非 faction〔0011-4 tag 派生〕、0091 的 faction-leverage 门读不到它——原「复用 0091 硬门」不成立、不借道**）＋ simulator 涌现轨自演叙事纹理，不建专机制——灾异归因/宫闱事件/哭穷联动逼退，**代价出皇威/内帑**（既有资源轴、非 game over；李国瑞逼捐忧惧死→退银复爵 = 内帑退银 + 收回成命折皇威，即涌现范例，锚同 0011-4 D4-1）。**②补 1–2 勋戚 seed 人物**（英国公张惟贤、国丈周奎级）进 0011-4 B 部分 seed 名册（characters.json + `seed_guilt`/`identity`）——名册 **74→75/76 扩容**、0011-4 B 已同批回标（罪稀疏统计随数据件重算、「重＋中 9 人全阉党」结构不变），纯数据件、不新增机制。首版触发阈/施压强度/皇威·内帑代价量随 playtest（同 0011-4 D4-6 先例，不发明精确值）。**毙案**：勋戚建独立否决层（`blocked_layer`）＝违 0065 红线，毙；为勋戚建新数据轴＝违 0065「不为场外阶层建任何新数据轴」，毙；给勋戚宫变档 game over＝勋戚无造反牙、史实无勋戚政变，毙（归内廷施压档）。
