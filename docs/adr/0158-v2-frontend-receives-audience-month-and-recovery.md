# 重构：独立前端接住召对、过月与恢复

Status: proposed（2026-09-09；决策票 [#1823](https://github.com/Akagilnc/ming-salvage-sim/issues/1823) owner 逐题拍、mock 三轮拍定；设计待评审，未实施；本次游戏重构，非独立版本）

前端只负责显示与交互；后端提供状态、流、记录、动作四类能力；请求形态归实现。呈现的视觉权威是拍定的 mock（throwaway 分支 `prototype/1823-frontend-mock` 的 `web/prototype/1823-frontend-mock.html`，本地未推；冻结副本在 vault `raw/ming-llm-runner/2026-09-09/1823-frontend-mock.html`），拍定 **召对 A · 核账期 A · 立绘 丁**；样式细节不进本 ADR（同 [0045](0045-highlight-judge-is-sole-source-same-backend-postpass.md)）。

## 决定（owner 原话：八题「可以。没意见」；立绘「丁看起来可以」；两屏「A吧 / A」；「加背景色太丑了。能不能换字体/粗体/字色？」）

1. **一夜一卷轴、一个输入框**：皇帝对殿上说话、不选大臣；宣 X 是话里的口令（名册点选 = 代发「宣 X」，[0047](0047-buttons-are-command-accelerators-composer-contract.md)）；谁答由场景 LLM 演；按大臣看的过滤只当回看用（[0044](0044-audience-stage-is-night-scroll-reading-story-ledger.md) 单大臣回看镜头）。现状按大臣开面板、URL 带大臣名的形态退役。
2. **一轮 = 一块卷（一卷戏文）**：流式中与流完后先以一段中性戏文呈现；转译标记到了，在原位按分段上 [0046](0046-message-contract-four-diegetic-roles-thin-system-layer.md) 四类样式（大臣名标、递话左侧虚线 + 斜体 + 名标、旁白居中），文字不动、顺序不变、块不拆、不重新滚动；重开 / 翻卷轴时标记已在。承重短语高亮（0045）不加底色，字色 + 粗体。未选：等标记到了才显示（挡前台，违 #1821）；永远中性不上样式；转译到了拆成分气泡（块跳）；剧本体说话人栏（离开气泡语言）。
3. **戏文轮上只补挂两样**：转译的分段标记与 0045 高亮，沿现有「按归属轮补挂」路子。引擎的数与拒收不进界面，下一句戏文由 LLM 说（#1821 决定 5）；交办去向沿用拟诏台（#1764 进行态 → 已成案·待盖玺）；当场实况经名册 / 案头读账本；读心轮询与 `mindreading` 事件退役。未选：轮下补挂机械回执（P4 / P7 / 0046）。
4. **左栏大立绘 = 御前主角，转译判**：转译 LLM 每轮顺手声明「本轮御前主角是谁」，代码只读（P6）；皇帝亲口「宣 X」当场先切（引擎入殿账）；其余切换与转译同步、晚一句。其余在场者 = 名册小头像（点即宣）+ 戏文名标 + 递话小头像。未选：跟最近宣入者（代码规则；王承恩独自回奏一轮时脸不对）；跟最后说话人（人走图在、多人轮换脸）；舞台并排半身（大图发挥不出）；大图 + 殿侧小立绘（owner「不用」）。
5. **核账期主面 = 本月推演卷**：已落定的段按序排着、正在写的段在末尾流；段落定即持久化，刷新 / 重开从账本读回接着看；顶栏四键仍是月初快照、王承恩递话条照旧（[0148](0148-settlement-period-shows-month-open-snapshot-not-engine-mid-state.md)）；不流「推敲」（模型推理，常带半程数）、不再有进度条；推进完成后这卷就是本月邸报（#343 第一页），不另呈一遍；请旨批红照旧弹批红文书页（[0048](0048-month-end-rescript-as-real-document-page-no-desk-workbench.md)），批完接着流。未选：右侧邸报房（主面无可看、正文挤窄）；文书页（压住 HUD、与批红页混）；沿用 SettlementLock（只挂会话忙碌、刷新即丢、进度条、整页 reload）。
6. **失败与恢复一种形态**：系统层只剩一种失败 = 某次模型调用重试耗尽；三处同一形态——出事那条记录下方一条系统提示行 + 一个「重试」钮：回话没生成完 → 皇帝最后那句问话下（[0036](0036-audience-night-restore-resume-at-last-entry.md)）；某轮转译耗尽 → 那轮戏文下、不挡下一句（#1821）；过月某段 / 转译耗尽 → 核账期推演卷末（HUD 级同一坑位，#1808）。重试只重跑那一次调用再自动续跑，重跑哪一次由后端按 [0157](0157-v2-month-waits-for-exhausted-model-call-recovery.md) 定（反复失败改丢段重演），皇帝只看见「重试」；不给跳过；重开同位同行。「未落库政务」面板与召对内密令失败行退役——拒收是戏内事实回场（#1820 决定 3），不是系统失败。系统提示行属系统层（0046），不是戏文。未选：两个钮「重试 / 重演此段」（把段摆到皇帝面前）；汇总面板（第二真源）。
7. **重开落点按账本状态直接落**：夜未收 → 直接回到殿上（召对卷开在最后一轮，0036）；核账期（含停住）→ 核账期同态（[0149](0149-enter-settlement-period-on-click-in-flight-continues.md)）；其余 → 本月盘面。未选：一律先落 HUD 由皇帝自己点进去。
8. **交接写到能力层**：前端要接住的 = 状态（在哪一面、停住没、能不能重试、御前主角是谁）、流（戏文 / 推演段的增量）、记录（按归属轮补挂的分段标记与高亮）、动作（说话 / 宣 X / 退朝 / 颁布 / 批红 / 撤回 / 重试）；请求形态（SSE 还是轮询、要不要后台任务端点、完成后 reload 还是局部刷新）归实现（前端规格票 + #1816）。未选：本票定死协议三件。

## 为什么

一个 LLM 演整场（[0155](0155-v2-single-scene-llm-with-complete-perspectives.md)）、一轮戏文可含多人（#1821）——按人分窗装不下插话与低语；转译晚一句——样式只能后补、块不能拆，否则每轮跳一次。0148 月初快照与 0149 重开同态要求推演文持久化、从账本读回，现状只挂会话忙碌的等待面做不到。0036 已定重试是系统层恢复动作，三处统一省去第二真源与第二套按钮。立绘归转译判是 P6（判断权归 LLM）在呈现上的落法：谁站在御前是戏里的事，代码规则（最近宣入 / 最后说话）都有治不了的错脸。

## 未定

转译声明「御前主角」与说话人分段的字段（#1815）；前端能力的请求形态与断线重接（前端规格票）；推演卷段与段之间的分隔、请旨暂停处的呈现细节（试玩调）；核账叙事（王承恩递话）由 LLM 长出（P7；现状为前端固定字串，接入时清理）；#1220「无进度条」口径与现状 SettlementLock 进度条的出入随本决定一并清理。
