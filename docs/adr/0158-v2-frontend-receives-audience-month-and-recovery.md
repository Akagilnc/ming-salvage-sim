# 重构：独立前端接住召对、过月与恢复

Status: proposed（2026-09-09；决策票 [#1823](https://github.com/Akagilnc/ming-salvage-sim/issues/1823) owner 逐题拍、mock 三轮拍定；2026-09-10 owner grill 改决定 5 / 6（[#1812 评论 5612672787](https://github.com/Akagilnc/ming-salvage-sim/issues/1812#issuecomment-5612672787)）；设计待评审，未实施；本次游戏重构，非独立版本）

前端只负责显示与交互；后端提供状态、流、记录、动作四类能力；请求形态归实现。呈现的视觉权威是拍定的 mock：仓内冻结副本 [archive/1823-frontend-mock-召对A-核账期A-立绘丁.html](../../archive/1823-frontend-mock-召对A-核账期A-立绘丁.html)（同北极星卡片先例）；来源为已推送的 throwaway 分支 `prototype/1823-frontend-mock`（`web/prototype/1823-frontend-mock.html`），拍定 **召对 A · 核账期 A · 立绘 丁**；样式细节不进本 ADR（同 [0045](0045-highlight-judge-is-sole-source-same-backend-postpass.md)）。

## 决定（owner 原话：八题「可以。没意见」；立绘「丁看起来可以」；两屏「A吧 / A」；「加背景色太丑了。能不能换字体/粗体/字色？」；给事中 r1 F2「A」）

1. **一夜一卷轴、一个输入框**：皇帝对殿上说话、不选大臣；宣 X 是话里的口令（名册点选 = 代发「宣 X」，「散夜」钮 = 「退朝」口令，「撤回」钮 = 撤回本轮，[0047](0047-buttons-are-command-accelerators-composer-contract.md) 对照）；谁答由场景 LLM 演；按大臣看的过滤只当回看用（[0044](0044-audience-stage-is-night-scroll-reading-story-ledger.md) 单大臣回看镜头）。现状按大臣开面板、URL 带大臣名的形态退役。
2. **一轮 = 一块卷（一卷戏文）**：流式中与流完后先以一段中性戏文呈现；转译标记到了，在原位按分段上 [0046](0046-message-contract-four-diegetic-roles-thin-system-layer.md) 四类样式（大臣名标、递话左侧虚线 + 斜体 + 名标、旁白居中），文字不动、顺序不变、块不拆、不重新滚动；重开 / 翻卷轴时标记已在。承重短语高亮（0045）不加底色，字色 + 粗体。未选：等标记到了才显示（挡前台，违 #1821）；永远中性不上样式；转译到了拆成分气泡（块跳）；剧本体说话人栏（离开气泡语言）。
3. **戏文轮上只补挂两样**：转译的分段标记与 0045 高亮，沿现有「按归属轮补挂」路子。引擎的数与拒收不进界面，下一句戏文由 LLM 说（#1821 决定 5）；交办去向沿用拟诏台（#1764 进行态 → 已成案·待盖玺）——拟诏台按 [#1772](https://github.com/Akagilnc/ming-salvage-sim/issues/1772)（owner 已拍：删御笔自拟入口、旨意只从召对来、御笔归批红「另旨·中旨」）收束后保留草稿 / 已发两区，本决定只用它看去向、不复活手拟，#1772 实施先于或独立于本决定；一句话含拟旨 + 拨帑 + 交办（#1777 类）由转译一次声明为一件事的一份载荷（[0028](0028-audience-secret-order-capture-and-action-classification.md) 后出注记）；当场实况经名册 / 案头读账本；读心轮询与 `mindreading` 事件退役。未选：轮下补挂机械回执（P4 / P7 / 0046）。
4. **左栏大立绘 = 御前主角，转译判**：转译 LLM 每轮顺手声明「本轮御前主角是谁」，代码只读（P6；不从戏文散文解析，[0142](0142-no-semantic-parsing-of-llm-prose.md)）；皇帝亲口「宣 X」当场先切（引擎入殿账）；其余切换与转译同步、晚一句。其余在场者 = 名册小头像（点即宣）+ 戏文名标 + 递话小头像。未选：跟最近宣入者（代码规则；王承恩独自回奏一轮时脸不对）；跟最后说话人（人走图在、多人轮换脸）；舞台并排半身（大图发挥不出）；大图 + 殿侧小立绘（owner「不用」）。
5. **核账期主面 = 等待面 + 邸报落位**（2026-09-10 owner grill 改，前版「本月推演卷」作废）：进核账期只见月初快照与核账叙事（[0148](0148-settlement-period-shows-month-open-snapshot-not-engine-mid-state.md)；顶栏四键、王承恩递话条照旧）；无进度条、不流「推敲」、**不呈现推演过程**——夜里预推文与月末世界段都不给皇帝看（owner「现在是把这个反复过程摆给了用户看。好不好我不确定」→ 不摆）；本月有待拍项时，等待第一段结束弹批红文书页（[0048](0048-month-end-rescript-as-real-document-page-no-desk-workbench.md)：打回三选 + 全部有司请旨），批完接着等（owner「两个1分钟比一个两分钟体验好得多」）；邸报写好在本面流出（能流就流、不能则一次落），写成即自动推进月份（[0149](0149-enter-settlement-period-on-click-in-flight-continues.md) / #1822 决定 4；owner 2026-09-10 答「甲」）；「朕知道了」只关闭阅读态、不控制月份；不另弹全屏窗、不要求重读；推进后邸报入历史（#343 第一页）；刷新 / 重开从账本读回同态。流程顺序归 [0157](0157-v2-month-waits-for-exhausted-model-call-recovery.md)。未选：推演卷（段文流给皇帝看，#1823 前版）；右侧邸报房；文书页压 HUD；沿用 SettlementLock；另弹邸报窗；「朕知道了」当推进闸。
6. **失败与恢复一种形态（两种失败、一种形态）**：系统层的失败有两种——某次模型调用重试耗尽（[0157](0157-v2-month-waits-for-exhausted-model-call-recovery.md) 射程）与代码异常响亮中止（[0008](0008-settlement-applier-contract-and-transaction-boundary.md) 决定 6 / [0005](0005-no-broad-except-swallow-loud-failures.md)；owner 2026-09-09 给事中 r1 F2 拍「A」）——对皇帝只有一种形态：出事那条记录下方一条系统提示行 + 一个「重试」钮（钮前后端已按 [0157](0157-v2-month-waits-for-exhausted-model-call-recovery.md) 的统一策略自动重试，用尽才出行与钮；owner 2026-09-10「肯定要放按钮」）；代码异常时行内带错误包路径与「请把它发给作者」（0008 决定 7 指引），失败在主界面上就看得见（#1808）。模型耗尽的三处：回话没生成完 → 皇帝最后那句问话下（[0036](0036-audience-night-restore-resume-at-last-entry.md)）；某轮转译耗尽 → 那轮戏文下、不挡下一句（#1821）；过月某步（预推补跑 / 世界推演 / 转译 / 邸报）耗尽 → 核账期等待面（HUD 级同一坑位，#1808）。重试做什么由后端定、皇帝不分辨：分段流程统一按 0157 的恢复边界；0008 的 ready 重放只属于 legacy 整段结算；皇帝只看见「重试」；不给跳过；重开同位同行；两种故障仍分别处理，不因界面同形而混同。「未落库政务」面板与召对内密令失败行退役——拒收是戏内事实回场（#1820 决定 3），不是系统失败。系统提示行属系统层（0046），不是戏文。未选：两个钮「重试 / 重演此段」（把段摆到皇帝面前）；汇总面板（第二真源）。
7. **重开落点按账本状态直接落**：夜未收 → 直接回到殿上（召对卷开在最后一轮，0036）；核账期（含停住）→ 核账期同态（[0149](0149-enter-settlement-period-on-click-in-flight-continues.md)）；其余 → 本月盘面。未选：一律先落 HUD 由皇帝自己点进去。
8. **交接写到能力层**：前端要接住的 = 状态（在哪一面、停住没、能不能重试、御前主角是谁）、流（戏文 / 邸报的增量）、记录（按归属轮补挂的分段标记与高亮）、动作（说话 / 宣 X / 退朝 / 暂离（召对退出，不收夜，[0047](0047-buttons-are-command-accelerators-composer-contract.md)）/ 颁布 / 批红 / 撤回 / 重试）；请求形态（SSE 还是轮询、要不要后台任务端点、完成后 reload 还是局部刷新）归实现（前端规格票 + #1816）。未选：本票定死协议三件。

## 为什么

一个 LLM 演整场（[0155](0155-v2-single-scene-llm-with-complete-perspectives.md)）、一轮戏文可含多人（#1821）——按人分窗装不下插话与低语；转译晚一句——样式只能后补、块不能拆，否则每轮跳一次。0148 月初快照与 0149 重开同态要求邸报持久化、从账本读回，现状只挂会话忙碌的等待面做不到。0036 已定重试是系统层恢复动作，三处统一省去第二真源与第二套按钮。立绘归转译判是 P6（判断权归 LLM）在呈现上的落法：谁站在御前是戏里的事，代码规则（最近宣入 / 最后说话）都有治不了的错脸。

## 未定

转译声明「御前主角」与说话人分段的字段（#1815）；前端能力的请求形态与断线重接（前端规格票）；批红页与邸报落位的细部（试玩调）；核账叙事（王承恩递话）由 LLM 长出（P7；现状为前端固定字串，接入时清理）；#1220「无进度条」口径与现状 SettlementLock 进度条的出入随本决定一并清理。
