## 决定（owner 原话：八题「可以。没意见」；立绘「丁看起来可以」；两屏「A吧 / A」；「加背景色太丑了。能不能换字体/粗体/字色？」；给事中 r1 F2「A」）

1. **一夜一卷轴、一个输入框**：皇帝对殿上说话、不选大臣；宣 X 是话里的口令（名册点选 = 代发「宣 X」；#1947 改定：「散夜」钮直接收夜，不经转译，打字说退朝由场景模型调退朝工具，末轮落账后走同一收夜）；谁答由场景 LLM 演；按大臣看的过滤只当回看用（单大臣回看镜头）。现状按大臣开面板、URL 带大臣名的形态退役。
2. **一轮 = 一块卷（一卷戏文）**（#1947 v10）：场景模型在回话里直接写【名】【王承恩·低语】【旨】【旁白】与加粗标记，前端照标记排成说话块、低语块、旨文与旁白，要紧处加粗；无标记段落接上一块。标记随回话到，不等转译、不晚一句；文字不动、顺序不变。版式照北极星 `archive/越次召对-杨嗣昌.png`。
3. **标记在戏文里，不再后补挂**（#1947 v10）：说话人、低语、旨文、旁白与要紧处随原样回话记账、显示。当场实况的引擎核算结果与拒收不进界面，下一句戏文由 LLM 说（#1821 决定 5；旨意的办理后果只在月末可知）；交办去向沿用拟诏台（#1764 进行态 → 已成案·待盖玺）：拟诏台按 [#1772](https://github.com/Akagilnc/ming-salvage-sim/issues/1772)（owner 已拍：删御笔自拟入口、旨意只从召对来、御笔归批红「另旨·中旨」）收束后保留草稿 / 已发两区，本决定只用它看去向、不复活手拟，#1772 实施先于或独立于本决定；一句话里的每道旨意各自一条声明（[#1928](https://github.com/Akagilnc/ming-salvage-sim/issues/1928) 修订旧合挂口径；同一道拨款含拟旨要求仍只成一条，#1777 不复发）；当场实况经名册 / 案头读账本；读心轮询与 `mindreading` 事件退役。未选：轮下补挂机械回执（P4 / P7）。
4. **左栏大立绘 = 当前说话的人**（#1947 v10）：读场景回话里的说话人标记，王承恩永远是小头像。不再有「御前主角」声明，也不由转译判。
5. **核账期主面 = 等待面 + 邸报落位**（2026-09-10 owner grill 改，前版「本月推演卷」作废）：进核账期只见月初快照与核账叙事（顶栏四键、王承恩递话条照旧）；无进度条、不流「推敲」、**不呈现推演过程**：夜里预推文与月末世界段都不给皇帝看（owner「现在是把这个反复过程摆给了用户看。好不好我不确定」→ 不摆）；本月有待拍项时，等待第一段结束弹批红文书页（打回三选 + 全部有司请旨），批完接着等（owner「两个1分钟比一个两分钟体验好得多」）；邸报写好在本面流出（能流就流、不能则一次落），写成即自动推进月份（#1822 决定 4；owner 2026-09-10 答「甲」）；「朕知道了」只关闭阅读态、不控制月份；不另弹全屏窗、不要求重读；推进后邸报入历史（#343 第一页）；刷新 / 重开从账本读回同态。主链顺序由 #1843 承接，批红由 #1847、邸报由 #1862 承接。未选：推演卷（段文流给皇帝看，#1823 前版）；右侧邸报房；文书页压 HUD；沿用 SettlementLock；另弹邸报窗；「朕知道了」当推进闸。
6. **失败与恢复一种形态（两种失败、一种形态）**：系统层的失败有两种：某次模型调用重试耗尽（#1846 失败与恢复射程）与代码异常响亮中止（owner 2026-09-09 给事中 r1 F2 拍「A」）；对皇帝只有一种形态：出事那条记录下方一条系统提示行 + 一个「重试」钮（自动重试用尽才出行与钮；owner 2026-09-10「肯定要放按钮」）；代码异常时行内带错误包路径与「请把它发给作者」，失败在主界面上就看得见（#1808）。提示行的位置：回话没生成完 → 皇帝最后那句问话下；整夜转译的声明重交耗尽 → 该夜记「接不住」，不挡后续夜或过月（#1943 / #1947）；夜里预推失败的处置由 [#1846 现行正文](https://github.com/Akagilnc/ming-salvage-sim/issues/1846) 顶部 2026-10-12 owner 裁定取代（源卷 `~/.claude/projects/-Users-akagilnc-WorkSpace-Ming-LLM/a45c2e6b-8c9a-4f56-85fb-73324ee40299.jsonl`，user uuid `c79b8ef7-731c-4dba-887a-95bebb8b6af3`）；过月某步（预推补跑 / 世界推演 / 转译 / 邸报）耗尽 → #1854 核账期等待面（HUD 级同一坑位，#1808）。皇帝只看见「重试」一个钮，不分辨两种故障；两种故障在后端仍分别处理，不因界面同形而混同。「未落库政务」面板与召对内密令失败行退役：拒收是戏内事实回场（#1820 决定 3），不是系统失败。系统提示行属系统层，不是戏文。未选：两个钮「重试 / 重演此段」（把段摆到皇帝面前）；汇总面板（第二真源）。
7. **重开落点按账本状态直接落**：夜未收 → 直接回到殿上（召对卷开在最后一轮）；核账期（含停住）→ 核账期同态；其余 → 本月盘面。未选：一律先落 HUD 由皇帝自己点进去。
8. **交接写到能力层**：前端要接住的 = 状态（在哪一面、停住没、能不能重试、当前说话人）、流（带标记的戏文 / 邸报增量）、记录（原样戏文）、动作（说话 / 宣 X / 退朝 / 颁布 / 批红 / 重试；召对除退朝外没有别的退出口，#1947 v10）；请求形态（SSE 还是轮询、要不要后台任务端点、完成后 reload 还是局部刷新）归实现（前端规格票 + #1816）。未选：本票定死协议三件。

## 为什么

一个 LLM 演整场、一轮戏文可含多人（#1821）：按人分窗装不下插话与低语。#1947 改为场景模型直接写轻标记，不再等待转译后补样式。月初快照与重开同态要求邸报持久化、从账本读回，现状只挂会话忙碌的等待面做不到。重试是系统层恢复动作，三处统一省去第二真源与第二套按钮。立绘随场景模型写出的说话人标记，王承恩小头像；依据与原话指针见 [0155](0155-v2-single-scene-llm-with-complete-perspectives.md)。
