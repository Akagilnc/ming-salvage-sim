# 0117: 承办人确定性双源路由＋执行层覆盖域（含任免）

Status: Proposed（决策：2026-07-08 #89 大臣系统设计闸 grill Q3＋Q6(3′) 用户拍板；承 #89/#555，接 0057 颁布判官词干表家族、0064 任别轴、0092 执行判官属地轴、0095 人物在途倒数、0013 issue 载体、0101/0106 反咬、0119 家产活账、本批同族「承办四态」）

**承办人不是新字段——＝0053 案卷参与人的机械档「主办」**：本 ADR 交付的是主办档的**确定性填充规则**（0053 主办可多人：点将多人＝多主办、职司路由默认单主办；大臣自遣之人经 0053 委派人链上溯背锅，不另建）。**承办人＝确定性双源路由（判官不指认，防漂移不可测）**：凡颁出后需人承办的旨意，其承办人由引擎**确定性两源**定：①**点将优先**——皇帝旨意里明点某人（下旨/密令的既有动作面）即钉该人；②**职司表兜底**——未点将则按事务类别经**确定性词干表路由**到对口衙门主官，复用 0057 颁布判官已立的 offices.json 词干表家族范式（`db.py:412` `_office_type_from_table` 按 priority 首中词干者胜、无 LLM，本 ADR 只多接「事务→职司→在任主官」一条查表路，不新建表）。**缺位降档链（确定性）**：对口主官出缺则降主官→署理侍郎→……→**无人可承＝怠办起步**（承办四态的意愿轴底档由「无人」直接落到消极端，涌现崇祯「无人可用」，与 0092 用人荒同源）。路由命中后**任别咬合**：署理/兼署承办者其号令带 0064 已钉的**署理号令折扣**（「头衔不实、别衙不买账」），折扣入承办四态成色/带宽判读、不重造轴。**净新契约仅两条**：(a) 承办人确定性双源路由函数（点将优先→职司词干兜底→缺位降档链，签名不接自由文本、判官零指认）；(b) 覆盖域判别把「凡需人承办」的旨意——含任免——统一纳入执行层过四态。承办四态本体、两本账、成色轴一律见本批同族 ADR，不在此重述。

**覆盖域 3′＝凡颁出后需人承办的旨意全过执行层**，三类咬合各有现成落点：①**多月执行类**（清丈/督赈/整饬类）落**差务/issue**（0013 载体＋0092 差务带 owner 绑定与属地 `region_id`），逐月过四态、态落 0058 月度轨；②**打击类差务化**——抄家/缉拿一月出结果，**通风报信的反噬发生在差务落地省**（承办人阳奉阴违/通风走 0101/0106 反咬与 #479 君臣边，发生地即差务属地），**抄没实收接 0119 家产活账**（economy_moves 当回合 P1，实收 clamp 到账面、LLM 零权碰钱数）；③**任免过执行层，执行主体＝被任命者本人**（非吏部、非承办衙门）——0051 本就把任免列入「带执行判定面」类（已颁→执行中→结案），本条与之同轨；打击类原属「效果落地即终局」的结案直达族，本 ADR 将其移入带执行判定面族（差务化即此意）。任免四态映射到**奉诏赴任／拖延观望／称病不视事／辞不拜**（辞不拜＝反噬当回合回退＋结构化事件），**当次结算内判定、当回合全落库（P1：持久化不是瞬时性，restore 只读 DB 无损接续）**；赴任在途沿用 0095 人物确定性倒数、并照罩 F23 已拍的「最多两月、第三月必到」上限兜底；**丁忧/夺情/自请等 reason_code 族与迁移矩阵 override 现成**（`person_archive_contract.py:28` `PERSON_REASON_CODES` 含丁忧/自请，`:57` `PERSON_REASON_TRANSITION_OVERRIDES` 已有 `(offstage,任命,丁忧)→derive:夺情`，本 ADR 直接复用、零新枚举）。**立即 delta 类不过执行层**（赏赐/开仓等无「人承办」语义者按现路即时落库，不入四态）。

**划界（挡回，归属别线）**：**吏部铨选流程不建**——任免的执行主体只有被任命者本人肯不肯赴任视事，不建吏部铨选/廷推为独立执行体（廷推阻力早在 0057 颁布判官侧、属颁布关不属执行关）；**中旨颁布合法性归 resolve 线**（0055/0057 mode=中旨判，执行层只管「颁出之后谁承办、办不办得成」）。**毙案**：以派系级承办为主轴、自废个人承办轴＝毙（承办的肯与不肯、能与不能是个人四态承载，派系级掩盖「能吏×不肯」最危险象限）；判官软判指认承办人＝毙（承办人一变即漂移不可测、restore 无锚，故走确定性双源路由）；任免维持「立即生效」＝毙（立即生效则通风报信无发生地、辞不拜无回退面，任免必须过执行层才长出赴任/称病/力辞的戏）。数值/阈值（降档链档距、折扣量级、四态分档）一律**首版随 playtest（0011-4 D4-6 先例）**，实现编码细节归切片验收。
