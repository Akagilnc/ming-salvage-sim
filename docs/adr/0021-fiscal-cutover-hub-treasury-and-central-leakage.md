# 财政 cutover hub：国库入账口径、京运补/边军军饷源、中央漏损与退役 calc_province_fiscal 的并轨边界

## Context

#261 是 cutover epic（#258）的 keystone（第 4 个也是最后一个 grill 点）——让省级 settle 基座真正驱动国库、退役旧 `calc_province_fiscal`。[ADR 0019](0019-fiscal-cutover-all-province-seed-hub-split.md) 已把「hub 本身的拆法」显式留作独立设计、本 ADR 展开。本 ADR 钉死：退役旧路径后国库的省税收入怎么形成、京运补与边军军饷走哪本账、中央层漏损怎么建、结算相位怎么排、cutover 怎么切。**只定设计决策，确切键名 / schema / 管线落点 / 账户名 / oracle 写法留 `/tdd`。**

> 本 ADR 为 cmr R1（3/3 全 findings：2 P0 / 2 P1 / 4 P2）后的修订版——R1 抓出的「京运补三本账双付」「双轨 isclose 不可能」「hub 事务相位未钉」「outbound 不变式自指」等真洞已在下列决策中收口。

## 决定

1. **cutover 作用范围 = 仅新开存档（前置定调）。** 退役 `calc_province_fiscal`、改用基座驱动国库，**只对新开游戏生效**（同 `content/buildings.json` 金手指先例）；老存档继续旧引擎。故**不存在「换引擎那一月」的口径跳变**——新游戏从首回合即用基座的真实数。「不跳口径」据此**正确理解为「保留收入科目结构」**（田赋 / 盐 / 商 / 起运 不丢类），**不是「数字与旧引擎一致」**（新基座的全部意义就是给出更真实、更低的数；旧公式的量级本就是脱节占位）。

2. **京运补分层。** 京运补（朝廷按史实年例从国库拨给边镇）= **#261 确定性史实年例基线 + #260 玩家拨饷偏移**，与 [ADR 0020](0020-fiscal-levy-effect-channel-event-driven.md) 的「饷率通道基线 + #260 offset」同构。使 #261 在未定型的 #260/#150 缺席下能独立闭环（边镇有史实注入），又给皇帝拨饷干预留叠加口（守「皇帝只经下旨影响世界」铁律）。

3. **边军军饷源 = 按军记欠、由所驻省财政驱动（解 R1 P0-1 三本账双付）。** cutover 后边军军饷**不再走「户部直接扣国库发饷」的全局路径**，改为单链：**国库 → 京运补 → 所驻省（+ 省存留）→ 付该省驻军 → 不足则该军欠饷增**。`armies.arrears` 仍是**按军记欠饷的唯一台账**（玩家感知单位、欠饷哗变按军发生），但其增减**由所驻省财政驱动**——省财政枯竭则驻军拿不到饷、该军欠饷涨（边镇财政塌 → 边军哗变，史实）。**基座不为边军另立省级「军饷欠」账**（消除 `armies.arrears` × 省级军饷欠 × 京运补 三本账双付）。军↔省映射、省级军费能力如何分配到多支驻军，留 `/tdd`。

4. **盐税 / 商税中央旁路（随 cutover=新档化简）。** 退役旧路后，盐 / 商税走独立中央旁路、按**史实定额**入账（seed 校准）。因 cutover 仅新档、无「换引擎那一月」，**不必对齐旧路 `×eff` 的 post-eff 值**，直接用史实定额。**失地省的盐 / 商定额随动态成员谓词从中央聚合中剔除**（失地即不贡献盐商，守地图联动）。盐商随局势波动留后续单独工作项。

5. **国库省税入账口径 + 守恒（纠正 R1 outbound 自指 / inbound 漏盐商）。**
   - 入账口径 = Σ各省起运到京（已扣净省级漏损）+ 盐商旁路 − 太仓亏空。
   - **inbound 不变式**：`Σ各省起运到京 + 盐商解京 == 国库省税入账 + 太仓亏空`（纳入盐商项，消除「盐商 == 0」矛盾）。
   - **outbound 不变式（改名消自指）**：`国库京运补拨出 == Σ各省实收(gross_after_central_transport) + 京运转运损耗`；省内再由 `gross_after_central_transport == 付驻军 + 省级中饱(C_中饱)` 守——转运损耗在「到省前」、中饱在「到省后付军前」，不同段、不双算。
   - 守恒守「**全系统（含 sink）钱不凭空增减**」、非「不漏」；立跨省 hub 守恒断言（独立 oracle 方法学，**仅测试期**；运行期 hub 入账读各省本 tick 已落的起运值，见决定 7）。

6. **中央层漏损：两段、不对称 + 账户表（补 R1 中央账户契约）。** 太仓亏空（inbound，起运入账后）+ 京运转运损耗（outbound，京运补到省前）。各拆「人为（可追赃回收 = 皇帝杠杆、走 #260）+ 自然（不可回收 sink）」共**四个中央 C_ 账户**（如 `C_太仓挪用` / `C_太仓纯亏空` / `C_京运克扣` / `C_京运运损`，确切名留 `/tdd`），与省级 C 表（`C_中饱` 可追 / `C_漂没`·`C_eff损耗` sink）**同构**；hub 除总守恒外**逐账户 per-account oracle 重算**（防可追款与永久损耗揉成黑箱）；可回收段**持久化**（供后续 #260 追赃读取）。率基用中央级 corruption 参数（seed、史实校准），**暂不挂未定型的大臣系统 #89**。

6b. **漏损可压低、手段开放（贯通四段、合 ADR 0007 上行软判）。** 每段漏损「人为分量」率**可被开放手段压低**——#261 只把率建成可调（留 hook、保证「可压低」），**绝不规定手段**（派锦衣卫护送 / 清丈 / 追赃 / 换官 / 监军… = #260 + LLM 软判 + 玩家自寻）；「自然分量」（漂没 / 运损 / eff 损耗）为**结构地板、不可清零**（survival 压力存活）。四段链：省在途漂没 → 中央太仓亏空 → 中央京运转运损耗 → 省到军前中饱。

7. **结算相位：全在一个 pre_settle atomic、ready=1 只重放 phase2（钉死 R1 P1-3 / P1-4）。**
   - 京运补注入各省 + 全省 `settle_province_tick` + hub Σ起运入国库 + 中央漏损落账 + 京运补付驻军 **必须在同一个 `pre_settle` atomic 内完成**，且在写 `turn_phase=settling` 前全部完成；`ready=1` 崩溃续跑**只重放后半段（phase2）、绝不重做前半段 / hub**（守 [ADR 0008](../SETTLEMENT_FLOW.md) 的「不重跑贵两步」）。运行期 hub 入账**读各省本 tick 已落的起运到京值（不重算）**；独立 oracle 重算**仅用于测试期**验证（消除「独立 oracle 重算 vs 不重跑」冲突）。
   - **京运补前置复用 ADR 0020 §6 机制**：只前移京运补特化注入、**不整体前移** `apply_event_terminal_states`，后置通用步显式排除防重复副作用。**京运补当月分配的资金源 = 上月末国库结转余额**（打破「京运补分配 ↔ 国库 ↔ hub 入账 ↔ 省 settle」相位环：本月 hub 入账只影响下月可分配额）。

8. **国库不足 → 按比例缩拨（k 系数）。** cutover 后国库赤字、京运补拨不全时，算中央拨饷系数 `k = min(1, 国库可用 / Σ应拨京运补)`，各镇按 k 缩拨，省库实收与国库实扣对齐（守恒不破）；发不出全饷 → 驻军欠饷累积（史实压力）。**不允许国库负余额、不碰现有非负 clamp**；k 在京运补前置注入时算定。

9. **cutover 失败分层。** 省「失地 / 非 ming 控」按 ADR 0019 动态成员谓词**静默出列**（剧情正常态、不算失败）；省 settle「守恒破 / 坏态」→ **月级 `SettlementAbort` 响亮错误包**（守 ADR 0008「shape 垃圾响亮中止、绝不让坏账静默漏进国库」）。

10. **双轨对账 = 测试期 sanity check，非生产硬闸（纠正 R1 P0-2）。** 新基座的数本就与旧引擎不同（更真实），生产环境**不做新旧 `isclose` 断言**（规模差数倍、必 FAIL）。双轨对账降级为**测试期**：新引擎在代表性 seed 上跑，断**守恒 + 末态硬期望 + 国库轨迹合理**（基座 G1–G22 oracle 风格），旧引擎仅作粗参照、**不做相等断言**。旧 `calc_province_fiscal` 在新档路径退役后**另起 commit 删**（守「评审轮 = 独立 commit」过程史）。ADR 0019 已排除逐省渐进 cutover。

## Consequences / 落位边界

- **单一预算源**：国库收入走「唯一预算源」契约，内部税源换为「Σ起运 + 盐商旁路 − 中央漏损」；落账 / UI 预算表 / 存档摘要三处同源、不各自重算；P4：收入明细以定性叙事呈现、不暴露裸数值。**月中预算表基于上月静态投影**（当月决策的预算影响下月可见；不做月中 dry-run，避免月中跑全省 settle 的相位复杂度）。
- **#265 转 native `blocked_by` + 须一并 seed 收复边镇的京运补史实年例基线**（同 ADR 0020 收复省须重建正赋起运基线，否则收复省京运补注入撞空）；#265 具体修法留其实现期。
- **实现留 `/tdd`**：确切键名 / schema / 管线落步 / 中央 C_ 账户名 / k 计算落点 / oracle 写法本 ADR 不展开。
