# 0087: 流民＝第八阶级，人口守恒转移账

Status: Proposed（2026-07-07 #477 设计闸 grill Q3 用户拍选项 1）

「流民」建为 classes 框架的**第八个阶级省级切片**（与农民/士绅/官僚/军户/商人/匠户/宗藩并列），不另起孤立流民表。加派/摊派（0089 双渠合流）、灾害、兵灾→农民→流民，军户逃亡→流民，一律走**确定性人口守恒转移**（applier 机械转移、两边同减同增、打 origin 标——0011「账本管累积量」分界）；流民→流寇兵源＝LLM 软判**吃池子当硬天花板**（不得凭空造兵源；判战本身照旧软判、代码只 clamp，P2 不破）；出口＝赈济/招抚屯田→流民回流农民（确定性减池、代价照付——环可管理、破局可真，「任何选择都有代价」不是死亡螺旋）。贼侧 `powers.military_strength` 保持 0-100 抽象强度不动，池子 cap 其增速的口径归实现契约。明末四籍管制已实质瓦解（一条鞭折银/匠班银/黄册失真）——**不做户籍管制机制**，现有七类＝阶层盘（正确史实读法），只加流民。旧档不迁移（新档生效，substrate cutover 先例）。#469 的跨圣旨累积因果环由本 ADR＋0089 承载，#477 own；M12 #87 硬化时对接（0057 interim 分层成例）。
