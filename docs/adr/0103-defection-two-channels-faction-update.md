# 0103: 叛变双通道＋faction-UPDATE 写路径

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G3 用户拍板；承 #555/#87/#89）

叛变落为**两条通道共用一条 faction-UPDATE 写路径**，均在 **7 派封闭集内移动**（0011-4 line186：高起潜 faction 阉党→中立即此先例——封闭集是 0011-3 矩阵 42 格地基，**凭空新建 faction 值会缺格，毙**；去向默认**中立、不自动入皇党**）。**通道①树倒猢狲散（自发·确定性）**：派系魁首被**依律清算**、或本派 leverage（factions.lev，0091 门读同源）崩至阈下 → 该派 identity 低于阈值的成员**自动脱党改投中立**，applier 机械落库＋邸报叙事——状态转移由引擎确定性判、LLM 零算账，范式承 0025 哗变状态机（确定性 latch＋applier 机械落库、软判只叙事）。此门与 G2（0102）identity 漂移「同党被依律坐实清算→余党切割自保降认同」同源，本条是其降到阈下的脱党尾。**通道②皇帝策反（主动）**：召对/密令招揽走既有动作闸 → **确定性判定**（目标 identity 低〔dig-6：0-40 可反正、高认同核心不可叛〕＋本派处境＋许诺分量）→ **成功**＝改 faction＋**其把柄边转证词挂进查案差务**（反正者能咬的＝他的 #479 把柄边清单〔0081 有向边引擎/0086 seed 网〕，挂 G1a 查案差务〔复用 0092 差务带宽＋0058 月度进展轨〕当进度加成，同 G1b 涌现苦主接同一差务轨的口径）；**失败**＝**告密回本派**＝惊蛇（目标及派系 wariness↑，0011-2 防备棘轮）＋提前毁证风险（G1c：察觉后坐实上限降档）。

净新契约仅三条：**(a) faction-UPDATE 写路径**——补 dig-6 已标的实现端缺口（db.py 现只在 INSERT 时写 faction、无 `UPDATE characters SET faction`），随建 `defected_from` 列，两通道共用、applier 机械独占写、不入 extractor 别名表；**(b) 自动脱党硬门**（魁首依律清算∨leverage 崩阈下 → identity<阈成员改中立）；**(c) 策反确定性判定＋成/败双分支**（成→改 faction＋把柄边转证词挂差务；败→告密回派＝惊蛇＋毁证）。identity 阈值、leverage 崩阈、策反判定各因子权重与成功概率一律**首版随 playtest**（同 0011-4 D4-6 先例）。**只做单通道（仅树倒或仅策反）＝半张网、毙**：自发脱党给「过去布局决定余地」、主动策反给皇帝局内动作，二者互补缺一不成破局回路。
