# 0103: 叛变双通道＋faction-UPDATE 写路径

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G3 用户拍板；承 #555/#87/#89）

叛变落为**两条通道共用一条 faction-UPDATE 写路径**，均在 **7 派封闭集内移动**（0011-4 line186：高起潜 faction 阉党→中立即此先例——封闭集是 0011-3 矩阵 42 格地基，**凭空新建 faction 值会缺格，毙**；去向默认**中立、不自动入皇党**）。**通道①树倒猢狲散（自发·确定性）**：派系魁首被**依律清算**、或本派 leverage 崩至阈下（`factions.leverage`——0091「lev」为缩写非列名；**本臂只辖 `_LEVERAGE_FACTIONS` 六朝堂派**——宗室无 leverage 真源、属 0065 场外，其树倒仅由「魁首依律清算」臂触发；faction-UPDATE 封闭集仍七派不变） → 该派 identity 低于阈值的成员**自动脱党改投中立**，applier 机械落库＋邸报叙事——状态转移由引擎确定性判、LLM 零算账，范式承 0025 哗变状态机（确定性 latch＋applier 机械落库、软判只叙事）。此门与 G2（0102）identity 漂移「同党被依律坐实清算→余党切割自保降认同」同源，本条是其降到阈下的脱党尾。**收敛口径（快照批处理——leverage 确为成员派生，cmr 勘正）**：现行引擎 leverage＝clamp(0,100, offset＋在朝成员官职权重和)（db.py `recompute_faction_leverage`、0065 同源）——脱党**会**反哺 leverage，故不援引「触发独立」，改钉**快照批处理语义**：每次结算对进入结算时的 leverage/identity **快照**单遍评估脱党门（魁首依律清算当回合即触发通道①、对快照 identity 评估）→ 批量落库 → 结算末重算一次 leverage、**本回合不再二次评估**（回合内有界终止）；跨月自然级联（本月脱党压低 leverage → 下月更多人过阈）＝设计允许的 **organic 崩解弧**（树倒在数月内展开、可观察可干预、对齐倒魏时间尺度），非无界雪崩——每月至多一遍、派系成员有限单调流出，全局必收敛。**中立 sink 口径**：脱党者入中立后 identity 置低档新来者值、与原派的 kinship 联动即止，中立无魁首不树倒、无同仇结构（矩阵行为按中立行准）——容量无上限、不畸变。**通道②皇帝策反（主动）**：召对/密令招揽走既有动作闸 → **确定性判定**（目标 identity 低〔dig-6：0-40 可反正、高认同核心不可叛〕＋本派处境＋许诺分量；概率抽签遵 0098 轨级确定性伪随机口径、重放/restore 可复现）→ **成功**＝改 faction＋**证词落点契约（cmr 勘正，对齐 0098 fact-lane/0099 开案口径）**：反正者把柄先产**结构化证词边入 0098 live 真相底**（fact_key＝边事件 id；他能咬的＝其 #479 把柄边清单〔0081/0086〕）——同 target 已有 open 查案差务则绑定对应 lane 当进度加成，**无 open 案则证词留存真相底、待「密查/命查实之」开案后并入**（不自行开案，同 0099 苦主口径）；**失败**＝**告密回本派**＝惊蛇（目标及派系 wariness↑，0011-2 防备棘轮、入参侦测语义同 0100）＋提前毁证风险**绑定本次招揽所指 fact_key**（指向不明则只惊蛇不毁证——fail-closed 宁轻不歪）。**策反成本轴（堵零成本掏派）**：招揽动作**计入母 ADR 决定5 密令透支账**（同期/累计密令数→朝野警觉→暴露 roll 单调变差——招揽即密令类动作、现账直接吃）；**策反成功同样对目标派落一笔小额 wariness**（派系察觉成员流失、棘轮）——掏派速率被「透支账＋警觉棘轮＋每案惊蛇风险」三重约束，「一两回合刷空一派」结构性不可行（时间尺度对齐倒魏弧标尺；量级首版随 playtest）。

净新契约仅三条：**(a) faction-UPDATE 写路径**——补 dig-6 已标的实现端缺口（db.py 现只在 INSERT 时写 faction、无 `UPDATE characters SET faction`），随建 `defected_from` 列，两通道共用、applier 机械独占写、不入 extractor 别名表；**(b) 自动脱党硬门**（魁首依律清算∨leverage 崩阈下 → identity<阈成员改中立）；**(c) 策反确定性判定＋成/败双分支**（成→改 faction＋把柄边转证词挂差务；败→告密回派＝惊蛇＋毁证）。identity 阈值、leverage 崩阈、策反判定各因子权重与成功概率一律**首版随 playtest**（同 0011-4 D4-6 先例）。**只做单通道（仅树倒或仅策反）＝半张网、毙**：自发脱党给「过去布局决定余地」、主动策反给皇帝局内动作，二者互补缺一不成破局回路。
