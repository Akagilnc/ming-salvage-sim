# 0049: 收夜提交即准旨——月末无颁诏复审步

夜内对话应允的主动旨意，**收夜批量提交即为准旨**——月末不设、不保留任何颁诏复审/准驳步；「圣旨收下拟旨候选、现阶段后续仍走既有颁旨准/驳界面」的过渡口径（#497/确认闸门词条所记）就此退役。这是对原收夜提交语义的显式扩展，链条变为：应允前=对话里润色/不准；应允后收夜前=夜域「已应允」态；**收夜提交后=准旨**，反悔走撤回成命。未表态暂存的「不回→默认同意」语义不变，其成案点随「结束回合」触发（细节归 #476 回合闭环）；收夜封窗不变**且对未表态项同样生效**——收夜后未表态暂存不再接受对话干预、只等结束回合默认同意（已提交准旨的反悔则仅走撤回成命）；原「颁诏成案点」的封窗语义由「结束回合」承接。月末仅剩批红（有 DECISION 时）与「结束回合」触发。转 Accepted 时补〔0049 后出为准〕回注，靶点全清单：#497「颁诏月度成案点与既有颁旨界面不动」句、#513「拟旨类照旧候选转档、颁诏物化」句、#502 body 旧口径句与「颁诏时照常提交」验收（#502 已先行落划界评论防实现期误读）；CONTEXT 确认闸门/颁诏两词条已当场修订。
