# 0049: 收夜提交即准旨——月末无颁诏复审步

Status: Proposed（决策：2026-07-03 #478 to-prd 追拍用户拍）

夜内对话应允的主动旨意，**收夜批量提交即为准旨**——月末不设、不保留任何颁诏复审/准驳步；「圣旨收下拟旨候选、现阶段后续仍走既有颁旨准/驳界面」的过渡口径（0038/#497/确认闸门词条所记）就此退役。这是对 0038 提交语义的显式扩展，链条变为：应允前=对话里润色/不准；应允后收夜前=夜域「已应允」态、撤回本轮可逆转；**收夜提交后=准旨**，反悔走撤回成命（0041，有代价的新命令，非 undo）。未表态暂存的「不回→默认同意」语义不变，其成案点随「结束回合」触发（细节归 #476 回合闭环）；收夜封窗不变（0038），原「颁诏成案点」的封窗语义由「结束回合」承接。月末仅剩批红（有 DECISION 时，0043/0048）与「结束回合」触发。转 Accepted 时给 0038、#497 相应句补〔0049 后出为准〕回注（CONTEXT 确认闸门词条已当场修订）。
