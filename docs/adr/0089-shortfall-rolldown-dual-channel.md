# 0089: 财政缺口下滚双通道——明渠加派、暗渠摊派

Status: Accepted（PR #663 merged 2026-07-07；决策：2026-07-07 #477 设计闸 grill Q2 用户拍选项 1）

## #1895 后出合同协调（待票庭重审）

暗渠摊派的官僚是否转嫁、转嫁给谁及自选量属于人物选择，不因财政缺口悬置或皇帝不作为就由代码自动决定。明渠仍由皇帝主动下旨；双渠、已发生摊派与加派的省域累积账、财政缺口、人口迁移及其世界后果保留。没有真实转嫁或加派行动时缺口仍记账，不凭空消失，也不凭缺口伪造一项人物行动。

## 历史决定（默认转嫁及不作为必走暗渠由上述修订取代）

「向有否决权者收钱失败→钱仍从小农出」的下滚做成**双通道**：**明渠＝正式加派杆**——皇帝主动下旨加派（三饷底座现成），公开选择公开代价，逐省加派量入累积账喂流民转移；**暗渠＝隐性摊派**——圣旨被否决/军费缺口悬置时官僚默认转嫁，**零新造机制，即执行变形的财政特例**：奏报口径「已筹措」、实况账「摊到某省小农」（两本账），暴露走 #476 三通道，暴露后处置＝管理（禁摊派→缺口顶回皇帝案头／默许→积流民／查办→得罪经手人），不可根治只可管理。两渠合流同一本累积账，环后半段只认账不认来源——**明选有明账，不选走暗账**：不作为也是有代价的选择。本 ADR 新拍的契约仅一条：**财政缺口悬置→摊派变形的触发与落账**（触发因子并入执行变形判官口径）。
