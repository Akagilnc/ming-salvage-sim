# 0089: 财政缺口下滚双通道——明渠加派、暗渠摊派

Status: Accepted（PR #663 merged 2026-07-07；决策：2026-07-07 #477 设计闸 grill Q2 用户拍选项 1）

## #1895 后出合同协调（待票庭重审）

法源见 [0011 后出修订](0011-edict-resistance-and-centrifuge-ledger.md)。暗渠摊派的官僚是否转嫁、转嫁给谁及自选量属于人物选择，不因财政缺口悬置或皇帝不作为就由代码自动决定。该选择及声明／实况落账接缝唯一引用 [#1895](https://github.com/Akagilnc/ming-salvage-sim/issues/1895)，不另定 run 或恢复协议。明渠仍由皇帝主动下旨；双渠、已发生摊派与加派的省域累积账、财政缺口、人口迁移及其世界后果保留。没有真实转嫁或加派行动时缺口仍记账，不凭空消失，也不凭缺口伪造一项人物行动。原财政线相抵的自动转嫁合同已按 #1895 改约并交票庭重审；本 ADR 不交付其它票的运行时。

## 历史决定（默认转嫁及不作为必走暗渠由上述修订取代）

「向有否决权者收钱失败→钱仍从小农出」的下滚做成**双通道**：**明渠＝正式加派杆**——皇帝主动下旨加派（三饷底座现成），公开选择公开代价，逐省加派量入累积账喂流民转移（0087）；**暗渠＝隐性摊派**——圣旨被否决/军费缺口悬置时官僚默认转嫁，**零新造机制，即 0072 执行变形的财政特例**：奏报口径「已筹措」、实况账「摊到某省小农」（0073 两本账），暴露走 #476 三通道，暴露后处置＝管理（禁摊派→缺口顶回皇帝案头／默许→积流民／查办→得罪经手人），不可根治只可管理。两渠合流同一本累积账，环后半段（0087）只认账不认来源——**明选有明账，不选走暗账**：不作为也是有代价的选择。本 ADR 新拍的契约仅一条：**财政缺口悬置→摊派变形的触发与落账**（触发因子并入 0072 判官口径）。
