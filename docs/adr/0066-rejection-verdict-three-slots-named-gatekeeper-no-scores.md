# 0066: 打回判决三格结构化——卡点关口/主否决方可具名到把关人/缘由句，不落数值

Status: Accepted（2026-07-06 随 PR #616 合入；决策：2026-07-06 #473 设计闸 grill Q4+Q4b 用户拍选项 1＋补六科；「派系非铁板」补丁随 1566 严嵩案讨论拍）

打回判决（0052 颁布格）落三格结构化：①**卡点关口** enum｛票拟/批红/封驳｝（对齐 0011-5 阶段一 blocked_layer 三层与 0052 颁布格既有口径；部院属阶段二执行层、其受阻显形在执行格 exec_fidelity——0011-5 P1-6 范畴分离不破，grill Q4 原案「四层」按 Accepted canon 校正为三值；M12 接管填值、格子不改）；②**主否决方**＝派系 key 清单（0056 反应方 typed 清单的 kind/key 骨架同形但 **kind 收窄为 faction**、且主否决方**不**承载 reaction 档——场外阶层不产打回（0065），反应方清单可含阶级、主否决方不可），**可具名到把关人**（人物 id，如「许誉卿封还」——许誉卿为六科切片待 seed 的示例，非现成在册）；③**缘由句**（面向批红页的戏内一句）。判决条目并携**判据快照**（判官当时读到的皇威档位／涉事任别／在持授权 id／背书条目 id——引用或值）供审计与读心追溯；快照＝审计记录、非第二真源，不回写不重算。不落阻力数值——interim 软判数值是假精度，M12 算法不同、历史数值即脏数据。**派系非铁板**（1566 严嵩案：首领担名但控不住/不知情）：判官按**把关位上的具体人**判（courage/integrity/faction 字段现成），不按首领意志判——安抚了魏忠贤不等于言官闭嘴。canon 句：**否决网的形状＝官员名单的函数**——换掉把关人（调走崔呈秀）是真实破局路径，而该任免本身再过否决网（人事即攻防，递归成局）。消费口：#472 读心结构化数据源（dry_run 口径≡实际口径，0011-5 D5-3）、批红页定性呈现（P4 不露枚举原值）。数据面唯一无人关＝六科：本闸带薄数据切片——「六科」官署类别＋史实给事中 NPC 2~3 名＋leverage 权重表一行；该 seed 切片须排在「具名把关人」消费口之前（to-issues blocked-by 布线）。转 Accepted 时回注：0052「颁布格」词条括注（主否决方可具名到把关人，指本 ADR）。
