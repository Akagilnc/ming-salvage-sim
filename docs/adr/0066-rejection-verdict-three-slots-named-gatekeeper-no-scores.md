# 0066: 打回判决三格结构化——卡点关口/主否决方可具名到把关人/缘由句，不落数值

Status: Proposed（决策：2026-07-06 #473 设计闸 grill Q4+Q4b 用户拍选项 1＋补六科；「派系非铁板」补丁随 1566 严嵩案讨论拍）

打回判决（0052 颁布格）落三格结构化：①**卡点关口** enum｛票拟/批红/封驳/部院｝（对齐 0011-5 四层，M12 接管填值、格子不改）；②**主否决方**＝派系 key 清单（0056 受损方 typed 清单同款形状），**可具名到把关人**（人物 id，如「许誉卿封还」）；③**缘由句**（面向批红页的戏内一句）。不落阻力数值——interim 软判数值是假精度，M12 算法不同、历史数值即脏数据。**派系非铁板**（1566 严嵩案：首领担名但控不住/不知情）：判官按**把关位上的具体人**判（courage/integrity/faction 字段现成），不按首领意志判——安抚了魏忠贤不等于言官闭嘴。canon 句：**否决网的形状＝官员名单的函数**——换掉把关人（调走崔呈秀）是真实破局路径，而该任免本身再过否决网（人事即攻防，递归成局）。消费口：#472 读心结构化数据源（dry_run 口径≡实际口径，0011-5 D5-3）、批红页定性呈现（P4 不露枚举原值）。数据面唯一无人关＝六科：本闸带薄数据切片——「六科」官署类别＋史实给事中 NPC 2~3 名＋leverage 权重表一行。转 Accepted 时回注：0052「颁布格」词条「卡在哪关」括注指本 ADR 枚举。
