# 0118: 欺瞒类执行双本账＋果因分离对账＋揭破通道族

Status: Accepted（PR #728 merged eb282e5a；决策：2026-07-08 #89 大臣线设计闸 grill Q5 用户拍板；承 0073 双口径两本账轨、0076 到期复核、0058 奏报进展轨、0054 实况效果轨、0098 查案差务轨、0091 弹劾硬门、0115 事件绑定、0108 阴谋轴、0111 藩府梗阻、0079 信用事件、#461 稽核带宽；#555/#87/#89）

凡颁出后需人承办的执行类旨意（Q6′ 覆盖域）落**两本账**——不新建第三载体，直接消费 0073 已钉的双口径轨：**表报进度**＝奏报口径（0058 月度进展轨），是**玩家面唯一读源**（邸报待办条〔F21 清单节 page2，docs/playtest-findings.md:292〕／召对复命／进度条全读它）；**实进度**＝实况口径（0054 效果轨＋执行格判决），机面真相，**仅实况入 apply**（0073 硬护栏：假进度永不改世界状态，同金手指审计教训）。两列**双列持久化 P1**——restore 只读 DB 即无损接续「报到哪、真到哪」，挂叙事＝漏。**果因分离铁轴**：约期满触发**确定性对账**，**只翻「果」**——表报承诺 vs 实进度的**交付缺口**是可数实物（清丈亩数／缉获人犯／补发饷银两），到期确定性可算、必见；**永不翻「因」**——归因不自动生成，承办人**带陈词复命**（「河南藩府梗阻税解」「岁歉民逃」——0111 真梗阻／灾情本身即他现成的**归因掩护**，真摩擦与推诿在陈词里不可机械分辨）。到期缺口成分＝真没办＋被吞，二者在对账侧同记为「缺口」、此处不归因。

**到期复命＝0076 到期复核的场面输出，不另立触发**（0076：到期复核＝执行格判官的正式触发形态，输入含 0073 两轨分叉／0078 催办史／0077 监督史，产执行格判决（格结构＝0052、判官评估＝0057 执行格判官——本批 0116 硬化其输入下界，两者勿混）＋顶出场面＋0079 信用事件，场面顶到**次回合召对面**、结算内不加串行 LLM 步——P5；裁判权归 #476 家族、落点执行格不迁，0052 cmr R10 原句照守）。本 ADR 钉的是其**玩家面**：判决真值入机面执行格（0072 真相层永不撒谎），玩家只得**缺口＋陈词**，走 0115 绑定御前裁**展限**或**问罪**（HITL）：**展限＝骗局续命**（再给一期、缺口滚存）；**反复展限累缺**→喂 0091 弹劾硬门（灾难账触发家族）＋厂卫探报概率上浮，骗局不能无限续。**揭破通道族**（皆吃代价，破局可真）＝0073 已钉三通道（玩家稽核 #461/0058、政敌检举 0077、民变自长 0014）＋本 ADR 补两条：①到期复核**兜底**（0076）——缺口是可数实物，装不装忠终局差额都藏不住；②**厂卫探报**——涌现侧概率揭破（接「探子回报」钩子）；其中玩家稽核的主动形态钉为**按问＝开一条 0098 查案差务**、占稽核带宽（#461），成功率吃目标**阴谋轴**（0108，善藏者难查）。揭破后落 0079 信用事件、治罪走现成打击语法，**处置三难复用 0091 原语法**（顺水办人可能错杀能吏＝寒心入 #479／压下弹劾耗皇威＋发难派怨气／查实再办占带宽稳而慢）。**欺瞒收益模型**：承办人赌的是「买时间拖死旨意＋以真摩擦作归因掩护＋你查有代价＋你可能乱杀寒心自证」——玩家对治＝依律坐实 vs 非法码破局，与 #87 宗藩同一套语法。**与 F21 正交**：邸报 page2 仍是 DB **实账**呈现——欺瞒 issue 的表报进度列本身就是「报到御前的账」，系统对玩家诚实（读的是真存的表报列）与戏内承办人对皇帝欺骗（表报≠实进度）是**两层**、不打架。**净新契约仅三条**：①执行 issue 绑双列（表报＝玩家唯一读源、实进度机面，双列 P1，复用 0073 轨不建第三载体，实现编码归切片验收）；②**果因分离对账算子**（到期只算交付缺口这个实物、归因永不自动、承办人带陈词复命，归切片验收）；③到期复命 HITL（缺口＋陈词→展限／问罪走 0115）＋反复展限反哺 0091／探报。对账阈／展限次数上限／稽核成功率因子／探报概率一律**首版随 playtest**（0011-4 D4-6 先例）。**毙案**：单账叙事粉饰（只邸报讲「已办」、无实况轨）＝纸老虎、restore 丢真相、违 P1，毙；两本账但无结构化揭破＝零 agency、骗局永续、玩家永看不穿，毙；到期 100% 翻「因」（对账自动判定「真没办 vs 藏／吞」）＝欺骗沦为蠢策略、稽核投资多余，且归因本无确定性真源、只能落回 LLM 软判（H5 注入面）——本 ADR 果因分离正是其修正：**果确定性可数、因永远靠玩家花代价去查**。
