Status: Accepted（设计收敛：grill-with-docs 八问 D1–D8 + 两轮 fan-out〔2026-06-14〕+ 每份子 ADR 内部对抗预检 + **本地 ship-pre cmr R1–R8 4/4 concur 收敛**〔2026-06-15，统一审全 5 ADR〕+ 线上 PR #123 三 bot 评审。**设计 ship-ready；实现属编码活、spawn 隔壁 session**——硬序：substrate〔血债 schema/矩阵 42 值/identity/seed/ceiling〕先落，四层 resolve 后做。）

## 脉络

圣旨/directive 颁布现状是**平的**：`decree.py` → simulator → 落库，颁布前后无任何 actor 阻力。大臣的 `loyalty/ability/integrity/courage`（models.py:Character）只当对话 flavor 喂 minister Agent、不机械影响「圣旨执不执行」；`estimate_resistance`（tools.py:134）是结构化阻力公式但只是大臣可调的估算工具、**不闸任何东西**；只有 `gentry_resistance`（士绅阻力）在财政到账率上有牙（flows.py）。密令核议（season_simulator.md:84-90「密旨动向」章，核议五项在 :88——原引 :79-82 系插章漂移、2026-07-08 M12 闸勘正；〔#883 勘正（密令源头隔离，2026-07-17）：密令核议已迁至 `score_extractor_personnel_secret.md` 密令节（核议五项随迁）；`season_simulator` 公共产出依 #883 硬约束不再预读密令，核议主体=personnel_secret extractor〕）已软判「承办人能力忠诚 + 目标实力反制」，是唯一已实装的 actor-属性-驱动判定。

目标：把「**圣旨未必颁得出、颁了未必有效、actor 各有算盘**」做成核心玩法——P社式 actor 博弈。哲学锚（贯穿全 ADR，凡子机制与之冲突以此为准）：

- **带真实代价的破局解谜，不是悲剧灭亡模拟器**。「越努力越无解」是**压力源不是剧本**，结局开放、破局可真（pressure-not-scripted-doom）。危机感是为了**破局的快感 + 引玩家思考怎么破局**，不是整死皇帝。
- **轻交互**：皇帝下旨、不微操官僚（明确「不是 CK3」，无 scheme/hook/联姻那套）。
- **organic 不 gamey**：拒绝 rubber-band、point-of-no-return flag、最后机会特例事件这类人造难度补丁；机制从连续状态涌现。
- 接现有铁律：P1（决策当回合全量落库）、P2（判定 LLM 软判、代码只 clamp）、P3（只算代价不分对错）、P4（皇帝无表，数值只定性叙事呈现）。

**本 ADR 是框架级母 ADR**：定哲学 + 确定性/软判分界 + 离心账本数据模型 + 九条设计脊梁（决定 1–9）。具体子机制（价值轴 schema / 四层票拟契约 / 抄家核议输入 / 恢复门 / 中旨密令曲线精确数）留各自 sub-ADR/spec。

## 决定 1：确定性账本 vs LLM 软判的分界（承重缝）

design-grounding fan 的红队四角度一致暴露同一承重缝：**若离心/阻力/中旨/称病全是 LLM 每回合即兴软判、代码侧零持久棘轮，则「反暴君」「反必输」两套机制全是装饰**——全局只持久化 `民心/皇威` 两个孤立 int（constants.py），simulator 每回合拿到的盘面无强推历史，暴君第 5 次中旨与第 1 次盘面上无差别。

**分界拍板**：

- **账本（确定性）管「累积量 + 天花板」**：applier 在 P1 落库链**机械累加**，不交 LLM 数数。进账本的量：①血债（逐派、单调不减）②中旨/廷杖频度 ③逐派离心 ④敏感度天花板（**由动作触及的实体 id 结构化查表得，不由措辞**——堵话术诱导 H5：实体 id 须从 delta 的**结构化字段**解析出目标 faction/勋戚/宗室/祖制 tag，**不经 LLM 解析措辞**;⚠️ 若实体解析本身仍走 LLM extractor 则注入面残留——查表 schema 与「实体解析是否非-LLM」留 sub-ADR，见决定 5）。
- **软判（LLM）管「本回合叙事化结果」**：这道旨意这回合具体怎么被封驳/阳奉阴违/反噬的叙事与裁定，**吃账本当硬约束（不得软判出比 resolve 算出的阻力更轻的结果；精确硬约束契约见 0011-5 D5-11 resolve↔simulator）**，花样交给 LLM（保 P2 软判哲学）。

弃案：①全软判（=承重缝本身，装饰性机制，暴君可被一个好回合洗白）；②全结构化数值结局机（顶撞 P2、且与现有裁判打架）。

**Q1 细化（确定性 ≠ 钦定，2026-06-14 拍）**：确定性账本与「判死」是两根轴，错挂会滑向 scripted-doom，须分清。

- **确定性因果链该有牙、可全做**：三饷→民变→流寇、血债棘轮这类因果尽管做成确定性——这是模拟器本该有的样子，要有牙、记得住。确定性 ≠ 钦定灭亡。
- **红线**：确定性账本**只累积压力变量**（民怨/流寇/血债 单调↑），**永不内嵌「判负」那一跳**。账本碰不到结局。
- **判死单独分层**：生死归**结局层**（已存在的结局三级判定 叙事→数值→到期 turn≥240，`decree.py:1122`），账本不参与。唯一会滑向钦定的特例 = 确定性正反馈环**且**无可达破局杠杆——但决定 6 的不变式（有 actor 在场时任一盘面 ≥1 条净离心为负窄路）保证出路杠杆恒可达，故判死从不必然、只是走投无路时的涌现态。
- 一句话：**账有牙（确定性、记得住），判死不准写进账，只在结局层涌现、永远留出路**。

## 决定 2：离心账本数据模型

**三层离心**：

| 层 | 性质 | 来源 | 谁读它 |
|---|---|---|---|
| **失望** | 可逆（常态满意度起落，≈现 `satisfaction`） | 寻常不满、办砸、冷落 | 寻常召对态度；好回合能回 |
| **血债** | **不可逆 / 极慢**（逐派系单调累积） | 对该派的暴力/背叛 | **阻力天花板 + 称病只读这层** |
| **敏感度天花板** | 动作级（查实体 id 得） | 动作撞哪些价值轴 + 目标 leverage/勋戚宗室祖制属性 | 决定阻力上限、强推能否推动 |

**血债算式**：`血债 = 基础(动作严重度) × 合法性系数 + 同类防备底`（⚠️ 「合法性系数」名 / 极性已被 0011-2 D2-4 收口为「**失称度**」= `max(0, severity − crime_weight)`——原名反了〔值越高越不正当〕、用户已纠；本行措辞以 0011-2 D2-4 为准）

- **合法性系数 = 罪罚相称度**（罪的大小〔坐实罪名 severity，查办落库的动作史〕 vs 罚的轻重〔抄家/廷杖/诛 vs 罢黜/申饬〕）：**大罪从宽 → 折扣大甚至 ≈0**；**小罪重罚 → 折扣小（「摆明找事儿」）**。`reason_code` 当载体（用 **ADR 0009 的 reason_code 列**；**坐实重罪码（依律集）扩 0009 enum**，**而「中旨除授/非正途/罗织」等污名 STIGMA 走独立常量表、不进 0009 enum**——码集二分真源见 0011-2 D2-5；均须协调 0009 静态围栏，是 build-upon、非无成本复用）。
- **同类防备底**：抄任一 X 派/X 阶层成员 → 其余 X 派 **+防备**（兔死狐悲），强度由该人**认同度 `k_id` 缩放、可真归零**（边缘投机者乐见顶包 = 无防备）。⚠️ 原「吃罪罚相称折扣但不到 100%」已被 **0011-2 D2 / CMR r1 去 `max(1)` 下界收口覆盖**——kinship 由 k_id / 认同度驱动（非罪罚相称折扣那个 direct 旋钮），本行以 0011-2「同类防备底（kinship 臂）」节为准。

**两条不可违背**：

- **阻力/称病只读血债（非失望）** → 一个好回合压不掉结构性负面（堵 H2 洗白）。
- **不可跨派冲抵**：安抚东林**清不掉阉党的血债**（偷 Tyranny「favor≠wrath」）→ 这是涌现尽头能成立的命根；可冲抵则总账永远能洗平、尽头永不到。

**血债 vs leverage 双轴解耦**：血债=该派**多恨你**、leverage=该派**多能挡你**。抄掉一党会降其 leverage（人没了挡不动），同时在旁观派飙血债。

载体：**失望层用现有 `factions` 表的 satisfaction 列**（结构化、逐派；避免双真源——失望本就是逐派状态，塞全局 `GameState.metrics` 自由 dict = data-drift，正是审计过要灭的病）；**血债是新增的结构化持久字段**（逐派列或新表，**非全局 metrics dict**），applier 机械累加。中旨频度**不**作本 ADR 新增逐派计数器／当回合撞派累加——当回合仅案卷 `mode=midzhi` 事实与不猜派标记；频度从案卷派生；正式逐派离心 later-wins → #657 contract **§C.8** → **M12**。精确 schema 留 sub-ADR。

## 决定 3：派系价值矩阵（6 轴 × 7 派）

- **6 轴**：礼法名节 / 既得利益 / 实务事功 / 皇权依附 / 华夷战和 / 民本恤民。
- **7 派**（游戏真实朝堂派系，characters.json 实证）：东林 / 阉党 / 军队 / 皇党 / 宗室 / 西学 / 中立。
- 同一动作**逐派按其价值算离心、符号可相反**（抄阉党 → 阉党血债爆、东林悦）→ 结构性不可调和 = 悲剧引擎。
- **入轴判据（Q4 软化，2026-06-14 拍）**：每轴须承载**真实价值张力**（两极都有真实立场根源），但**不强求两极对称占位**——不把「对称」当设计规矩，**史实不对称就按史实**（某极可 emergent、无常驻派系扛旗）。判据底线只是「不塌成『你是不是 X 派』=派系身份」。弃案：宦权轴（反宦官干政=阉党+皇党对整个外朝，1-对-其余，折回礼法+既得利益）；财政路线/用人路线轴（折叠进既得利益+民本 / 礼法+皇权依附）。
- **华夷战和轴 = 不对称入轴（待复核 flag 收口，Q4）**：主战极常驻（东林道德主战 + 军队向）；**主和极常驻无人占**——这正是「皇帝在外压下被迫想议和、撞上全朝主战共识」的 emperor-vs-consensus 张力，是 feature 不是缺陷。务实派（中立/皇党/西学）在外压够大、代价够明白时可被推着默许（降阻力），但**无人公开扛主和旗**。议和 = **高血债破局杠杆**（攘外必先安内的真解：暂抚后金腾手剿寇），代价 = 撞清流 → 东林血债爆。史实锚：陈新甲议和泄露弃市、杨嗣昌「攘外必先安内」覆盖论点。**不发明假『主和党』**（反史实 + gamey）。
- **P4 硬契约**：轴值是 simulator/extractor 纯内部参数，**永不呈现玩家**（连定性标签都不播报），只经 actor 言行间接感知。哨兵值测试防泄漏。
- 28+ 个具体轴值（7 派 × 6 轴的方向档与精确值）留 sub-spec 手填——设计活非代码活。

## 决定 4：两阶段五结局 + 四层票拟全幕后

**阶段一·颁布**（过**前三层票拟**：内阁票拟 → 司礼监批红 → 六科/言官）：顺颁 / 知难而退打回 / 中旨强推（见决定 5）。**部院 = 阶段二执行层、不在阶段一颁布 blocked_layer 序列**（产 exec_fidelity，见 0011-5 D5-2；「四层」含部院但部院属执行非颁布）。
**阶段二·执行**（部院承办）：忠实 / 打折扭曲 / 阳奉阴违 / 反噬；密令可暗补救（见决定 5）。
**议题敏感度 = 阻力天花板**：撞礼法/祖制/既得利益/华夷的命门题 → 可真推不动（史实：国本之争皇帝 15 年完败、三王并封几天撤回）。

**玩家可见度（D5，你最在意的「轻」）**：**四层全幕后一次 resolve、零新面板**。玩家接口三件：

1. **事前**：召对大臣给**定性谏言**（复用 `estimate_resistance` 公式，但**输出成大臣的话、不给裸数值/不给四层面板**）——大臣 in-character 流露**撞了什么忌讳、触了哪派逆鳞**（如「六科那边怕要争」「此事撞了清议」），够你盘算破局方向但**不暴露价值轴这个系统概念**（轴永不呈现玩家 per 决定 3——信号是大臣的话与态度、不是 axis 标签），不微操。LLM 大臣本就是「侦察阻力」的天然接口。**（⚠️ 「复用 `estimate_resistance`」已被 sub-ADR `0011-5` D5-3 覆盖：召对谏言改走 dry-run wrapper（`resolve(dry_run=True)` → 纯算核 `resolve_core(action, substrate, mode)`，`dry_run` 不进核签名）、`estimate_resistance` 废弃；本行「复用」措辞以 0011-5 D5-3 为准。）**
2. **决策**：三选——顺颁 / 一意孤行（中旨）/ 改路（先密令、先查办坐实、搁置等时机）。
3. **事后**：邸报**叙事性复盘**它怎么过的层（六科封还、阉党阳奉阴违、某老臣称病）——学习入口，建心智模型供下次破局。被打回 → 触发二次决策点（重新想缝在哪）。

弃案：逐层交互（点击疲劳、违轻交互、违「不是 CK3」）；裸阻力数值面板（违 P4）。

现成件：颁旨链复用 **ADR 0004** `pre_settle`/`settle_with_delta`；四层票拟代码**当前零存在**（grep 票拟/批红/封驳/六科/中旨 零命中）→ 从零造，最重、排最后，先读 0009 的 `rejection_wiring`/`initiative_resolve_pairing` 契约避免平行造第二套。

## 决定 5：中旨/密令代价曲线

代价**耦合议题敏感度、非线性（平—陡）**，目的=让中旨/密令是**精准工具（用对时机=破局），不是拐杖（乱用=螺旋）**：

- **中旨**（明着绕内阁票拟）：低敏感行政旨意几乎无伤（崇祯特旨日常）；命门题陡升（六科封驳概率高 + 法理污名）。中旨当回合落库（P1），但 ①六科仍可封驳（硬推后仍可被打回）②落了带「非正途」污名（STIGMA 独立常量、非 0009 reason_code，见 0011-2 D2-5）③**不**在当回合写该派／相关价值派血债、中旨侧 `edict_overdraw` 或「频度进血债账」——正式逐派离心／频度反噬落派 later-wins → #657 contract **§C.8** → **M12**（当回合只留 `mode=midzhi` 案卷事实 + 不猜派标记）。**防「既成事实套利」（H6）= 中旨落库带 `provisional`/未生效标记**：封驳窗口内其机械后果（钱入库/将就位/家产已没）不计入不可逆下游判定，封驳到达即作废该标记下的后果、转「打回」。⚠️ 这是**净新机制、非复用既有回滚**——`applier.atomic`（ADR 0008）只管结算回合内原子性、无跨回合反转语义，`undo_chat_turn`（PR#106 处置级回滚）只撤全局最后一轮 active 召对（LIFO 即时单轮），两者都反转不了更早结算回合已 commit 的中旨。provisional 的生命周期（何时转 final、跨回合续命、与 0008 重跑/恢复门交互）留 sub-ADR。**⚠️ 钱-封驳语义已由 sub-ADR 0011-2 D2-8 收口**：用户 2026-06-14 拍「钱没了就是没了」，上文作废集中『钱入库』一项**不反转**（escrow 溶解），改 append-only 双笔留痕（国库净额 **−amount**＝钱真没了，落 `economy_ledger`；封驳为不退款的作废审计行）——详见 0011-2 D2-8 坑④。
- **密令**（暗道走核议）：复用密令核议（已软判承办人能力忠诚 + 目标实力反制；写作时锚 season_simulator 密令章——〔#883 勘正（2026-07-17）：核议已迁 `score_extractor_personnel_secret.md` 密令节，主体=personnel_secret extractor，决策「复用既有核议、不另起平行引擎」不变〕）。抄家拿人 = **结构化输入**（目标 leverage × 承办人立场/派系对齐 × 离心）喂软判，不靠 AI 随机（堵 H5）。**命门级/高 leverage 目标有成功率地板**（承办能力压不破，不能靠暗道稳过命门）；**密令透支账**（同期/累计密令数 → 朝野警觉 → 暴露 roll 单调变差 → 暴露反噬确定性落库，堵 H4 旁路提款机）。

破局教学：玩家看懂曲线就会悟到「对命门目标，聪明解法是先查办坐实罪名把它压成顺颁/低代价，不是中旨硬推或密令赌」——曲线在教「攒合法性、别硬来」（史实：崇祯定逆案 262 人是走程序坐实，故清议撑、易成）。

## 决定 6：破局出路 + 涌现尽头（非钦定灭亡）

- **正和动作保留**：同时兑现多派共同价值轴 → 净离心为负（大罪从宽抄真贪 / 整顿吏治追赃 / 赈灾恤民 / 平反起复）。条件苛刻、路窄（撞错派就翻成净正）、见效慢 → 「协调的大明不会亡」**机制上为真、实操极难**。
- **不变式**：有 actor 在场时任一盘面 **≥1 条净离心为负的窄路**。⚠️「净负」**只聚合在失望层 + leverage 改善上、不含血债**（血债单调不减、不参与净负判定，否则与决定 2 棘轮直接抵触）；该窄路靠**降 leverage / 招回退场 actor 解锁回流前置**移动盘面，而非抵消「阻力只读」的血债。正和路**吊在 actor 在场上**（平反要清流在、吏治要能臣肯干）。
- **无显式封死点**：不是阈值/状态/flag。就是连续累积——血债涨、actor 按各自节操+血债**自然退场**、回流路径（**每种离场 reason_code ≥1 条，极难但恒在**）的前置随状态变难。盘面烂到没好棋就是没好棋，**游戏从不判定「你封死了」**。尽头是「回流前置被血债烧光」的**涌现态**，不是设计的点。
- **预警叙事化**（账本过阈触发、邸报/召对递送、零数字）：老臣称病乞骸骨 / 廷议冷落推诿 / 泣血死谏 / 王承恩忠谏升级 / 人才池可见缩。这些是**离心高到某程度 actor 自然如此反应**，碰巧是信号、**不是设计的检查点**。
- 弃案：硬编码 point-of-no-return / 「最后机会」特例事件（gamey 人造物）。

## 决定 7：恢复 + 开放结局

- **恢复**：慢（5-10 年量级）、**行动驱动**（平反/听谏/起复 + actor 提案的恢复事件，非被动计时）；安抚回失望易、**回血债极难**（P3 边际递减）。
- **国难条件加速**（diegetic，非机械 rubber-band）：后金叩关/流寇糜烂时，各派「不合作=同归于尽」→ 你**真改**则人心思安、冰释加速；**硬来照样螺旋**（棘轮的牙保住）。
- **高初始政治资本**（崇祯元年蜜月：扳倒魏忠贤、众望所归）取代「首年-50%」特例——organic 兜学习期、红利随花递减、平滑过渡到艰难中盘。
- **开放结局谱**：LLM 终局对「**你实际做成了什么**」的开放叙述（中兴 / 征服周边 / 延祚 / 局部转圜 / 史实 1644 / 速亡 / 异变）。**无设计天花板**——玩得够狠就让他中兴乃至拓边；玩家真实目标从作为浮现、结局如实反映（偷 Frostpunk 分级道德审判旁白，落 P3「只算代价不分对错」；复用现有 LLM 邸报/裁判，近零成本）。
- 弃案：单一 240 回合数值线判生死（抹平选择）；把「生存」设为唯一好结局轴（违开放结局）。

## 决定 8：派系功能/效用（供给面 + 反咬 + 接触途径）

**问题**：`factions` 表只有 satisfaction/leverage/agenda（全是索取/阻力面，零供给面），`leverage` 唯一机械读点是 `estimate_resistance()` 把全派 leverage 拍平进启发式（tools.py:147）。弃一派 = 纯减阻力、零代价 = 无脑最优解 → 反噬悲剧引擎（「少一派反而好事」当前字面成立）。

**决定**：每派有一条**承重功能轴**（供给面），同一根轴有两个 failure mode：

1. **承重功能（在场且合作）= 替皇帝干一类活**：阉党=厂卫情报 + 批红代行 + 抄家脏活；军队=九边动兵/平叛/京营守城（唯一暴力通道）；中立=六部九卿日常行政机器（沉默多数，丢了百业停）；东林=清流合法性背书 + 士林人才池；皇党=皇帝直属执行班子（清账/补库/推旨落地，唯一无条件站皇帝）；西学=火器/历法/水利技术加成（接 P2 军备）；宗室=血缘合法性锚 + 潜在藩兵钱（日常供给≈0）。
2. **走光（弃派/派系灭）= 功能没了**：杀魏后无人替你看/抄/办的真实失明。
3. **惹毛但人还在 = 功能被扣留/武器化反咬**（承重功能负片）：阉党厂卫瞒报掺水（你瞎）、军队拥兵不前/哗变、中立怠政百司废弛、东林清议骂昏君/辞官、宗室串联撤合作（极端时动用潜在藩兵=谋逆苗头）、西学撂挑子停火器工。

**配套约束**：

- **功能数不设配额**（FF-3）：按各派实际，可 0、可 1、可多（阉党天然多条，宗室日常≈0），realism 优先于对称，不铺能力矩阵。
- **不发明新机读态**（承 决定 1）：承重功能 = **裁判规则知识**，落 `season_simulator.md`（凭在场名单 + satisfaction 判合作度），**不给 `factions` 表加功能字段**。软判定形态/时机（哪种扣留、多狠，按动的「理」+ 力度，承 决定 3 折扣）；**持久后果落已有槽位**：factions 离心（satisfaction/leverage）+ issues（如「宗室串联抵制削藩」在办事项）+ 功能效果被否（裁判反映本回合没干净厂卫情报）。装病拖延**不扩 status enum**（合 0009 立场：不为风味态扩 enum），真后果落「issue 不进/不动」。
- **接触途径分层**（FF-4 = A，召对加 `location` 闸）：在朝（location ∈ 京）→ 召对直达；场外（∉ 京，如宗室藩王/边镇武将/classes 阶层）→ 召对够不着即时奏对，要么旨意经制度中介间接、要么「召其入京」触发 ADR 0009 在途（几回合后抵达，**叙事判抵达、非 #93 的距离/ETA 计算**）。宗室/边镇/阶层共用此「场外 actor 接触模型」。**用 0009 的 `location` 字段（TEXT region_id，「在京」= `location == 'beizhili'`〔京师 / 北直隶 同一 region_id；精确以 live db `_CITY_LEVEL_TIERS` 为准，Gemini 线上〕、非 boolean）+ 在途，不碰 #93**——小闸修掉「召对无视距离」一大半（实证 `summon_minister` 当前纯透传 `__summon__{name}`、零 location 闸，tools.py:476）。（**取代注〔2026-07-07 #475 闸〕**：括注「几回合后抵达、叙事判抵达、非 #93 的距离/ETA 计算」与「不碰 #93」已被 0095/0096 取代——在途改 0094 距离矩阵确定性倒数、抵达为引擎事实；本条 location 闸方向〔FF-4〕由 0096 兑现为召对 travel-gating＋候见制。）
- **宗室特性**（FF-2）：威胁度 < 明初藩王（无独立军权靖难），但**不束手就擒**（削/抄会激起抵抗、串联、装病拖延、舆论，极端时藩兵苗头）；低日常供给 + 高反应性自卫 + 场外间接接触；否「少了反而好」。
- **P4**：功能态/合作度**永不裸呈现**，定性叙事（「厂卫密报开始慢/掺水/对不上」「百司文书积压」）。

**根因接缝**：阉党承重功能失能的机械根 = `set_character_status` 退场未联动派系 leverage（治 B1/#9：阉党核心走光 → 厂卫情报应失能却不联动）。

**依赖 / 承重落地点（→ sub-ADR / 切片）**：

- 依赖 ADR 0009 `location` 字段——**已 MERGED（#106）实装**（db.py:212/827，带 invariant transit_implies_active），依赖已满足；但召对仍不 gate location、仍无在途时间（#93）→ 召对 location 闸 = 单独切片。（取代注〔2026-07-07 #475 闸〕：召对 location 闸已由 0096 落成机制〔travel-gating＋候见制〕、在途时间已由 0095 建成——本条「仍不 gate／仍无在途时间／留 #93」陈述随之取代。）
- `season_simulator.md` **需净增「各派承重功能 + 反咬」裁判规则**（现无）——待核现状 + 起草。
- 「issue 不进/不动」作为装病/拖延的后果落点，需确认 issues 机制支持「停滞」语义。

## 决定 9：外压集成（外压 = 破局压力引擎）

**论点**：外压（后金/流寇/三饷/灾荒）是逼皇帝下「会惹派系离心」的旨意的源头；无外压则派系博弈死。外压 → 逼旨 → 惹离心 → 破局 = 管外患 + 内耗两线。

**意外收获**：引擎前半截（外压 → 逼旨）**已大半接好**——gate 机器 `_eval_gate_key` 已支持 region/army/building/power/class/faction 六表前缀 + 聚合（min/max/avg/sum）+ AND，**加触发链 = 零代码加 `seed_events` JSON 条目**；史实时间线「是否发生」已确定性（events.json 带 trigger_year）；unrest→国库到账率已闭环（flows._province_efficiency）；事件结案写 factions 已通。

**集成接缝**：

- **exists（不用设计）**：unrest→国库到账率；外压→危机触发（gate READ 六表）；史实时间线是否发生；事件结案→factions WRITE。
- **net-new 承重（按优先级）**：① **血债棘轮**（= 决定 2 收口，总解锁，优先级第一——红队四角共指「无持久棘轮则反必输机制全装饰」）；② **三饷→民怨确定性传导**（接 settle_tick breakdown → classes 失望层；islanded，issues.py:2185 明文「联动靠 LLM 不在代码做」= 绞索正反馈环代码层零实现；timing 属实现注记）；③ **确定性 power_tick**（后金/流寇当真活 actor，现有字段无 tick；顺带修死 gate bug：cohesion 永不降 → houjin_split 战机永不触发；后置）；④ **退场 → leverage 联动**（set_character_status 治 B1/#9，= 决定 8 根因）；⑤ **华夷轴不对称**（= 决定 3，主和极 emergent 高血债杠杆）。

**困境链（设计要保护的情感载荷，每条都留真出路，非 death 螺旋）**：

- **三饷绞索**：军费 → 加饷 → 民欠/军饷欠 → 离心 → 民变 → unrest → 到账率↓ → 更凑不齐。出路：清隐田/追赃富省扩税基、走程序抄真贪（大罪从宽血债≈0）、赈灾压 unrest、密令策反后金贝勒。
- **攘外必先安内**：后金（辽东）× 流寇（中原）双线撕扯同一支机动兵，按下葫芦浮起瓢。出路：华夷轴做真选择（暂抚后金腾手剿寇）、追赃给实饷 + 起复能臣、国难加速恢复（决定 7）。
- **暴君螺旋**：命门题被打回 → 中旨强推 → 血债棘轮 + 频度透支 → 老臣称病 → 人才池缩 → 更只能硬推。出路：先查办坐实罪名把命门压成顺颁（史实定逆案 262 人走程序），攒合法性别硬来。

（出路均落决定 6 的「净负窄路」不变式。）

**defer**：后宫/外戚/监军（剧本-gated，崇祯关、武媚娘等剧本开，非删除——架构信号：游戏当多剧本平台，记着不展开）；**史实大事（如北京陷落）后果保持 LLM 软判、不钉确定性**（防滑向钦定剧本，只在 gate READ 端机械化「是否触发」）。
