# 圣旨颁布阻力网 + 离心账本（actor 博弈框架母 ADR）

Status: Proposed（草案；grill-with-docs 八问 D1–D8 + 两轮 fan-out 于 2026-06-14 收敛。**待评审**——按 CLAUDE.md 设计文档铁律走本地 cmr + 线上三 bot，未收敛前不进实现期。）

## 脉络

圣旨/directive 颁布现状是**平的**：`decree.py` → simulator → 落库，颁布前后无任何 actor 阻力。大臣的 `loyalty/ability/integrity/courage`（models.py:Character）只当对话 flavor 喂 minister Agent、不机械影响「圣旨执不执行」；`estimate_resistance`（tools.py:134）是结构化阻力公式但只是大臣可调的估算工具、**不闸任何东西**；只有 `gentry_resistance`（士绅阻力）在财政到账率上有牙（flows.py）。密令核议（season_simulator.md:79-82）已软判「承办人能力忠诚 + 目标实力反制」，是唯一已实装的 actor-属性-驱动判定。

目标：把「**圣旨未必颁得出、颁了未必有效、actor 各有算盘**」做成核心玩法——P社式 actor 博弈。哲学锚（贯穿全 ADR，凡子机制与之冲突以此为准）：

- **带真实代价的破局解谜，不是悲剧灭亡模拟器**。「越努力越无解」是**压力源不是剧本**，结局开放、破局可真（pressure-not-scripted-doom）。危机感是为了**破局的快感 + 引玩家思考怎么破局**，不是整死皇帝。
- **轻交互**：皇帝下旨、不微操官僚（明确「不是 CK3」，无 scheme/hook/联姻那套）。
- **organic 不 gamey**：拒绝 rubber-band、point-of-no-return flag、最后机会特例事件这类人造难度补丁；机制从连续状态涌现。
- 接现有铁律：P1（决策当回合全量落库）、P2（判定 LLM 软判、代码只 clamp）、P3（只算代价不分对错）、P4（皇帝无表，数值只定性叙事呈现）。

**本 ADR 是框架级母 ADR**：定哲学 + 确定性/软判分界 + 离心账本数据模型 + 八条设计脊梁。具体子机制（价值轴 schema / 四层票拟契约 / 抄家核议输入 / 恢复门 / 中旨密令曲线精确数）留各自 sub-ADR/spec。

## 决定 1：确定性账本 vs LLM 软判的分界（承重缝）

design-grounding fan 的红队四角度一致暴露同一承重缝：**若离心/阻力/中旨/称病全是 LLM 每回合即兴软判、代码侧零持久棘轮，则「反暴君」「反必输」两套机制全是装饰**——全局只持久化 `民心/皇威` 两个孤立 int（constants.py），simulator 每回合拿到的盘面无强推历史，暴君第 5 次中旨与第 1 次盘面上无差别。

**分界拍板**：

- **账本（确定性）管「累积量 + 天花板」**：applier 在 P1 落库链**机械累加**，不交 LLM 数数。进账本的量：①血债（逐派、单调不减）②中旨/廷杖频度 ③逐派离心 ④敏感度天花板（**由动作触及的实体 id 查表得，不由措辞**——堵话术诱导，见决定 5/H5）。
- **软判（LLM）管「本回合叙事化结果」**：这道旨意这回合具体怎么被封驳/阳奉阴违/反噬的叙事与裁定，**吃账本当硬约束（不低于天花板）**，花样交给 LLM（保 P2 软判哲学）。

弃案：①全软判（=承重缝本身，装饰性机制，暴君可被一个好回合洗白）；②全结构化数值结局机（顶撞 P2、且与现有裁判打架）。

## 决定 2：离心账本数据模型

**三层离心**：

| 层 | 性质 | 来源 | 谁读它 |
|---|---|---|---|
| **失望** | 可逆（常态满意度起落，≈现 `satisfaction`） | 寻常不满、办砸、冷落 | 寻常召对态度；好回合能回 |
| **血债** | **不可逆 / 极慢**（逐派系单调累积） | 对该派的暴力/背叛 | **阻力天花板 + 称病只读这层** |
| **敏感度天花板** | 动作级（查实体 id 得） | 动作撞哪些价值轴 + 目标 leverage/勋戚宗室祖制属性 | 决定阻力上限、强推能否推动 |

**血债算式**：`血债 = 基础(动作严重度) × 合法性系数 + 同类防备底`

- **合法性系数 = 罪罚相称度**（罪的大小〔坐实罪名 severity，查办落库的动作史〕 vs 罚的轻重〔抄家/廷杖/诛 vs 罢黜/申饬〕）：**大罪从宽 → 折扣大甚至 ≈0**；**小罪重罚 → 折扣小（「摆明找事儿」）**。`reason_code` 当载体（**复用 ADR 0009 的 reason_code 列**，需新增「中旨除授/非正途/罗织」等污名码）。
- **同类防备底**：抄任一 X 派/X 阶层成员 → 其余 X 派 **+防备**（兔死狐悲）；**吃罪罚相称折扣但不到 100%**（大罪从宽可压到极低，小罪重罚拉满）。

**两条不可违背**：

- **阻力/称病只读血债（非失望）** → 一个好回合压不掉结构性负面（堵 H2 洗白）。
- **不可跨派冲抵**：安抚东林**清不掉阉党的血债**（偷 Tyranny「favor≠wrath」）→ 这是涌现尽头能成立的命根；可冲抵则总账永远能洗平、尽头永不到。

**血债 vs leverage 双轴解耦**：血债=该派**多恨你**、leverage=该派**多能挡你**。抄掉一党会降其 leverage（人没了挡不动），同时在旁观派飙血债。

载体：离心标量复用 `GameState.metrics`（自由 dict + clamp 0-100 + save/load 零迁移）；血债/频度计数需新建持久字段，applier 机械累加。

## 决定 3：派系价值矩阵（6 轴 × 7 派）

- **6 轴**：礼法名节 / 既得利益 / 实务事功 / 皇权依附 / 华夷战和 / 民本恤民。
- **7 派**（游戏真实朝堂派系，characters.json 实证）：东林 / 阉党 / 军队 / 皇党 / 宗室 / 西学 / 中立。
- 同一动作**逐派按其价值算离心、符号可相反**（抄阉党 → 阉党血债爆、东林悦）→ 结构性不可调和 = 悲剧引擎。
- **入轴判据**：每轴**两极都有人占**（否则塌成「你是不是 X 派」=派系身份，不是价值轴）。弃案：宦权轴（反宦官干政=阉党+皇党对整个外朝，1-对-其余，折回礼法+既得利益）；财政路线/用人路线轴（折叠进既得利益+民本 / 礼法+皇权依附）。
- **P4 硬契约**：轴值是 simulator/extractor 纯内部参数，**永不呈现玩家**（连定性标签都不播报），只经 actor 言行间接感知。哨兵值测试防泄漏。
- 28+ 个具体轴值（7 派 × 6 轴的方向档与精确值）留 sub-spec 手填——设计活非代码活。

## 决定 4：两阶段五结局 + 四层票拟全幕后

**阶段一·颁布**（过四层票拟：内阁票拟 → 司礼监批红 → 六科/言官 → 部院）：顺颁 / 知难而退打回 / 中旨强推（见决定 5）。
**阶段二·执行**：忠实 / 打折扭曲 / 阳奉阴违 / 反噬；密令可暗补救（见决定 5）。
**议题敏感度 = 阻力天花板**：撞礼法/祖制/既得利益/华夷的命门题 → 可真推不动（史实：国本之争皇帝 15 年完败、三王并封几天撤回）。

**玩家可见度（D5，你最在意的「轻」）**：**四层全幕后一次 resolve、零新面板**。玩家接口三件：

1. **事前**：召对大臣给**定性谏言**（复用 `estimate_resistance` 公式，但**输出成大臣的话、不给裸数值/不给四层面板**）——指方向（哪派/哪轴/撞不撞命门），够盘算但不微操。LLM 大臣本就是「侦察阻力」的天然接口。
2. **决策**：三选——顺颁 / 一意孤行（中旨）/ 改路（先密令、先查办坐实、搁置等时机）。
3. **事后**：邸报**叙事性复盘**它怎么过的层（六科封还、阉党阳奉阴违、某老臣称病）——学习入口，建心智模型供下次破局。被打回 → 触发二次决策点（重新想缝在哪）。

弃案：逐层交互（点击疲劳、违轻交互、违「不是 CK3」）；裸阻力数值面板（违 P4）。

现成件：颁旨链复用 **ADR 0004** `pre_settle`/`settle_with_delta`；四层票拟代码**当前零存在**（grep 票拟/批红/封驳/六科/中旨 零命中）→ 从零造，最重、排最后，先读 0009 的 `rejection_wiring`/`initiative_resolve_pairing` 契约避免平行造第二套。

## 决定 5：中旨/密令代价曲线

代价**耦合议题敏感度、非线性（平—陡）**，目的=让中旨/密令是**精准工具（用对时机=破局），不是拐杖（乱用=螺旋）**：

- **中旨**（明着绕内阁票拟）：低敏感行政旨意几乎无伤（崇祯特旨日常）；命门题陡升（六科封驳概率高 + 相关价值派血债陡升 + 法理污名）。中旨当回合落库（P1），但 ①六科仍可封驳（硬推后仍可被打回）②落了带「非正途」污名（reason_code）③频度进血债账。被封驳走**对称回滚**（复用 **ADR 0008** `applier.atomic` + PR#106 处置级人工回滚的对称还原），防「既成事实套利」（H6）。
- **密令**（暗道走核议）：复用 season_simulator 密令核议（已软判承办人能力忠诚 + 目标实力反制）。抄家拿人 = **结构化输入**（目标 leverage × 承办人立场/派系对齐 × 离心）喂软判，不靠 AI 随机（堵 H5）。**命门级/高 leverage 目标有成功率地板**（承办能力压不破，不能靠暗道稳过命门）；**密令透支账**（同期/累计密令数 → 朝野警觉 → 暴露 roll 单调变差 → 暴露反噬确定性落库，堵 H4 旁路提款机）。

破局教学：玩家看懂曲线就会悟到「对命门目标，聪明解法是先查办坐实罪名把它压成顺颁/低代价，不是中旨硬推或密令赌」——曲线在教「攒合法性、别硬来」（史实：崇祯定逆案 262 人是走程序坐实，故清议撑、易成）。

## 决定 6：破局出路 + 涌现尽头（非钦定灭亡）

- **正和动作保留**：同时兑现多派共同价值轴 → 净离心为负（大罪从宽抄真贪 / 整顿吏治追赃 / 赈灾恤民 / 平反起复）。条件苛刻、路窄（撞错派就翻成净正）、见效慢 → 「协调的大明不会亡」**机制上为真、实操极难**。
- **不变式**：有 actor 在场时任一盘面 **≥1 条净离心为负的窄路**；正和路**吊在 actor 在场上**（平反要清流在、吏治要能臣肯干）。
- **无显式封死点**：不是阈值/状态/flag。就是连续累积——血债涨、actor 按各自节操+血债**自然退场**、回流路径（**每种离场 reason_code ≥1 条，极难但恒在**）的前置随状态变难。盘面烂到没好棋就是没好棋，**游戏从不判定「你封死了」**。尽头是「回流前置被血债烧光」的**涌现态**，不是设计的点。
- **预警叙事化**（账本过阈触发、邸报/召对递送、零数字）：老臣称病乞骸骨 / 廷议冷落推诿 / 泣血死谏 / 王承恩忠谏升级 / 人才池可见缩。这些是**离心高到某程度 actor 自然如此反应**，碰巧是信号、**不是设计的检查点**。
- 弃案：硬编码 point-of-no-return / 「最后机会」特例事件（gamey 人造物）。

## 决定 7：恢复 + 开放结局

- **恢复**：慢（5-10 年量级）、**行动驱动**（平反/听谏/起复 + actor 提案的恢复事件，非被动计时）；安抚回失望易、**回血债极难**（P3 边际递减）。
- **国难条件加速**（diegetic，非机械 rubber-band）：后金叩关/流寇糜烂时，各派「不合作=同归于尽」→ 你**真改**则人心思安、冰释加速；**硬来照样螺旋**（棘轮的牙保住）。
- **高初始政治资本**（崇祯元年蜜月：扳倒魏忠贤、众望所归）取代「首年-50%」特例——organic 兜学习期、红利随花递减、平滑过渡到艰难中盘。
- **开放结局谱**：LLM 终局对「**你实际做成了什么**」的开放叙述（中兴 / 征服周边 / 延祚 / 局部转圜 / 史实 1644 / 速亡 / 异变）。**无设计天花板**——玩得够狠就让他中兴乃至拓边；玩家真实目标从作为浮现、结局如实反映（偷 Frostpunk 分级道德审判旁白，落 P3「只算代价不分对错」；复用现有 LLM 邸报/裁判，近零成本）。
- 弃案：单一 240 回合数值线判生死（抹平选择）；把「生存」设为唯一好结局轴（违开放结局）。

## 后果

### 落地顺序与可行性（详见 design-grounding fan 合成）

前置：0009 person 线已并 main（#106/#107），`reason_code`/character 写路径围栏可复用。

- **第 0 步（现在）**：本母 ADR + `season_simulator.md` 软判规则草案（prompt 文件低冲突）。
- **第 1 件**：离心账本 + 6 轴价值画像（最省、不撞 0009——factions/metrics/flows 全在 0009 diff 外；含血债棘轮 + 中旨频度计数器）。
- **第 2 件**：抄家核议结构化输入（decree.py 注入点 + simulation.py payload + season_simulator prompt 三处独立，0009 不碰）。
- **第 3–5 件（0009 之上）**：节操退场/称病（复用 0009 reason_code 载体）→ 恢复门 actor 前置（`_eval_gate_key` 加 character 前缀 + audiences active 过滤）→ 四层票拟+中旨闸（最重最后）。
- **探针第一刀**：母 ADR + 件1 + 件2 输入侧 + 红队三 high 缓解（密令透支账 / 中旨非正途污名不可洗 / 恢复门 actor 前置占位）。四层票拟整套 defer。

### 红队承重缝 + 缓解（全 high，共同根=无持久棘轮）

| | 洞 | 缓解（落点） |
|---|---|---|
| H1 | 中旨频度反噬无载体 | 皇权透支账（决定 1/2） |
| H2 | 离心可被好回合洗白 | 血债棘轮、阻力只读血债（决定 2） |
| H3 | 恢复门 fail-open（清流走光照刷恢复） | actor 前置 `requires_onstage_proposer`（决定 6） |
| H4 | 密令旁路吞四层 | 命门成功率地板 + 透支账（决定 5） |
| H5 | 软判可被话术诱导降敏感度 | 敏感度锚实体 id、同回合禁重判（决定 1/5） |
| H6 | 中旨当回合落库 + 封驳异步套利 | provisional 标记 + 对称回滚（决定 5） |
