## 历史设计（相抵条款由上述修订取代；非并行施工合同）

## 脉络

圣旨/directive 颁布现状是**平的**：`decree.py` → simulator → 落库，颁布前后无任何 actor 阻力。大臣的 `loyalty/ability/integrity/courage`（models.py:Character）只当对话 flavor 喂 minister Agent、不机械影响「圣旨执不执行」；`estimate_resistance`（tools.py:134）是结构化阻力公式但只是大臣可调的估算工具、**不闸任何东西**；只有 `gentry_resistance`（士绅阻力）在财政到账率上有牙（flows.py）。密令核议（season_simulator.md:84-90「密旨动向」章，核议五项在 :88——原引 :79-82 系插章漂移、2026-07-08 M12 闸勘正；〔#883 勘正（密令源头隔离，2026-07-17）：密令核议已迁至 `score_extractor_personnel_secret.md` 密令节（核议五项随迁）；`season_simulator` 公共产出依 #883 硬约束不再预读密令，核议主体=personnel_secret extractor〕）已软判「承办人能力忠诚 + 目标实力反制」，是唯一已实装的 actor-属性-驱动判定。

目标：把「**圣旨未必颁得出、颁了未必有效、actor 各有算盘**」做成核心玩法——P社式 actor 博弈。哲学锚（贯穿全 ADR，凡子机制与之冲突以此为准）：

- **带真实代价的破局解谜，不是悲剧灭亡模拟器**。「越努力越无解」是**压力源不是剧本**，结局开放、破局可真（pressure-not-scripted-doom）。危机感是为了**破局的快感 + 引玩家思考怎么破局**，不是整死皇帝。
- **轻交互**：皇帝下旨、不微操官僚（明确「不是 CK3」，无 scheme/hook/联姻那套）。
- **organic 不 gamey**：拒绝 rubber-band、point-of-no-return flag、最后机会特例事件这类人造难度补丁；机制从连续状态涌现。
- 接现有铁律：P1（决策当回合全量落库）、P2（判定 LLM 软判、代码只 clamp）、P3（只算代价不分对错）、P4（皇帝无表，数值只定性叙事呈现）。

**本 ADR 是框架级母 ADR**：定哲学 + 设计脊梁（决定 6–9；原决定 1–5 的阻力、血债、票拟、密令算式已依 #1895 删除）。具体子机制（价值轴 schema / 四层票拟契约 / 抄家核议输入 / 恢复门 / 中旨密令曲线精确数）留各自 sub-ADR/spec。

## 决定 6：破局出路 + 涌现尽头（非钦定灭亡）

- **正和动作保留**：同时兑现多派共同价值轴 → 净离心为负（大罪从宽抄真贪 / 整顿吏治追赃 / 赈灾恤民 / 平反起复）。条件苛刻、路窄（撞错派就翻成净正）、见效慢 → 「协调的大明不会亡」**机制上为真、实操极难**。
- **不变式**：有 actor 在场时任一盘面 **≥1 条净离心为负的窄路**。⚠️「净负」**只聚合在失望层 + leverage 改善上、不含血债**（血债单调不减、不参与净负判定）；该窄路靠**降 leverage / 招回退场 actor 解锁回流前置**移动盘面，而非抵消血债。正和路**吊在 actor 在场上**（平反要清流在、吏治要能臣肯干）。
- **无显式封死点**：不是阈值/状态/flag。就是连续累积——血债涨、actor 按各自节操+血债**自然退场**、回流路径（**每种离场 reason_code ≥1 条，极难但恒在**）的前置随状态变难。盘面烂到没好棋就是没好棋，**游戏从不判定「你封死了」**。尽头是「回流前置被血债烧光」的**涌现态**，不是设计的点。
- **预警叙事化**（账本过阈触发、邸报/召对递送、零数字）：老臣称病乞骸骨 / 廷议冷落推诿 / 泣血死谏 / 王承恩忠谏升级 / 人才池可见缩。这些是**离心高到某程度 actor 自然如此反应**，碰巧是信号、**不是设计的检查点**。
- 弃案：硬编码 point-of-no-return / 「最后机会」特例事件（gamey 人造物）。

## 决定 7：恢复 + 开放结局

- **恢复**：慢（5-10 年量级）、**行动驱动**（平反/听谏/起复 + actor 提案的恢复事件，非被动计时）；安抚回失望易、**回血债极难**（P3 边际递减）。
- **国难条件加速**（diegetic，非机械 rubber-band）：后金叩关/流寇糜烂时，各派「不合作=同归于尽」→ 你**真改**则人心思安、冰释加速；**硬来照样螺旋**（棘轮的牙保住）。
- **高初始政治资本**（崇祯元年蜜月：扳倒魏忠贤、众望所归）取代「首年-50%」特例——organic 兜学习期、红利随花递减、平滑过渡到艰难中盘。
- **开放结局谱**：LLM 终局对「**你实际做成了什么**」的开放叙述（中兴 / 征服周边 / 延祚 / 局部转圜 / 史实 1644 / 速亡 / 异变）。**无设计天花板**——玩得够狠就让他中兴乃至拓边；玩家真实目标从作为浮现、结局如实反映（偷 Frostpunk 分级道德审判旁白，落 P3「只算代价不分对错」；复用现有 LLM 邸报/裁判，近零成本）。
- 弃案：单一 240 回合数值线判生死（抹平选择）；把「生存」设为唯一好结局轴（违开放结局）。

## 决定 8：派系功能/效用（供给面 + 反咬 + 接触途径）

**问题**：`factions` 表只有 satisfaction/leverage/agenda（全是索取/阻力面，零供给面），`leverage` 唯一机械读点是 `estimate_resistance()` 把全派 leverage 拍平进启发式（tools.py:147）。弃一派 = 纯减阻力、零代价 = 无脑最优解 → 反噬悲剧引擎（「少一派反而好事」当前字面成立）。

**决定**：每派有一条**承重功能轴**（供给面），同一根轴有两个 failure mode：

1. **承重功能（在场且合作）= 替皇帝干一类活**：阉党=厂卫情报 + 批红代行 + 抄家脏活；军队=九边动兵/平叛/京营守城（唯一暴力通道）；中立=六部九卿日常行政机器（沉默多数，丢了百业停）；东林=清流合法性背书 + 士林人才池；皇党=皇帝直属执行班子（清账/补库/推旨落地，唯一无条件站皇帝）；西学=火器/历法/水利技术加成（接 P2 军备）；宗室=血缘合法性锚 + 潜在藩兵钱（日常供给≈0）。
2. **走光（弃派/派系灭）= 功能没了**：杀魏后无人替你看/抄/办的真实失明。
3. **惹毛但人还在 = 功能被扣留/武器化反咬**（承重功能负片）：阉党厂卫瞒报掺水（你瞎）、军队拥兵不前/哗变、中立怠政百司废弛、东林清议骂昏君/辞官、宗室串联撤合作（极端时动用潜在藩兵=谋逆苗头）、西学撂挑子停火器工。

**配套约束**：

- **功能数不设配额**（FF-3）：按各派实际，可 0、可 1、可多（阉党天然多条，宗室日常≈0），realism 优先于对称，不铺能力矩阵。
- **不发明新机读态**：承重功能 = **裁判规则知识**，落 `season_simulator.md`（凭在场名单 + satisfaction 判合作度），**不给 `factions` 表加功能字段**。软判定形态/时机（哪种扣留、多狠，按动的「理」+ 力度）；**持久后果落已有槽位**：factions 离心（satisfaction/leverage）+ issues（如「宗室串联抵制削藩」在办事项）+ 功能效果被否（裁判反映本回合没干净厂卫情报）。装病拖延**不扩 status enum**（不为风味态扩 enum），真后果落「issue 不进/不动」。
- **接触途径分层**（FF-4 = A，召对加 `location` 闸）：在朝（location ∈ 京）→ 召对直达；场外（∉ 京，如宗室藩王/边镇武将/classes 阶层）→ 召对够不着即时奏对，要么旨意经制度中介间接、要么「召其入京」触发在途（按距离确定性倒数，抵达为引擎事实）。宗室/边镇/阶层共用此「场外 actor 接触模型」。**用人物的 `location` 字段（TEXT region_id，「在京」= `location == 'beizhili'`〔京师 / 北直隶 同一 region_id；精确以 live db `_CITY_LEVEL_TIERS` 为准，Gemini 线上〕、非 boolean）+ 在途**——小闸修掉「召对无视距离」一大半（实证 `summon_minister` 当前纯透传 `__summon__{name}`、零 location 闸，tools.py:476）。（〔2026-07-07 #475 闸〕本条 location 闸方向〔FF-4〕已兑现为召对 travel-gating＋候见制。）
- **宗室特性**（FF-2）：威胁度 < 明初藩王（无独立军权靖难），但**不束手就擒**（削/抄会激起抵抗、串联、装病拖延、舆论，极端时藩兵苗头）；低日常供给 + 高反应性自卫 + 场外间接接触；否「少了反而好」。
- **P4**：功能态/合作度**永不裸呈现**，定性叙事（「厂卫密报开始慢/掺水/对不上」「百司文书积压」）。

**根因接缝**：阉党承重功能失能的机械根 = `set_character_status` 退场未联动派系 leverage（治 B1/#9：阉党核心走光 → 厂卫情报应失能却不联动）。

## 决定 9：外压集成（外压 = 破局压力引擎）

**论点**：外压（后金/流寇/三饷/灾荒）是逼皇帝下「会惹派系离心」的旨意的源头；无外压则派系博弈死。外压 → 逼旨 → 惹离心 → 破局 = 管外患 + 内耗两线。

**意外收获**：引擎前半截（外压 → 逼旨）**已大半接好**——gate 机器 `_eval_gate_key` 已支持 region/army/building/power/class/faction 六表前缀 + 聚合（min/max/avg/sum）+ AND，**加触发链 = 零代码加 `seed_events` JSON 条目**；史实时间线「是否发生」已确定性（events.json 带 trigger_year）；unrest→国库到账率已闭环（flows._province_efficiency）；事件结案写 factions 已通。

**集成接缝**：

- **exists（不用设计）**：unrest→国库到账率；外压→危机触发（gate READ 六表）；史实时间线是否发生；事件结案→factions WRITE。
- **net-new 承重（按优先级）**：① **血债棘轮**（总解锁，优先级第一——红队四角共指「无持久棘轮则反必输机制全装饰」）；② **三饷→民怨确定性传导**（接 settle_tick breakdown → classes 失望层；islanded，issues.py:2185 明文「联动靠 LLM 不在代码做」= 绞索正反馈环代码层零实现；timing 属实现注记）；③ **确定性 power_tick**（后金/流寇当真活 actor，现有字段无 tick；顺带修死 gate bug：cohesion 永不降 → houjin_split 战机永不触发；后置）；④ **退场 → leverage 联动**（set_character_status 治 B1/#9，= 决定 8 根因）；⑤ **华夷轴不对称**（主和极 emergent 高血债杠杆）。
