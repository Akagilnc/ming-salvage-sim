# 边军军饷并轨：按军 per-source 记欠（省份额欠 + 中央份额欠）× 饷源比例分账 × 派生军饷欠容器 —— Due.军饷 动态化

## Context

#287 从 #261（[ADR 0021](0021-fiscal-cutover-hub-treasury-and-central-leakage.md)）cmr R1–R3 拆出——「省级 `st['军饷欠']` ↔ 按军军饷欠」的并轨在 #261 内三轮收不敛（每轮打补丁、每轮冒新边界），按 cmr drift 规矩回设计层拆出专门 grill。本 ADR 钉死并轨机制；#261 `blocked_by` #287、不在 ADR 0021 展开。**只定设计决策，确切键名 / schema / 管线落点 / 账户名 / oracle 写法留 `/tdd`。**

本 ADR 经 `grill-with-docs` 结晶，期间跑了两道支撑研究：① 明末边军军饷「饷源」史实结构 + 西南土司兵供饷特例（中英文源、对抗校验）；② B 真源模型（按军记欠 / 容器派生）对代码 + ADR 0007/0020/0021 的对抗压测。史实结论：明末边军饷 = 「中央京运池 + 多省协饷」多对多结构，驻防省 ≠ 饷源省，《万历会计录》逐镇分列「主兵年例 : 客兵年例」，欠饷哗变按军 / 营发生（非整镇匀崩），土司兵兵田制自给、出征自筹为主。

> **设计评审 cmr R1 修订**：R1（3 腿，土司守恒洞 3/3 concur）抓出 per-source 精度洞——单标量 arrears + runtime 乘份额会让省偿还补贴中央（F5）、容器聚合误用驻地键（F2）、phase2 留陈旧容器（F4）、土司 arrears>0 破守恒（F1）、k 分母漏中央应付（F3）。本版改采 **per-source 双累加器**（省份额欠 + 中央份额欠），一举收口 F1/F2/F4/F5；F3 扩 k 分母；F6–F10 见各决定。

## 决定

1. **（D1）真源 = 每军 per-source 双累加器（省份额欠 + 中央份额欠），容器派生；旧 `armies.arrears` 标量退役为派生只读合计。** 每支军的军饷欠按饷源记成**两个累加器**：`省份额欠`（由其饷源省财政承担）+ `中央份额欠`（由中央京运承担）。**这对累加器是唯一权威账本**（玩家只见两者**合计** = 该军总欠饷，P4）。**旧 `armies.arrears` 标量退役为「派生只读合计 = 省份额欠 + 中央份额欠」**（cmr R3：现 codebase 多处直读 `arrears`——morale 公式 / 呈现 / danger 排序，故保留为同步只读列向下兼容、不删）；**且 extractor 的 `army_delta.arrears` 直写须被拦截 / 改路由经源感知偿还路径（D7④ 补饷）**——否则标量被直改而两累加器不动 = 第三本账、破唯一真源（现 `db.py` 接受 `army_delta.arrears` 直加，须改）；commitment / 呈现停 gate 读派生合计。各「军饷欠」容器是**同源累加器之和**、每结算 tick 派生、**不自带独立结转**。基座那套 waterfall 守恒算术**原样保留**（[ADR 0007](0007-province-fiscal-substrate-ai-judged.md) G1–G22 不动；G9/G15 golden 期望值随 D8 动态 Due 重算、`/tdd`）；省级聚合**对玩家隐藏**（P4）。压测确认：waterfall 不改、容器派生不破 G9 螺旋 / G15 偿还序。

2. **（D2）饷源 ≠ 物理驻地；饷源 = 每军「省存留 : 中央京运」二元比例。** 一支军的饷记在其**饷源**、不记在当下站的地盘——关宁军北伐到朝鲜边境 / 收复沈阳，饷源仍是辽饷京运、不变成当地出钱。`station/theater` 管物理位置（随调防可变、驱动军事软判），**饷源**管记账归属（稳定、可写字段、驱动军饷欠）。饷源 = 每军一个「省存留份 : 中央京运份」比例（= 《万历会计录》逐镇「主兵年例 : 客兵年例」结构），**该比例只 govern「新欠如何分账到两累加器」**（accrual split），不是 runtime 对单标量乘份额。**`station` 仅作迁移期 seed / 解析的一次性输入，绝不作 runtime 聚合键**（cmr F2）。史实校准示意值：关宁 / 京营 / 山海关 / 东江 `0:100`、蓟镇 `20:80`、宣大 `55:45`、陕西 `65:35`、登莱 `80:20`、南京 / 闽广水师 `100:0`；西南土司 = 自养特例（D6）。**精确比例 = 史实 seed（`/tdd` 按会计录校准）。**

3. **（D2b）两类容器 = 同源累加器之和（聚合键 = 饷源省，非驻地）。** ① 省级 `st['军饷欠']` = `Σ(饷源省 == 该省 的军的 省份额欠)`；② **中央军饷欠账**（新增）= `Σ(各军 中央份额欠)`。**守恒恒等**：`Σ所有容器 == Σ(各军 省份额欠 + 中央份额欠) == Σ非自养军总欠`（自养军 = 土司，两累加器恒 0、排除出此 Σ，见 D6）。因容器就是累加器的直和、无 runtime 乘份额，F2/F5 的「驻地误用」「按比例拆单标量」两洞从根上不存在。基座 waterfall 管省级容器、hub / 中央池管中央容器。**本决定细化 ADR 0021 决定 3 的「单链 国库→京运补→所驻省→驻军」措辞**：中央份额走国库直拨、不全经驻省（关宁军等纯中央养军不依赖驻省基座，辽东失地不成孤儿欠饷）。

4. **（D8）`Due['军饷']` 动态派生（聚合键 = 饷源省）。** `Due['军饷']`（省级月军饷义务）= `Σ(饷源省 == 该省 的军的 月需 × 省份额)`；中央军饷应付 = `Σ(各军 月需 × 中央份额)`（月需沿用 `army_needed` 口径）。静态 `Due` 与「容器 == Σ省份额欠」恒等冲突（waterfall 用静态 45 算欠、军级真实需求是 `Σ army_needed`，对不上则恒等破），故 `Due.军饷` 必须按军需动态派生。**修订 [ADR 0020](0020-fiscal-levy-effect-channel-event-driven.md) 落位契约 5**：月初 applier 的 set-to-target 可写 `Due['军饷']`（军需派生），`Due` 其余项（`官俸 / 宗禄 / 赈济`）仍静态不动。**按 ADR 0021 决定 3④ 的要求**（「若并轨需动 `Due.军饷` 须在 #287 显式修订 0020」），本 ADR 据此显式修订 0020（cmr F10：0021 ④是「须显式修订」的程序条件、非「已预授权」）。玩法属性：军队规模动态影响财政负担（募军 → 省 / 中央负担涨，史实压力；裁军则松）。

5. **（D3）cutover seed 一致 = 按军累加器为真源、容器派生。** 新档 seed 以每军 per-source 累加器为唯一真源（种子单值 arrears 按饷源比例拆成 省份额欠 / 中央份额欠），各容器由 `Σ累加器` 派生写入；删除 / 仅校验 `regions` seed 里独立的 `st['军饷欠']`。cutover 首 tick **reconcile 不变式**：容器 := `Σ累加器`，存量差额**不计欠 / 不生钱**（加 reconcile oracle）。现 seed 矛盾（陕西 `st['军饷欠']=20` vs `shaanxi_army.arrears=25`）以 arrears 为准。**种子土司 `arrears=4` → reconcile 归零**（土司自养、两累加器恒 0），归零记一次性「自养核销」账（写 army_logs / 核销账、**非静默吞钱**，守本不变式，cmr F1）。

6. **（D5）物理调防永不自动改饷源；改饷源 = 皇帝杠杆、归 #260。** 调防 / 出征改 `station/theater`、**不改饷源**（累加器跟军走、容器下 tick 重派生）。皇帝主动「令某省协济某军 / 某军改就食」= #260 action 层（旨意 → 改写饷源比例 / 饷源省字段）；#287 只把饷源做成**可写字段**、不建玩家命令。物理调防与改饷源走「累加器跟军走 + 容器重派生」同一机制。**改饷源省后，该军累加器里积攒的历史 `省份额欠` 随容器重派生（`st = Σ(饷源省==该省的军)`）自动转为新省债务、无需跨省转移结算**（新省接手背账、原省 st 立减——cmr R2，明文点破防 LLM 演绎漂移）。

6b. **（D6）零军省 / 收复省 / 土司特例。** 动态 `Due` 使无省养军的省 `Due['军饷']=0`、无幽灵债（纯中央养省的省份额聚合 = 0、`st = 0`、失地不成孤儿）。**残留**：`省份额欠 > 0` 的军撞「无 settle 基座」的饷源省（收复省 #265 未 seed）→ **fail-loud 报配置错**（守 ADR 0005）；#265 须先 seed 收复省基座 + 其驻军。**西南土司 = 自养特例（C1）**：兵田制自给、**两累加器恒 0、排除出守恒恒等、不入任一容器**，只征调时一次性行粮**走另账**（叙事事件、高自筹、不进军饷欠容器）——消解其「广西 / 云南 / 贵州」一对多 station。**守恒 Σ 右边的「非自养军」精确 = `owner_power == ming 且非土司` 的军**（cmr R2）：`army_needed` 对 `owner_power != ming` 恒返 0（满洲/蒙古/朝鲜/流寇不吃明国库）。**DB 层强约束键 = `owner_power != 'ming' 或 is_tusi → 省份额欠 == 中央份额欠 == 0`（置非零即 `ValueError`）**，**不用「`需 == 0`」作判据**（cmr R3-agy：`army_needed` 对 `manpower == 0` 也返 0，用「需==0」会误杀**有历史欠饷但兵力降为 0 的明军残兵**[D7 明示「零需残军」可携历史欠存在]、又漏拦**兵力>0 的土司**[其需>0 绕过恒 0 保证]）。土司 / 非明军易主（如八旗倒戈归 ming）后按新 `owner_power/is_tusi` 重判口径一致。

7. **（D7）结算算法（源内独立、按军、统一三处偿还路径）+ clamp + 校验 + 核销 + 日志。** 两累加器**源内独立结算**——每源只算自己的应付/实付/缺口/偿还，绝不先求总缺口再乘份额（cmr R3-codex：总缺口×份额会在「省源足额、中央断供」时把中央缺口错摊回省份额、破各销各源）。三处偿还路径在设计级钉死、不留 `/tdd`（cmr R1–R3 实测：留则撞洞、耦合 morale/哗变/US#10）：
   - **① 增债 = 源内缺口（codex R3）+ 当月实付按军分摊（codex R4）**：`省份额欠增 = max(0, 该军省份额应付 − 该军省份额实付)`；`中央份额欠增 = max(0, 该军中央份额应付 − 该军中央份额实付)`。省份额应付 = 月需×省份额、中央份额应付 = 月需×中央份额。**当月该源池只够部分支付时，aggregate 实付按各军「该源本月应付占比」线性摊到各军**（与增债归属同口径、守 Σ；省源用省 settle 当月省份额总实付、中央源用 k 缩拨后中央总实付）——这把 US#10「多军同省欠饷按军合理累积」+ D11 per-army morale 缺口钉死、不留实现自由（codex R4）。各源独立算、各加各累加器、无跨源混。
   - **② 省源自动偿还（phase1，军维度）**：省 waterfall 盈余偿还，按该省各军**偿还时点余额**（opening + 本月新增省份额欠）占比线性摊到各军（cmr R3-Claude：用余额、非纯 opening——余额恒 ≥ 偿还标量、为 0 则偿还标量必 0、自然消除除零，且与增债口径连续）。任何线性摊守 `Σ` 恒等。
   - **③ 中央源（phase1）= 无 hub 自动偿还**：中央 k-tier **只决定当月中央份额缺口是否增债**（当月足额则不增、不动老欠）；**老 `中央份额欠` 不由 hub 自动偿还**（省源有 surplus-waterfall、中央源无——史实京运罕有余，此不对称有意）。
   - **④ 补饷 = 唯一手动偿还杠杆（phase2），对两源都开放（cmr R3-Claude）**：玩家补饷指向某军时，按该军**当前 `省份额欠 : 中央份额欠` 实际欠额占比**（非饷源比例——欠额占比才「补多少销多少」）分销到两累加器，**同一事务原子重算该军饷源省容器 + 中央容器两者**。这给纯省源军（南京/闽广水师 100:0）、混合军、纯中央养军都一条补饷偿还路——否则纯省源军「补了饷不销欠、照旧哗变」复活 US#2 要消灭的反模式。补饷是省财政塌、省 waterfall 无盈余时玩家的偿还手段。
   - **⑤ 各销各源、无跨源补贴**：省 waterfall 只动省份额欠、中央只增中央份额欠、补饷按实际欠占比分两源——省现金绝不替中央自动销账。
   - **clamp**：各累加器 `≥ 0`（守 `fiscal_tick.py` 负军饷欠 `ValueError`）；偿还额 = `min(可用, 该源该军累加器欠)`，**残余留 surplus / 现金、绝不灌进容器**（容器是派生直和、非 sink）。
   - **份额校验**：seed / #260 写饷源比例须断「省 + 中央 == 1（非自养军）/ == 0（自养军）」，违则 fail-loud（cmr F6）。
   - 新军两累加器 = 0；零需残军不分账；**军被歼 / 裁撤、或 `owner_power` 转出 ming（投敌 / 易主，使 D6 强约束要求归 0）→ 有非零累加器时必先写显式核销账（army_logs）再置新 `owner_power` / 删除，绝不静默清零**（cmr R4/F8：否则有欠饷明军易主即静默抹债、破审计链）。每笔分账 / 偿还 / 核销 + 所用分摊算法写 army_logs（actor = 户部 / 兵部）+ 并入 oracle。

8. **（D4）相位插点（细化 ADR 0021 决定 7 + ADR 0020 §6）。** 同一 `pre_settle` atomic 内：**tick 入口**（`settle_province_tick` 之前）算各军月需 → 派生写各省 `Due['军饷']` + 中央军饷应付（amended applier）→ reconcile 容器 := `Σ累加器`；**③ `settle_province_tick`** 用动态 `Due` 跑 waterfall、付军、省份额源**增债（源内缺口）/ 盈余按余额占比偿还各军 `省份额欠`**（D7①②）；**④ hub** 中央军饷应付由国库 / 京运补付（k 缩拨后）、**只按当月中央份额未付增 `中央份额欠`、不销老中央份额欠**（D7③——cmr R3：删原「销中央份额欠」措辞，与 D7③ 一致、消内部矛盾）。**③④ 的源内缺口都用 tick 起始累加器值算**（两步先各算、再应用），消除「中央看到省已改 arrears」的顺序依赖（cmr F7）。**该「tick 起始值」仅 phase1 内存临时**（消 ③↔④ 顺序依赖用）、**不持久化到 DB、不在 `ready=1` phase2 重放中作读源**（cmr R3-agy：phase2 不重跑 ③④、补饷用当下 arrears、强读冻结值反而抹当月变动）。**phase2 补饷**按该军实际欠额占比分销两源 + **原子重算该军饷源省容器 + 中央容器两者**（D7④）；**restore oracle**「phase2 后 DB 即满足 **两类容器都** == Σ累加器」（cmr F4/R3）。**morale 更新插在 ③④ 之后**（两源本月缺口都算出后才扣 morale，因 D11 缺口 = 省 + 央两源本月缺口之和）；**省份额本月缺口（流量）随「tick 起始值」同属 phase1 内存临时**、供 morale 合并两源缺口用、不持久化（cmr R4：morale 是与 ③↔④ 同型的跨相位流量依赖，显式留插点）。**两前置序**：饷率前置 → `Due.军饷` 派生前置 → 京运补前置。`ready=1` 只重放 phase2（补饷幂等）。确切插点 `/tdd`。

9. **（D9）中央军饷应付 = 第二条中央 outbound，复用既有损耗、k 分母含整个边饷 tier。** 中央养军（关宁/京营等）的「中央军饷应付」与京运补并列为 hub 层中央 outbound，**同吃** ADR 0021 决定 6/7 的**京运转运损耗**（途中克扣/运损）+ 决定 8 的 **k 缩拨**。**k 分母须含整个最高优先 tier（cmr F3）：`k = min(1, 国库可用 / (Σ应拨京运补 + Σ中央军饷应付))`**——否则两条同 tier outbound 各按 `k=min(1,国库/Σ京运补)` 缩拨会超拨（国库 100 / 京运补 100 / 中央应付 100 → 旧式 k=1 → 合扣 200）。零分母（**两项和** `Σ应拨京运补 + Σ中央军饷应付 == 0`）→ k=1、outbound 各 C_ 置 0。**ADR 0021 决定 8 的旧零分母判据 `Σ京运补 == 0` 收口为两项和**（cmr R2）：单项为 0、另一项 > 0（如京运补省全失地但关宁 / 京营纯中央养军仍在）时**仍按合并分母缩拨、不短路 k=1**。**Hub outbound 守恒不变式 = 本 ADR 取代 ADR 0021 决定 5 原式**（cmr R2/R3：0021 决定 5 原「`国库京运补拨出 == Σ各省实收 + 京运转运损耗`」单 outbound、漏中央养军那两项、非等价细化，故为「取代」非「并存」）：`国库京运补拨出 + 国库中央军饷拨出 == Σ各省实收(gross_after_central_transport) + 京运转运损耗 + Σ中央养军实收 + 中央养军转运损耗`。中央养军本月**实收 = 中央应付 × k − 转运损耗分摊**，欠饷累在此 gap（关宁军欠饷 = 「国库赤字 + 中央漏损」的可见后果，皇帝反腐压人为漏损 / 补国库抬 k 即降欠 = 冰汽时代杠杆）。**细化 ADR 0021 决定 8 优先序**：中央军饷应付与京运补同属边饷最高优先 tier（先于百官俸 / 建筑维护）。**不新建损耗账户**，复用 ADR 0021 既有四 C_ 账户。

10. **（D10）呈现契约：军饷欠是真钱、可出 approximate 奏报数；细化 P4。** P4「不见裸数值」严格版针对**抽象 stat**（忠诚 / 能力）；**财政钱数（军饷欠、国库，万两）是 ADR 0007 铁律 3 的「真钱进预算流」、不是抽象 stat**，故军饷欠**可以 approximate 奏报口吻数字呈现**（「辽东边军欠饷已逾二十万两、军心浮动」= 数字 + 定性军心，史实题本口吻），不出裸数值表。玩家见的是该军**总欠饷**（两累加器合计），不见省 / 中央分账。**未来精度 hook**：报数 ≠ DB 直读，挂奏报者 忠诚 / 派系 / 实力（贪官瞒克扣少报、政敌夸大构陷、忠能之臣报准）——即 P4 已配「锦衣卫查家产不保准、精度挂阴谋类能力」的财政镜像。**那些机制未实装时，占位 = 报实际欠饷大概数**（可接受）。抽象 stat（忠诚 / 能力）仍 qualitative-only、不松动。呈现叙事本体由 LLM 层（season_simulator 等）生成、#287 只定数据 + 此契约。

11. **（D11）哗变 substrate（#287 侧）+ 哗变状态机（军事线、单独 issue）。** 哗变属军事后果线、非财政；#287 只产**底料**两件：① 把 `arrears → morale` 确定性公式（欠饷 `morale_delta = -max(1, round(8×缺口/应发))`、足额无欠 `+2/月`）从**退役的旧发饷路搬进新饷源比例结算**——防回归（cutover 后 morale 仍随欠饷动、否则哗变底料断）。**口径（cmr R2/R3）**：`应发 = 该军本月总月需 army_needed（= 省份额需 + 中央份额需）`（与旧路单一 needed 同源）；`缺口 = 省份额本月缺口 + 中央份额本月缺口`（两源本月**流量**欠发、各在其相结算时点取、**非存量总欠饷**）、且 clamp 到 `[0, 应发]`（防两相 clamp 后相加越界使 `8×缺口/应发 > 8`）；旧公式当月发足但有旧欠时 `morale_delta=0`，故**旧欠只决定「是否允许足额无欠 +2」gate、不进每月扣分**（用存量总欠会重复扣士气、改 morale 动力学）；② provision 军队 `哗变` 旗标字段（#287 加字段、留空，军事线填）。**哗变状态机本体** = **军事线第一片独立 issue（`blocked_by` #287）**、不在本 ADR / #287 展开：确定性触发地板 `morale ≤ 阈值` + LLM 软判 / 剧本事件入口；后果 = 0 战力 + 不听调遣 + 仍占军需；恢复 = 补饷清欠 + 持续足额 → `morale` 滞回过较高阈值解除（单信号 `morale` 编码「补没补 + 撑够没」、入低出高滞回防抖）。阈值精确值 = seed / `/tdd`。

## Considered Options

- **省级 `st['军饷欠']` 自带结转、按军是其切片（D1 反选）**：要三处显式同步（seed / 补饷 / 调将），正是 #261 收不敛那片 bug 面。改按军 per-source 累加器为真源 + 容器派生，三问题随「容器永远 == Σ同源累加器」化解。
- **单标量 arrears + runtime 乘份额（cmr R1 前的初版，已否）**：cmr R1 实测三洞——省偿还按比例减单标量 → 补贴中央（F5）、容器误用驻地聚合键（F2）、phase2 留陈旧。改 per-source 双累加器：份额只管 accrual 分账、偿还各销各源、容器是累加器直和，三洞从根消除。
- **每军单一饷源省（D2 反选 A）**：史实 poor——边军饷是中央京运 + 多省协饷多对多、驻防省 ≠ 饷源省；硬绑单省把辽东（无税基）错当关宁军出饷主体、且辽东失地即孤儿。
- **多省协饷逐军分摊到各省（D2 反选 B）**：游戏已用「起运 → 国库 → 京运补」抽象协饷，再逐军多省分摊 = 重复建模；改「省存留 : 中央京运」二元比例（= 会计录主兵 : 客兵年例）。
- **静态 `Due['军饷']`（D8 反选）**：与「容器 == Σ省份额欠」恒等冲突，且军规模不影响省负担（失真）。改动态派生。
- **土司硬挂单一省 / 计入守恒 Σ（D6 反选）**：土兵兵田制自给、不吃常规省饷，硬挂任一省常态错耗其国库、且 arrears>0 即破守恒恒等（cmr F1）；改自养特例、两累加器恒 0、排除出 Σ。次优工程妥协（若引擎强制每军挂省）= 挂四川（石柱土司本籍 / 集结地），须设极低常规负担 + 征调行粮另账。

## Consequences / 落位边界

- **修订 ADR 0020 落位契约 5**：applier 放开写 `Due['军饷']`（军需派生），其余 `Due` 项不动（按 ADR 0021 决定 3④ 要求显式修订，非「预授权」，cmr F10）。**新数据依赖（cmr R2）**：applier 派生 `Due['军饷']` 须读各军 `饷源省 + army_needed + 省份额`（即 applier 阶段新增对 armies 表的读 / JOIN；`饷源省` 字段须在此前 seed / 迁移已填，不用 `station`）。
- **细化 ADR 0021**：决定 3 单链措辞补「中央份额国库直拨、不全经驻省」；决定 7 子相位序补「`Due.军饷` 派生前置 + 省级 / 中央缺口·偿还插点 + tick 起始值分摊」；决定 5 outbound 不变式**取代**为含中央养军的四项式（D9，cmr R3）；决定 8 补「中央军饷应付与京运补同属边饷最高优先 tier」+ **`k` 分母扩为 `Σ应拨京运补 + Σ中央军饷应付`**（D9，cmr F3）。
- **旧 `armies.arrears` 标量退役**（cmr R3）：保留为派生只读合计（= 省份额欠 + 中央份额欠、DB 同步），现有读路径（morale / 呈现 / danger 排序）向下兼容；拦截 / 改路由 extractor `army_delta.arrears` 直写（防第三本账）。
- **新增容器 + 字段**：每军 per-source 双累加器（省份额欠 / 中央份额欠）+ 饷源比例字段 + **饷源省字段** + **自养判别字段（`is_tusi` 或更通用 `self_funded_pay`/`pay_exempt`，D6 强约束 + Σ 排除依赖它，现 `armies` schema 无、须新增；seed / 新建军 / owner_power 变更路径一起维护，cmr R4）**；中央军饷欠账 + 中央军饷应付（hub 层），与省级容器对称；并入 hub 守恒 oracle（仅测试期）。中央军饷应付**复用** ADR 0021 决定 6/7/8 的损耗 + k，**不新建损耗系统**（D9）。
- **守恒不变式（承重，进 oracle）**：`Σ所有容器 == Σ非自养军(省份额欠 + 中央份额欠)`，破即 `SettlementAbort`；土司军两累加器恒 0（DB 强约束）；饷源比例和 == 1（非自养）/ 0（自养），seed + #260 写时 fail-loud 校验；cutover reconcile + phase2 补饷后 DB 即满足容器恒等（restore oracle）。
- **呈现契约（D10、细化 P4）**：军饷欠（真钱万两）可 approximate 奏报数呈现、非裸数值表；玩家见总欠饷、不见省/中央分账；未来挂报者忠诚 / 派系 / 实力。**注**：CLAUDE.md 的 P4 措辞或可补一句「财政钱数 vs 抽象 stat」澄清——属用户原则、留用户决定、本 ADR 不擅改。
- **依赖**：#265（收复省 seed settle 基座 + 驻军，否则省份额军撞空 fail-loud）；#260（玩家改饷源 action）；#70（全省 seed）。#261 `blocked_by` #287。
- **实现留 `/tdd`**：饷源比例精确值（会计录校准）、累加器 / 容器键名 / schema、分账·偿还·核销算术、相位确切插点、reconcile / 分账 / 守恒 / restore oracle、army→饷源省 解析 + 可写字段 schema。
- **状态**：`proposed`（`grill-with-docs` 结晶 + 设计 cmr 进行中；收敛后 → `accepted`）。
