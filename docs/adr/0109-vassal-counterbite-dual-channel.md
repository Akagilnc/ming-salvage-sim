# 0109: 宗藩反制双通道——0101 row④ 反咬内容 + 0091 发难门宗室输入扩展

Status: Proposed（决策：2026-07-08 #87 宗藩闸 grill Q1/Q2/Q3 用户拍板〔口径 3′ + 双通道 + 自发栏加宗禄欠水位〕；承 0101 目标类别 cap 表第④行「阶层阻力/串联反制面归 #87」+ #112 收口 + 0106 勋戚同族先例）

宗藩（宗室藩王）被打击时与积怨时的反制**走两条现成通道、不建第三条轨**：

- **挨打反咬** = 并入 **0101 反咬评估**（resolve 判打击宗藩类动作时同步评估），row④ 填宗藩版档位内容（档位表见 0110）——同 0106 勋戚收编先例，零新层零新轴（守 0065 红线：场外阶层不进颁布关、不为其建任何新数据轴）。
- **平时自发** = **0091 发难门宗室专属输入扩展三条**（M12 已把门输入扩到读血债/wariness，本 ADR 再扩宗室侧）：①**宗室派系血债水位**（0011-2 `faction_axis_debt` 现成账）；②**宗禄欠水位**（读 `fiscal_tick` CLAIM 键「宗禄欠」现成账，读端接线零新账——皇帝一旨不下、宗禄常年欠着怨气也涨；与军镇「军饷欠→0025 军心→哗变」同语法的第二条欠账线，两条欠账线一个语法）；③**已 fire 危机事件**（请援形态，输入与 0011-4 D4-3「代价明白度」同批：已 fire 史实危机 events + unrest 过阈，见 0114 件④）。自发出戏形态 = B 档族（联名讼冤/请复宗禄/哭庙），烈度随水位、不另设升档。

**同一怨源两通道 = 出戏两次、不记账两次**：两通道读同一本账（0037 入账即入机制，账本单一），挨打当场反咬 + 后续持续闹是史实形态，非重复记账。

**划界两条（口径 3′ 收口，用户拍）**：①**继统 defer**——前置 = 储位 substrate + 事件燃料（现册无太子/皇子，朱慈烺不在 101 人名册；无读端的设计即变纸，#151-154 清账教训）；南迁/立储的命门分类 0011-4 D4-4(c) 已兜底，不欠债。②**宗禄债权/捐输义务细化归财政线**（#70 cutover）——本家族只**读**现成宗禄欠 CLAIM，不动财政 schema；撤捐输无常设账可撤（捐输仅为 extractor 入账词），作为 B 档武器只在皇帝索捐类动作的对抗中表达。

**毙案**：独立「宗藩阻力轨」（第三条评估机制）＝重复载体，毙；经济反制单独成第五档＝破坏烈度轴单调、捐输侧无常设账半边是纸，毙（经济怨源改走自发门宗禄欠输入，见上）；宗藩建颁布否决层/新数据轴＝违 0065 红线，毙。
