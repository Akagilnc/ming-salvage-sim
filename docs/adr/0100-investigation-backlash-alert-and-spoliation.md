# 0100: 查案过程反噬＝打草惊蛇 + 毁证（时机有真重量）

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G1c 用户拍「反噬全建」，本 ADR 收其过程反噬子集〔打草惊蛇 + 毁证〕；承 #555/#87/#89）

查案取证（本批 0098 的确定性查案差务轨）带**过程反噬两面**，让「查得早不早」有真重量、堵「零成本信息按钮」。**① 打草惊蛇**：每月差务进展推进时 roll 目标是否察觉（概率＝目标 `characters` 阴谋能力〔G8 本轮 substrate 同批建的 per-人阴谋 int〕vs 办差方差务能量，首版随 playtest），命中则目标及其所属 faction **wariness↑**——复用 0011-2「同类防备棘轮」`faction_axis_debt.wariness` 单调防备列、走既有 `kind='kinship'` accrue 写路径，**零新轴/零新表**（轴路由沿 0011-3 目标感知撞轴集，PRD 定）→ 后续查案遮蔽加重（查案变慢）、清算反应更敏感。**② 毁证**：察觉后该查案的**「可坐实上限」降一档**（＝能走到的坐实**路径**档，非 0011-4 的阻力 ceiling）——`seed_guilt` 真相底不动（真源 0011-4 B / 0011-2 crime_weight），但依律路（`reason_code ∈ 依律集`〔0011-2 D2-5〕坐实 → 0011-4 D4-4 翻轴塌阻力 ceiling）可被**毁死**，依律路一断即无从翻轴、极端只剩罗织路（STIGMA、cw=1、血债满档的 0011-2 D2-4/D2-5 恶路）。故「查晚了＝永久损失」，时机有真重量。

**复用点名**：差务/进展＝本批 0098（承 0092 带宽 + 0058 进展轨）；wariness＝0011-2 现成防备列 + `kind='kinship'` accrue 写路径；真相底/依律集/罗织/翻轴＝0011-2 + 0011-4；阴谋能力＝G8 同批 int。**净新契约仅两条**：(a) 惊蛇 roll——概率函数口径本轮 PRD 定，命中即对目标 faction 累一笔 wariness（0011-2 kinship 路）＋加重该查案差务遮蔽因子；(b) 毁证降档——一条「察觉 → 可坐实上限降一档（关依律路、留罗织路）」规则，首版降档量随 playtest（同 0011-4 D4-6 先例）。**毙案：查案零反噬（免费按钮）＝ 时机/阴谋能力/办差方三者全无重量、查案退化为无痛信息按钮（违「时机有真重量」设计意图 + 母 ADR 0011 organic 非剧本），毙。**
