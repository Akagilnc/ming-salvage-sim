# 0100: 查案过程反噬＝打草惊蛇 + 毁证（时机有真重量）

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G1c 用户拍「反噬全建」，本 ADR 收其过程反噬子集〔打草惊蛇 + 毁证〕；承 #555/#87/#89）

查案取证（本批 0098 的确定性查案差务轨）带**过程反噬两面**，让「查得早不早」有真重量、堵「零成本信息按钮」。**① 打草惊蛇**：每月差务进展推进时 roll 目标是否察觉（概率＝目标 `characters` 阴谋能力〔G8 本轮 substrate 同批建的 per-人阴谋 int〕vs 办差方差务能量，首版随 playtest；**roll＝0098 轨级确定性伪随机口径**〔(game_seed, turn, roll_domain=`investigation_alert`, 差务 id) 派生、domain 盐隔离、重放/restore 可复现〕），命中则目标及其所属 faction **wariness↑**——复用 0011-2「同类防备棘轮」`faction_axis_debt.wariness` 单调防备列与 accrue 单一写函数，**零新轴/零新表**；⚠️ 惊蛇是**侦测型事件、非惩罚事件**，accrue 的 kinship 入参按侦测语义合成：severity＝惊动强度（首版常量）、legitimacy_pct＝100（无法理折扣）、axis 沿 0011-3 目标感知撞轴集——入参口径由本批 PRD 钉，**「复用写路径」收窄为「复用列与写函数、入参侦测语义新定」**（0011-2 CHECK 强制 kinship 行 base/legitimacy_pct 非空，此处即其取值）。同一事件每轮对同 faction 至多累一笔（0079 式事件 id 幂等键，与 0101①/0102③ 的 wariness 源统一去重）→ 后续查案遮蔽加重（查案变慢）、清算反应更敏感。**② 毁证**：察觉后**可坐实上限降一档，作用域＝在查的那条可坐实事实**；**案级惊蛇→lane 选择（cmr 勘正）**：惊蛇 roll 是案级（investigation_alert＝差务 id），命中时毁证作用于**当月进度最高的那条 lane（确定性选一）、绝不跨 lane 团灭**——「不团灭」为不变式非旋钮（守本条救济保底），lane 选择细则首版随 playtest（键同 0098：seed_guilt 记录键＝(target)、把柄边键＝边事件 id；＝能走到的坐实**路径**档，非 0011-4 的阻力 ceiling；绑定事实而非差务——关差务重开**不重置**已毁项，毁证不可绕）——`seed_guilt` 真相底不动（真源 0011-4 B / 0011-2 crime_weight），但该事实的依律路（`reason_code ∈ 依律集`〔0011-2 D2-5〕坐实 → 0011-4 D4-4 翻轴塌阻力 ceiling）可被**毁死**。**救济路存在、不设死锁**：其余可坐实事实（各把柄边独立成键）不受累，且 0098 可坐实集是 live 集——运行期新长的把柄边（策反证词 0103／密令暴露 0107＝**新事实、非旧证**）可再战；倒魏锚可玩性由此保底（魏＝seed 罪谱一条＋**把柄网多边**〔0086〕——毁谱不毁边、边各自可再战，多路非多罪项）。全部旧证被毁的极端＝该 target 该批只剩罗织路（STIGMA、cw=1、血债满档的 0011-2 D2-4/D2-5 恶路）或等新事实。故「查晚了＝真损失」，时机有真重量而不锁死。

**复用点名**：差务/进展＝本批 0098（承 0092 带宽 + 0058 进展轨）；wariness＝0011-2 现成防备列 + `kind='kinship'` accrue 写路径；真相底/依律集/罗织/翻轴＝0011-2 + 0011-4；阴谋能力＝G8 同批 int。**净新契约仅两条**：(a) 惊蛇 roll——概率函数口径本轮 PRD 定，命中即对目标 faction 累一笔 wariness（0011-2 kinship 路）＋加重该查案差务遮蔽因子；(b) 毁证降档——一条「察觉 → 可坐实上限降一档（关依律路、留罗织路）」规则，首版降档量随 playtest（同 0011-4 D4-6 先例）。**毙案：查案零反噬（免费按钮）＝ 时机/阴谋能力/办差方三者全无重量、查案退化为无痛信息按钮（违「时机有真重量」设计意图 + 母 ADR 0011 organic 非剧本），毙。**
