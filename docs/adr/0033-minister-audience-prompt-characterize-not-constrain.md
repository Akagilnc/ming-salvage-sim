# 大臣召对 prompt = 客观特征化，不做形式约束、不做输出守门

Status: Accepted（2026-07-02：本地 cmr 3 轮收敛（codex+agy+Opus4.8）+ 线上 bot 评审收敛，PR #495）

## 决定

被召见者（大臣/太监/将领）的召对 prompt 是对「**这个人是谁 + 这个党是什么 + 他对党的认同度**」的**客观特征化描述**，不是给模型下的一串指令/规矩：

- **人物**：身份/脾性/动机/包袱的客观描述 + **一些事例**（用实例立起"他是谁"）。
- **党派**：这个党是什么样一伙人、要什么、什么做派的**客观陈述**（不写"阉党就该拖延构陷"当行为命令）。
- **认同度**：见 CONTEXT「[党派认同度](../../CONTEXT.md)」——per-character 数值（本质动态、探针期可静态），按分桶选 per-faction 档料；最低桶≈不喂党派料。
- **零形式约束**：不限字数、不限结构（放开上/中/下策式分条陈策，护栏只留"像奏疏不像 PPT"）、**不给可照抄的范例 few-shot**。深度/结构由模型"成为这个人"自然长出，不由规则逼出。**本约束覆盖整条组装链**：上游调用方/组装器/编排层同样不得再施加长度、结构类形式约束（线上 R1 Sourcery：防止约束在别的层偷偷加回来）。

## 为什么

现役 `content/prompts/minister_agent.md` 满是形式约束（80-220 字硬顶、禁清单/论文、"言辞分寸自己悟"却无范例）且特征稀薄（只喂派系数值 + 名册）→ 逼出"公文报告体"。北极星那种深奏对（毕自严五事、杨嗣昌上/中/下策）不是被要求写的，是模型"成为毕自严"后自然摊出；**约束把模型压扁，范例让它模仿一个样本而非成为这个人**。这也解释了 bench 判上线腿"公文体"——是拿这份薄 prompt 测的、测的是 scaffolding 不是模型天花板。

## 否决的备选（防日后重议）

- **加 few-shot 范例 + 抬字数上限**（本 grill 一度推荐，已否）：范例=模仿一个样本、抬上限仍是"约束思路"，治标不治本。要的是**厚特征化 + 放开形式**。
