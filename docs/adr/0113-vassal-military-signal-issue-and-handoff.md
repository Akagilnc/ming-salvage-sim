# 0113: 藩府异动 issue——军事苗头留痕、军事线交接实体、唐王圈禁锚

Status: Proposed（决策：2026-07-08 #87 宗藩闸 grill Q6 用户拍板〔形态 2 + 唐王锚〕；承 0110 D 档、0101 row④「带兵作乱归军事线」口径）

D 档「藩兵苗头」触发 → 产**「藩府异动」issue**，绑（藩王，就藩省）：内容＝请增护卫/结交军镇/缮甲募兵风闻；在场进盘面喂判官（同 0111 语法）。**本闸不机制化真叛乱。**

**对治面**：遣官按问、削护卫、圈禁——圈禁本身是打击动作、再入反咬评估，但**依律有据则封顶 A**（藩王擅动兵本身违祖制、可坐实 → 走 0011-4 D4-4 翻轴），语法自洽不递归爆炸。三手段机械路由（线上 R1 勘正，零新 enum）：**圈禁/削护卫＝打击动作词表现成族**（进 resolve；圈禁落 characters 状态现成机制，削护卫落藩卫资产轻档处置）；**按问＝差务类**（0098 差务轨现成形态，查案式遣官）——具体词表扩条与状态值归 S5 切片验收，本 ADR 只钉路由归属。

**军事线交接契约（一句话钉死）**：藩兵**真武装化/举兵**的判定与后果归军事线（0025 哗变状态机/#299 后续，同 0101 row③ 军镇口径——缺口显式承认、非遗漏）；**本 issue 即军事线将来的交接实体**——军事线开闸前，issue 只恶化/持续，**不自行变成叛乱**。

**史实锚：唐王朱聿键 1636 擅勤王出兵 → 圈禁凤阳**。双向立范：①「苗头≠叛乱」——明代藩王连勤王都被办，D 档 fiction 的烈度上界即此；②给依律对治路背书——藩王动兵违祖制、天然有据可坐实，圈禁走依律集即安全。唐王入册＝可选 seed 数据件（非本闸硬件，实现侧定；现册福王/桂王/幼藩已够 D 档取材）。

**毙案**：直接接 0025 哗变状态机＝0025 是 armies 实体键控、藩卫非 army，接它须建新 substrate、越军事线界，毙；纯叙事纹理（探子回报无结构）＝违 P1（restore 后世界忘了某王在缮甲），毙。
