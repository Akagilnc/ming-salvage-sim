# 饷率 effect 通道 = 史实时间线事件（结局即决策）+ 读事件结局算确定性增量；结局由圣旨（#260）/shadow stub 置；起运 = 通道基线（正赋基线 + Σ在征三饷）、玩家偏移归 #260

Status: Proposed（2026-06-20 grill 结晶；2026-06-21 设计 cmr R1 折叠引入「饷别决策态」字段；**同日 cmr R2 折叠：单独决策态字段引出粒度/寻址/截留三洞 → 改为「事件结局即决策」回归纯 ADR 0014**，见决定 1–2 + Considered Options。待 cmr 收敛转 Accepted。）

## 背景

[ADR 0019](0019-fiscal-cutover-all-province-seed-hub-split.md) + [FISCAL_PROVINCE_SUBSTRATE.md](../FISCAL_PROVINCE_SUBSTRATE.md) §#70 把「三饷时间线注入 + 起运定额联动选型」deferred 给 #259。#70 只静态 seed 开局辽饷九厘。

#259 grill 揭示定调更正：三饷是史实里**皇帝的决策**（加则民变深、不加则边军溃），不是无声改数。设计 cmr 两轮进一步收敛**它在引擎里的落法**：

- **R1**：「准奏后才落」是 ADR 0014「触发即落」两类之外的第三类 → 曾试图引入单独的「饷别决策态」字段承载。
- **R2**：单独决策态字段引出三个新洞——粒度（per-省 vs 全国一道旨意）、寻址（`settle.p` 里的态不可被 `trigger_gate` 寻址，引擎门只认 `event.<id>.{triggered/terminal_state}`）、截留矛盾（「增量共存」与「硬下界」站不住）。**本 ADR 改为「事件结局即决策」**：决策不另存字段，就是那道加饷历史事件的**结局**（ADR 0014 已有的「事件结果记录」），全部三洞随之化解。

## 决定

1. **（D1）时间线 = 史实事件生成器，事件结局即决策。** 到史实时点生成「军费危机 → 是否加这道饷」的**历史事件**（[ADR 0014](0014-historical-event-trigger-and-effect-model.md)），摆两难。**该事件的结局 ∈ {已准 / 已驳}（议停事件：{已停 / 仍征}）就是「加不加这道饷」的决策**——**全国一道旨意、一事件一结局**（per-省只是各自校准的增量额，非各省独立决策）。结局由 **#260 圣旨置定**（shadow 期用显式 stub 置史实默认 = 已准、明标 #260 替换）。**复用 ADR 0014「事件结果记录（终态 + 结局标签）」承载，不另造决策态字段**（cmr R2）。

2. **（效果 = 读事件结局算确定性增量）** 确定性效果**读事件账**（在征 = 开征事件结局 == 已准 ∧ 对应议停事件结局 ≠ 已停；**议停被驳「仍征」仍算在征**——区别于议停**门**的「¬议停已发」，那只管不重复弹）→ 定当前**在征饷集** {辽? 剿? 练?} → 算各省 `settle.p`：`三饷应征 = Σ(在征分量，逐省校准)`、起运联动（决定 5）、v23 `火耗应派=(正赋+三饷)×火耗率` 派生。**幂等 set-to-target**（每 tick 按当前在征集重算到目标值，**不逐月叠加**——cmr R2 防重复加）。**#259 定义事件 + 结局标签集 + 读结局的确定性效果，不实现圣旨路由**（结局的置定 = #150/#260）。

3. **（D4b）军费危机触发门 = 天定。** 军费窟窿如期出现（根因不在 #259 范围），皇帝杠杆是「加这道饷 vs 另寻财源/硬扛民变」；**破局不在让战争消失**（越界战略线），在上行软判（追赃/挪借/招抚/清丈，#260/软判）。

4. **（D3）升降通吃 + ADR 0014 事件链门（读事件账，非活财政软读）。** 既生成开征/升率，也生成议停。**议停剿饷的触发门 = `剿饷开征.结局 == 已准 ∧ ¬剿饷议停已发`**——纯 ADR 0014 事件账寻址（`event.<id>.terminal_state/结局`，cmr-β 化解：不再读 `settle.p` 里的活态）。剿饷开征未达已准（未触发/已驳）→ 议停按 ADR 0014 级联**作废**、不空弹。准奏议停 → 剿饷议停.结局 = 已停 → 在征集去掉剿饷 → 效果回退其分量、起运回落。

5. **（D2）起运 = 通道基线（正赋基线 + Σ在征三饷），不是最终定额的硬下界。** 通道把 `settle.p` 起运定额设为**通道基线 = 正赋起运基线 + Σ(在征三饷分量)**（正赋基线 seed 定、由月初 applier 读 `settle._meta`/seed——**非 `settle_tick` 读**，cmr-P2 化解）。**这是通道自己的基线贡献，不是最终起运定额的硬下界**：玩家的缓起运/截留（#260/软判破局）在基线之上**另施偏移、可下压**——能否压穿「正赋解京」是 **#260/ADR 0011 的产品判断、scope 出 #259**（cmr-γ 化解：基线与玩家偏移不在同一层，无矛盾）。**通道不变式 = 「通道基线 == 正赋基线 + Σ在征三饷」**（守三饷全解 + 通道自身不抹正赋基线）。不拆三饷-正赋为对外字段（#261 hub 才消费），内部留正赋基线。

6. **（boundary）#259 全程 shadow、不吞邻项。** 起运到京只算/打印（hub = #261）；**结局的置定（圣旨准/驳）+ 玩家起运偏移（截留/缓起运）= #260/#150/ADR 0011**；#259 = 生成事件 + 定义结局集 + 落「读结局的确定性增量」+ 保持辽/剿/练分量可归因，止于此。

## Considered Options

- **单独的「饷别决策态」字段（cmr R1 引入）**：**R2 否决**——per-省字段引出粒度矛盾（全国一道旨意 vs per-省态）、寻址洞（`settle.p` 态不可被 `trigger_gate` 寻址）、截留-vs-下界矛盾。改用「事件结局即决策」（决定 1）回归纯 ADR 0014，三洞一并化解。
- **统一通道（历史事件与皇帝旨意同一套机制）**：否决——确定性历史与 LLM 软判代价纠缠、违 ADR 0007 边界；拖入未完工 #150。
- **时间线强制注入（无玩家 agency，到点直接改三饷）**：否决——抹掉核心两难、违「皇帝角色保真」。cmr R1 实证「shadow 自动应用史实默认」= 这条复活 → 由「结局即决策 + 显式可替换 stub」消解。
- **复用 `effect_on_trigger` 触发即自动落**：否决——承载不了「结局决断后才落」的 gating、且绝对设冲玩家调整。改用读事件结局 + 幂等 set-to-target。
- **拆三饷-正赋独立起运对外字段**：暂否——只有 #261 hub 才消费、违 boundary；内部留正赋基线已足。
- **可避/半可避触发门（平辽 → 免辽饷）**：否决——要求判定战略状态，越界；破局靠上行软判。

## Consequences

- **取代 FISCAL/#259 把三饷写成「到点直接改三饷应征」「触发即自动落」「单独决策态字段」的措辞** → 「到点生成事件；事件结局（#260/stub 置）即决策；效果读结局算确定性增量」（FISCAL §#259 + PRD 同步）。
- **ADR 0014 微补一笔**：事件结局除「软判收敛到标签 / 天灾处置自动」外，**可由玩家圣旨（#260）置定**（加饷 = 决树结局事件）——**无需新字段、无需扩门语法**，结局走现成「事件结果记录」、门走现成 `event.<id>.结局`。此「圣旨置结局」的通用化留 ADR 0014 后续，本 ADR 只为饷率立。
- **#259 可在 #150/#260 未动时独立设计/推进**：定义事件 + 结局集 + 读结局的确定性增量 + 显式 stub 置结局；**完整可玩闭环**（皇帝实际经圣旨准/驳）待 #260/#150。#259 单独 DoD = 「事件按史实节奏与链门出现 + 给定事件结局时 shadow 末态可断言验证 + stub 可被 #260 无缝替换」。
- **失地/收复（cmr-G）**：结局是**全国单值**（一事件一结局）→ 无 per-省分歧；饷率增量算到**全 17 seed 省 `settle.p`、不论控制方**（动态成员谓词只管「是否 tick/settle」、不管「是否收 rate 更新」）；失地省 settle.p 按在征集算、收复即现行饷率（与 #265 邻接）。
- **起运不变式落在「通道基线」、非最终定额**——通道保证基线 = 正赋基线 + Σ在征三饷；玩家偏移（#260）在其上另算，能否压穿正赋解京由 #260/ADR 0011 判。
- **正赋基线由月初 applier 读**（`_meta`/seed），`settle_tick` 只读 `settle.p` 合成值；幂等 set-to-target 防每月重复叠加。
- **万两估算口径（cmr-F）**：加饷是全国一道旨意 → 奏报估算用**国总加征所得 vs 国总军费缺口**（可附各省分解），不对单省缺口比。
- **精度沿用 #70**（量级定稿、田亩占比折算、`_meta.provisional`、一手《会计录》#272 deferred）；月份锚该年正月（provisional、`_meta`）。
- **cutover 后（#261）** 确定性效果从 shadow 隔离相位转 fail-loud；**shadow stub 在 #260 落地时替换为真圣旨置结局**。
- **确切字段名 / schema 细节留 #259 `/tdd`；但接口契约（结局承载 / 在征谓词 / baseline 分键 / applier 写集）由下「落位契约」在设计级钉死**（cmr R3：纯留 /tdd 会让实现期撞洞）。本 ADR 钉「效果走读事件结局 + 改 `settle.p` 增量、议停门走事件账、不走 `actions[]`、不另造决策态字段」。

## 落位契约（cmr R3 钉 — 设计级最小契约；确切字段名 / schema 留 /tdd）

R3 三腿在「事件结局即决策」架构已认可的前提下，点出几处接口/字段须在**设计级**钉死（否则 /tdd 实现期撞洞）：

1. **结局承载 + 封闭标签集（δ/ε）**：事件结局落 ADR 0014 `event.<id>.terminal_reason`（「结局」是其语义名）；**声明封闭结局标签集**——开征/升率事件 `{已准, 已驳}`、议停事件 `{已停, 仍征}`（走 ADR 0014 结局标签机制 + extractor 白名单校验）。**议停门**读 `event.剿饷议停.triggered`（¬已发 = 未触发，只管不重复弹）；**在征**读 `terminal_reason`（结局值）——两谓词不同源、不混用。

2. **在征谓词（显式 per-饷，η）**：辽饷默认在征（`辽饷升.结局==已准` 则升至一分二厘、否则九厘）；练饷在征 iff `练饷开征.结局==已准`；剿饷在征 iff `剿饷开征.结局==已准 ∧ 剿饷议停.结局≠已停`。**无议停事件 / 无结局记录 ⇒ 第二合取项恒真**（vacuously not-stopped）。

3. **shadow stub 默认 + 时序（ζ）**：stub 在天定门触发的**同 tick 原子**置结局（不留 triggered-but-outcomeless 的中间 tick → 那一 tick 会误判不在征）；史实默认——开征/升率 → 已准、剿饷议停 → 已停（驳则仍征）。#260 落地换真圣旨置结局、保同语义 + 同时序。

4. **起运 baseline / offset 分键（δ / cmr-γ 落实）**：**正赋起运基线**存独立键（如 `settle._meta.正赋起运基线`，seed 值 = `seed 起运定额 − 开局辽饷`，确切键名 /tdd）；通道写 `settle.p.起运定额 = 正赋起运基线 + Σ在征三饷`；**玩家缓起运/截留（#260）是另一个量（offset），最终解送 = 通道基线 + #260 偏移、组合在 #260**——#259 只写通道基线、不碰 offset，#260 接口 = 读基线 + 施偏移。

5. **applier 写/保集（θ）**：月初 applier 的 set-to-target **仅 UPDATE `{三饷应征, 起运定额}`**，**保留** `{正赋应征/正赋亩额, Due, 火耗率, 逋赋率}` 不动（火耗应派在 `settle_tick` 内派生、不存 `p`）。
