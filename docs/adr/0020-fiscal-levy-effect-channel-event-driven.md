# 饷率 effect 通道 = 史实时间线事件生成器 + 饷别决策态门控的确定性增量；决策态由圣旨（#260）驱动、shadow 用显式 stub；起运随三饷增量联动（保正赋基线）

Status: Proposed（2026-06-20 grill-with-docs（#259）决策结晶；2026-06-21 设计 cmr R1 折叠——三腿独立判出「准奏后才落」的效果在 ADR 0014「触发即落」两类里无落点，引入**饷别决策态**抽象修正，详见决定 2 + Consequences。待 cmr 收敛再转 Accepted。）

## 背景

[ADR 0019](0019-fiscal-cutover-all-province-seed-hub-split.md) + [FISCAL_PROVINCE_SUBSTRATE.md](../FISCAL_PROVINCE_SUBSTRATE.md) §#70 把「三饷时间线注入 + 起运定额联动选型」deferred 给 #259「饷率 effect 通道」。#70 只静态 seed 开局辽饷九厘（剿饷 1637 / 练饷 1639 不进 seed），起运定额静态、注「#259 后动态接管」。

#259 grill 揭示一处定调更正：三饷**不是**「到点强制注入、改 `三饷应征`」的确定性背景。三饷是史实里**皇帝的决策**——崇祯逐次拍板加辽饷、开剿饷、行练饷，**加则民变深、不加则边军溃**，两边都有代价。故时间线该把「该不该加这道饷」的两难**摆到皇帝面前**，玩家有 agency，而非被无声改数。

设计 cmr R1 进一步揭示：ADR 0014 的历史事件只有「触发即落」两类结果（软判 / 确定性后果），而「皇帝准奏后才落」是**第三类**事件形态——在 #260 圣旨层未落地前没有触发点。本 ADR 用一个显式的**饷别决策态**消解它（决定 2）。

## 决定

1. **（D1）时间线 = 史实事件生成器，不是强制注入器。** 到史实时点生成一个「军费危机 → 是否加这道饷」的**历史事件**（复用 [ADR 0014](0014-historical-event-trigger-and-effect-model.md) 触发门），把两难摆到皇帝面前并把该饷标记为**待决**。**效果不在「触发即落」**——见决定 2 的决策态门控。

2. **（饷别决策态——本 ADR 核心，cmr R1 引入）** 本通道引入**饷别决策态**：每省、每饷分量（辽/剿/练）一个**持久状态 ∈ {未决 / 已准 / 已驳 / 已停}**。这是 ADR 0014 之外的**第三类事件形态**（ADR 0014 原只「触发即落」两类——软判 / 确定性后果；本 ADR 显式承认「触发 → 待决 → 决断后落」第三类）。规则：
   - 确定性效果**读决策态、按增量改 `settle.p`**（三饷分量 + 起运联动 + v23 火耗自动派生），**不在触发即自动落**；
   - **状态转移（未决 → 已准/已驳/已停）由 #260 圣旨驱动**（复用 [ADR 0013](0013-decree-commitment-ledger.md) 决策落库）；#259 **定义该状态 + 其确定性效果**，**不实现圣旨路由**（那是 #150/#260）；
   - **shadow 期用一个显式 stub default-setter**（史实默认 = 已准）置决策态，**明标「#260 落地即替换」**——故本通道在 live **不直接强改三饷**（只读决策态），shadow 的默认仅是一个**可替换的占位驱动**、不是通道自身行为（消解「shadow 自动注入 = 复活被否决的强制注入」cmr-D）。
   - 民变/加征反噬是上行通道、交 LLM 软判（ADR 0007 边界 + ADR 0011 消费）。

3. **（D4b）军费危机的触发门 = 天定。** 辽东战事/流寇/练兵的军费窟窿如期出现（根因不在 #259 范围内），皇帝的真两难是「加这道饷，还是另寻财源/硬扛民变」。**破局不在「让战争消失」**（越界战略/事件线），而在财政基座已有的上行软判通道（追赃/挪借/招抚/清丈，#260/软判）。守「越努力越无解是压力源、破局可真」。

4. **（D3）升降通吃 + 决策态链门。** 既生成开征/升率（辽饷 1631 升、剿饷 1637 开、练饷 1639 行），也生成「议停」（剿饷 1640 撤）。**议停剿饷的触发门 = 读「剿饷决策态 == 已准」**（持久决策态，**不是**活财政软读——cmr-B：「已开征且仍在征」拆成「决策态曾达已准」的持久事实 + 「现仍 == 已准」的态读，靠决策态一个字段同时表达，避开 ADR 0014 链门只认冻结账、表达不了「仍在征」的洞）。未准/已驳/已停则议停不触发。准奏议停 → 决策态转**已停**（终态、防重弹）、对应分量增量回退、起运定额随之回落（见决定 5）。

5. **（D2）起运随三饷**增量**联动 = 单一 `起运定额` + 保正赋基线。** `起运定额 = 正赋起运基线 + Σ(active 三饷分量)`：**正赋起运基线**由 seed 定、存 `settle._meta`（cmr-C：单一定额只有下界 `≥三饷` 时，议停回落会把正赋起运抹到 0、堵正赋解京）。效果对**三饷侧按增量**改（**非绝对设**——cmr-E：绝对设会冲掉玩家经 #260/软判的缓起运/截留；增量式让「基线侧玩家偏移」与「三饷侧饷率增量」共存）。**不变式：`起运定额 ≥ 正赋起运基线 + 当期三饷应征`**（双下界，守正赋解京 + 三饷全解）。**不拆「三饷/正赋」为两个对外字段**（只有 #261 hub 才消费、违 boundary），但**内部保留正赋基线**供回落与共存；将来 #260 真要演「截留正赋」再拆对外字段。

6. **（boundary）#259 全程 shadow、不吞邻项。** 起运到京只算/打印、不汇国库（hub = #261）；**决策态的转移逻辑（圣旨 → 决策态）归 #260/#150**，#259 只定义状态 + 读状态的确定性效果；不实现加征反噬消费（ADR 0011）。#259 = 生成事件 + 定义饷别决策态 + 落「读决策态的确定性增量」+ 保持辽/剿/练分量可归因，止于此。

## Considered Options

- **统一通道（历史事件与皇帝旨意同一套机制）**：否决——会让确定性历史轨迹和「LLM 软判玩家代价」纠缠进一个通道、违 ADR 0007 边界；且把 #259 拖进未完工的 #150 圣旨地基。
- **时间线强制注入（无玩家 agency，到点直接改三饷）**：否决——三饷史实是皇帝的决策，强制注入抹掉核心两难、与「皇帝角色保真」相悖（grill 更正点）。**cmr R1 实证**：把「shadow 自动应用史实默认」当通道行为 = 这条被否决项的复活（三腿独立判出）→ 由决定 2 的「决策态 + 显式可替换 stub」消解。
- **复用 ADR 0014 `effect_on_trigger` 触发即自动落（如 `apply_historical_power_renames`）**：否决——那是无条件自动设，承载不了「准奏后才落」的 gating，且绝对设会冲玩家调整（cmr-A/E）。改用决策态门控 + 增量。
- **拆三饷-正赋独立起运通道（gemini PR#113 选项 b）对外字段**：暂否——拆出的对外字段只有 #261 hub 才消费、违 boundary；**但内部保留正赋基线**（决定 5）已足够表达回落 + 玩家共存。#260 真要演截留正赋时再拆对外字段。
- **可避/半可避触发门（平辽 → 免辽饷）**：否决——要求 #259 判定辽东/流寇等战略状态，远超财政时间线范围；破局改由上行软判承载。

## Consequences

- **取代 FISCAL doc / #259 issue 把三饷写成「到点直接改 `三饷应征`」或「触发即自动落」的措辞** → 改为「到点生成事件 + 标记待决；效果读饷别决策态、按增量落」（FISCAL §#259 + PRD 同步更新）。
- **ADR 0014 显式补一类**：历史事件结果除「软判 / 触发即落确定性后果」外，**新增「触发 → 待决 → 决断后落」第三类**（饷别决策态门控）。此第三类的通用化（是否其它事件也需要）留 ADR 0014 后续，本 ADR 只为饷率立。
- **#259 可在 #150/#260 未动时独立设计/推进**：定义决策态 + 读态的确定性增量 + 显式 stub 驱动；**完整可玩闭环**（皇帝实际加/不加经圣旨）须等 #260/#150。#259 单独 DoD = 「事件按史实节奏与决策态链门出现 + 给定决策态时 shadow 末态可断言验证 + stub 可被 #260 无缝替换」。
- **失地/收复（cmr-G）**：饷率时间线更新应用到**全 17 seed 省的 `settle.p`，不论当前控制方**；动态成员谓词（`controlled_by==ming` ∧ 有 settle）只管「**是否 tick/settle**」、**不管「是否收 rate 更新」**——故失地省 `settle.p` 仍随时间线更新、收复即现行饷率（与 #265 on_restore 邻接，不冲突）。
- **不变式断言 `起运定额 ≥ 正赋起运基线 + 当期三饷应征`**（双下界）——漏上界守护则超额三饷漏进省内池，漏下界守护则正赋解京被抹（`settle_tick` 不 raise，是静默经济学改变）。
- **万两估算口径（cmr-F）**：加饷是**全国一道旨意**，故奏报的「岁可多征 / 可补军费」估算用**国总加征所得 vs 国总军费缺口**（可附各省分解），不对单省缺口比。
- **精度沿用 #70**（量级定稿、田亩占比折算、`_meta.provisional`、一手《会计录》deferred）；各饷开征/升率/停征「月份」锚该年正月（provisional、`_meta` 标注）。
- **cutover 后（#261）** 本通道的确定性效果从 shadow 隔离相位转 fail-loud；**shadow stub default-setter 在 #260 落地时替换为真圣旨驱动**。
- 决策态字段落位 / 事件数据格式 / stub 实现是可逆代码级实现，留 #259 的 `/tdd` 现场长；grill + 本 ADR 只钉「效果走读饷别决策态 + 改 `settle.p` 增量路径、不走 `actions[]` 动作路径」（后者误踩 #260）。
