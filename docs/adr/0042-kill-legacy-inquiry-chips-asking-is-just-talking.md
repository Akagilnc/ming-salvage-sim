# 0042: 砍旧询问 chips——「问」不设词条，问就是说话

Status: Accepted（2026-07-03 随 PR #530 合入；决策：2026-07-02 #471 grill Q5 用户拍，了结 #497/#342 悬置判决）

旧「询问」机制（召对面板快捷问句 chips：问在办事项/问阻力/查钱粮/查驻军/密查，点击即替皇帝发预置问句、千人一答）判决为**砍**：问事的角色保真形态 = 皇帝直接开口问 + ADR 0034 角色见闻（千人千答，承载归 #507 切片——**在建**、以「证非旧询问机制」为验收；chips 移除以其就绪为前置，砍机制不砍体验）；**「问」本身不设词条**——泛泛问事是普通对话、分类落「无」零机械后果，有标记问法（追问/压问/提案征询/密查·查访）各有词条；问话与大臣建议不得静默升格为皇命（US19，playtest 实测过此 bug）。本判决不含意图声明按钮类（ADR 0028 权威三类：密令/拟旨/任免——现行载体为拟旨/下密令前缀钮与任免面板路，#504 已收编为确定性分类节点）；#15（旧 chips 改良提案）随判决了结。
