# 0070: 案卷背书条目——会签/当面站台/御笔手敕，担名改否决难度

Status: Proposed（决策：2026-07-06 #473 设计闸 grill Q5 用户拍选项 1）

案卷可挂**背书条目**：（背书人物 id 或御笔标记，形式∈｛会签/当面站台/御笔手敕｝），收夜时从夜内对话捕获（大臣「臣愿会签」、皇帝「朕亲书手敕」→落条目，走收夜抽取管线——#470 家族既定设计、落地为前置依赖；单向新指旧，0054 合规）。与参与人三档（0053）**分立**：参与人＝办事的人，背书人＝担名的人（毕自严会签吏部题本、不办吏部的事）——语义不混，毁约追责（0056 按主办/委派人）不误伤只签名者。消费口：颁布判官读之——重臣会签则否决方「不好再拖」阻力降（北极星毕自严站台 beat：王绍徽伏地领旨）；**御笔手敕＝皇帝本人背书特例**，「驳＝抗旨」，打回概率大降（毕自严「臣需皇爷亲下手敕」beat）。背书意愿受皇威高端反噬调制（0068 杠杆②）。背书人分担物议的长期名声账**不在本闸**→#479 关系账（信用主线 watch-item cross-ref）。转 Accepted 时回注：0053「委派人」词条括注（背书人与参与人分立指本 ADR）。
