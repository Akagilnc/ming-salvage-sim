# 0070: 案卷背书条目——会签/当面站台/御笔手敕，担名改否决难度

Status: Accepted（2026-07-06 随 PR #616 合入；决策：2026-07-06 #473 设计闸 grill Q5 用户拍选项 1）

案卷可挂**背书条目**：（背书人物 id 或御笔标记，形式∈｛会签/当面站台/御笔手敕｝）。捕获由每轮转译声明（#1842 改定 #612）：转译在声明交办/应允时一并声明本轮谁对哪一项暂存交办会签、当面站台或御笔手敕；背书挂在该暂存载荷上，成案时继承到案卷（须带 exact `source_chat_turn_id`；单向新指旧，0054 合规；不造待背书关系表）。撤回该轮则背书随撤（ADR 0038）。与参与人三档（0053）**分立**：参与人＝办事的人，背书人＝担名的人——语义不混，毁约追责（0056）不误伤只签名者。消费口：颁布判官读之——重臣会签则否决方「不好再拖」阻力降；**御笔手敕＝皇帝本人背书特例**，「驳＝抗旨」。背书意愿受皇威高端反噬调制（0068 杠杆②）。背书人长期物议账**不在本闸**→#479。转 Accepted 时回注：0053「委派人」词条括注（背书人与参与人分立指本 ADR）。

## Later-wins（#658 / 2026-08-27）

批红/自由下旨路径的背书 provenance 允许 typed `decision_key`，作为本 ADR 的 later-wins 个案：同一背书恰有一种来源——真实召对继续使用 `source_chat_turn_id`（每轮转译声明），批红决策与自由下旨御笔使用 `decision_key`，不得伪造 chat turn。表结构与写口强制 XOR。
