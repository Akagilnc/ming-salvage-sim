# 0110: 宗藩反咬四档——组织度阶梯、存亡度×非法度双因子、依律封顶 A

Status: Proposed（决策：2026-07-08 #87 宗藩闸 grill Q3 用户拍板〔四档 + 双因子 + 依律封顶 A；经济不单独成档〕；承 0109 通道归属 + 0101 反咬评估框架）

0101 row④ 的宗藩反咬档位内容 = **四档组织度阶梯**：

| 档 | 反制形态 | 机械落点 |
|---|---|---|
| **A 礼仪抗议** | 哭庙、称病、上疏搬祖宗成法（个体、无需组织） | 账面血债照记（0011-2；「称病只读血债」不变式沿用）+ simulator 叙事纹理——零净新 |
| **B 串联政治** | 宗人府联名、诸王合疏讼冤、撤捐输、闹宗禄 | 0091 发难 issue + 防备棘轮↑；持续对抗落 issue ongoing 月度效果（0013 载体） |
| **C 地方对抗** | 庄田盘根发力（勾连士绅抗清丈、藩府拖死执行） | 「藩府梗阻」issue，见 0111 |
| **D 藩兵苗头** | 请增护卫、结交军镇、缮甲风闻 | 「藩府异动」issue + 军事线交接，见 0113 |

**升档驱动 = 双因子**（复用 0101 宫变档三量中的两量，**无「要害抓手」因子**——宗藩藩居外地够不到大内抓手，正是 row④ 封宫变档的依据）：**打击存亡度**（申饬/减禄低档→削藩/圈禁/抄宗室满档，取 resolve 动作 severity）× **程序非法度**（码集二分真源 0011-2 D2-5，同 0101 第三连续量）。

**硬规则：依律封顶 A**——`reason_code ∈ 依律集{依律/谋逆坐实/贪墨坐实}`（0011-4 D4-4 三码，非单码）的打击，宗藩反制**封顶 A 档**（反扑动员力塌；史实：依律办的藩王无人敢替他串联）。玩家破局语法与打权阉**完全同一套**：走程序＝安全、莽＝挨全套，不学新规则。

**武器≠档位**：档位＝烈度阶梯（升档驱动对阶梯才好使），武器（上疏/撤捐输/勾结士绅）＝档内内容——经济不合作是 B 档武器、不是独立档（五档毙案见 0109）。首版各档触发阈/效果量级随 playtest（0011-4 D4-6 先例，不发明精确值）。

**毙案**：五档（经济独立档）＝轴不单调 + 触发判据另发明，毙（0109 同判）；抓手因子入宗藩评估＝违 row④ 封顶依据，毙；档位对玩家露名/露数＝违 P4（玩家只见奏疏/邸报/风闻定性叙事），毙。
