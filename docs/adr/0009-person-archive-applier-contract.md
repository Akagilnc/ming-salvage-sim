# 人事世界的四条规则：被俘≠易主、出狱是新旨、官印人腿分离、人才池

Status: accepted（评审收敛并 main：PR #94，2026-06-11；前置 PR #90 / PR #95 均已落地——2026-06-12 进入实现期，载体 #13，实现 kickoff checklist 见 #13 评论）

## 规则 1：被俘未降 ≠ 易主

被掳而未降不是易主：人仍是明臣，算下狱（陷虏）一类（洪承畴被俘到降隔了数月，两段是两个事件）。数月后真降才是易主；陷虏期间对他下任命不成立——人在敌手，朝廷放不了；要用被俘者，先经局内营救、赎还、交换改其处境。

## 规则 2：出狱永远是新动作

处置无回滚。放出不是撤销下狱，是新组合：官复原职＝放归＋任命原职（史实「起复」本就是新诏）；官降三级＝放归＋任命低阶官。出狱永远是一道新的旨。

## 规则 3：官印和人腿是两个系统

调任不自动产生在途——官印和人腿是两个系统（实证：袁崇焕领旨数月未动身）。领了新职不等于人已动身或到任。

## 规则 4：被顶替进人才池，起复有政治分量

「不在任上」不是一个状态，是一张谱系；「启用被错误排挤的有才之士」是核心玩趣，池子必须可发现、有来历、起用有政治分量。

- 被顶替（无过错）→ 听用候铨：人留在可用人才池，再任命零摩擦、无政治分量。
- 起复阶梯：候铨→直接任命；致仕／赋闲→起复（温和）；获罪削籍→昭雪（翻案＝政治事件，引来派系风暴，昭雪本身记入账本——你平反过谁，史官记得）；丁忧→夺情（清流哗然）。
- 人才池裁判与玩家都看得见，带来历：「某公，因忤逆案削籍，居家」。
