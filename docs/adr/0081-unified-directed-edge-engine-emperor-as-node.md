# 0081: 统一有向边引擎——皇帝是一个特殊节点

Status: Proposed（决策：2026-07-06 #479 设计闸 grill Q2 用户拍）

本轴（#479）两维同一 schema：关系＝**有向边**（甲→乙的账 ≠ 乙→甲的账：王绍徽记恨毕自严、毕自严未必记恨王绍徽；「皇帝辜负了他」与「他辜负了皇帝」是两条边）；君臣关系＝一端为皇帝的边，与大臣边完全同构。**维度差异放酿制口径、不放 schema**——君臣边的摘要用知遇/辜负/跨年回声视角（coda 素材从这里长），大臣边用恩怨/站台/派系态势视角。理由：一套写端一套酿制腿；荐人一个事件落两条边（荐主→被荐人恩义连坐＋君→荐主知遇）同一入口；「必须有」的维度 2 因同构而不会被做薄。否决（防重议）：两张独立账（写端/酿制腿翻倍、荐人拆两笔进两套系统）；只做君臣、大臣边降级为摘要附注（砍掉 #479 body 明列的站台/联名/派系态势半个轴）。
