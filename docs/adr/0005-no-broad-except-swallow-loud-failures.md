# 异常不得宽吞:区分代码 bug 与 LLM 脏数据,落库失败不静默

Status: accepted（实现渐进,站点清单见 issue #14）

全系统约 200 个 `except` 里约 127 个吞掉异常(不重抛),其中约 55 个是宽 `except Exception` / 裸 `except`。这些宽吞本意是兜「LLM 输出不稳 / 数据脏」让游戏别崩,但捕获面盖到了 `KeyError`/`AttributeError`/`TypeError` —— 于是**任何代码 bug(字段名 typo、schema 漂移、真异常)都被伪装成「数据问题」无声跳过**,与 MEMORY 记的最严重落库 bug(simulator 幻觉人事并落库、真实指令丢失)同一种失效:错误不抛,盘面与玩家意图悄悄背离。最毒的单点 `decree.py:400` —— 月末结算抽取 `except Exception → extracted={}`,任何错让本月**全部 delta 静默蒸发**,只一行 WARN,restore 还原不回,直接违反 P1 落库铁律(决策机械后果当回合全量落库)。

作用域:本 ADR 治「LLM **已产出** delta、想落库却失败」这一侧。「该产没产」(omission)另议。

我们决定:**异常处理按「这是谁的错」分流,禁止用宽吞把两类错混为一谈。**

- **代码侧的错(KeyError/AttributeError/schema 不符/真异常)= 必须响亮**:抛出或显式告警中断,绝不吞。except 必须**窄**(只捕获预期的具体异常,如 `(TypeError, ValueError)`);宽 `except Exception` 仅允许出现在确证安全的旁路(如调试 dump、token 统计),且**必须 log,不得静默**。
- **LLM 数据侧的错(幻觉 id / 枚举非法 / 类型错 / 引用不存在实体)= 可拒收,但必须留痕,且只拒该项、不带走整批**:坏项隔离 + 记录原因,好项照落(见 issue #63 的「不带走整批」)。
- **落库失败不得静默**:决策的机械后果要么落库,要么响亮失败 —— 不允许 `extracted={}` 这种「整月蒸发只打 WARN」。
- **「库里有的一定落库,库里没有的交给 LLM 发挥」**:schema 能装的(manpower/arrears/character.status/office)= 该落必落;schema 没有的(给军队上 M6 步枪)= 不强求结构化,留给 narrative。

## Considered Options

- **维持宽吞(现状)**:游戏不崩、对 LLM 抖动最宽容。但代码 bug 被伪装成数据问题、玩家决策静默丢、DB↔叙事漂移无人知 —— 正是 #14 / #3 / #63 一路在治的病根。**否决**。
- **一刀切 fail-loud(任何异常都抛)**:最严、最一致,但一个脏 LLM 项就崩掉整月结算,带走同批合法 delta,探针/玩家体验极差。**否决**(用 per-item 隔离替代「整批崩」)。
- **改名/加注缓解**:治不了「宽 except 捕获面过宽」这个失败类本身。**否决**。
- **按「谁的错」分流 + 禁宽吞 + per-item 隔离**:代码 bug 响亮、LLM 脏数据可拒但留痕、坏项不带走整批。两类错各归各位,既不崩整月也不静默丢。**采纳**。

## Consequences

- 宽 `except Exception` 逐个收窄到具体异常或加显式 log;站点 checklist 在 issue #14,`decree.py:400` 单独优先做(一个点堵住整月落库蒸发)。
- 落库改 per-item 语义:坏项隔离 + 留痕,好项照落;这是 #63「产了落不进」死法目录的统一修法方向,与 #3(事务边界半落库)同框。
- 与既有方向一致:`apply_score_extraction` 建军段已注释「不吞异常(全局严格)」、ADR 0003「未知动作响亮拒收不静默」—— 本 ADR 把这条零散意图升成项目级守则。
- **新代码不得引入宽吞**:code review 守则;宽 `except Exception` 需在 PR 里说明为何安全 + 必带 log。
- **短期成本要认**:以前被吞的 bug 现在会响亮失败甚至崩当回合 —— 这是**把隐性数据腐蚀换成显性报错**,需逐个真修而非继续掩盖,是刻意付的代价。
- 「留痕」给谁看、坏项要不要回喂 LLM 重产(re-ask)、玩家侧怎么呈现 —— 这些**本 ADR 不决**,留待落地时按通道(web 真实管线为主)再议;本 ADR 只钉「不宽吞、不静默、不带走整批」三条底线。
