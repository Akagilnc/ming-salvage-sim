# 0097: 判官距离项填实与承办人在途态——银饷押解在途 defer

Status: Proposed（2026-07-07 #475 设计闸 grill Q7 用户拍：承办人在途态进、押解 defer）

0092 带宽轴第⑤预留项的填法：接口层查 0094 矩阵（**承办人所在地×差务地**——承办人所在地取 characters.location，空则该项不参与，与差务 region_id 可空同款退化），折成**语义档**（远近＋预估耗时量级）进判官输入清单，不喂裸数（0095 同禁）；语义档与 0095 接口层语义量**同源同措辞**（「远近＋全程约 T 月量级」的折档），不另立枚举、不产「预计还需 X 月」。接口层另加一行**承办人在途/已到差**态——零 schema、不碰 #556 案卷状态机与月度节拍：判官软判「人在路上、差没开张」，到差后进展照 #556 既有机制走（派李若琏赴陕的「人」已被 0095 通用覆盖，本条只管让判官看得见）。**银饷/物资押解在途 defer**：给银子加在途＝改到账时点＝踩省级财政基座结算 tick（「起运当 tick 到京」是 22 轮评审收敛的现行契约）、动太仓/边饷 hub 时序与分源欠饷账，爆炸半径大；而押解的戏剧面（折损/对账/被劫）已有 #556 对账折损＋0092 阻力轴软判承载，缺的只是「晚几个月到」一格——defer 到 #93＋财政线 backlog，注明 0094/0095 底座可复用（车队＝慢速档）。
