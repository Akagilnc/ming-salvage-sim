# V2：账本记实况，中间层双向供料与记账，不裁判剧情

Status: proposed（2026-09-09；owner 已拍方向，设计待评审，未实施；仅适用于 V2）

沿用 [CLAUDE.md「探针设计铁律」总纲与判断权原则](../../CLAUDE.md)：世界实况、公开说法和角色经历不能混为同一真相。V2 中间层向外按职责提供材料，世界推演可见全局实况，人物演绎使用角色见闻；向内承接 LLM 的推演结果与要保存的经历，完成规定的计算并记回引擎。它不是仅筛选真实 DB 行的权限层，也不是审核剧情合理性的裁判。

人物回话本身成为经历和记忆，不能因为一句「人已死」就变成实际死亡；推演决定实际结果。忠诚、党派认同、派系满意度等是演绎依据，不由代码换算成角色必须如何行事。损耗、截留、贪腐等必要核算仍可存在，不能把「判断权归 LLM」误读为禁止数值计算。

取舍是容纳真假并存，而不提前建设复杂的信念或消息传播模拟器。公共说法不必给每个大臣复制一份；记忆具体住在哪个模块/表尚未决定。人物实际已死是 owner 明举的少数硬边界，但 LLM 仍可演冒名、替身或死讯被隐瞒；不从叙述逐句推导不可更改的世界断言。

[0034](0034-minister-audience-fed-perspectival-knowledge-not-omniscient.md) 的角色见闻与 [0073](0073-two-books-reported-vs-actual-rails.md) 的实况/奏报区分是已有依据，不声称视野能力从零开始。V2 多人同场供料的具体取舍见 [0155](0155-v2-single-scene-llm-with-complete-perspectives.md)。本决定不把旧 schema、名单机制、人格分档公式等全部承认为 V2 必保契约，也不直接废止现行运行规则。

原话及假死、易容、F35 案例见 [讨论依据](../design/game-v2-architecture.md#方向依据)；不把案例扩写为首期功能清单。
