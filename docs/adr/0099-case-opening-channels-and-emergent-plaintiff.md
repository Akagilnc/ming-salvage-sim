# 0099: 查案开案两入口＋涌现苦主加成——密查/检举转案皆接现成轨，只加「命查实之」一词

Status: Accepted（PR #708 merged 2026-07-08；决策：2026-07-08 M12 设计闸 grill G1b 用户拍；承 #555/#87/#89）

G1a 取证引擎的**查案差务轨**（确定性判定轨，复用 0092 差务/带宽 + 0058 月度进展；查案差务轨本体＝同批 0098，本 ADR 只定「怎么开案」，承办方带宽归属留 PRD）有**两条开案入口＋一个涌现加成源**，全部接线现成机制、零新轨道：**①厂卫密查**——皇帝经召对/密令用既有 `密查·查访` 词条（0042/#471 已立、「问」有标记者才设词条）对某人开查案差务，密查＝皇帝主动耳目、方向自定；**②政敌检举转案**——0077 政敌免费审计与 0091 弹劾潮浮现的检举/弹章（皆带真伪底、党争越凶耳目越多但每条须自辨），皇帝下一个**「命查实之」**动作把它转成查案差务，政敌已给的线索算**首付进度**（差务起点非零；**首付落点口径〔cmr 线上 R2 勘正〕＝绑定弹章所指事实的 fact_key、入对应 lane**〔0098 案内 fact-lane 口径〕——弹章全罗织、目标真相底无此事实则**无 lane 可挂：首付确定性丢弃＋落诊断日志、差务起点＝零，案照开照占带宽走 0098 空 lane 口径、机械终点＝查无实据**；查案轨自身**不产罗织坐实事件**——罗织永远只有 STIGMA 路〔0098 铁律〕，其血债账走 0011-2 恶路、非查案轨产物）、方向由党争定、夹带私货的罗织风险自担（命查一条罗织弹章＝亲手走 0011-2 的 STIGMA/cw=1 恶路，后果自负）；**涌现苦主上告（加成源、非开案入口）**——清算开动后由事件涌现轨（0091 同款 `gather_candidate_events`＋`auto_trigger_seed_issues` 机制）产「苦主上告」候选事件，接**同一已开**查案差务当**进度加成**（民间人证补实；案不在查则只是耳目噪声、不自行开案），呈现走 0034 见闻层 + #463 近臣回奏。**净新契约仅三条**：扩 #471 召对词表加「命查实之」一个动作词条（遵 0028 确定性动作闸——皇帝显式声明→确定性路由入查案差务，不靠 LLM 分类、不静默升格，同 0042「问≠皇命」精神）；检举线索→首付进度的映射（政敌已给的算差务起点非零、按 0098 fact-lane 口径绑 lane，无 lane 可挂则丢弃）；苦主上告事件→进度加成的接口（接 0091 涌现轨，非新事件源）。**毙案**：苦主独立 actor 层（自主诉讼实体/新数据轴）＝毙——不建场外新层，苦主只作涌现候选事件喂同一差务轨；检举浮现即自动转案＝毙——必须皇帝「命查实之」显式开案，否则检举只是耳目噪声（0028 确定性闸，同 0042「问≠皇命」）。首版进度量/苦主涌现概率/加成幅度一律「首版随 playtest」（同 0011-4 D4-6 先例）。
