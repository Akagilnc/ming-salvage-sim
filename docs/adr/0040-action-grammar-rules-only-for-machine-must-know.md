# 0040: 动作语法两部分制——语法规则只收机器必须懂的

Status: Proposed（2026-07-02，#471 grill Q2 用户拍）

皇帝动作语法 = **动词条 + 语法规则**两部分；语法规则只收录有机械消费方、机器必须懂的规则（如一句多旨拆分——#502 按提案粒度指向与 #150 切分消费它），**戏能自己演出来的规律不进规则、只作词条特征化素材**（实证校准：北极星里「默留殿侧」从无「不叫退则不走」引擎规则——大臣演员自演角色保真，基建只支持在/不在两态结果状态，#500 已够；「超额恩准」同理，落库金额即口谕金额，机器无需识别「超额」概念）。这是 ADR 0037「不预建」从词条到语法规则的延伸：基建支持结果、不裁决戏该怎么演。
