# 省级财政基座:AI 软判 + 真钱账本 + clamp 带原因

Status: accepted（实现 deferred;字段草表见 [docs/FISCAL_PROVINCE_SUBSTRATE.md](../FISCAL_PROVINCE_SUBSTRATE.md)）

> 注:ADR 0006 由并行的 chat-action 分支占用;本编号取 0007 避撞。文档碎片化(CONTEXT/ADR 散在 probe 分支、main 仅有 0005)是单独的分支收口问题,不在本 ADR 范围。

探针要把游戏 LLM 后端当裁判,需要一块**省级财政基座**让 AI 站在上面演绎崇祯财政绝境。现有实现不够格:`tax_per_turn` 是手填定额、`_province_efficiency` 是黑箱单系数,既不史实、也不给 AI「为什么收不上来」的因果,AI 只能凭空编财政叙事 → DB↔叙事漂移。

我们决定:**省级财政重设计为「引擎持真钱账本 + clamp,AI 当裁判软判」的基座**,落点如下:

- **分工**:引擎 = 账本 + clamp + 挤压算术(死账);AI = 裁判(判各状态这回合动多少、软后果怎么爆)。
- **收入侧三道漏**:隐田(一级,清丈直接挪)/ 火耗(二级,=官俸缺口×腐败)/ 逋赋(二级,=f(灾,负担率,民变))。
- **腐败度 = 三口抽水软系数**:火耗(征收)/ 漂没(解运)/ 中饱(拨付),反腐三口同降。
- **支出侧 per-province 存留/起运**:本省收先付本省出血(宗禄/边粮/驻军饷/官俸),余额起运,负=净亏空 →(中央补 + 就地拖欠 双重恶果)。
- **三饷 = 加赋逼反闭环**:支出赤字逼出加饷两难(加→逼反 / 不加→哗变),把支出侧和收入侧咬合成环。
- **死亡螺旋 = 一个因子**:AI 耦合(民负担→民变/人口流失→人均负担↑)+ 引擎一根钉(灾→逋赋下限)。

### 设计铁律(基座必守)

1. **压力是提供的,不是强制的** —— 结局开放、破局可真;杠杆只调难/慢/代价,不设「不准赢」的硬顶。
2. **不防爽不防作弊** —— 基座做深困境,不逼玩家受苦;玩家拨款几千万、上金手指是其自由。
3. **财政量用真钱(万两/月)进预算流**;「够不够/重不重」配标准值看比率,不写抽象绝对分数(负担→负担标准值;官俸→官俸所需)。软系数(腐败/士绅阻力/民心)例外,但必须乘/gate 在真钱流上,不孤立。
4. **引擎从不静默 clamp** —— AI 提 delta → 引擎返回(实际落地值 + 约束原因)。「火耗推不动」是被明确告知「因没动腐败/官俸」,不是黑箱。与 issue #14「不静默吞」同向。
5. **杠杆按机械效果定义,不绑历史名/关键词** —— 引擎只暴露机械动作(法定俸率 +X);AI 把玩家任何说法(养廉银/加俸禄/高薪养廉)映射到同一动作 + 叙事。

## Considered Options

- **维持黑箱效率系数(现状)**:`tax_per_turn × _province_efficiency`。已有、简单,但非史实、不给 AI 因果、各省无差异表达力,AI 财政叙事必漂移。**否决**。
- **Victoria 3 式确定性经济沙盒**:引擎自己算 pop/物价/产出/收支全链。最自洽,但**引擎一旦自己判进度,AI 当裁判的魂就没了**,且与探针「session 当 LLM」定位冲突。**否决**。
- **AI 软判 + 引擎真钱账本 + clamp 带原因**:引擎守住「真钱账本 + 结构 clamp + 挤压算术」这块死地,AI 在界内判戏。既不黑箱、不漂移,又不退化成经济沙盒。**采纳**。

## Consequences

- 实现是大活,**草表先行**(FISCAL_PROVINCE_SUBSTRATE.md),分省 seed 值史实量级粗校、部分待精验。
- 引擎落地需先建「**AI 提 delta → 返回 实际值+原因**」契约层,这也是 #14 不静默治理在财政侧的落点。
- 砍掉 `_province_efficiency` 黑箱、`tax_per_turn` flat 基准,改为「官民田×亩率×(1−火耗−逋赋)」+ 真钱出血侧;迁移面不小。
- **边粮供给 / 宗禄拆成 per-province 出血**,与现有「宗室禄米」全国线(fiscal_config)冲突,需重做。
- 短期不影响线上玩家;此为设计基座,落地按切片推进。
- 待办:腐败三口(火耗/漂没/中饱)的具体抽成函数、burden_baseline 校准、分省宗室口/驿卒精验。
