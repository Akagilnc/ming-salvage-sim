# 0125. 额度墙处置：park vs 换棒三段式

Date: 2026-07-10

## Status

Accepted；ADR 0134 拟取代其中“无活棒 → 静默 park 兜底”的候选耗尽规则

## Decision

worker 撞额度墙（#683 探针 429，带 `resetAt`）时三段式裁决：①同池重置在阈值 T 内 → park 等原棒（现场热、零成本）；②超 T 且花名册/池表有活棒 → 换棒接续现场（relay，铁律 #10：未提交 drift 原样保留）；③无活棒 → park 兜底。T 为 route 池表可配常量，起步 30 分钟（依据：换棒冷启动重读现场 ≈5-15 分钟等效开销 + 双份配额）。

## Consequences

#683 的 quota park 与 #686 的 relay 在同一处置点分叉；判据机械可测，不留模型自由裁量。ADR 0134 生效后，①解释为同一可执行席位等待，②解释为沿固定席位顺序换棒，③候选耗尽不再静默 park，而是保留现场并走既有 decision gate。
