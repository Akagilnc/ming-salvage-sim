# 0044: 召对主视图 = 夜流单卷轴——呈现层按时序合流双 store

Status: Accepted（2026-07-03 随 PR #554 合入 90c7a70a；决策：2026-07-03 #478 grill Q4/Q7 用户拍；配套推演已在文内标注）

召对主视图从「按大臣分线程」（现状 ChatModal 按大臣拉历史）改为**夜流单卷轴**：整场一卷到底——开场 scene → 宣X → 入殿 → 对话 → 递话 → 退下 → 软段分幕 → 下一位 → 收夜 → coda 插槽；北极星连场体验（乾清宫一夜）只有这条路能给。卷轴内容**按时间序合流两个 store**：故事账本（scene/进出/框架账，ADR 0035）+ 已持久化对话轮（朕/大臣/递话）——0036 的双 store 口径不变、不分叉不搬家，呈现只是合流读。「夜」承 0035 术语（召对夜不必在夜里，白日同构）；玩家可见的卷名/档名从容器时辰地点长出，不硬称「夜」。**归档同源**：退朝后该场入「起居注」档，只读复用同一卷轴渲染器，场内回看=卷轴上滚；起居注平替「邸报详明」裸账目入口（该入口判砍：#478 grill 用户拍 2026-07-03，落点 #486 收口日志）。单大臣回看是过滤镜头、留后续（设计推演，非用户拍范围）。摆位类可逆细节（命令物件槽位、左栏跟随）归 #478 PRD。与 ADR 0006 不冲突：0006 否决的是动作确认类第二套 UI（面板/角标），确认仍在对话里完成；夜卷轴是主舞台本身的形态，不是确认面板。
