# 0121: identity 派生第五向——执行表现回写党籍（用人即烧人·孤臣弧）

Status: Proposed（决策：2026-07-08 #89 大臣系统设计闸 grill Q8 用户拍板；承 0102 派生规则表、0011-3 立场矩阵、0103 叛变双通道、0104 君臣分轴；同批 0116/0118 到期对账/结案事件）

**0102 identity 漂移规则表「首刀四向」在本闸补第五向**——差事表现回写党籍：**忠实承办伤本派的差务→对本派 identity 降（行动切割：替君办了党不愿办的脏活，党心离）；打折／阳奉阴违庇护本派→identity 升（为党挡刀，党内声望涨）**。语法**严格沿用 0102 全部铁律、零变体**：读端消费**已落库的差务结案事件**、以**一案一笔（结案事件 id 为幂等去重键）**各消费一次、产**确定性 Δ 经 0102 惯性缩放函数**（identity≈100 的铁杆纹丝不动、边缘人一推就移）、走 0102 那个**单一确定性写函数**落库并 clamp[0,100]、**LLM 不碰这个 int**（只叙事离党／护党的花样，零算账）；差务结案事件是上游（Q5 到期确定性对账＋0058 月度轨定态的产物，同批 0116/0118）**只产事件、不得另行联动调用本表**（防 double-apply，同 0102 与 0107 的入口单一律）。**「伤本派」判别＝结构化查表、不读语境**：读该差务所辖旨意撞的**轴集 × 承办人本派在 0011-3 矩阵的 42 格立场**（清核宗室隐田撞宗室命门轴、抄阉党撞阉党皇权依附轴——撞轴集本就从动作类型＋目标 faction-tag 结构化派生，resolve 线现成分类、0011-3 已钉），判定通式覆盖三种立场（Gemini 线上 R3 勘正补全）：本派在被撞轴上立场为**护（+）**——忠实交付＝伤本派→**降**、打折／庇护＝护党→**升**；立场为**抑（−）**——忠实交付＝遂党愿→**升**、打折（实为庇护党敌）→**降**；立场**中立（0）**——执行表现不动 identity。即 **Δ 方向＝立场符号×执行顺逆、中立零**，各分支量级首版随 playtest；判别**不读自由文本陈词**（H5 注入面同 0102 铁律——一读语境即落回启发式软判，把「刷党籍」的话术面重开）。

本向与 **0104 loyalty 严格分轴**：本规则动的是**对党认同 identity**、**不碰对君忠诚 loyalty**（0104 辖君臣、由 0079 信用事件派生；同一次忠实承办可同时让 loyalty 升〔0104 兑现所托〕、identity 降〔本向切割〕——两轴正交，正是 Q4 双轴地基）。**设计意图＝孤臣弧机制化（用人即烧人）**：皇帝每把脏活（清丈、抄没本党同僚、缉拿）压给一个能吏承办，其对本派 identity 就被这一向确定性拉低→**过阈后经 0103 通道①被本派自发切割（树倒尾门：identity<阈成员改中立）**、或皇帝可趁其低认同经 **0103 通道②策反（dig-6：0-40 可反正）**收为孤臣；孤臣若再被皇帝弃卒，其 loyalty 走 0104 崩解且无党可回（identity 本已低；派内认同不动——0102 rule④只辖党魁弃自己人，皇帝弃卒不 fire）——**重用能吏办党的对头，他就一步步离党成边缘人／孤臣，温体仁、杨嗣昌那种「办成了事、也办没了党」的命运由此机制化涌现**，而非剧本硬写。**净新契约仅两条**：①0102 规则表新增第五向（伤本派降／护本派升，Δ 权重与阈值**首版随 playtest**，同 0011-4 D4-6 先例，不发明精确值）；②差务结案事件接入 0102 派生入口（一案一笔幂等消费）——**无新数据轴、无新写函数、无新查表**（identity 列、惯性缩放、单一写函数、0011-3 矩阵、结案事件全现成，实现编码细节归落地切片验收 DoD）。**毙案**：不建此向＝忠实替君办了伤党的脏活、党内地位纹丝不动＝戏假（用人无最重的那层代价、「逼谁去办脏活」这一皇帝核心难题失重）、孤臣弧缺失（温体仁式弧线无处生成），毙。
