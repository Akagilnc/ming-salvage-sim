# 大臣召对喂「角色见闻」（perspectival），永不喂全知盘面

Status: Accepted（2026-07-02：本地 cmr 3 轮收敛（codex+agy+Opus4.8）+ 线上 bot 评审收敛，PR #495）

## 决定

喂给大臣召对 prompt 的「世界」= 该大臣的**角色见闻**（见 CONTEXT「[角色见闻](../../CONTEXT.md)」）——由**职位/网络该知道的** + **亲身参与过的事**（召对/密令/差事/事件，**参与即知**）+ 对没参与之事的**零星风闻**共同界定，**完全个人角色化**。不知道的事，大臣 in-character 说「臣不知 / 容臣查访」（真大臣本就常这样）。

**永不喂全知盘面。** 探针期实现可简化（如：先按职位桶 + 参与标记界定见闻，略去细粒度风闻扩散），但**不变式：再简单也绝不退回全知 / 人人同一个世界**。

**界定补钉（2026-07-02 cmr R1）**：①「职位该知」= 按职位对**当前世界状态**的裁切（非仅事件留痕）——新开局即有职位级见闻、无 Turn 0 真空；②**明发旨意/邸报所载走公开层、人人该知**（不需参与）；③密令「瞒某人」的**显式排除压过公开与职位桶**——被瞒者的世界里没有这件事。排除须有结构化留痕，且**留痕形态 = 显式排除名单（黑名单）**、判定时先查黑名单一票否决（线上 R1 Gemini：公开层/职位桶是动态判定，只存「圈定知情人」白名单会在密令后续公开或职位变动时失去覆盖力；黑名单硬覆盖才稳）；密令捕获可另存知情圈作辅助。

## 为什么

召对的价值一大半在**信息本身就是博弈**——不同大臣给不同信息、有人瞒报、有人真不知，皇帝须交叉验证、透过奏对读势。若所有人看见同一个世界，这层全塌（用户 2026-07-01：「不可能所有人看见的世界都一样，那样还做什么不如别做」）。本 ADR 把 [ADR 0033](0033-minister-audience-prompt-characterize-not-constrain.md) 的「只喂他正常看得到的东西」从「他自己的属性」扩到「整个盘面」，并给 #93（距离/情报时滞：皇帝看到的永远是过去的盘面）留了位。

## 否决的备选（防日后重议）

- **全知定性盘面 + 靠角色自觉克制**（"这不是我该多嘴的事"）：否决——靠自觉不可靠，且丢掉「他真不知道」的质感（模型会假装知道），实质仍是人人同一个世界。
