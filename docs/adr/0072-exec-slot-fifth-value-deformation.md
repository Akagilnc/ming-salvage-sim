# 0072: 执行格第五值「变形」——真相层永不撒谎

Status: Accepted（2026-07-06 随 PR #630 合入；决策：2026-07-06 #476 设计闸 grill Q2 用户拍「变形进执行格当一等值」；「先判兑现暴露后追改」当场毙）

执行格枚举扩为**执行中/兑现/打折走样/烂尾/变形**：变形=名义奉行、实质借旨行私（剿饷加派三厘而地方浮收翻倍、名义练兵实质虚冒兵额型）；与打折走样的判官分界＝**恶果/受益是否在旨外**——打折走样=旨意方向仍在、力度范围缩水跑偏，变形=借旨之名行旨外之私（另有受益人或另生旨外恶果）；#473 seed 三分「奉行/拖磨/变形」映射=奉行→兑现、拖磨→打折走样/烂尾（既有值装得下）、变形→唯一新值。0052 四值句、#565 AC、CONTEXT「颁布格/执行格」词条随本闸 later-doc-wins 修订（执行格零代码、#565 未动工——改枚举于此刻最便宜）；M12 交接映射钉死：变形⊂0011-5 exec_fidelity「阳奉阴违/打折扭曲」之借旨行私亚型，resolve_core 接管后产同值、表结构不改仍成立（同列新枚举值；0052 cmr R14 先例只挡**玩家动作**入判官枚举，不挡判官判决值）。**真相层永不撒谎**：判官**产出变形判决的那一刻**执行格即记真值（触发时机循 0076 到期/松手复核，非「借旨行私物理发生月」；执行中途改判＝执行格在 0051「执行中→结案」链内的正常填值更新，非判决可撤销）——「先判兑现、暴露后追改判决」被毙：暴露前 DB 无法区分「真办成」与「被歪办」＝B11 静默漂移不可辨，且需发明「判决可撤销」碰 0052 结案语义；骗局只活在奏报口径（0073）与情报层（#472），皇帝被骗、数据库不被骗。
