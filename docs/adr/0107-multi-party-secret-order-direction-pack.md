# 0107: 多人密令第二刀方向包——四方向只钉方向，HOW 归第二刀密令结构化裁判

Status: Accepted（PR #708 merged 2026-07-08；决策：2026-07-08 M12 设计闸 grill G7 用户拍板；承 #555/#87/#89。**本 ADR 无本轮实现切片**——(a)(b)(c) 随第二刀密令结构化裁判交付，ADR↔切片对表时非孤儿）

多人密令（同一密令有多个共谋者主办/协办/知情）本 ADR **只钉四条方向、不设 HOW**——暴露判定算法、跳档精确阈、认下/弃卒后果表全归**第二刀密令结构化裁判**（0011-5 D5-7 + defer 清单「执行层四态细分 + 密令结构化裁判，与现存密令核议合一 = 第二刀」，本方向包与其同批、不在本轮展开）。**方向①保密度随知情人数衰减 → 暴露 roll 恶化**：承母 ADR（0011）决定5「密令透支账」（累计密令数 → 朝野警觉 → 暴露 roll 单调变差 → 暴露反噬确定性落库，堵 H4 旁路提款机）的多人扩展——现账按密令数/单人透支驱动 roll，本条把「同一密令的知情人数」（0053 参与人名单三档 {主办,协办,知情} ∪ 0028 捕获的知情圈——**按人物稳定 id 并集去重后计数**〔cmr 线上 R3 勘正：直接相加会把「既在参与名单又被捕获入圈」者重复计入、虚增恶化惩罚〕）加成**第二条暴露恶化臂**，人越多保密度越低、roll 越差。**方向②共谋者互握把柄 = 落 #479 把柄边**（0081 有向边引擎 / 0086 seed 网），**不建新库**；密令暴露后这些把柄边成党争弹药，可被 G1 查案差务（0092 差务/带宽 + 0058 月度进展轨）吃到当进度加成（同 0103 反正者把柄边转证词挂差务的口径）。**方向③暴露跳档（密 → 半公开 → 满朝风闻）**：暴露非布尔而逐档跃迁，档语义落 0058 月度进展轨（逐月落库、restore 无损接续，P1），0028 知情圈黑名单（排除名单，子结构 schema 真源归 #489）定「谁本不该知道」，档越高党争弹药越足。**方向④陈新甲选择题（认下 vs 弃卒）**：暴露到满朝风闻档、皇帝二选——**认下**（自担污名；落点桶＝STIGMA 独立常量表 + 血债走 0011-2——**此为方向级落点，量级/后果表仍归第二刀**）或**弃卒保车**（把承办人推出去顶罪）；弃卒只产 0079 信用事件「弃卒保车」类薄记录（当事人/事件类/一句语境/案卷 origin，发生当场落库，**并携带结构化施弃方类别＝皇帝**——0102/0104 判别契约的写端要求、缺失会被 0104 fail-closed 跳过，字段已列 #628 写端 schema/DoD）——**下游派生由 0104（loyalty 降）与 #479 君臣边在各自读端消费（0079 事件 id 幂等），本方向不另行联动调用**；0102 rule④ 只辖派内弃卒、皇帝弃卒不 fire 其 identity 规则（0102 已明）。**不做选项菜单**（召对无 chips 铁律，同 0079）——就是平常下旨、判官识别其为处置并记事件。净新契约只有三条：**(a) 暴露 roll 的「知情人数臂」**（挂母 ADR 密令透支账，人数越多 roll 越差）；**(b) 暴露度逐档字段**（密/半公开/满朝风闻，落 0058 进展轨的进展档语义）；**(c) 认下 vs 弃卒的分支落点**（认下 → STIGMA/血债〔方向级落点、量级第二刀〕；弃卒 → 0079 信用事件 + **0104/G4 loyalty + #479 君臣边**派生——G2/0102 只消费**派内弃卒**结构化事件、皇帝弃卒不 fire 其 identity 规则，与本段前文及 0102 边界一致）——三条阈值/衰减系数/跳档阈一律**首版随 playtest**（同 0011-4 D4-6 先例）。载体契约全已拍（**Accepted 设计载体、实现随各自家族切片落地**——0058 进展轨=#619、0079 信用事件=#628、#479 边=#632 起；0073 明文「勿当现成表直接 SELECT」，消费侧以原生 blocked_by 对齐）：0053 参与人（知情档）/ 0028 知情圈黑名单 / 0058 进展轨 / #479 把柄边 / 0079 信用事件，零新库、零新 actor 层。

**毙案**：本轮把 HOW（暴露判定算法、跳档精确阈、认下/弃卒后果表）全设计完 = 抢第二刀密令结构化裁判的活（0011-5 defer 明置其为第二刀、与现存密令核议合一），毙。平行另起一套多人密令核议引擎（脱离 season_simulator.md:84-90「密旨动向」章现存密令核议〔核议五项在 :88；0011-5 L107 原引 :79-82 系文件后续插章漂移，本 ADR 顺附勘正〕）= 违 0011-5 D5-7「执行层四态与密令核议是同一套软判、不另起平行核议」+ dont-overbuild，毙。
