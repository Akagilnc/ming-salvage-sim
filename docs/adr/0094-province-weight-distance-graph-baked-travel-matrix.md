# 0094: 省权重距离图＋离线烘焙耗时矩阵（#475 空间底座）

空间底座：**手工邻接图为真源，离线烘焙全对耗时矩阵为运行时唯一读面**（29 region 起步）。图＝节点权重（横穿该省的时间成本，**原生小数**——东江这类岛镇 0.2 量级）＋**边附加成本**（海路/险隘：登莱—东江渡海、大庾岭）；烘焙对每一对取**总权重最小路线**（权重即时间成本，最小＝最快——运河官道快、蜀道慢全是权重的事）；**头尾各半**（出发/目的省各计一半、途中省全计）→ 矩阵自动对称（A→B＝B→A，与物理现实对齐）且每省权重对进出行程都生效（调参直觉成立：「东莞不够远」→拧广东）。运行时纯查表、零寻路代码。弃案：运行时寻路（引擎多一块活代码、路线对错藏进算法，不如烘焙表可人工审）；直接手拍 29×29 矩阵（406 格无结构保证一致性，「绕路比直达快」无人报错）。节点集不封顶：要冲节点（喜峰口类）将来加点重烘、矩阵跟着宽，架构不动——要冲节点/军队走图归 #93。
