# V2：按一件事连贯推演，按基础信息落账

Status: proposed（2026-09-09；owner 已拍方向，设计待评审，未实施；仅适用于 V2）

同一件事的人事、财政、军事因果由综合推演连起来，落库时才区分人、钱、军队等基础信息，避免各领域各演一份相互矛盾的结果。
世界推演同时考虑多件事共用的人手、钱粮和兵力，保持事务联系，但不规定每件事一次调用或全天下只能一次调用。
原话、时间节奏及「一件事不拖垮其他事」的总原则见 [讨论依据](../design/game-v2-architecture.md#事务与时间依据)，本决定只定推演与领域记录的组织关系，不预设 DB 原子性、回滚、重试或重演协议。
