# 0075: 半途反噬——松手先过挽留一场，坚持撤按「根基几分」分档倒扣

Status: Proposed（2026-07-06 #476 设计闸 grill Q3 用户拍「软判程度＋挽留一场」）

承诺存续期内玩家松手（判据四类草案，机器可查、细化归 PRD：**断供**——承诺月供停拨/长欠；**挪用**——附带条件破坏，动了说好不动的专款；**撤人**——罢/调主办，人亡政息；**改弦**——颁相反新旨）**不立即事废**：先顶出主办大臣哭谏一场（复用 form③ 到期待裁→DECISION 通道，零新基建；「臣的信心一半是皇爷给的」机制化——毕自严泣血陈情直面皇帝），当面反悔或坚持；坚持则执行格判官按**「根基成了几分」**软判分档（判官定性读事实——已过段数/已投入/实际进度，**不建完成度数值字段**，0077 拒假精度同源；档界细化归 PRD）：刚起头撤=损失小白花钱；**办到一半撤=最痛**——沉没投入＋国势本身倒退（承诺所系局势恶化/涌现新事件，挂 0014 涌现轨），比不办还糟；根基已成撤=事不废、只失后续红利。与 0056 毁约代价轨**叠加不重复**：0056 管皇威/当事大臣观感/派系三笔，本条管「事」本身的倒退——「办到一半松手事便废」是世界的账，不是名声的账。时序：先挽留场；当面反悔则两轨皆不落；坚持撤才各落各账——0056 名声笔仅当松手动作构成其毁约触发时落（收权·罢差按 0041③ 本不触发 0056），本条事轴倒退照落；单次编排细节归 PRD。
