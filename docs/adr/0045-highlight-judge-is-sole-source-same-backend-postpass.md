# 0045: 大臣奏对高亮唯一源 = 同通道判官后处理

Status: Proposed（决策核：2026-07-03 #478 grill Q3 用户拍；配套口径为设计推演、细节归 PRD/切片）

**决策核（用户拍）**：关键短语高亮（北极星「文字墙 vs 引导阅读」分界元素）的唯一来源 = **判官后处理**——大臣回话完成后，用玩家配置的**同一 LLM 执行通道**发一次附加短调用，读成品全文、输出承重短语清单；**organic markdown 一律从显示文本剥离**（治现存字面星号 bug），可作判官输入信号但不直接当高亮。判官是**生成完成后的独立机器面调用、不在大臣回话的生成组装链内**——ADR 0033（特征化不约束，覆盖整条生成组装链）因此不适用于判官，判官可施硬格式约束。**配套口径（设计推演）**：短语清单随消息落库、前端只认清单；高亮只标大臣气泡（帝/递话不加，循北极星）；判官设超时上限，超时/失败一律静默降级为无高亮、回话先行展示——永不挡回话、不挡下一轮输入；非流式通道可折进等待窗出场即带高亮，流式通道流完补挂（补挂方式留试玩调）。**否决的路**：大臣自标（违 0033）；渲染 organic 粗体当机制——2026-07-03 实测 14 样本完全通道相依（codex 0/6 零粗体、DeepSeek 3/3 段首式、MiMo 3/3 公文清单式、Nemotron 1 发 27 处轰炸），北极星的 organic 高亮是 Claude 形态1 特有笔性（原始 session ae148299 逐字带 `**` 为证），不可移植。
