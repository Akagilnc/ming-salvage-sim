# 0101: 反咬三档 + 宫变档——resolve 同步评估反制、修「崇祯不死金身」

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G1c 用户拍板〔反咬全建、宫变档净新〕；承 #555/#87/#89）

resolve 判打击类动作（抄家/赐死/罢黜/申饬等）时**同步评估目标反制能力**，把 0011-5 `ResolveResult{ …反咬列表… }` 输出契约里的「反咬列表」字段语义**首度钉死为三档**：**①账面**——血债爆 + 同类防备棘轮 `wariness`↑（0011-2 D2 既有 `faction_axis_debt.wariness` kinship 臂，零新轴）；**②政治反扑**（弹章雨/构陷/试探）——**不建专门机制**，`wariness`/血债/`leverage` 的数据变化经 0091 弹劾潮硬门（`gather_candidate_events` + `auto_trigger_seed_issues`）+ simulator 涌现轨自演（0037 铁律：入账即入机制、下游读账、不预建专机制）；**③宫变档（净新）**——触发 = 三连续量乘积：**要害抓手**（提督东厂/掌司礼监批红/净军京营职/宫内网络，全 `characters`/`office_type`/`faction` DB 现成、抓手拆一个少一分）×**打击存亡度**（抄家赐死满档、申饬低档，取 resolve 动作 severity）×**程序非法度**（＝反扑动员力，与「合法性」反号——`reason_code ∈ 依律集` 依律坐实 → 非法度低 → 反扑动员力塌〔史实：定逆案后无人敢反〕；STIGMA/中旨强颁〔0052 中旨强颁组合态：颁布格留判官「打回」值 + 0051 中旨标记字段置位〕→ 非法度满 → 全党存亡同仇；码集二分真源 0011-2 D2-5。三乘子同向：值越高越危，乘积单调）→ 过阈 → **接现成结局叙事层判定**（复用 `decree.py:1308` 三级判定〔叙事→数值→到期〕的**叙事型入口**，退位/自尽同族，此处产被废/暴毙）→ game over。政变之夜「谁护驾谁倒戈」的帝侧变量读 `loyalty`（本批 0104，双向互指）。**dry-run 呈现口径（世界诚实、死于莽撞）**：召对侦察对反咬列表的宫变档**如实透出但只给定性二值**（「恐激变／尚无虞」级，大臣 in-character 谏止＝剪刀之夜式征兆同源）——D5-3 等价性在 **ResolveResult 对象层**保持不破，呈现层一律定性（P4 本就禁裸值）；宫变档对外**无连续读数可二分**（反 probe：只此二值），金身破口惩罚的是**不问而莽**者——反复问「现在动手安否」是史实君主行为、非 exploit。

设计意图（用户明示）= 修「崇祯不死金身」：开局莽抄九千岁（魏掌东厂 + 司礼监批红 + 净军、帝无班底）→ 中旨强颁 → 三量俱高触宫变 → game over；会玩者复现倒魏史实弧（先拆抓手 → 纵容弹章攒把柄边〔#479〕→ 差务坐实真重罪〔G1a 取证轨〕→ 依律清算 → 反扑动员力塌 → 安全）。**净新契约只此一条**：「三连续量乘积 → 宫变触发阈 → 结局叙事层入口 signal」+ 反咬列表三档语义钉死——三量各读现成（抓手/存亡度/合法性/`loyalty` 全在既有列或 resolve 产物内）、tier①② 零净新、结局层复用 `decree.py:1308`。首版阈值/概率/clamp 口径随 playtest（同 0011-4 D4-6 ceiling 先例，不发明精确值）。**organic 非剧本**（母 ADR 0011 决定 6 明拒 point-of-no-return flag / 「最后机会」特例事件，机制从连续量涌现、抓手拆一个少一分）；**破局可真**（依律坐实后动手安全，史实定逆案 262 人走程序、反扑动员力塌）。剧本陷阱（`if 抄魏 and turn==1 then death` 式硬编码不可逆点）＝违母 ADR 0011 organic 铁律，毙；给崇祯加血条/生命值 bar＝人造难度补丁 + 违 P4「皇帝无表、数值只定性叙事呈现」，毙。**目标类别 cap 表（单一真源，cmr 集中化——通用三量评估之上按目标类别裁档位上限，防「勋戚持京营职被通用算进宫变」类实现分叉）**：①**内廷权阉类**（掌东厂/批红/净军/宫内网络）＝宫变档可达（三量评估全开）；②**勋戚外戚**＝封顶内廷施压档（0106——勋戚虽可持京营职，其法统全系皇权、造反自毁根基〔同宗室双命门逻辑〕，史实无勋戚政变）；③**军镇将门**（总兵/督师级边镇野战兵权）＝不入宫变档，军事式反咬（部众哗变/率部投敌/拥兵观望）**归军事线**（0025 哗变状态机/#299 后续），第一刀只走 ①账面＋②政治档——此缺口显式承认、非遗漏（PRD Out of Scope 同批载明）。0106 的勋戚封顶即本表第②行、两处同源。
