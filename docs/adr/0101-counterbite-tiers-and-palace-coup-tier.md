# 0101: 反咬三档 + 宫变档——resolve 同步评估反制、修「崇祯不死金身」

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G1c 用户拍板〔反咬全建、宫变档净新〕；承 #555/#87/#89）

resolve 判打击类动作（抄家/赐死/罢黜/申饬等）时**同步评估目标反制能力**，把 0011-5 `ResolveResult{ …反咬列表… }` 输出契约里的「反咬列表」字段语义**首度钉死为三档**：**①账面**——血债爆 + 同类防备棘轮 `wariness`↑（0011-2 D2 既有 `faction_axis_debt.wariness` kinship 臂，零新轴）；**②政治反扑**（弹章雨/构陷/试探）——**不建专门机制**，`wariness`/血债/`leverage` 的数据变化经 0091 弹劾潮硬门（`gather_candidate_events` + `auto_trigger_seed_issues`）+ simulator 涌现轨自演（0037 铁律：入账即入机制、下游读账、不预建专机制）；**③宫变档（净新）**——触发 = 三连续量乘积：**要害抓手**（提督东厂/掌司礼监批红/净军京营职/宫内网络，全 `characters`/`office_type`/`faction` DB 现成、抓手拆一个少一分）×**打击存亡度**（抄家赐死满档、申饬低档，取 resolve 动作 severity）×**程序合法性**（`reason_code ∈ 依律集` 依律坐实 → 反扑动员力塌〔史实：定逆案后无人敢反〕 vs STIGMA/中旨强颁〔0052 中旨强颁组合态：颁布格留判官「打回」值 + 0051 中旨标记字段置位〕→ 全党存亡同仇；码集二分真源 0011-2 D2-5）→ 过阈 → **接现成结局叙事层判定**（复用 `decree.py:1308` 三级判定〔叙事→数值→到期〕的**叙事型入口**，退位/自尽同族，此处产被废/暴毙）→ game over。政变之夜「谁护驾谁倒戈」的帝侧变量读 `loyalty`（本批 0104，双向互指）。

设计意图（用户明示）= 修「崇祯不死金身」：开局莽抄九千岁（魏掌东厂 + 司礼监批红 + 净军、帝无班底）→ 中旨强颁 → 三量俱高触宫变 → game over；会玩者复现倒魏史实弧（先拆抓手 → 纵容弹章攒把柄边〔#479〕→ 差务坐实真重罪〔G1a 取证轨〕→ 依律清算 → 反扑动员力塌 → 安全）。**净新契约只此一条**：「三连续量乘积 → 宫变触发阈 → 结局叙事层入口 signal」+ 反咬列表三档语义钉死——三量各读现成（抓手/存亡度/合法性/`loyalty` 全在既有列或 resolve 产物内）、tier①② 零净新、结局层复用 `decree.py:1308`。首版阈值/概率/clamp 口径随 playtest（同 0011-4 D4-6 ceiling 先例，不发明精确值）。**organic 非剧本**（母 ADR 0011 决定 6 明拒 point-of-no-return flag / 「最后机会」特例事件，机制从连续量涌现、抓手拆一个少一分）；**破局可真**（依律坐实后动手安全，史实定逆案 262 人走程序、反扑动员力塌）。剧本陷阱（`if 抄魏 and turn==1 then death` 式硬编码不可逆点）＝违母 ADR 0011 organic 铁律，毙；给崇祯加血条/生命值 bar＝人造难度补丁 + 违 P4「皇帝无表、数值只定性叙事呈现」，毙。
