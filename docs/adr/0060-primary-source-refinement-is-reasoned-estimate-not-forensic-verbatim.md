# 0060: 一手史料精化 = 有锚推算,非逐字文献核验

Status: Accepted(2026-07-04 #272 grill-with-docs Q1 用户拍)

《万历会计录》一类一手史料精化工作(#272)的精度标准,延续 #70/#259 已定的「量级定稿、逐条可驳」,**不升级为逐字文献学核验**——编排器今早两轮 #272 都卡在「查不到逐字对应就不敢写」,把「一手数据」误读成「每个数字须指回影印图像的具体字迹」。真正标准:**推测(可接受)= 有可指认的锚点(真实史料记载 / 项目已认可的换算法)+ 一条可被复核挑战的推导链,即使终值非逐字抄录;瞎猜(不可接受)= 无锚点、凭感觉定量级、说不出推导链**。史料本身(含《会计录》未覆盖的时段/字段,如剿饷 1637、练饷 1639 均晚于万历九年成书、天然无一手数)不可得时,延用既有折算法(如 #259「国总×该省田亩占比」)即成立,不因缺逐字源而单独摘出验收范围或增设特殊标记。
