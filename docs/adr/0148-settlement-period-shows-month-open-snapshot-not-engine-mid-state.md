# 0148 — 结算未完成时皇帝看见月初快照与核账叙事，不看引擎半程状态

Status: proposed（陛下 2026-08-16 拍：mock 四版比选取「丙」）

## 决定

**核账期的皇帝可见面 = 月初呈现口径 + 核账叙事，由持久回合相位驱动、跨刷新一致。** 不改 [ADR 0008](0008-settlement-applier-contract-and-transaction-boundary.md) 的 phase / 事务 / 恢复语义，不提前置位或改义 `settling`。会话内自点颁布/退朝起即入核账呈现；跨刷新的核账期以持久相位为准——前半段尚未提交即中断重开，回到点击前盘面（与 0008 一致）。至本月推进完成止：钱与民心皇威按月初口径，年月标核账态，王承恩递话「事情在办」；无进度条、百分比或剩余秒数。

**月初呈现真源（只服务呈现，非结算恢复权威）。** 现成相位能判定「是否在核账期」，但不能单独给出跨刷新同一份月初钱粮民心。实现前按最小复杂度比较三条路径再择一或组合：①复用既有可读值（相位、恢复上下文、既有回合/账本资料里已能确定的月初口径）；②从既有账本与历史资料重建；③仅当①②对冻结字段集不足，再为呈现切片新增存储。禁止未比较就另存整世界快照，禁止与相位竞争的第二结算权威。生命周期：进入核账期时按「点击前盘面」确定；本月推进完成即失效；刷新后从同一真源再取，不得靠会话忙碌标志。

**入口与只读面。** 「会推进或改写本月」= 会推进本月管线，或改写本月尚未收官盘面上玩家可写事实的入口，一律关闭；按此判据涵盖旨稿增删改与成诏、颁布/退朝/亲裁续跑、召对发言与重试/撤回、会落入本月的待确认动作之确认/撤回/重试——枚举以判据为准，不靠点名穷尽。优先复用既有「前半段已提交」服务端拒写门或缩小暴露面，不另造平行真源。收藏/画像/选妃等非本月推进入口不强制封；存档允许；读档与重置属离开本局，不伪装成核账继续。只读投影必须自洽：省份/军队/议题/户部预算与库藏在核账期要么与顶栏同取月初口径，要么缩小为不可浏览——禁止顶栏冻结而抽屉读活值，把不自洽挪进抽屉。

## 为什么

固定财政等前半段先提交、月份推进在管线末（0008），撞上亲裁暂停时皇帝会看见「钱已动、月份未过」——QA #1201 国库/内库/民心已变而日历仍在十月。这是检查点泄漏到呈现层。同时 #1203：整屏核账锁曾只跟会话忙碌标志，刷新即消失；服务端拒写门已按相位拦住推进/改写，但**持久相位未驱动呈现与控件态**，玩家见可操作界面加「待批、钱未扣」，合理误判为没批成。取月初口径而非标「未过账」：标注只标出不自洽，冻结才消除它。取叙事而非进度条：P4「皇帝无表」，「户部还在核这个月的账」本身可叙。

## 边界

- 不动 [ADR 0008](0008-settlement-applier-contract-and-transaction-boundary.md)：`pre_settle` 仍先提交；`settling` 仍只表示前半段已完成；恢复与 ready context 语义不变。本 ADR 只约束中间态对皇帝的可见性与可操作入口。
- 冻结与月初真源是呈现投影；活盘面与结算/恢复真源仍按既有契约。
- 失败态（结算真挂）呈现另议。

## 否决的备选（防日后重议）

- **显示新数但标「未过账」**：多一套视觉语言，世界仍不自洽。
- **数值区整块让位给叙事**：批红常要看库藏余额，真碍事。
- **会话忙碌标志作核账真源**：刷新必丢（#1203），且与已有服务端相位门平行。
- **提前置位或改义 `settling` 以覆盖「自点击起」**：违 0008。
- **未比较复用/重建就新增整世界快照或第二结算权威**：过重，且与相位/恢复真源竞争。
