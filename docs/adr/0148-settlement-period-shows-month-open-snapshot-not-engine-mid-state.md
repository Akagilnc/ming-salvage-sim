# 0148 — 核账期可见面 = 月初快照 + 核账叙事，相位驱动

Status: proposed（陛下 2026-08-16 拍：mock 四版比选取「丙」；月初真源三路比较已定案）

## 决定

**核账期的皇帝可见面 = 月初快照 + 核账叙事，由持久回合相位驱动、跨刷新一致。** 不改 [ADR 0008](0008-settlement-applier-contract-and-transaction-boundary.md) 的 phase / 事务 / 恢复语义，不提前置位或改义 `settling`。跨刷新以持久相位为准——前半段尚未提交即中断重开，回到点击前盘面（与 0008 一致）。核账期内：国库、内库、民心、皇威按点击前口径；年月标核账态；王承恩递话「事情在办」；无进度条、百分比或剩余秒数。核账期关闭省 / 军 / 议题浏览（叙事：皇帝在等档房核账、各部尚未呈报）；**不做全量世界快照**。户部若开，余额必须与顶栏同取该四键快照。会推进或改写本月的入口关闭；非本月推进面不强制封；存档允许；读档与重置属离开本局。**禁止顶栏冻、抽屉活。** 核账期何时起算、一点即进与未了续跑见 [ADR 0149](0149-enter-settlement-period-on-click-in-flight-continues.md)。

**月初呈现真源（只服务呈现，非结算恢复权威）= 最小新增四键投影，唯一可行。** 在颁诏与退朝两条进入核账的写路径上、任何突变之前，按点击前盘面持久化国库 / 内库 / 民心 / 皇威（并记所属回合以防串月）；核账期内顶栏与户部余额读此投影，引擎与恢复仍读活盘。进入核账期时确定，本月推进完成即失效；刷新从同一真源再取，不以会话忙碌标志为核账真源。三路比较后：

- **路①复用既有可读值——不可行。** 主库无点击前四键；度量只有当前值、无历史。最接近的既有热备有硬洞：退朝无诏不写、失败静默、恢复重进可被半程态覆盖、只留近回合、整库文件非可读投影。
- **路②从既有流水重建——不可行。** 民心 / 皇威无账可反推；钱侧非负截断有损、无点击时刻游标，月中内库一次性扣与固定批扣混在同回合流水。
- **路③最小新增——唯一可行。** 只为呈现切片记下点击前四键 + 回合；禁止另立第二结算权威或整世界快照。

## 为什么

固定财政等前半段先提交、月份推进在管线末（0008），撞上亲裁暂停时皇帝会看见「钱已动、月份未过」——QA #1201 国库 / 内库 / 民心已变而日历仍在十月。这是检查点泄漏到呈现层。#1203：整屏核账锁曾只跟会话忙碌标志，刷新即消失；服务端拒写门已按相位拦住推进 / 改写，但**持久相位未驱动呈现**。取月初口径而非标「未过账」：标注只标出不自洽，冻结才消除它。取叙事而非进度条：P4「皇帝无表」。只读浏览亦漏半程（军饷士气已变、新局势可立），故关省 / 军 / 议题，不靠整世界冻结撑「只读自洽」。

## 边界

- 不动 [ADR 0008](0008-settlement-applier-contract-and-transaction-boundary.md)：`pre_settle` 仍先提交；`settling` 仍只表示前半段已完成；恢复与 ready context 语义不变。本 ADR 只约束中间态对皇帝的可见性与可浏览面。
- 四键投影是呈现投影；活盘面与结算 / 恢复真源仍按既有契约。
- 入口起算与未了续跑归 [ADR 0149](0149-enter-settlement-period-on-click-in-flight-continues.md)；失败态全面设计另议。

## 否决的备选（防日后重议）

- **显示新数但标「未过账」**：多一套视觉语言，世界仍不自洽。
- **数值区整块让位给叙事**：批红常要看库藏余额，真碍事。
- **会话忙碌标志作核账真源**：刷新必丢（#1203），且与已有服务端相位门平行。
- **提前置位或改义 `settling` 以覆盖「自点击起」**：违 0008。
- **复用现成热备或活值当月初真源**：见上①硬洞。
- **从流水反推四键**：见上②不可逆。
- **未比较就新增整世界快照或第二结算权威**：过重，与相位 / 恢复真源竞争。
- **顶栏冻、抽屉活**（含省 / 军 / 议题读半程）：把不自洽挪进抽屉。
