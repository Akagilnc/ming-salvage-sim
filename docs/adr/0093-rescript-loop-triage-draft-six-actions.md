# 0093: 票拟-批红回路——急务分拣（actor 立场）＋六动作批红

多线告急的呈现与拍板做成**票拟-批红回路**：月末结算→**分拣人**（司礼监批红太监/内阁首辅，读现有 office＋faction）挑「今月急务」3-5 条**带立场排序**（0034 瞒报管「看不看得到」、分拣管「先看哪条」，同一博弈原理的排序形态；全量邸报照旧可读——只排序不过滤；**反茧房窄路全系既有机制、零新造**：召见动作听票拟外声音、任免换分拣人〔分拣人＝真实官职，office_changes 现成，换人即换立场〕、密奏渠道照旧）→每条附**票拟**（内阁拟办意见，夹立场：荐自己人/不动自家奶酪＝决策层的代理人问题镜像；可**两拟**陈两端不荐＝内阁甩锅信号，actor 行为留 LLM 演）→皇帝**批红六动作**，各占（时间×担名）不可能三角〔快/不担责/不放权至多取二＝高压发动机〕一格：依拟（快/内阁担/夹带照收）、发回改票（中/内阁续担/多轮怨）、另旨·中旨（快/皇帝独担 0070 御笔；中旨案卷／频度／离心 later-wins → #657 contract §C.8，正式逐派离心归 M12）、下部议·廷议（慢/站台者担/谁的部谁做局/**无人站台→议而不决**——南迁议 beat 从机制涌现）、留中（无人担/惯性恶化＋寒心＋派系解读沉默）、召见（中/吃注意力/可当面索态）；**不批＝留中**结算。站台闭环全现成轨：事前肯不肯＝LLM 读 #479 关系账＋0084 态势软判，强推＝御笔手敕（0070），事后 0053 委派链上溯、处置站台者入 #479 信用账。**与 0055 批红页同一案头**：打回件三选（0055）与急务票拟六动作是同一批红页上的两类条目，不建第二案头；廷杖/办上疏人不占批红槽位（走自由下旨通道，office_changes 现成）；**下旨自由通道照旧并存**（批红＝世界找你，下旨＝你找世界）。落库走 issue/DECISION 待核议通道（form③ 顶出同通道）；依拟/另旨产生的差务照 0092 绑承办人吃带宽；票拟全奏疏体零数值（P4）；票拟生成与结算 extractor 并行（P5）。**新造量（本闸最大交互面）＝票拟生成 LLM 步＋web 批红表单面**，其余全接现成轨。系统中立优先级警报＝仪表盘，毙。
