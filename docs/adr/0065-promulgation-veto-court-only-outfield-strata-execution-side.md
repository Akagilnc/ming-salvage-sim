# 0065: 颁布关否决只属朝堂——场外阶层阻力全在执行侧、只用现成信号

Status: Proposed（决策：2026-07-06 #473 设计闸 grill Q3 用户拍选项 1）

能把旨挡在「颁不出去」的只有朝堂：三关口（票拟/批红/封驳，对齐 0011-5 阶段一 blocked_layer 与 0052 颁布格）＋六派权势（faction leverage 已由在朝官职权重现算，db.py recompute_faction_leverage，零新建）。部院属阶段二执行层（0011-5 P1-6 范畴分离）：其打折走样归执行格、不产打回。场外阶层（宗藩/勋戚/军镇/地方士绅）**不进颁布关**——史实同构（封驳科抄是京官武器，地方未接旨无从挡颁）；其阻力只在执行侧起作用且**只用现成信号**：士绅＝region 级 gentry_resistance（既有真牙，咬到账率），军镇/将领＝执行格判官读现有军队姿态数据软判。不为场外阶层建任何新数据轴；宗藩线维持不展开、只落最小口径（既有纪律）。M12 resolve 硬化后此界不变（硬化换引擎不换边界）。
