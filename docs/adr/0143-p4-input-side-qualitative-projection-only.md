# 0143 P4 执行机制唯一化：输入侧定性投影，辖区=玩家可感知通道

Status: Proposed（决策：2026-07-19 owner grill 四问收口；#1000 终审方向落法；同日文档闸修一轮吸收 completeness 双腿候选——混合通道字段级口径、家产对齐 0122、对 0010 的局部废止点名）

P4「皇帝无表」的唯一执行机制是**输入侧定性投影**：在结构化数据层把**角色属性数值**（忠诚/能力/清廉/胆略等六轴类属性；**家产除外——沿 0122「报大概数放行」的奏报口吻约数**）翻成档位词（0122 词表、0010 定性版口径），使**玩家可感知通道**（召对回话、邸报叙事、旁白、读心、见闻等——凡产出会被玩家读到的 LLM 调用）的输入里没有裸属性数值；世界事实数值（年月/银两/兵额/城防等）不在此限。**混合调用按字段分层**（season simulator 一次调用既判定又写邸报）：P2 建模数值（军力/钱粮/城防）保留裸数供判定，角色属性以档位词进入——构造性保证叙事写不出属性分、判定不失燃料。纯机面通道（`inspect_*` 类工具、extractor 抽取——产出不回流玩家）照旧吃裸数值（P2 域）。对 LLM 已生成散文的一切措辞级擦洗与扫描（redline 枚举、regex 替换、LLM 回话守门断言及其测试）整族废除，不得以「二道闸」名义保留（0142 世系；485 五轮 fix-fix 与 over-redact 实证）；P4 守门测试收缩到**确定性引擎产物面**（上下文构造、渲染、装配）。

对既有法的局部废止（后出为准，0010 原文已加括注）：0010 决定 3「simulator payload＝带数值版」在**角色属性字段**上改为档位词，其余字段照旧；0010 方案 (b)（玩家面 LLM 回话运行时脱敏）废止；0010 测试级「扫 LLM 回话出现裸属性即红」废止。0122 全文（六轴词带、家产放行、prompt 正向铁律）照旧，并为本 ADR 的词表真源。

弃案：输出侧守卫词表扩容（洞空间=自然语言表数方式，无界打地鼠+over-redact 误伤，owner 2026-07-18 终审毙）；全 LLM 通道罩投影（伤 P2 判定输入契约）；擦洗层降级保险丝（掩盖 choke 真洞、违 0142）。
