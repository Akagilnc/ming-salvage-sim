# 0143 P4 执行机制唯一化：输入侧定性投影，辖区=玩家可感知通道

Status: Proposed（决策：2026-07-19 owner grill 四问收口；#1000 终审方向落法，#983 epic 重构随行）

P4「皇帝无表」的唯一执行机制是**输入侧定性投影**：在结构化数据层把**角色属性数值**（忠诚/能力/清廉/胆略/家产等）翻成档位词（ADR 0122 词表、渲染适配器定性版口径），使**玩家可感知通道**（召对回话、邸报叙事、旁白、读心、见闻等——凡产出会被玩家读到的 LLM 调用）的输入里没有裸属性数值；世界事实数值（年/月/银两/兵额）不在此限（沿 0010/0083 既有口径）。引擎机面通道（season simulator 判定、extractor 抽取）照旧吃裸数值（P2 域）。对 LLM 已生成散文的一切措辞级擦洗（redline 枚举、regex 替换及其测试）整族废除，不得以「二道闸」名义保留（0142 世系；485 五轮 fix-fix 与 over-redact 实证）。

弃案：输出侧守卫词表扩容（洞空间=自然语言表数方式，无界打地鼠+over-redact 误伤，owner 2026-07-18 终审毙）；全 LLM 通道罩投影（伤 P2 判定输入契约）；擦洗层降级保险丝（掩盖 choke 真洞、违 0142）。
