# 0091: 弹劾潮＝事件涌现轨上的硬门 issue

Status: Accepted（PR #663 merged 2026-07-07；决策：2026-07-07 #477 设计闸 grill Q5 用户拍选项 2；2026-08-23 owner 修订）

党争「借灾难发力」（改稻为桑标杆案第三线）落为**事件涌现轨上的一类 issue**：灾难事实账（民变升级/战败/哗变/变形暴露）×对立派系 leverage 够高时，`gather_candidate_events` 硬门只向现有月末 issues extractor 提供候选资格与结构化事实；现有调用中的**发难派系 LLM 角色**决定是否发难、标靶与归因，并仍由既有 `new_issues` 写口产出，不输出即不发难。不得由代码自动立项，不新增 LLM 调用或第二事件生命周期。

**处置三难全有代价**：顺水推舟办人（快，可能错杀能吏——胡宗宪 beat，寒心入 #479）／压下弹劾（耗皇威＋发难派系怨气积累）／查实再办（稳但慢，走 #461 稽核轨占带宽）。弹劾**真假混杂**：灾难是真的、归因带私货（与 #476 政敌检举同一原则——党争越凶皇帝耳目越多，但每条都要自辨）。factions 表（lev/sat）、faction_delta、legacy 门读派系 leverage 全现成；本 ADR 新拍仅「灾难账→候选硬门→派系角色决策→处置代价」一条契约。完整派系攻势系统（行动点/冷却/结盟倒阁）＝CK3 化，0011 明拒，毙。
