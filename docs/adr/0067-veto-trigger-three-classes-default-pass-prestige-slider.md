# 0067: 否决触发面三类、默认顺颁——皇威当滑杆调宽窄，不设固定难度旋钮

Status: Proposed（决策：2026-07-06 #473 设计闸 grill Q6/Q6b 用户拍「听起来合理」＋要求挖 1↔2 平衡点与皇威联动）

合规常务一律顺颁；否决审视只咬三触发面：(a) **越制破格**（品级破格标 0057/任别越权 0064/绕程序）；(b) **撞派系逆鳞**（动某派的人/钱/命门——命门语义 0011-4 已定，interim 判官对齐不重定义）；(c) **撞把关关口**（否决方派系把持必经衙门——从官员名单派生，杨嗣昌「崔呈秀把着都察院」beat）。**皇威档位当滑杆**（0057 已钉的判官输入，本 ADR 给语义）：皇威高→触发面收窄（言官不敢撄锋、只有硬越制硬逆鳞才有人敢挡）；皇威低→触发面变宽（威福下移，边缘越制也被试探）——游戏在「打回稀少」↔「常态拉扯」之间的位置由皇威**内生决定**，不是固定难度参数。例外：命门级逆鳞不因皇威高而豁免。官僚摩擦感**不新增颁布层拖磨态**（判决枚举保持 0052 顺颁/打回）：事前拉扯＝召对软否决（#470/#472 已建，北极星拖字诀本就发生在对话里），事后折扣＝执行格（0052，interim 填值由 0057 执行格判官软判）——**打回稀少而重，拉扯常见而软**。判官 prompt 用正向口径（写「三类才判」，不写「不要刁难」负向句）。
