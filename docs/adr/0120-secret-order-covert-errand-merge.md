## 后出设计修订：人心底约束退役（#1895，待票庭重审）

**相抵部分**：covert 差务并入执行层时的**共用意愿底档／带内只准加重**退役——代码不再为密令承办人算出「肯不肯办」的底档，判官／4a 的选择也不再只准往更重方向压。承办人本月查法、投入、敷衍或通风报信由模型按身份读其可及事实自己决定。**保留（明确不废）**：共用案卷、密令外廷豁免（「应允即落地」）、**确定性暴露累积器**（本 ADR 的世界传播设计：知情人数×目标反制的月度累积、逐档跳、落月度进展轨）。本 ADR 的暴露轨不是被废的旧每月概率掷骰门——**人物自选泄密／应对**与**风声传播的世界事实**是两条不同的东西，不可混删；旧概率门不可恢复。确定性暴露累积器的建设仍归 #725，本票既不建设也不废止它，不把待建设计验成现役核算。

## 历史设计（与上述 #1895／#1896 修订相抵条款不作并行施工合同）

密令并入执行层**同一套软判**——「执行层四态软判与密令核议是同一套执行软判、吃 resolve 算出的账本约束，不另起平行核议」正式兑现，**分裂裁判态收口**：现状 edict 走 resolve 确定性、密令仍由 LLM 自判 `done/failed`（写作时锚 `content/prompts/season_simulator.md:88` 待核议组核议五项——任务可行性/承办人能力忠诚/目标实力反制/风声暴露/承办人陈词真伪；〔#883 勘正（密令源头隔离，2026-07-17）：核议五项已随密令核议迁至 `score_extractor_personnel_secret.md` 密令节，核议主体=personnel_secret extractor；`season_simulator` 公共产出不再预读密令〕），本闸把密令收进与旨意差务共用的**机械底档＋判官带内选态（只准加重不准减轻）＋后果确定性派生**同一形状（承 #89 Q6 覆盖域），差务子类＝**covert 差务**（密令案卷本就在案卷·执行格体系内——应允即落地、始态已颁；并轨＝其执行格判定共用本批底档，**非新载体**）。三处差异与旨意差务正交：**①成色轴读阴谋非政务 ability**——covert 差务的成色臂读 `阴谋能力`（新列，独立 clamp 调制、与带宽臂同族），这是**阴谋轴自「被查」外首个「办事」读点**（阴谋轴原钉三消费方＝查案遮蔽/惊蛇/查家产精度全属被查侧，本闸开其主动办差侧）；**②暴露轨**（见下段）；**③豁免颁布关**——covert 差务不过颁布关（颁布关明文密令「应允即落地、绕外廷正是其存在意义」豁免现成），底档判定自结算内直接起、无票拟封驳层。**done/failed 退役为派生量**：结案不再由密令侧 LLM 自判，改由**到期确定性对账**从实进度只翻交付缺口（承 #89 Q5 两本账、果因分离，对账不翻归因），**陈词＝表报账**（承办人带一句复命），**谎报办成＝密令版阳奉阴违**（表报与实进度背离即底档反噬纹理）；核议五项各归其位（写作时锚 `season_simulator.md:88`；#883 后见 personnel_secret 密令节）——**可行性/目标反制→判官带内纹理与暴露臂，能力忠诚→底档轴**（loyalty＋identity×42 格立场＋satisfaction/血债），**风声→暴露轨，陈词真伪→两本账**，五项无一悬空、皆落确定性载体，公共 simulator 不再持结案真源。

**暴露轨＝确定性累积器**（兑现多人密令方向包契约(a) 的 HOW——方向包本将暴露判定算法/跳档精确阈 defer 给「第二刀密令结构化裁判」，本闸即其收口）：月度累积、**速率臂＝知情人数×目标反制**（两因子相乘前各自 clamp 非负——设计不变量防数值倒置；**时间不入速率臂**：累积值＝Σ月速率、天然随持续月数增长，速率再乘月数会二次方失控——Gemini 线上 R3 勘正；若 playtest 要超线性紧迫感，在跳档阈侧调、不改速率形状）——知情人数按**参与人三档 {主办,协办,知情} ∪ 捕获知情圈、按人物稳定 id 并集去重**（R3 勘正：直接相加会把既在参与名单又被捕获入圈者重复计入、虚增恶化惩罚）；累积过阈**逐档跳（密→半公开→满朝风闻）**，档语义落**月度进展轨**（已钉、逐月落库 restore 无损，P1）；「暴露 roll 恶化」在本闸**实现为累积速率恶化**、非每月独立掷骰。**毙案：真 RNG＝毙**——引擎无 RNG 先例、暴露度须 restore 可复现且可测试（另注策反抽签、惊蛇 roll 皆用「轨级确定性伪随机」口径，切片若需抽签沿该口径、不新引真随机）。**跳档后果全复用现成载体、零新枝**：半公开＝**把柄边成立**（#479 有向边）＋**查案差务可吃进度**（走差务/带宽＋月度轨）；满朝风闻＝**强制陈新甲选择题 HITL**（事件↔决策绑定，非选项菜单——召对无 chips），认下→**STIGMA 独立常量表＋血债**，弃卒→**「弃卒保车」信用事件携结构化施弃方＝皇帝**（写端 #628；此结构字段正是供派内认同 rule④ 做「不 fire」判别——明界：**皇帝弃卒不动派内认同**，rule④只辖党魁弃自己人、君弃臣动摇的是君臣轴）＋被弃者 loyalty 崩（规则表消费）＋#479 君臣边派生；同派物伤其类走叙事、不另立机制。**密令透支账继续吃**（累计密令数→朝野警觉→暴露速率单调变差，招揽/差务即密令类动作、现账直接吃）。**净新契约仅三条**：(a) covert 差务子类并入执行层同一套软判（同底档＋带内选态＋两本账、成色轴读阴谋）；(b) 确定性暴露累积器（月度累积、双因子速率〔知情人数×目标反制，各自 clamp 非负〕、逐档跳、落月度轨）；(c) done/failed 退役为到期确定性对账的派生量（陈词＝表报账、谎报＝密令版阳奉阴违）。**毙案（另）**：平行另起一套多人密令核议引擎＝毙（违「不另起平行核议」＋dont-overbuild，早已毙、本闸不复活）；让 simulator 续持 `done/failed` 真源＝毙（分裂裁判态渗漏、restore 丢账，收口正为关此面）。所有阈值/衰减系数一律**首版随 playtest**——暴露累积速率三臂权重、各档跳档阈、成色轴调制幅度、到期对账缺口成分（真没办 vs 被吞）口径俱不在本 ADR 发明，归切片验收。
