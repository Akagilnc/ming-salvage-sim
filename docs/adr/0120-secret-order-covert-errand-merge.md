# 0120: 密令并轨＝covert 差务子类＋确定性暴露累积器＋0107 HOW 落点

Status: Proposed（决策：2026-07-08 #89 设计闸 grill Q7 用户拍板；承 #89/#555/0011-5 D5-7、0107 方向包、0055 密令豁免）

密令并入执行层**同一套软判**——0011-5 D5-7（`0011-5:107`「执行层四态软判与密令核议是同一套执行软判、吃 resolve 算出的账本约束，不另起平行核议」）正式兑现，**分裂裁判态收口**：现状 edict 走 resolve 确定性、密令仍由 simulator 自判 `done/failed`（`content/prompts/season_simulator.md:88` 待核议组核议五项——任务可行性/承办人能力忠诚/目标实力反制/风声暴露/承办人陈词真伪），本闸把密令收进与旨意差务共用的**机械底档＋0092 判官带内选态（只准加重不准减轻）＋后果确定性派生**同一形状（承 #89 Q6 覆盖域），差务子类＝**covert 差务**（密令案卷本就在 0051/0052 案卷·执行格体系内——应允即落地、始态已颁；并轨＝其执行格判定共用本批 0116 底档，**非新载体**）。三处差异与旨意差务正交：**①成色轴读阴谋（0108）非政务 ability**——covert 差务的成色臂读 `阴谋能力`（0108 新列，独立 clamp 调制、0092 带宽臂同族），这是**阴谋轴自「被查」外首个「办事」读点**（0108 原钉三消费方＝查案遮蔽/惊蛇/查家产精度全属被查侧，本闸开其主动办差侧）；**②暴露轨**（见下段）；**③豁免颁布关**——covert 差务不过 0055 颁布关（0055 明文密令「应允即落地、绕外廷正是其存在意义」豁免现成），底档判定自结算内直接起、无票拟封驳层。**done/failed 退役为派生量**：结案不再由 simulator 自判，改由**到期确定性对账**从实进度只翻交付缺口（承 #89 Q5 两本账、果因分离，对账不翻归因），**陈词＝表报账**（承办人带一句复命），**谎报办成＝密令版阳奉阴违**（表报与实进度背离即底档反噬纹理）；`season_simulator.md:88` 核议五项各归其位——**可行性/目标反制→判官带内纹理与暴露臂，能力忠诚→底档轴**（0104 loyalty＋0102 identity×42 格立场＋0011-2 satisfaction/血债），**风声→暴露轨，陈词真伪→两本账**，五项无一悬空、皆落确定性载体，simulator 不再持结案真源。

**暴露轨＝确定性累积器**（兑现 0107 契约(a) 的 HOW——0107 本将暴露判定算法/跳档精确阈 defer 给「第二刀密令结构化裁判」，本闸即其收口）：月度累积、**速率臂＝知情人数×目标反制×持续月数**——知情人数按 0107 方向① **0053 参与人三档 {主办,协办,知情} ∪ 0028 捕获知情圈、按人物稳定 id 并集去重**（0107 R3 勘正原文：直接相加会把既在参与名单又被捕获入圈者重复计入、虚增恶化惩罚）；累积过阈**逐档跳（密→半公开→满朝风闻）**，档语义落 **0058 月度进展轨**（0107 方向③已钉、逐月落库 restore 无损，P1）；「暴露 roll 恶化」在本闸**实现为累积速率恶化**、非每月独立掷骰。**毙案：真 RNG＝毙**——引擎无 RNG 先例、暴露度须 restore 可复现且可测试（另注 0103 策反抽签、0100 惊蛇 roll 皆用「0098 轨级确定性伪随机」口径，切片若需抽签沿该口径、不新引真随机）。**跳档后果全复用现成载体、零新枝**：半公开＝**把柄边成立**（#479/0081 有向边）＋**查案差务可吃进度**（0107 方向②，走 0092 差务/带宽＋0058 轨）；满朝风闻＝**强制陈新甲选择题 HITL**（0115 事件↔决策绑定，非选项菜单——召对无 chips），认下→**STIGMA 独立常量表＋血债**（0011-2），弃卒→**0079「弃卒保车」信用事件携结构化施弃方＝皇帝**（写端 #628；此结构字段正是供 0102 rule④ 做「不 fire」判别——0102 明界：**皇帝弃卒不动派内认同**，rule④只辖党魁弃自己人、君弃臣动摇的是君臣轴）＋被弃者 loyalty 崩（0079→0104 规则表消费）＋#479 君臣边派生（0107 方向④口径）；同派物伤其类走叙事、不另立机制。**密令透支账继续吃**（母 ADR 决定5，同 0103 招揽先例——累计密令数→朝野警觉→暴露速率单调变差，招揽/差务即密令类动作、现账直接吃）。**净新契约仅三条**：(a) covert 差务子类并入执行层同一套软判（同底档＋带内选态＋两本账、成色轴读 0108）；(b) 确定性暴露累积器（月度累积、三臂速率、逐档跳、落 0058 轨）；(c) done/failed 退役为到期确定性对账的派生量（陈词＝表报账、谎报＝密令版阳奉阴违）。**毙案（另）**：平行另起一套多人密令核议引擎＝毙（违 0011-5 D5-7「不另起平行核议」＋dont-overbuild，0107 已毙、本闸不复活）；让 simulator 续持 `done/failed` 真源＝毙（分裂裁判态渗漏、restore 丢账，收口正为关此面）。所有阈值/衰减系数一律**首版随 playtest（0011-4 D4-6 先例）**——暴露累积速率三臂权重、各档跳档阈、成色轴调制幅度、到期对账缺口成分（真没办 vs 被吞）口径俱不在本 ADR 发明，归切片验收。
