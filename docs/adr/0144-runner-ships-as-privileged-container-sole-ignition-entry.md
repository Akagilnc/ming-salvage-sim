# 0144 — runner 以特权容器镜像交付，镜像 CLI 是唯一点火入口

Status: Proposed（2026-07-19 owner grill 四拍；待设计闸 cmr）

编排器 runner（确定性代码）烤进自带 docker socket 的特权容器镜像交付，镜像 CLI 即「开工入口」词条的唯一实现体——点火/态势/复飞/隔离重建/清理全走它的子命令，宿主不再有 launch-*.mjs 家族与 env 咒语。socket 是宿主 root 等价物，**只许确定性 runner 代码持有，LLM worker 容器永不挂载**。备选「host CLI 收敛」被否：宿主环境即状态是 2026-07-19 值夜八项点火事故的共同根因，止血档的中间产物会被最终形态整体作废（#975 构建源分离随之降级为镜像构建内部步骤）。
