# 边军军饷并轨：按军记欠 × 饷源比例（省存留 : 中央京运）× 派生军饷欠容器 —— armies.arrears 唯一真源、Due.军饷 动态化

## Context

#287 从 #261（[ADR 0021](0021-fiscal-cutover-hub-treasury-and-central-leakage.md)）cmr R1–R3 拆出——「省级 `st['军饷欠']` ↔ 按军 `armies.arrears`」的并轨在 #261 内三轮收不敛（每轮打补丁、每轮冒新边界），按 cmr drift 规矩回设计层拆出专门 grill。本 ADR 钉死并轨机制；#261 `blocked_by` #287、不在 ADR 0021 展开。**只定设计决策，确切键名 / schema / 管线落点 / 账户名 / oracle 写法留 `/tdd`。**

本 ADR 经 `grill-with-docs` 结晶，期间跑了两道支撑研究：① 明末边军军饷「饷源」史实结构 + 西南土司兵供饷特例（中英文源、对抗校验）；② B 真源模型（arrears 唯一真源 / 容器派生）对代码 + ADR 0007/0020/0021 的对抗压测。史实结论：明末边军饷 = 「中央京运池 + 多省协饷」多对多结构，驻防省 ≠ 饷源省，《万历会计录》逐镇分列「主兵年例 : 客兵年例」，欠饷哗变按军 / 营发生（非整镇匀崩），土司兵兵田制自给、出征自筹为主。

## 决定

1. **（D1）真源方向 = `armies.arrears` 唯一权威账本、军饷欠容器派生。** `armies.arrears`（按军、万两）是玩家感知的唯一军饷欠真源（哗变按军发生）。各「军饷欠」容器每结算 tick 由 `Σ(arrears × 份额)` 派生、**不自带独立结转**。基座那套 waterfall 守恒算术**原样保留**（[ADR 0007](0007-province-fiscal-substrate-ai-judged.md) G1–G22 不动）；省级聚合**对玩家隐藏**（P4）。压测确认：waterfall 不改、容器派生不破 G9 螺旋 / G15 偿还序。

2. **（D2）饷源 ≠ 物理驻地；饷源 = 每军「省存留 : 中央京运」二元比例。** 一支军的饷记在其**饷源**、不记在当下站的地盘——关宁军北伐到朝鲜边境 / 收复沈阳，饷源仍是辽饷京运、不变成当地出钱。`station/theater` 管物理位置（随调防可变、驱动军事软判），**饷源**管记账归属（稳定、可写字段、驱动军饷欠）。饷源 = 每军一个「省存留份 : 中央京运份」比例（= 《万历会计录》逐镇「主兵年例 : 客兵年例」结构）。史实校准示意值：关宁 / 京营 / 山海关 / 东江 `0:100`、蓟镇 `20:80`、宣大 `55:45`、陕西 `65:35`、登莱 `80:20`、南京 / 闽广水师 `100:0`；西南土司 = 自养特例（D6b）。**精确比例 = 史实 seed（`/tdd` 按会计录校准）。**

3. **（D2b）两类容器。** ① 省级 `st['军饷欠']` = `Σ(该省驻军 arrears × 省份额)`；② **中央军饷欠账**（新增）= `Σ(各军 arrears × 中央份额)`。两者相加 = `Σ` 全部 arrears（份额和 = 1、守恒不破）。基座 waterfall 管省级容器、hub / 中央池管中央容器。**本决定细化 ADR 0021 决定 3 的「单链 国库→京运补→所驻省→驻军」措辞**：中央份额走国库直拨、不全经驻省（关宁军等纯中央养军不依赖驻省基座，辽东失地不成孤儿欠饷）。

4. **（D8）`Due['军饷']` 动态派生 = `Σ(该省驻军月需 × 省份额)`；中央军饷应付 = `Σ(月需 × 中央份额)`。** 静态 `Due` 与 `st = Σ(arrears × 省份额)` 恒等冲突（waterfall 用静态 45 算欠、军级真实需求是 `Σ army_needed`，对不上则恒等破），故 `Due.军饷` 必须按军需动态派生。**修订 [ADR 0020](0020-fiscal-levy-effect-channel-event-driven.md) 落位契约 5**：月初 applier 的 set-to-target 可写 `Due['军饷']`（军需派生），`Due` 其余项（`官俸 / 宗禄 / 赈济`）仍静态不动。此修订 **ADR 0021 决定 3④ 已预授权**。玩法属性：军队规模动态影响财政负担（募军 → 省 / 中央负担涨，史实压力；裁军则松）。

5. **（D3）cutover seed 一致 = arrears 为真源、容器派生。** 新档 seed 以 `armies.arrears` 为唯一真源，各容器由 `Σ(arrears × 份额)` 派生写入；删除 / 仅校验 `regions` seed 里独立的 `st['军饷欠']`。cutover 首 tick **reconcile 不变式**：容器 := `Σ(arrears × 份额)`，存量差额**不计欠 / 不生钱**（加 reconcile oracle）。现 seed 矛盾（陕西 `st['军饷欠']=20` vs `shaanxi_army.arrears=25`）以 arrears 为准。

6. **（D5）物理调防永不自动改饷源；改饷源 = 皇帝杠杆、归 #260。** 调防 / 出征改 `station/theater`、**不改饷源**（arrears 跟军走、容器下 tick 重派生）。皇帝主动「令某省协济某军 / 某军改就食」= #260 action 层（旨意 → 改写饷源字段）；#287 只把饷源做成**可写字段**、不建玩家命令。物理调防与改饷源走「arrears 跟军走 + 容器重派生」同一机制。

6b. **（D6）零军省 / 收复省 / 土司特例。** 动态 `Due` 使零军省 `Due['军饷']=0`、无幽灵债（纯中央养省份额 = 0、`st = 0`、失地不成孤儿）。**残留**：省份额 > 0 的军撞「无 settle 基座」的饷源省（收复省 #265 未 seed）→ **fail-loud 报配置错**（守 ADR 0005）；#265 须先 seed 收复省基座 + 其驻军。**西南土司 = 自养特例（C1）**：兵田制自给、不入任一容器、近零常规欠饷，只征调时产生一次性行粮（叙事事件、高自筹）——消解其「广西 / 云南 / 贵州」一对多 station。

7. **（D7）增量分摊 + clamp + 日志。** 净增债月：每军欠饷增 = 月需 − 实收（按份额从各容器分付）。净偿还月：按该军在该容器 arrears 占比偿还（零 arrears 军不分偿还）。**clamp**：每军 `arrears ≥ 0`（守 `fiscal_tick.py` 负军饷欠 `ValueError`）；偿还不压负、余额由容器吸收以守 `Σ = 容器值` 恒等。新军 `arrears=0` 入 `Σ`；零需残军不占分摊。每笔分摊写 `army_logs`（actor = 户部、带口径）。补饷（phase2）减军总 arrears、份额拆分内部记账、下 tick 重派生。

8. **（D4）相位插点（细化 ADR 0021 决定 7 + ADR 0020 §6）。** 同一 `pre_settle` atomic 内：**tick 入口**（`settle_province_tick` 之前）算各军月需 → 派生写各省 `Due['军饷']` + 中央军饷应付（amended applier）→ reconcile 容器 := `Σ(arrears × 份额)`；**③ `settle_province_tick`** 用动态 `Due` 跑 waterfall、付军、省级 ΔB 分摊回各军省份额 arrears；**④ hub** 中央军饷应付由国库 / 京运补付（k 缩拨后）、中央 ΔB 分摊回各军中央份额 arrears。**两前置序**：饷率前置 → `Due.军饷` 派生前置 → 京运补前置。`ready=1` 只重放 phase2（补饷幂等）。确切插点 `/tdd`。

## Considered Options

- **省级 `st['军饷欠']` 自带结转、arrears 是其切片（D1 反选）**：要三处显式同步（seed / 补饷 / 调将），正是 #261 收不敛那片 bug 面。改 arrears 唯一真源 + 容器派生，三问题随「容器永远 == Σ加权 arrears」化解。
- **每军单一饷源省（D2 反选 A）**：史实 poor——边军饷是中央京运 + 多省协饷多对多、驻防省 ≠ 饷源省；硬绑单省把辽东（无税基）错当关宁军出饷主体、且辽东失地即孤儿。
- **多省协饷逐军分摊到各省（D2 反选 B）**：游戏已用「起运 → 国库 → 京运补」抽象协饷，再逐军多省分摊 = 重复建模；且全游戏仅土司一支真·一对多。改「省存留 : 中央京运」二元比例（= 会计录主兵 : 客兵年例），proportional 且不爆。
- **静态 `Due['军饷']`（D8 反选）**：与 `st = Σ(arrears × 省份额)` 恒等冲突，且军规模不影响省负担（失真）。改动态派生。
- **土司硬挂单一省（D6 反选）**：土兵兵田制自给、不吃常规省饷，硬挂任一省常态错耗其国库；改自养特例。次优工程妥协（若引擎强制每军挂省）= 挂四川（石柱土司本籍 / 集结地），须设极低常规负担 + 征调行粮。

## Consequences / 落位边界

- **修订 ADR 0020 落位契约 5**：applier 放开写 `Due['军饷']`（军需派生），其余 `Due` 项不动（ADR 0021 决定 3④ 预授权）。
- **细化 ADR 0021**：决定 3 单链措辞补「中央份额国库直拨、不全经驻省」；决定 7 子相位序补「`Due.军饷` 派生前置 + 省级 / 中央 ΔB 分摊插点」。
- **新增容器**：中央军饷欠账 + 中央军饷应付（hub 层），与省级容器对称；并入 hub 守恒 oracle（仅测试期）。
- **依赖**：#265（收复省 seed settle 基座 + 驻军，否则省份额军撞空 fail-loud）；#260（玩家改饷源 action）；#70（全省 seed）。#261 `blocked_by` #287。
- **实现留 `/tdd`**：饷源比例精确值（会计录校准）、容器键名 / schema、分摊算术、相位确切插点、reconcile / 分摊 oracle、army→饷源省 解析 + 可写字段 schema。
- **状态**：`proposed`（`grill-with-docs` 结晶；下一步 `to-prd` → 设计评审闭环）。
