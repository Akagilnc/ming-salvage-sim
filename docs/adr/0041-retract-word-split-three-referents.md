# 0041: 「撤回」拆三义——悔棋出词表、毁约与收权各立词条

Status: Proposed（2026-07-02，#471 grill Q4 用户拍）

「撤回」一词拆为三个所指、各归各位：①**撤回本轮**（悔棋）是玩家层系统动作、不入皇帝动词表，机械语义仍以 ADR 0038 为唯一 canonical，触发形态循 ADR 0036 系统层先例（可为界面控件、不占「皇帝无按钮」名额——了结 #470 侧悬置的「撤回按钮还是话语」）；②**撤回成命**（毁约：许过的赏/职/饷反悔）入词表动作档，是有代价的新游戏内命令（ADR 0006），代价口径归 #226；③**收权·罢差**（收回尚方剑/罢监军）入词表动作档、与毁约分立——收放权是正当治术、代价是观感不是信誉，消费方 revoke_skill 现成、#460 建成后扩大。
