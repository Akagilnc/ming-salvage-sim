# 重构：模型调用重试耗尽时，保留成功结果并补完本月

Status: proposed（2026-09-09；owner 已拍取舍，设计待评审，未实施；本次游戏重构，非独立版本）

过月期间，其他事务已成功、唯独某件事因模型调用错误且自动重试耗尽而未处理完时，保留已成功结果、留在本月，只补处理失败项，补好后再进入下个月。
这是避免玩家进入缺失后果的下个月所接受的等待，不把剧情中办事失败当系统故障，也不把该决定扩展为所有类型故障的处理政策。
[owner 的限定与选择](../design/game-v2-architecture.md#模型调用耗尽的选择)是本决定依据，重试次数、恢复入口及具体存储协议均未在这里定下。
