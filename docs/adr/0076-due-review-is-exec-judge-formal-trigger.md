# 0076: 到期复核＝执行格判官的正式触发形态——不另立第三判官

## 后出设计修订：撤令有效后接执行后果，不顶次回合必演（#1894）

法源为 #1894 顶部裁定（owner 答「可以。按照史实走」，`6acb3f04-87e4-4822-bfd7-325a783999af`）。本段修下文中「0075 松手挽留后坚持撤」与「挽留/反催谏/待裁等场面一律顶到次回合召对面」对**明确撤旨**的适用口径：撤一道已发出的旨不再依赖「挽留后坚持撤」这道触发，也不因撤令而把该必演场顶到次回合；撤令经外廷判决生效后即接既有执行格后果（ADR 0075 后出修订同段）。其余触发——0074 各分段到期、正式到期复核、反催谏、待裁场面顶次回合召对——一律不变，不另立判官，不新增串行 LLM 步。求情与否由模型读材料自定，不由本触发形状强推。

#476 的正式到期复核不另立判官：它是 **0057 执行格判官的一个触发形态**——到期月（含 0074 各分段到期、0075 松手挽留后坚持撤）触发，输入面加全（承诺进度/分段判据/奏报-实况两轨分叉 0073/催办史 0078/监督在场史 0077），产 0052 执行格判决（含 0072 变形值）＋顶出场面＋0079 信用事件。0057 双判官结构（颁布判官＋执行格判官）不动。接管 #565 interim 按 0052 cmr R10 原句执行：**落点同格不迁**，#565 的 0057 软判填值被本正式流程替换、不另建平行判决落点。P5 并行铁律显式承接：复核触发并入 0057 执行格判官步（非 0055 颁布判官步），挽留/反催谏/待裁等场面一律顶到**次回合召对面**，结算管线内不新增串行 LLM 步。
