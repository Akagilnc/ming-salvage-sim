# 0108: 阴谋能力＝M12 substrate 新列（本轮建列＋seed，查家产精度函数留 #462）

Status: Accepted（PR #708 merged 2026-07-08；决策：2026-07-08 M12 设计闸 grill G8 用户拍；承 #555/#87/#89）

## 后出修订（#1896，2026-10-01）

**陛下裁定遮掩轴本次交付**（大理寺上呈 `01a0f305-a36e-7512-a4fb-8deed9df6871@judge` decisionGate 第一项；owner `b83b71af-9883-4f82-bbf6-8bc0aa14e1df` 答「这次就补上」）。本 ADR 净新契约 (a) 的**建列＋seed 数据件本次落地**：`characters.intrigue INTEGER NOT NULL DEFAULT 50`（CREATE 块 ＋ `ensure_column` 老档迁移同款），seed 值随 `content/characters.json` 逐人显式给出（厂卫/权阉顶格、清流低，理由随值可查），沿既有装载／入册／持久存读／当前格式恢复路径承载；一次性回填走 `__intrigue_seed_v1` meta flag，守卫形状同 `identity`（只补仍在 DDL 缺省上的名册行，不改写已玩过的值）。

**遮蔽消费方①（0098 逐证难度）本次一并接通**：`investigation_fact_difficulty` 读目标的 `characters.intrigue`，按参考值 50 归一后相乘——同等条件下目标越会遮掩越难查，兑现已准设计原句「被查的人越会遮掩、关系网越深，越难查」。**不**以 `characters.identity`（党籍认同，CONTEXT.md 孤臣轴）冒充遮掩。查案对象不在 `characters` 行里时该轴退化不参与。

**P4 呈现**：`ming_sim/qualitative.py` 的 ADR 0122 占位词（`INTRIGUE_QUALITATIVE_PLACEHOLDER`）随本列到位退役，改喂真档投影（`intrigue_band` 五档，与四能力轴同形同 `qualitative_band` 切点）——扮演路径只吃定性词，人物呈现上下文不见裸 int。

**本次未交付、不因此改口的**：②惊蛇概率（#1896 票面明文不建设惊蛇概率，0100 后出修订已改由 4a 真实知情声明承接）；③#462 查家产精度函数（仍留 #462，见下）。`wealth` 追赃折率吃阴谋轴的读点（ADR 0119:5）随本列到位而**变为可接线**，但本票不接线、不改 0119 口径。

per-character `阴谋能力` int 本轮进 M12 substrate、与 `identity`（0102）/`loyalty`（0104）同批列、同落 `characters` 表（补 #462 点名的「现四轴 loyalty/ability/integrity/courage 无一承载阴谋」缺口，作第五条能力轴）。**性质＝静态 seed 能力轴**（与 ability/integrity/courage 同型，本批不建其事件派生规则——不同于 0102 identity/0104 loyalty 那种承重派生；LLM 亦不碰这个 int）；**seed 值本批补产为数据件**（补现有名册无此列：厂卫特务/权阉顶格、清流低；产法同 74 人名单 seed roster，精确整数随该数据件校准、不在 ADR 发明）。**三个机械消费方本轮成立、故过 0037「有机械消费方才预建」判据当批建列**（非为未设计消费方预付结构）：①**查案遮蔽**——作 0098 确定性查案差务月度进展的修正因子（目标阴谋高→遮蔽重→办差方进展慢，grill G1a「目标阴谋能力遮蔽」）；②**惊蛇概率**——作 0100 打草惊蛇 roll 的一臂（概率＝目标阴谋 vs 办差方差务能量）；③**#462 查家产精度**——「精度挂目标阴谋类能力」的因子输入。

**净新契约仅两条**：(a) `characters` 加 `阴谋能力` int 列（第五能力轴，确切键名留实现）＋其 seed 数据件（粗档：厂卫/权阉顶格、清流低）；(b) 消费口径——0098 遮蔽因子与 0100 惊蛇概率的函数口径本批 PRD 定、量随 playtest（同 0011-4 D4-6 先例），**#462 查家产精度函数留 #462**（#462 own 可错情报精度模型、须与 #456 同口径一次定，本 ADR 只交付这条阴谋轴当其因子输入、不建家产 ground-truth 字段/查探动作链——那两件仍 #462/#89 线）。**#462 精度函数未落地期间，查家产占位＝报实际家产大概数**（同 0023 D10「精度机制未实装时占位＝报实际大概数、可接受」先例；抽象 stat 仍 qualitative-only、不松 P4）。**毙案**：①字段连精度函数一起 defer 到 #462＝毙——0098 查案遮蔽/0100 惊蛇本批即硬需此轴，缺列只能用代理轴凑合、#462 落地必返工，两个在建消费方已把「预建」正当化（正是过 0037 判据）；②本批连查家产精度函数一起做＝毙——精度模型是 #462 own 的可错情报设计（须与 #456 同口径统一定），抢在其 to-prd 前实现＝越 #462 scope，本 ADR 只交付轴、精度留 #462。
