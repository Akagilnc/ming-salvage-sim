# 0105: 财政可行性不入 resolve 臂——机械后果包落分段承诺对象

Status: 修订待票庭重审（#1895；原决定 PR #708 merged 2026-07-08，M12 设计闸 G5；承 #555/#87/#89）

撤销本 ADR 的“resolve 三臂保持政治纯度／resolve 公式一字不动”保留义务；血债 floor、命门合法性 floor 及 min(ceiling, dynamic_term) 不再替人物定阻力或选择上下界。

「这道旨付不付得起」仍**不新增为颁布关的机械财政否决臂**；国库实账不是人物必然反对或必然放行的判据，财政可行性由引擎在真实履约时核算。「付不起」的显形全走三处现成机制：①颁布关政治阻力叙事（户部哭穷 = 打回缘由句素材，非新阻力臂）②摊派双通道（官僚自主声明暗渠转嫁或皇帝主动下旨明渠加派）③折发系数 + 偿还序（「先亏谁」入旨）。**净新契约只有一条**：旨意机械后果包（ResolveResult）中的钱粮承诺**不即时全额划扣**——**分期载体＝分段承诺对象**（#476 家族 Accepted、实现随其切片 #620「十年之诺一个对象」；由 **resolve 确定性生成**、非 extractor 自由裁量——cmr R15 勘正：Due 真源是固定四科目月度应付参数〔fiscal_tick `_DUE_KEYS`=军饷/官俸/宗禄/赈济，未知科目 ValueError〕，**不扩 Due key**、per-decree 分期不塞 Due 账），月度履约步按偿还序/折发与国库现实结算，settlement 单回合 delta 不得超月拨额一把清（顺修试玩 F4 实证：旨意明设「每月一百万两·二月内清完」被 extractor 无视、196 万旧欠一回合清光、`until_stop` 承诺当回合即 `resolved`——此契约即修此洞：把「哪件量化机械承诺该结构化追踪」从 LLM 自由裁量里拿出来、走确定性兜底）。

**毙案**：确定性第四臂（affordability gate）＝给 resolve 加「付不起就挡」的算账臂，把财政实账核算偷换为人物颁布选择的机械门（不保留或恢复旧三臂人物阻力公式），毙。付不起干净作废＝钱不够就当没下过这道旨，毙——缺口不能凭空消失，无真实加派或摊派行动时仍留欠账与世界后果。
