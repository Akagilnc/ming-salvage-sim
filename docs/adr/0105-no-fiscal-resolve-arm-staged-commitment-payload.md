# 0105: 财政可行性不入 resolve 臂——机械后果包落 0074 分段承诺对象

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G5 用户拍板；承 #555/#87/#89）

「这道旨付不付得起」**不新增为 resolve 的第四臂**：resolve 三臂（血债 floor / 命门合法性 floor / min(ceiling, dynamic_term)）保持政治纯度，**0011-5 D5-4 公式一字不动**——颁布关只判政治阻力、不算国库余额（延续 resolve 阻力只读血债/leverage/ceiling/外压、不读 satisfaction / 不读 identity 的政治纯度原则）。「付不起」的显形全走三处现成机制：①颁布关政治阻力叙事（户部哭穷 = 0011-5 打回缘由句素材，非新阻力臂）②0089 摊派双通道（缺口悬置→暗渠官僚默认转嫁小农，或明渠皇帝主动下旨加派）③0090 折发系数 + 偿还序（「先亏谁」入旨）。**净新契约只有一条**：旨意机械后果包（0011-5 ResolveResult）中的钱粮承诺**不即时全额划扣**——**分期载体＝0074 分段承诺对象**（#476 家族 Accepted、实现随其切片 #620「十年之诺一个对象」；由 **resolve 确定性生成**、非 extractor 自由裁量——cmr R15 勘正：0090 Due 真源是固定四科目月度应付参数〔fiscal_tick `_DUE_KEYS`=军饷/官俸/宗禄/赈济，未知科目 ValueError〕，**不扩 Due key**、per-decree 分期不塞 Due 账），月度履约步按 0090 偿还序/折发与国库现实结算，settlement 单回合 delta 不得超月拨额一把清（顺修试玩 F4 实证：旨意明设「每月一百万两·二月内清完」被 extractor 无视、196 万旧欠一回合清光、`until_stop` 承诺当回合即 `resolved`——此契约即修此洞：把「哪件量化机械承诺该结构化追踪」从 LLM 自由裁量里拿出来、走确定性兜底）。

**毙案**：确定性第四臂（affordability gate）＝给 resolve 加「付不起就挡」的算账臂，破三臂政治纯度 + 把财政拉进颁布关（P4/品味双违、且颁布关不算国库是 resolve 铁律），毙。付不起干净作废＝钱不够就当没下过这道旨，毙——0089 明禁：缺口不能凭空消失，不明选加派就走暗渠摊派，「不作为也是有代价的选择」。
