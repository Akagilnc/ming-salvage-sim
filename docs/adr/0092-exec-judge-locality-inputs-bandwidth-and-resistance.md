# 0092: 执行判官属地输入两轴——带宽（忙）与阻力（顶）

Status: Proposed（2026-07-07 #477 设计闸 grill Q6 用户拍选项 2 并三轮加码成形〔人均带宽/属地衙门/天灾〕）

执行判官（0072）的属地输入定为两轴，**接口层数数、LLM 软判**（0011 分界；皇帝不见槽位数，只见「一身难兼二任」推辞与延宕变形叙事——P4）。**带宽轴（忙不忙）→主判拖磨**：①承办人层＝在办差务数×能力（能吏 2-3 件并行、庸人 1 件勉强；数据＝owner 绑定未结差务计数〔#471 交办·责成〕＋characters.ability）；②属地衙门层＝同省在办差务浓度×该省官僚盘（classes[官僚][省]）——schema 增量唯一一条：**差务记录带属地 region_id（可空）**；③**天灾＝不请自来的头号差务**：灾情局势计入在办清单且占用权重最高，让路（新差默认延宕）或不让（旨意变形↑且赈灾打折→流民池入超）两边都有代价；④**全国性旨意落账按省拆成各省差务**（一道大旨与十道省旨带宽账自动等价）；⑤距离层＝**预留输入项，归 #475 填实**。全局约束不单独建——用人荒＋衙门荒涌现（崇祯「无人可用」）。**阻力轴（顶不顶）→主判变形**（0065：外场阶层阻力全在执行侧）：士绅（gentry_resistance＋classes[士绅][省]）／当地官僚（classes＋督抚派系操守）／党派（0072 已有因子不重列）／流寇治安（military_pressure＋贼强度）。忙→拖磨、顶→变形，两轴叠加（灾年贼区强推清丈）自然出大事，不写剧本。与 0068 咬合成负反馈（皇威高→颁得多→执行消化不良→变形多），不重复。硬限「每月 N 道旨」＝圣旨点数，gamey，毙。
