# 0098: 取证＝确定性查案差务轨＋真相天花板

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G1a 用户拍板；承 #555/#87/#89）

破局回路后半截「谁帮你坐实」（#89 大臣线主菜）落为**确定性查案差务轨**、不建独立查案系统：下令查某人＝开一条**查案差务**——复用 0092 差务/带宽轴（查案是一类差务、占办差方带宽账，owner 绑定未结差务计数×characters.ability），月度进展复用 0058 月度进展轨（逐月落库进展档＋密奏一句、restore 无损、月报推送与垂问拉取吃同一份进展），**零新轨道**。每月进度由**引擎确定性推进**，三修正因子＝办差方能量（承办人 ability）／目标阴谋能力遮蔽（读 G8 本批新建的 per-character 阴谋 int）／目标 identity 网络（identity 列真源 0011-4 B、0011-2 消费＋0081 有向边关系网）。**硬天花板＝真相底（live 集、kind 限定）**：进度只能坐实 DB 里**已存在的真相**——可坐实集＝seed_guilt（真源 0011-4 B 部分名册、0011-2 消费）＋**把柄类 edge-kind** 的 #479 边（0081 统一有向边；0086 seed 把柄网如崔呈秀为田尔耕盖印掩护，**及运行期由结构化事件新长的把柄边**——策反证词〔0103〕/密令暴露〔0107〕/检举附据属之；恨边/kinship/一般关系边**不入集**）；运行期新边入集须过守门：把柄边只能由结构化事件产、不得由酿制文本长出（防经长边制造真相——罗织永远只有 STIGMA 路）。查无此罪 → 产不出依律证据、只能走罗织（STIGMA｛中旨除授/非正途/罗织｝、cw=1、血债满档＝0011-2 D2-5 二分＋D2-4 失称度已设计的恶路，故「时机/正当靶」有真重量）。进度到阈 → 产**坐实事件**，reason_code ∈ 依律集｛依律/谋逆坐实/贪墨坐实｝（二分真源 0011-2 D2-5）→ 喂 0011-4 D4-4 翻轴（走程序坐实 → axis 翻转 → 命门 ceiling 塌）。净新契约仅三条：①查案＝一类差务、进度逐月引擎确定性推进（三修正因子如上）；②天花板锚在真相底（seed_guilt＋把柄类边 live 集），无真罪不产依律证据、只落罗织恶路；③到阈产坐实事件、reason_code∈依律集接 D4-4 翻轴。**轨级口径三条（防刷防漂）**：(i) 同一目标同时至多一条 open 查案差务（密查/检举/苦主多源**汇同一案**、不并开）；(ii) 坐实按 (target, 罪项) 记账、坐实即标已用——同一罪项不得被多差务/多源重复坐实重复翻轴；(iii) 各源进度加成设单月上限＋坐实设最低在查月数 floor（保 0100 惊蛇/毁证窗口，堵一月速坐实）。**本轨一切概率抽签（含 0100 惊蛇、0103 策反、0107 暴露）＝由 (game_seed, turn, 差务/目标 id) 派生的确定性伪随机——重放与 restore 可复现**（P1/TD 确定性铁律的 roll 口径）。每月进度增量／坐实阈／三因子权重／加成上限／月数 floor＝**首版随 playtest**（同 0011-4 D4-6 先例），不发明精确值。**查案进展/坐实/遮蔽交 LLM 软判承重＝话术可诱导降敏、失确定性、restore 不可复现（违 0011 接口层数数/LLM 软判分界，0092 同源），毙**——LLM 只叙事查案花样、算账全归引擎接口层。
