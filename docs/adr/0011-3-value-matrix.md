# 派系价值画像矩阵 schema（ADR 0011 决定3 子 ADR · 0011-3）

Status: Proposed（草案；承母 ADR `0011-edict-resistance-and-centrifuge-ledger.md` 决定3，由 design-dig `dig-5` fold 而成。**待评审**——按 CLAUDE.md 设计文档铁律走本地 cmr 收敛 + 线上三 bot 收敛，未收敛前不进实现期。实现属编码活、spawn 隔壁。）

承 GitHub #112 tracker。本 ADR 收口母 ADR 决定3 留给子机制的「7 派 × 6 轴价值立场精确值 + 入轴判据 + 史实不对称 + P4 哨兵契约」。它是血债棘轮（`0011-2`）与四层票拟 resolve（`0011-5`/dig-8）读取的**离心方向真源**：血债按「动作轴方向 × 派系立场」决定累到哪些 `(faction, axis)` 格、符号可相反（悲剧引擎）。

## 为什么这是「悲剧引擎的地基」

母 ADR 决定3 把价值矩阵的**精确立场值留给本子 ADR**。这张表是「同一动作逐派符号相反」的唯一来源——抄阉党 → 阉党血债爆、东林悦；清核宗室隐田 → 宗室强怒、东林却只微悦（查自家江南田产是盲区）。它不落则离心无方向、血债不知累到哪格、四层 resolve 读空值退化纸面。

质量标尺是北极星（`0011-design-dig/north-star-90fen.md`）：矩阵必须能稳定产出「东林割到自己人时只微悦、刀口对宗室行对己不行」这种**结构性不可调和**，而不是「得罪谁都一样」的平面。任何决定点都拿北极星问一句：「这张表喂不喂得出那种符号相反的戏？」

## 矩阵（7 派 × 6 轴，−2 强反 … +2 强护；两路独立推导 42/42 逐格一致）

|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 东林 | +2 | −1 | −1 | −2 | +1 | +1 |
| 阉党 | −1 | +2 | −1 | +2 | 0 | −2 |
| 军队 | −1 | +1 | +2 | −1 | +2 | −1 |
| 皇党 | −1 | −1 | +1 | +2 | +1 | −1 |
| 宗室 | +2 | +2 | −2 | +1 | 0 | −1 |
| 西学 | −1 | −1 | +2 | +1 | +1 | 0 |
| 中立 | −1 | 0 | +2 | 0 | +1 | 0 |

- **值语义**：矩阵值 = 该派在该轴的**立场**（+ 护、− 反、0 中立 / 不站队），强度 1=弱 / 2=强。
- **离心公式（目标感知的撞轴集 × 立场）**：对某派在某轴的离心 ≈ `动作在该轴的方向 × 该派在该轴立场`（符号可相反 = 悲剧引擎）。**关键：动作「撞哪些轴」是目标感知的**（⚠️ CMR：dig-5 验证例隐含此抑制规则、本 ADR 首次落公式契约，须复核）——
    - **泛化轴**（绑动作本身、不绑目标身份，如清账的既得利益、加征的民本恤民）：对**所有有立场的派**按其立场 fire（旁观派照吃）。
    - **目标命门轴**（绑目标身份的轴，如清宗室隐田撞的「宗室祖制·礼法」、抄阉党撞的「阉党权位·皇权依附」）：**只对目标派满档 fire**（+ 同类经 0011-2 kinship 旁及）；**旁观派在此轴不 fire**（「江南田产盲区」：刀口对宗室行、对东林自家不行）。
    - 撞轴集从动作类型 + 目标 faction-tag **结构化派生**（承母 ADR 决定1、对齐 D3-8、堵 H5），非 LLM 措辞判。满档 vs 泛化弱的精确档 = 首版随 playtest，**但「旁观派不 fire 目标命门轴」是设计语义、非调参旋钮**。
- **6 轴定义**（母 ADR 决定3 / dig-5）：礼法名节 / 既得利益 / 实务事功 / 皇权依附 / 华夷战和 / 民本恤民。
- **7 派**（characters.json 实证朝堂派系）：东林 / 阉党 / 军队 / 皇党 / 宗室 / 西学 / 中立。
- **P4 硬契约**：矩阵值是 simulator/extractor 纯内部参数，**永不呈现玩家**（连定性标签都不播报，见「P4 呈现契约」节）。

## 决定点（D3-1 ~ D3-9）

> 每点给：**决定 / 弃案 / 残留诚实标**。带「⚠️ CMR」标记的是 fold 时新做的 reconcile 或须本轮评审复核的承重 claim、不当已收敛。

### D3-1 粒度 = 7 派 × 6 轴 42 格立场值

**决定**：矩阵 = 42 个**立场值** −2…+2，逐 `(faction, axis)` 手填。这是设计活（非代码活）的「调参旋钮」真源，血债棘轮（0011-2 D2-1）的 42 格仇恨**累积在它给出的方向上**（怒侧累 blood_debt、悦侧落 satisfaction，见 D3-8）。

**两路独立推导 42/42 逐格一致**（dig-5：7 派 profile 路 + 6 轴定列路，14-agent，逐格交叉无冲突）= 这套立场值不是单源臆断，是双盲收敛。

**弃案**：scalar 单派立场（喂不出按轴定性的离心，北极星「割到自己人只微悦」说不出）；动态从成员能力均值算（见 D3-2 裁尺）。

**残留**：立场值是**首版**，随矩阵 α/β playtest 调参（镜像 spike G1-G22 方法学），非现在拍死；但「符号方向」（哪格 +、哪格 −）是设计语义、非调参旋钮。

### D3-2 裁尺 = 政治机器运转逻辑、非成员能力均值（✅ 用户拍 ①）

**决定**（用户 2026-06-14 拍）：派系轴值取**该派作为政治机器的运转逻辑**，不取成员个人能力 / 立场均值。统一管所有 split 格（成员立场分歧的格）。

**典型例**：东林 实务事功 = **−1**。东林不乏能吏，但作为政治机器其逻辑偏清议名节、轻实务事功 → 立场取机器逻辑（−1），不取「东林里也有能臣」的成员均值。

**为什么**：成员均值会让矩阵随人事漂移、且糊掉派系的结构性立场（机器逻辑才是「同一动作逐派符号相反」的稳定来源）。个人偏离机器立场的部分，落**个人认同度层**（dig-6 / 0011-2 kinship，与本矩阵正交，见 D3-9），不污染矩阵。

**弃案**：成员能力 / 立场均值动态算轴值（漂移 + 糊结构性立场）。

**裁尺一致性自审**（防 universal claim 由 n=1 撑，逐 split 格用同尺裁同号）：

- **阉党 实务事功 −1**：阉党机器是权力寻租机器，事功对它是**敛权工具非价值**——辽饷 / 矿税 / 关宁是聚敛掌权的壳，事功与敛权冲突时弃事功（卖官坏实务）。故机器逻辑轻「事功本身」= −1（与东林 −1 同号不同因：东林因重清议轻事功、阉党因事功只是敛权壳）。区别于「魏党办过实务」的成员行为。
- **西学 民本恤民 0**：西学机器举的是**技术事功旗**（火器 / 历法 / 水利），民本是事功副产品非纲领 → 不站民本轴 = 0。徐光启等个人恤民改革是成员行为，非西学作为机器的立场；民本正极独留东林（+1，清流以蠲免赈灾为道德正统）。
- **军队 民本恤民 −1**：军队机器逻辑 = 军费优先，加饷养兵与恤民（蠲免减赋）直接对冲 → 机器轻民本 = −1。或有体恤百姓的将领（成员），但机器逻辑是军费 > 民生。

三格皆用「机器逻辑 ≠ 成员行为」同一尺裁出、与东林事功 −1 同理；dig-5 两路 42/42 逐格一致为每格双盲背书。

### D3-3 入轴判据 = 真实价值张力、不强求两极对称（承母 ADR 决定3 Q4 细化）

**决定**：每轴须承载**真实价值张力**（两极都有真实立场根源），但**不强求两极对称占位**——不把「对称」当设计规矩，史实不对称就按史实（某极可 emergent、无常驻派系扛旗）。判据底线只是「不塌成『你是不是 X 派』= 派系身份」。

**弃案**（母 ADR 决定3 已记，本 ADR 原样承接）：宦权轴（反宦官干政 = 阉党+皇党对整个外朝，1-对-其余，折回礼法+既得利益）；财政路线 / 用人路线轴（折叠进既得利益+民本 / 礼法+皇权依附）。

**残留**：民本恤民轴最接近塌成派系身份（见 D3-5 不对称③ / 不变式审计），保留但盯塌缩。

### D3-4 华夷战和轴 = 不对称入轴、主和极 emergent 无常驻派系（✅ 用户拍，Q4）

**决定**（用户 2026-06-14 拍：「我一直都没觉得一个轴一定要对称……我更看重事实情况」）：

- **主战极常驻**：东林（道德主战）+ 军队（+2）；皇党 / 西学 / 中立各 +1（弱主战倾向）。
- **主和极常驻无人占**（矩阵无负值）——这正是「皇帝在外压下被迫想议和、撞上全朝主战共识」的 **emperor-vs-consensus** 张力，是 feature **不是缺陷**（前提见下「可颁机制」：议和经外压杠杆仍可颁；否则退化为「皇帝永远推不动议和」的死墙 = 缺陷）。
- **议和可颁机制 = 华夷命门 floor 吃外压调制（决定性机制，真源 0011-4 D4-3；fold dig-2 Q4 ✅）**：议和不靠翻轴（无罪可坐实、华夷轴无依律翻轴路，见 D3-8 / 0011-4 D4-4），靠 **dig-2 Q4「✅ 用户拍」节明载的「外压够大 + 代价够明白 → 务实派被推着默许」**。**决定性落点（0011-4 D4-3 真源）= 华夷命门 floor 本身随外压下调**（区别于祖制硬核 floor 不松）——因议和是华夷命门题、命门 floor 顶到 ceiling，**只降 dynamic_term 会被 `max()` 短路、不足以可颁**；务实派默许的 dynamic 软化是**次要项**。均**非矩阵静态值改动**——不与 ✅②「矩阵值不改 / 无悦」冲突（floor 松动 / 默许 ≠ 对议和悦）。
- **议和 = 高血债破局杠杆**（攘外必先安内的真解：暂抚后金腾手剿寇），代价 = 撞清流 → 东林血债爆 + 军队最怒。**与出路恒可达相容**：议和累的是 blood_debt（冻土，0011-2）、**不触底任何派 sat/lev**（不烧薄冰），故母 ADR 决定6「≥1 派未触底则净负窄路恒存」不被破；议和的出路 = 此外压杠杆逃逸（非翻轴），emperor-vs-consensus 是张力不是闸。
- **不发明假『主和党』**（反史实 + gamey）。史实锚：陈新甲议和泄露弃市、杨嗣昌「攘外必先安内」覆盖论点。

**弃案**：给某派安排「主和」常驻立场（反史实、且把 emperor-vs-consensus 张力抹平成又一组党争）；按弃案折叠华夷轴（丢掉破局杠杆 + 外压集成的承重轴，决定9）。

### D3-5 三史实不对称 accept（✅ 用户拍 ③）

**决定**（用户 2026-06-14 拍：「符合真实历史就行」）三处不对称按史实保留：

1. **民本恤民正极只东林 +1**（无 +2）：史实少数派；保留但盯「塌成东林身份」风险。
2. **实务事功负极只宗室 −2 单撑**：宗室是天然载体（食利不事生产）；宗室长期离场则该负极有变薄风险（残留，见不变式审计）。
3. **加征三饷只东林朝堂怒**：真政治代价在**阶层**（三饷绞索 → 民变 → unrest，决定9 外压侧），朝堂别硬塞反应。

**弃案**：为对称而加厚（给民本恤民硬塞第二个正极派、给事功负极硬塞第二派、把三饷代价硬塞朝堂）——反史实、且违 D3-2 机器逻辑裁尺。

### D3-6 议和语义 = 弱不爽 not 悦（✅ 用户拍 ②，矩阵值不改）

**决定**（用户 2026-06-14 拍：「对议和反应弱就行，不爽还是不爽但不是特别不爽」）：

- 矩阵值**不改**；本条只澄清**语义**：议和**没人 happy**。
- 反应梯度：军队最怒（华夷 +2 逆）、东林怒（华夷 +1 逆）、务实派（皇党 / 西学 / 中立 华夷 +1）只**弱不爽**。
- **东林（怒）与务实派（弱不爽）矩阵同为华夷 +1，档差不在静态矩阵、在外压 dynamic 臂**（P2-2 收口）：务实派外压够大时被推着默许、dynamic resistance 降（弱不爽 → 默许，D3-4 可颁机制）；东林清流死守主战、dynamic 不降（静态 +1 逆之怒保持）。故「东林怒 > 务实弱不爽」是 dynamic 外压臂产的**可机械复现档差**、非 LLM 即兴、非矩阵值差。议和 axis-tag = **单轴 {华夷战和}**（见 D3-8），不引名节轴。
- **别让任何派对议和「悦」**——主和极无常驻派系（D3-4），故无受益侧。
- 破局杠杆性来自 **①可咽下的代价**（强怒仅军队，东林为华夷 +1 之怒、余皆弱不爽）+ **②战略收益在外压侧**（腾手剿寇）+ **③外压 dynamic 臂令务实派默许使其可颁**（D3-4），**不是来自某派对议和的悦**。死按钮（全场强怒 + 零收益 + 无可颁路）≠ 议和（可咽代价 + 真收益 + 外压杠杆可颁）。

**⚠️ CMR（fold 期纠偏，须复核）**：dig-5 末尾「我 lean 给皇党留议和缝（条件性支持 = 破局杠杆）」是**拍板前的旧倾向，已被 ✅② 否决**（「别让任何派对议和悦、矩阵值不改」）。本 ADR fold 的是 ✅② 的「无悦」版，**不是**旧 lean 的「皇党留缝」版。**关键 reconcile（内部红队抓）**：✅② 删的不止「派系对议和的悦」，还连带删掉了旧 lean 隐含的「派系让步 / 默许 = 议和可颁性来源」；故 fold 后**可颁性来源必须显式补回**——已补为 D3-4 的「外压 dynamic 臂」（dig-2 Q4 ✅ 的务实派默许降阻力，非旧 lean 的皇党悦缝）。须复核：① 未把被否 lean 当决定；② 杠杆结论有可颁机制支撑、非悬空。

**弃案**：给皇党（或任何派）一个对议和的正向 / 条件性「悦」缝（被用户 ✅② 明确否决）。

### D3-7 P4 呈现契约 = 轴值永不呈现 + 哨兵测试

**决定**：42 个立场值是 simulator/extractor 纯内部参数，**永不呈现玩家**（连定性标签都不播报，对齐母 ADR 决定3 / 0011-2 P4 呈现契约）。玩家只经 actor 言行**间接感知**派系立场（大臣的话与态度，不是 axis 标签）。

- **接口层不裸带 + 翻译层单一真源（P2-6 对齐 0011-2）**：矩阵值不进 simulator-narration payload 的裸数值通道（对齐 0011-2 实证的 `faction_report` raw-int 直灌 → `factions_brief` 进 payload、`registry.py` 现存「满意度 / 影响力为实值据此判断」裸值指令的泄漏先例）。**矩阵定性翻译挂在与 0011-2 的 blood_debt/legitimacy_pct 同一条 memories 侧翻译层（同接口、同套哨兵）；该翻译层唯一真源 = 0011-2 P4 节，本 ADR 只声明矩阵值是其输入之一、不另立翻译机制。** 矩阵接入 narration 那一刀须复核 `registry.py` 这类现存 prompt 不被复制成「矩阵立场值是实值、据此判断」的裸值指令。
- **哨兵测试 = DoD 硬项**：既测原始 axis 值不回显（sentinel int），也加 paraphrase / 概念泄漏断言（narration 不得含「价值轴」「立场值 +2」等系统词面）。**⚠️ 六轴名易踩 paraphrase 漏网（P3-6）**：「华夷战和」「礼法名节」既是系统词又是合理史实政治术语，simulator 可能自然写「此事撞了华夷之辨」——哨兵须对六轴名各列 2-3 史实变体（华夷战和 → 华夷之辨 / 主和之议；礼法名节 → 清议 / 名节之防），断言这些变体**不得作「因你撞了 X 轴所以 Y 派如何」式机械归因口吻**出现（轴名当史实叙事词可以、当系统判定依据不可）；扩 `season_simulator.md` 散文禁令枚举。
- 落 prompt 用**正向表述**（「以奏对口吻定性描述派系态度」），不写「不要显示数值」式负向句。
- **extractor-side 非免哨兵区（P3-6）**：「只进 extractor-side」不等于天然安全——extractor 输出若经 `effect_brief` / 盘面快照回流进下一回合 narration，仍受同一哨兵约束，只是延后到回读那一刀。

**残留**：与 0011-2 一致，P4 呈现层在 simulator-narration **接入那一刀**生效（哨兵 DoD 随之），非「只落库」第一刀的悬空承诺；第一刀只须保证矩阵值不被任何已有 payload 通道裸带出。

### D3-8 离心符号路由（怒 → 血债、悦 → satisfaction；接 0011-2）

**决定**：矩阵给出带符号离心后——怒侧（立场与动作方向逆）→ `blood_debt`/`wariness`；悦侧（派系受益，如抄阉党时东林悦）→ `satisfaction`（可逆层）；`blood_debt` 只增、只记怒，「悦」格不进血债账。

**⚠️ 符号路由真源单向钉死（P2-4，避双真源漂移）**：此路由的**权威定义 = 0011-2「依赖 substrate · 价值画像矩阵」节（CMR r1 codex 补、产于血债 schema 评审）**；**本节为消费侧复述，值 / 语义以 0011-2 为准、不另定义**（0011-2 已反向加指针「此路由被 0011-3 D3-8 引用、改此须同步」）。改路由只改 0011-2 一处。

**动作轴方向 + 撞轴集来源**（堵 H5，承母 ADR 决定1）：动作撞哪条轴、方向、**撞轴集**（泛化轴 vs 目标命门轴，见上「离心公式」），**须从 delta 的结构化字段派生**（动作类型 / reason_code / 目标 faction-tag），**不由 LLM 解析措辞**。

**议和 axis-tag 契约（收口 P2-2）**：议和 = **单轴 `{华夷战和}`**（不引名节轴——引则东林 华夷1+名节2=3 反超军队 2、破 ✅②「军队最怒」梯度）。「东林怒 > 务实弱不爽」的档差由**外压 dynamic 臂**产（D3-4 / D3-6），非第二轴、非 LLM 即兴。

**残留**：与 0011-2 H5 同源——`source_name`→faction 解析的话术诱导面仍在（彻底归零留母 ADR 决定5），本 ADR 原样传递、不在此消解。

### D3-9 个人认同度层正交（人 ≠ 党；不在本 ADR）

**决定**：矩阵是**派系层（地基）**；个人偏离其挂名派系机器立场的部分，落**个人认同度层**，与本矩阵**正交、不在 0011-3 scope**。

- 矩阵答「东林作为机器对清账什么立场」；认同度答「钱谦益多大程度真是东林核心」。
- 抄核心死党 → 全党炸（kinship 高）；抄边缘投机 → 该党几乎不反应（kinship≈0）。
- **真源单指（P3-2）**：认同度层中与血债耦合的部分（`identity` / `k_id` / kinship 臂 / 四象限）**已由 0011-2 定稿并经 CMR r1-r4 收敛** → 真源 = `0011-2`（已收敛子 ADR）；dig-6 为深挖底稿（勿据它找已被 0011-2 覆盖的旧值）。`max(1)` 下界**已去（kinship 可真归零 = 乐见顶包）= 已决**（dig-6 ✅ / 0011-2 D2，非待拍）。
- 本 ADR 只声明「矩阵 = 派系层、认同度 = 正交修正层」，**不重复其公式**；per-轴 identity / 动态漂移 / 叛变归 #89（真 defer）。
