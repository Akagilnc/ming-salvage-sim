# 0116: 执行层四态硬化——机械底档＋判官带内选态＋双轴正交

Status: Proposed（决策：2026-07-08 #89 设计闸 grill Q2/Q4/Q6 用户拍板；承 #89/#555、0011-5 D5-7/D5-8、0057、0092、0052/0072、0076）

本 ADR 是 **0011-5 D5-7/D5-8 显式 defer 的「执行层四态细分」正式收口**——`ResolveResult.exec_fidelity` 从第一刀的 `None`（0011-5 D5-7：「阶段二执行层产物、第一刀不入 payload」）转为**有值四态｛忠实／打折／阳奉阴违／反噬｝**。四态是**过程语汇**（判官口径与月度态，0092「拖磨」同系），**落格时映射 0052/0072 执行格既有枚举、不新增格值**（0092 先例句式）：忠实→兑现；打折→打折走样；阳奉阴违→烂尾／变形（变形＝借旨行私亚型，分界按 0072「恶果/受益是否在旨外」——0072 的 M12 交接映射「变形⊂阳奉阴违/打折扭曲亚型」即此对应的反向表述）；反噬→其后果以 issue＋场面物化（见后果包），案卷本身按实况落打折走样/烂尾。执行格表结构不改、interim 由 0057 软判填、本刀接管填值；**0072「真相层永不撒谎」照守**——判官产出真值判决那一刻执行格即记真（欺瞒只活在奏报轨 0073 与情报层，皇帝被骗、数据库不被骗）。同时**取代 0057 interim 执行格判官的既定路线**：0057 明文「identity 列属 M12 substrate 不在本族，**identity seed 落地后改读该列机械化**」——0102 已让 identity 转动态承重值落地，本 ADR 即那一刀，把 interim 的「判官定性读 faction/loyalty 启发式软判」硬化为机械底档。判定形状（Q2）＝**三段**：①**意愿轴机械底档确定性计算**——读现成三源 `loyalty`（0104）＋`identity`×0011-3 四十二格立场（0102）＋承办派 `satisfaction`/血债（0011-2），确定性算出一个初档，**LLM 零算账**（镜像 settle_tick / 0102 单一写函数）；②**0092 执行判官带内落态给纹理**——判官读局势上下文在带内选态、**只准加重不准减轻**（防好回合／漂亮话把不肯办洗成忠实，与 0011-2 D2-6「阻力不因失望松动」同精神、与 0102「确定性派生关掉 H5 话术注入面」同护栏）；判官读上下文走**现成路径**（0092 属地两轴〔带宽忙/阻力顶〕＝带内加重的输入面；0111 藩府梗阻即先例：判官读该省对抗上下文令落地旨意 fidelity 恶化，接线零成本）；③**后果由落定的态确定性派生**。**双轴正交（Q4）**：**态＝意愿轴**（上述三源，肯不肯办），**成色＝`ability` 独立 clamp 调制**（办得成不成，0092 带宽臂同族语法：接口层数数、LLM 软判，**代码只 clamp 不算胜负**）——两轴不混，四象限里**能吏×不肯办＝最危险**（能力越高、阳奉阴违／反噬越有力）；与 0092 带宽臂分工：带宽管「顾不顾得上」（数量，映射拖磨），成色管「办出什么水准」（质量，落账效果系数），同读 ability 不同臂。**每月重评**：态每月按覆盖旨意重算、落 **0058 月度进展轨**为载体，判官**读上月态保持惯性**（承 0102 惯性缩放精神，态不逐月跳变）。**与 0076 分工**：月度态是奏报/过程口径；执行格正式判决的更新走 0051「执行中→结案」链，**到期复核仍＝执行格判官的正式触发形态（0076 不动、不另立判官）**——本 ADR 硬化的是这名判官的**输入下界**（机械底档），不改触发、不迁落点。

**覆盖域（Q6，「3′ 全量」）**：凡**颁出后需人承办**的旨意全过四态——多月执行类、**打击类**（抄家缉拿差务化、一月出结果，通风报信反噬发生在承办地）、**任免类**（执行主体＝被任命者本人：奉诏赴任 transit／拖延／称病占职不视事／辞不拜＝反噬当回合回退＋结构化事件，当次结算内判定当回合全落库，合 P1 铁律）；**立即 delta 类**（赏赐、开仓）**不过四态**（无承办走样面）。**四态后果包**：**忠实**＝全额×成色；**打折**＝按成色折减；**反噬**＝复用 **0101 双因子（打击存亡度×程序非法度）升档评估**（非 0101 宫变档三乘子——执行侧反噬只取存亡度×非法度两因子判轻重），产 issue **走 0106 post-resolve 当回合增量补扫物化**（同回合进 simulator payload／月报、幂等按 origin 查重、合 P1），形态族＝**抗疏喂 0091 弹劾发难门／挂冠求去／通风报信／煽动本派 factions 离心**，后果落 issues 停滞＋factions 离心、**不扩 status enum**（守 0009，同 0011-5 D5-7）。所有阈值、折减率、带宽/成色 clamp 上界、惯性系数**一律首版随 playtest**（0011-4 D4-6 先例）。净新契约仅三条：意愿轴底档确定性公式＋只准加重的带内选态规则；态×成色双轴正交 clamp 调制；覆盖域 3′ 三类旨意入四态钩子＋每月重评惯性——判官（0092）、升档评估（0101）、物化补扫（0106）、月度轨（0058）、意愿三源（0102/0104/0011-2/0011-3）、执行格（0052）全现成，不建新轴、不扩枚举。

**毙案：纯机械映射**（意愿轴算完直接定态、废判官读上下文）＝毙——丢掉 0092 判官对属地局势（藩府梗阻／灾年贼区）的软判纹理，四态退化成查表、走样戏无源（0111 已证局势上下文是纹理真源）。**纯软判硬化契约**（不落机械底档、全交判官自由裁量）＝毙——正是 0057 interim 2.5 档的**试玩 F8 自由裁量失败模式**（judge-in-loop 无机械锚、不可 golden、越级任免零阻力类漏判必复现），机械底档＋带内选态正是给自由裁量套上确定性下界的护栏。
