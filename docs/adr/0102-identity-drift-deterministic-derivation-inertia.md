# 0102: identity 漂移＝确定性派生规则＋惯性缩放

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G2 用户拍；承 #555/#87/#89）

per-character `identity`（seed 真源 0011-4 B 部分、落 0011-2 `characters.identity` [0,100]）从静态 seed 转为**动态承重值**——0011-2 D2-9 当初把「identity 动态漂移」显式 defer 给 #89，本闸收口。漂移由**确定性派生规则表**消费既有落库事件产 Δ，**LLM 不碰这个 int**（只叙事漂移花样、零算账，镜像 settle_tick / 0011-2 `accrue` 单一写函数）。规则表首刀四向（首版数值/阈值随 playtest，同 0011-4 D4-6 先例）：①授官恩遇拉拢派内边缘人→对本派 identity 降（被帝私恩、离党心）；②同党被**依律**坐实清算（`reason_code`∈依律集，0011-2 D2-5）→余党 identity 降（切割自保）；③被**罗织**打击（STIGMA，0011-2 D2-5）→不降反升＝同仇，并联动该派 `wariness`↑（0011-2 kinship 臂现成列，本规则只多接一条 fire 路）；④派内弃卒保车/顶包→**被弃者** identity 暴跌趋 0（0079 信用事件「弃卒保车」类镜像到派系侧；**本规则只辖派内弃卒**〔党魁弃自己人〕——皇帝弃卒承办人走 0104 loyalty＋#479 君臣边、不 fire 本规则：君弃臣动摇的是君臣轴、非其对党认同）。**派生入口单一、幂等**：四向规则全在读端消费已落库事件、以事件 id 为幂等去重键各消费一次——0107 等上游只产事件、不得另行联动调用本表（防 double-apply）。**路由判别＝结构字段（cmr 勘正）**：弃卒保车事件须携带**结构化施弃方类别｛皇帝, 党魁｝**（0079 薄记录现无此字段——字段需求提给写端 #628，或由案卷 origin 类型机械可判时消费侧派生），rule④ 只读结构判别、**不读自由文本语境**（确定性铁律——读语境＝落回 LLM/启发式判，H5 注入面重开）；**判别缺失的弃卒事件消费侧 fail-closed 不派生**（宁漏不歪）。**惯性缩放**：Δ 按当前 identity 缩放，identity≈100 的铁杆几乎不动、边缘人一推就动——「认同度当刀」成为玩家可学杠杆（善待边缘人→松其党心，作 G3 反正/G1 取证的前置）。净新契约仅三条：单一确定性写函数（幂等落库、缩放后 clamp[0,100]、签名物理不接自由文本）＋四向派生规则表＋惯性缩放函数；**无新数据轴**——identity/wariness 列、0079 事件、依律集/STIGMA 全现成，不建表。

三个既有消费口口径不破：0033 召对 prompt 仍按 identity 分桶选 per-faction 档料（0033 已言「本质动态、探针期可静态」，本闸只让分桶随事件移动、契约不改）；0011-2 kinship 的 `k_id = clamp(identity/100.0, 0, 1)` 仍读同一 int（公式不动、值会动）；#456 读心仍把 identity 当真相读出。与 0083 划界：**关系摘要走 LLM 酿制软判（定性文本），identity 这个承重 int 走确定性派生**，两者不混。**kinship 下游单源澄清（堵间接洗白疑虑）**：identity 经 k_id 参与的 kinship 臂下游＝wariness（0011-2 真源）——wariness 属反咬/查案敏感面、**不在 0011-5 D5-4 颁布三臂公式内**（0011-5:44「identity 仅经 kinship 旁及反咬强度、不入 resistance」为准）；故恩遇下压 identity **不会间接降颁布阻力**，好回合洗白面保持关闭。毙案：让 LLM 打分产 `identity_delta`（酿制式软判 int）＝毙——它开 H5 话术刷认同的注入面（0011-2 H5：软判可被话术诱导；identity 是 kinship 与读心的真源，LLM 一旦打分，玩家一段漂亮话即可刷高同派 wariness、糊弄读心），确定性派生正是关掉这个面的护栏。
