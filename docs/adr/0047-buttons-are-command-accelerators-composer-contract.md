# 0047: 按钮=口令加速器原则 + composer 前缀钮集修正（0028 修正案）

Status: Proposed（决策：2026-07-03 #478 grill Q5/Q6 用户拍；配套推演已在文内标注）

**原则**：呈现层按钮凡对应皇帝口令的，都是**口令加速器**——同一语义管线的第二发起入口，永不另开语义旁路（与 0028「按钮=权威分类声明」同族）。实例：名册点选=代发「宣X」；退朝钮=「退朝」口令（触发收夜 beat）。宣召的 diegetic 执行者是「王承恩这个职位」（御前常在内侍传旨——皇帝不自己喊人，也**没有皇帝外出机制**，殿内视角即全部舞台）；此为特征化素材非语法规则（0040 口径），缺位由常在员额顶替（#470），不新增机制。**composer 前缀钮集修正**：收缩为**密令+拟旨两件**，composer 不设任免前缀钮（修正 0028 决定 1 的「密令／拟旨／任免」三按钮集；0042 所记「任免面板路」〔#504〕去留**不在本决策范围**）；任免语义走自然语言识别+确认闸门（管线已有）。用户方向：按钮后续可能全砍——加速器原则保证砍钮零语义损失。本 ADR 转 Accepted 时在 0028 决定 1 与 0042 相应括注处补〔0047 后出为准〕回注。配套可逆细节归 #478 PRD：「转入诏书草案」钮废除（用户实证零点击，拟旨前缀钮覆盖）；「暂离」控件=触发既有「召对退出」词条语义的界面入口，不新增语义。
