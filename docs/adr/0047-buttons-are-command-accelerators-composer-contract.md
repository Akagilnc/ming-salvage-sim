# 0047: 按钮=口令加速器原则 + composer 前缀钮集修正

Status: Accepted（2026-07-03 随 PR #554 合入 90c7a70a；决策：2026-07-03 #478 grill Q5/Q6 用户拍；配套推演已在文内标注）

**原则**：呈现层按钮凡对应皇帝口令的，都是**口令加速器**——同一语义管线的第二发起入口，永不另开语义旁路（与「按钮=权威分类声明」同族）。实例：名册点选=代发「宣X」；退朝钮直接收夜，和打字说退朝经转译落到同一个收夜（#1947 替代，不等语义识别）。宣召的 diegetic 执行者是「王承恩这个职位」（御前常在内侍传旨——皇帝不自己喊人，也**没有皇帝外出机制**，殿内视角即全部舞台）；此为特征化素材非语法规则，缺位由常在员额顶替（#470），不新增机制。**composer 前缀钮集修正**：收缩为**密令+拟旨两件**，composer 不设任免前缀钮（修正此前「密令／拟旨／任免」三按钮集；「任免面板路」〔#504〕去留**不在本决策范围**）；任免语义走自然语言识别+确认闸门（管线已有）。用户方向：按钮后续可能全砍——加速器原则保证砍钮零语义损失。配套可逆细节归 #478 PRD：「转入诏书草案」钮废除（用户实证零点击，拟旨前缀钮覆盖）；「暂离」控件=触发既有「召对退出」词条语义的界面入口，不新增语义。

后出注记（2026-09-09，决策票 [#1823](https://github.com/Akagilnc/ming-salvage-sim/issues/1823) owner 拍）：一夜一个输入框对殿上说话，名册点选 = 代发「宣 X」不变；composer 无前缀钮（现状已如此，本注记 supersede 上文「密令 + 拟旨两件」前缀钮集）。界面动作 ↔ 口令对照：「奏」= 发话；名册点选 = 「宣 X」；「散夜」钮直接触发收夜，打字退朝由转译辨意后走同一收夜（#1947；依据与原话指针见 [0155](0155-v2-single-scene-llm-with-complete-perspectives.md)）；「暂离」= 召对退出（本 ADR 原文）；撤回成命走对话、收权走另旨，均非钮；「重试」= 系统层恢复。
