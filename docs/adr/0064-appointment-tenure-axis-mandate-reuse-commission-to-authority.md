# 0064: 任别名分轴——真除/署理/兼署/加衔入库，特旨复用中旨标记，差遣归授权档

Status: Proposed（决策：2026-07-06 #473 设计闸 grill Q2 用户拍「按推荐整套」）

每笔任命带**任别**属性（真除/署理/兼署/加衔，枚举字典 PRD 定稿），落人物官职档案，随任免案卷（0051）写入。三个消费口：①颁布判官——署理/加衔阻力轻于真除（北极星王绍徽三策的排序本身）；②执行格判官＋月末推演——署理号令折扣（「头衔不实号令不动」，别衙可不买账）；③召对读心——大臣 in-character 流露名分成色（「臣毕竟是署理，名不正」）。署理转真除不设新机制＝再下一道任免旨（新案卷）。**特旨钦命不另建轴**：来路语义已由 0055/0056 的 mode=中旨标记＋代价轨完整承载，词表连线、不重造。**任务型差遣（专差/钦差督办）不挂官位轴**，归授权档（0071）——持有型权力语义（可收回/有生效期）；总督/巡抚类占坑差遣不在此列，仍属职名分官位轴。北极星锚：毕自严案＝官（右侍郎·真除）＋授权（督理钱粮专差，0071）＋背书（御笔手敕，0070），三格分立持久化，restore 零丢失（P1）。与 0057 品级破格公式正交：跳级公式管纵向破格，任别管名分成色，两标可同挂一笔任命。四值中「兼署」（以本职兼掌他署印）在三消费口的口径随枚举字典在 PRD 定稿——显式留 PRD、不留实现期臆测。转 Accepted 时回注：CONTEXT「名分」词条（职名分/身名分二分之外补任别维度指本 ADR）。
