# 0056: 强颁与毁约的 interim 代价轨——#226 排进本闸，修订 0013「无损可撤」

Status: Proposed（决策：2026-07-03 #474 设计闸 grill 用户拍「强颁还是有点代价吧，扣皇威+分派系满意度，暂时简单粗暴」+「#226 同意排进」）

**强颁**（批红页强颁；预先中旨直发经判官 mode=中旨 顺颁时同此——中旨非跳过判决，0055 cmr R2）当回合确定性落三笔：①皇威扣——非意思意思，皇威已有真牙（辽饷到账率随皇威折扣，flows.py:141，扣皇威=真银少收）；②**分派系/阶级** satisfaction 扣——颁布判官产出**受损方 typed 清单**（{kind: faction|class, key}——faction key 限 DELTA_SCHEMA 合法集〔阉党/东林/皇党/军队/宗室/中立/西学〕走 faction_delta，阶级〔如士绅〕走 class_delta 轨——cmr R6 校正混键，×2 concurrence）＋程度档（大怒/不满），确定性映射成各方扣减（class 轨落 class_delta 须为嵌套结构 {"士绅":{"satisfaction":-N}}——_apply_class_dict 既有 shape，扁平值被静默跳过，cmr R9 钉形），每方不同（清丈强颁例：士绅〔class〕大怒/东林〔faction，「清流」非合法 key 以东林承载〕不满/阉党〔faction〕旁观）；③中旨标记＋缘由（append-only，=proto-血债账底）。**mode=中旨 被打回的 attempt 同样落②③两笔（payload 效果与皇威扣不落）——0011-5「白绕还多担污名」；判官对 mode=中旨 案卷无论判向一律输出受损方 typed 清单＋程度档（正规案卷仅打回时输出），S9 数据源恒足。**代价幂等（cmr R3 补、R8 修判据）**：三笔只在**强颁**或 **mode=中旨 attempt** 时落——**正规案卷被打回不落任何代价**（与批红「收回」零代价台阶语义一致）；幂等判据=**代价流水存在性**（该案卷已有②扣减记录即不重扣——与中旨标记**解耦**，标记只管污名），已落②③的中旨案卷批红强颁只补①皇威笔；留中重判被再次打回不重复落；判决流水照 append、代价不重刷（防单案多月放血）。**毁约「当事大臣」判定规则（cmr R3 补、R8 修定义）**：=案卷**主办条目全体**（可多人）∪ **主办/协办条目上的委派人 id**（委派人是名单条目字段非案卷全局字段——0053；**知情档条目及其委派人不入**，追责链纪律）；案卷无个体关联时该笔 no-op、只落皇威＋派系两笔。**毁约**（撤回成命 0041）走同一根轨：皇威＋当事大臣观感＋相关派系各一笔——**#226 就此排进本闸**，显式修订 0013「无损可撤」（机械可撤性 cancellable='decree' 不变，新增代价落账），撤回成命从「只识别不结算的空词条」变实词条。satisfaction 在**颁布/执行阻力路径**今日零消费方（db 他系统的既有读端如省级/阶层阻力不在此路径——cmr R1 校准口径）——其牙由 0057 的执行走样环装上；量级数值不进 ADR，playtest 调参（0011-5 既有口径）。M12 血债棘轮建成后本轨被吸收，标记与扣减流水为其账底。P4：呈现全定性（言官哗然/士绅寒心），不露数。转 Accepted 时回注靶点：0013 D2/D9 括注、#226 body、#471 词表「撤回成命」词条代价口径。
