# 0048: 月末批红呈现 = 真文书页；御案逐条准驳工作台废除

Status: Proposed（决策：2026-07-03 #478 grill Q8 + 当日追补用户拍）

月末 `<<DECISION>>` 批红（形态归 ADR 0043）的呈现 = **真文书页**：一桩一疏、逐份文书——疏文正文 → 内阁票拟呈签条/批语条 → 朱笔亲批框 → 批红落印；现有逐桩节奏即「逐份批红」。「保守换皮」（弹窗布局不动只换文言标签）被否：出不来「此框内按钮=皇帝真实作业」的体感。**边界（用户拍）**：只有「有选择的」进批红——批红页只装结算蹦出的 DECISION 决策块（推论：0 桩的月份无批红页）。**御案多条目准驳工作台废除（当日追补用户拍）**：夜内对话应允即真下旨（确认闸门+收夜批量提交，#470 canonical），御案再逐条盖玺=重复确认；#342 归轴的「多条目页界面」义务由夜卷轴呈现+确认闸门承载，不建工作台；驳回=对话里不准，改稿=应允前对话润色/应允后撤回成命（0041）。文书视觉语言只用于批红页。
