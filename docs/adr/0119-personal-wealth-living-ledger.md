# 0119: 家产活账——wealth ground-truth 列＋三笔大流水＋抄没 clamp 铁律

Status: Proposed（决策：2026-07-08 #89 设计闸 grill Q5 用户拍板；承 #89/#555/#70/#462；配套同批 0116 意愿轴 / 0117 承办人路由 / 0118 到期对账）

per-character **家产**转为 substrate 承重值——`characters` 表现无任何资产字段（实核 `ming_sim/db.py:537-561` CREATE 块 + `db.py:1216-1237` ensure_column 全表，loyalty/ability/integrity/courage 四能力轴与 identity/阴谋能力（0102/0108）皆在、**无一承载家产**），本闸补 `wealth` int 作 **ground-truth 真源列**（确切键名留实现，归切片验收）。**铁律＝LLM 零权碰钱数**：判官叙事里的抄没/籍没金额落库时由确定性守门 **clamp 到账面**——与 P2「代码只 clamp 不算胜负」同款语法，抄没入库现走 `economy_moves`（`simulation.py:40`「钱粮收支」别名，`score_extractor_internal.md:126` 抄没入内帑即此路），本闸只在其落账处夹一层账面上限；**LLM 一旦自由填金额入库＝虚存/几千万违锚**（大臣审计会拆穿），确定性 clamp 正是关掉这个面的护栏。三笔大流水驱动这本账、**俸禄等月度小流水不记**（无机械消费方，记了徒增噪声）：**①seed 量级锚（数据件）**——严嵩籍没约二百万两级＝权阉天花板≈太仓岁入几分之一到一倍级，京官万两级、清官千两级，「几千万＝数年国家岁入」**永远违锚**；74 人 seed 值随 74 人名册 seed roster 补产为**切片数据件、显式列入 DoD**（精确整数不在 ADR 发明，随数据件校准）。**②中饱流入**——财政基座现成「中饱」概念（`fiscal_tick.py:28` `C_中饱` CASH 账、`:237-241` 中饱率杆）挂 0117 承办人，**吞占率读 integrity**（清廉轴在本模型的唯一自然机械读点，分成比率首版随 playtest，0011-4 D4-6 先例），未被具体承办人吞走的余额沉没＝胥吏漂没（`fiscal_tick.py:229-232` 漂没同族账）；**基座 live 状态按存档分野**（cmr 线上 R1 Codex 勘正，以 CLAUDE.md 现状为准——**新档已接 substrate hub cutover**、明控已 seed 省的省级 tick 在跑，旧档 legacy）：挂接契约**跟随 cutover 开关**——凡该存档省级 tick 在跑，中饱流水即须挂承办人 wealth，**不得以「等 #70 全量」为由让已 live 的流水漏记**；legacy 档不接；#70 全量 cutover 只扩大覆盖面、不改本契约。**③抄没/追赃流出**——`economy_moves` 当回合 P1 落库，**实收＝clamp(≤wealth×追赃折率)**，折率**吃阴谋轴**（0108 阴谋能力高→藏匿转移多→折率低→追不回全数）；按问稽核坐实贪墨后的追赃回收走同一条路（`fiscal_tick.py:194-195` 追赃 `C_中饱→省库` 已是现成 CASH 内转，人物侧追赃挂本列）。

到期缺口成分因此天然拆成**真没办＋被吞两分量**（接 0118 到期确定性对账：对账只翻交付缺口不翻归因，而「被吞」＝②中饱流入在本人 wealth 上留下的痕迹，供揭破三渠道的按问稽核对读）。**P4 边界＝家产报大概数放行**：银两是**可数实物**（区别于 loyalty/阴谋这类抽象 stat），皇帝／厂卫问家产得「约值几万两」量级即合 P4（0023 D10「精度机制未实装时占位＝报实际大概数、可接受」先例）；0108 已把「#462 精度函数未落地期间查家产占位＝报实际大概数」的过渡口径先行钉下，**本闸让那条占位口径由 wealth ground-truth 正式承接**（此前无真源列，占位无处取数）。**划界**：查探动作链＋可错情报精度函数仍归 #462（0108 已钉同口径、须与 #456 读心一次定），**#462 将来读的可错情报底就是本账这一列**——本 ADR 只交付 ground-truth 真源，不建查探动作、不建精度模型。**动机案例三层收口一句**：一桩贪墨案的**数额**由本 ADR 的 wealth／三流水承载、**阻力**（宗藩／士绅挡旨）归 #87 线、**动机**（承办人肯不肯办）归 0116 意愿轴，三层各归其账、不串。**净新契约仅三条**：(a) `characters` 加 `wealth` int ground-truth 列＋其 74 人 seed 数据件（列入切片 DoD）；(b) 抄没 clamp 铁律——实收 clamp(≤wealth×追赃折率)、LLM 零权写钱数、复用现成拒收守门；(c) 中饱流入挂接契约——吞占率读 integrity、流向本列，live 流水随 #70 cutover 接。折率、吞占率、量级阈一律首版随 playtest（0011-4 D4-6 先例）。**毙案**：①让 LLM 自由填抄没金额入库＝毙——开虚存注入面、「几千万＝数年岁入」违锚必被审计拆穿，确定性 clamp 到 wealth 正是护栏；②家产走 qualitative-only 不落 ground-truth int＝毙——0108 过渡占位口径无处取数、抄没 clamp 无账面参照、按问稽核「被吞」分量无真相底可对读，抽象 stat 仍 qualitative-only 不受影响、P4 不松。
