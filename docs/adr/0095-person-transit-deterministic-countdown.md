# 0095: 人物在途确定性倒数——引擎定抵达、叙事跟随

Status: Proposed（2026-07-07 #475 设计闸 grill Q1/Q4/Q5/Q6 用户拍；核心模型为用户手订：省距离参数＋每月减「基础速度×系数」）

人物移动的抵达从「叙事优先＋2 月硬兜底」改为**确定性倒数**：行止(启程)按 0094 矩阵记**剩余距离**＋速度系数（常速 1；**加急＝皇帝的修饰词**「星夜兼程」×1.5~2，落 #513 宣召/行止修饰位；M11 内加急无机制代价、风味归判官软判）；每月结算的确定性 tick 对所有在途人物统一 `剩余距离 −= 基础速度×系数`（**基础速度＝1.0/月，单位规约**——距离数即「常速月数」，校准只动图权重与系数档、不动此基准）；≤0 当月**引擎落行止(抵达)**、更新 location 清在途——**抵达是引擎事实，叙事跟随演出**（transit_nudge 从「按惯例该到了」变「X 本月抵达，请演出来」）。**倒数起点**＝颁旨当月月末结算落启程、次月首减——颁旨整月即「旨驰递＋收拾行装」的叙事空间；**旨意去程不单独建模**（信使≈人速 3-5 倍、去程只占全程两三成，含糊进校准；速度系数天然覆盖信使＝高速档，#93 解冻政令时滞时同底座复用零改造）。适用＝**所有起讫可解析成 region 的人物行止**（传召/赴任/回京/贬归——F8 病根即同类动作两种处理，底座必须通用）；解析不出的退化回纯叙事。**取代 0009 决定 5 的「不做距离/ETA 计算」与「抵达由叙事产出」两句**，force_transit_arrivals/transit_nudge 现实现整体替换——**旧档直接不支持，不背历史包袱**；倒数 tick 继承原调用点的结算顺序约束（先于 apply_event_terminal_states/auto_trigger_seed_issues——门控事件读 location 前，在途者须先完成本月抵达；decree.py:953 既有教训）；0009 其余全部不动：两态模型、官印人腿分离（**启程仍由旨意/叙事触发**，引擎只管路上、不管他肯不肯动身——袁崇焕领旨不动身的戏保留）、`transit_to 非空⟹active` 不变式沿用（迁出 active 连带清倒数账）。**接口层只喂语义量**（「别让 LLM 自己数数」的反向同禁——也别让它看裸账）：判官/叙事拿「〔行速语态：加急→快马加鞭星夜兼程；常速不注〕已在途 M 月、全程约 T 月」——剩余距离点数与系数数值不出接口层，**预计抵达月不喂**（已在途/全程足够，剩下判官自己演）；玩家侧循 P4/F16：里程、月数准出数字，「约腊月初可至京师」式叙事由判官从语义量演出。**调参验收＝北极星三人锚**：同月传召孙传庭（河南）/徐光启（南直隶·快马）/袁崇焕（广东），抵京相对快慢＝下月/月余/两三月量级为准。
