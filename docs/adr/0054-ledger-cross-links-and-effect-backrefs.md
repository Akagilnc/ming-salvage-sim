# 0054: 案卷关联与效果单向回指；普通押解随拨银旨

Status: Accepted（2026-07-04 随 PR #573 合入）；#1900 修订稿（2026-10-02，按后出总令撤销相抵处方）已署——给事中 `01a107bc-4cbd-717a-86b8-40d8dc328fa6`、符宝郎 `01a107cb-0111-7757-87d5-78c1adb9513b`。Accepted 不等于已实现。

## 决定与理由

案卷关联沿用单向新指旧，关系为护卫、稽核、接应；效果记录单向回指来源案卷，案卷不复制效果清单，跨实体引用不双向互写、关联自身不带状态位，以免制造第二真源。此处不改变其他领域的引用纪律。

普通押解属于同一道拨银交办，押解人物复用案卷参与人（[0053](0053-participants-roster-three-tiers-dispatcher-chain.md)），不另立密令或关联；另行暗中加派护送才用密令，所护对象可为当夜已记录的拨银交办。关联说明安排，不等于实际护成；沿途损耗与实抵按 [0153](0153-v2-world-record-and-two-way-mediation.md) 的数值归属由引擎核算，不恢复 LLM 软判实抵口。

#1900 的重构验收只引用 [#1812「重构验收（2026-10-02 陛下重定）」](https://github.com/Akagilnc/ming-salvage-sim/issues/1812)。此前本 ADR 指定的 `escort_pending_targets` / `escort_sources` 双载体承接、配对聚合读口、入口专用资格校验及 `dossier_escort_outcomes` 专用账本处方撤销，不作为继续扩展或保全本切片新增机制的依据；配套记录、核算、供料、重开及撤回路径随本切片删简，不另定替代机制。职责搬迁、旧路退役由 [#1900](https://github.com/Akagilnc/ming-salvage-sim/issues/1900) 承接，功能如何接续留家族收尾，发现的缺口记 #1873；不是以新处方补齐全部功能，也不是宣布取消暗护或沿途损耗的玩法。
