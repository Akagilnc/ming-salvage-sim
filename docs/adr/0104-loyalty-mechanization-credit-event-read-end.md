# 0104: 忠诚机械化——承重转正、读端接 0079 信用事件

Status: Proposed（PR 待开；决策：2026-07-08 M12 设计闸 grill G4 用户拍板；承 #555/#87/#89）

`characters.loyalty`（忠诚＝对皇帝、非对党——CONTEXT 三轴之一，与党派认同度 identity、派系级满意度/影响力 satisfaction 严格分离：忠诚只辖君臣，不与另两轴混同，亦不与军心 `loyalty`〔0025 军队轴〕同物）从既有 flavor 值**转正为承重 int**，进 M12 substrate（与 identity/阴谋同批列）。**确定性派生、LLM 不碰 int**：delta 由既有落库的 0079 信用事件按规则表产——事件类即 0079 四类瘦记录（兑现所托/辜负/撑腰/弃卒保车，写端发生当场落库、本 ADR 只在读端消费），映射兑现所托·撑腰（知遇/撑腰）→ 升、辜负·弃卒保车 → 降（**弃卒仅消费施弃方＝皇帝的结构化事件**——判别字段口径同 0102：只读结构判别、缺失 fail-closed 不派生；党魁弃自己人不动君臣轴、归 0102 rule④）；**惯性缩放同 0102**：loyalty≈100 铁杆政变之夜也不倒、边缘人一推就移，「以恩结忠」成玩家可学杠杆。**读端三口全在本批 / 既有闸内、零新读通道**：①宫变档帝侧变量（本批 0101——政变之夜谁护驾谁倒戈按 loyalty 判）；②策反的**镜像面**消费（cmr 勘正符号）——loyalty 辖的是**对方策反皇帝之人**的镜像判定：loyalty 低者易被外力拉走（本刀只钉语义、其触发机制归涌现/第二刀）；**皇帝自己的策反判定（0103）第一刀不读 loyalty**——拍板因子集＝identity 低＋本派处境＋许诺分量（若第二刀补读，方向为 loyalty 高更愿为帝效力、与「对皇帝忠诚」同号）；③第二刀执行格判官 seam（0057）——**两轴拆清**：执行格判官第二刀将各读两根轴——identity（党色偏向，机械化归 0102、interim「党派认同深浅」软读即其前身）与 loyalty（君臣忠实执行，**本 ADR 交付的列**、执行输入侧的净新轴——0011-5:44 执行层输入原清单不含 loyalty，此为第二刀新增消费）；本 ADR 只交付 loyalty 列与派生规则，执行层四态硬化仍归第二刀。**空账期口径**：#628（0079 写端）落地前 loyalty 读 seed 静态值、无事件不动（切片已挂硬 blocked_by #628，「以恩结忠」杠杆随写端激活）；0079 事件 id 为派生幂等键（与 0102 同口径，防 double-apply）。

**颁布关照旧不读 loyalty**（0011-5 D5-2 铁律不破）：阶段一颁布三层（内阁票拟/司礼监批红/六科封驳）的 `per_layer_resistance` 只读血债 floor/leverage/ceiling/外压，satisfaction/identity/loyalty 三个个人轴均**不入颁布阻力**——守 0011-2 D2-6「阻力不读失望」不变式（堵好回合洗白）+ 不教会玩家一个 M12 要拆的规律。净新契约仅两条：loyalty 列转承重 int + 0079 事件类→loyalty delta 派生规则表（事件枚举/升降权重/惯性系数首版随 playtest，同 0011-4 D4-6 先例，不发明精确值）。**毙案**：loyalty 留 flavor 只写不读＝一根不驱动任何机制的死列、宫变/策反/执行判官无料可读，毙；颁布层读个人 loyalty 轴＝违 0011-5 D5-2、把 M12 要拆的洗白规律教回给玩家，毙。
