### 决定 8：派系功能/效用（供给面 + 反咬 + 接触途径）

**问题**：`factions` 表只有 satisfaction/leverage/agenda（全索取/阻力面），零供给面。弃一派 = 纯减阻力、零代价 = 无脑最优解，反噬悲剧引擎（"少一派反而好事"字面成立）。

**决定**：每派有一条**承重功能轴**（供给面），它有两个 failure mode，压在同一根轴上：
1. **承重功能（在场且合作）**：替皇帝干一类活——阉党=厂卫情报+批红+脏活；军队=动兵/守城；中立=六部行政；东林=合法性背书+士林人才；皇党=皇帝直属执行；西学=火器/历法/水利技术；宗室=血缘合法性锚+潜在藩兵钱（日常≈0 供给）。
2. **走光（弃派/派系灭）= 功能没了**：失能（杀魏后无人替你看/抄/办的真实失明）。
3. **惹毛但人还在 = 功能被扣留/武器化反咬**（= 承重功能负片）：阉党瞒报掺水、军队拥兵不前/哗变、中立怠政废弛、东林清议骂昏君/辞官、宗室串联撤合作→极端动用潜在藩兵=谋逆苗头、西学撂挑子。

**配套约束**：
- **功能数不设配额**（FF-3）：按各派实际，可 0 可多，realism 优先，不铺能力矩阵。
- **不发明新机读态**（承 决定 1）：承重功能 = **裁判规则知识**（落 `season_simulator.md`，凭在场名单+satisfaction 判合作度），**不给 factions 表加功能字段**。软判定形态/时机（哪种扣留、多狠，按动的"理"+力度，承 决定 3 折扣），**持久后果落已有槽位**：factions 离心(sat/lev) + issues（"宗室串联抵制削藩"在办事项）+ 功能效果被否（裁判反映本回合无干净情报）。装病拖延**不扩 status enum**（合 0009:38），真后果落"issue 不动"。
- **接触途径分层**（FF-4=A）：召对加 `location` 闸——在朝(∈京)直达；场外(∉京)够不着即时奏对，靠旨意经制度中介间接 or "召其入京"触发 0009 在途（叙事抵达，非 #93 的距离/ETA）。宗室/边镇/阶层共用此"场外 actor 接触模型"。
- **宗室特性**（FF-2）：低日常供给 + 高反应性自卫（不束手就擒）+ 场外间接接触；非"少了反而好"。
- **P4**：功能态/合作度**永不裸呈现**，定性叙事（"厂卫密报开始慢/掺水/对不上""百司文书积压"）。

**依赖 / 承重落地点**（→ sub-ADR / 切片）：
- 依赖 ADR 0009 `location` 字段——**重验：#106 已 MERGED 实装，依赖已满足**。
- 召对 location 闸 = 动现有 `summon_minister` 机制，单独切片论证。
- season_simulator.md **需净增"各派承重功能 + 反咬"裁判规则**（现无）——待核现状 + 起草。
- "issue 不动/不进"作为装病/拖延的后果落点，需确认 issues 机制支持"停滞"语义。

- **(A 推荐)** 召对闸在 `location`(0009 字段)：在朝(∈京)召对直达；场外(∉京)够不着即时奏对 → 旨意间接 or 召其入京触发 0009 在途（几回合后抵达，叙事判非 ETA）。**用 0009 location boolean + 在途，不碰 #93 距离计算**，小闸修掉"无视距离"一大半。代价：依赖 0009 location、动召对机制（单独切片）。
