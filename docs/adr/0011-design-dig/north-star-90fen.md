# 设计北极星 — 90 分体验标尺

> 本游戏的**质量标尺**。任何机制/决策，拿它问一句：「**能不能产出这种时刻？**」
> 来源：用户某晚 form-1（Opus 4.8 当 LLM）实玩口述（2026-06-14）。同晚类似案例还有好几个，用户很满意。

## 那个 90 分时刻

玩家推「东林查隐田」改革 → **机制撞上预装的真实**：查出东林**自己一个知名人物**的隐田。负责的 **黄道周（硬骨头那位）犹豫了**——护党 vs 守节——最终节操赢、还是上报了。玩家因**早先**让杨（嗣昌？谋略深远那位）在东林强硬背后铺了一条「自首补税」的软线，遂给对方一个**自首机会**。结果东林**没不满、反觉皇帝公正**。

## 为什么是 90 分（每块都对应在造的机制）

| 体验元素 | 对应机制 |
|---|---|
| 查隐田**有机割到自己盟友**（非剧本） | **seed-guilt 不止阉党、人人有点脏**（阉党多、东林少但非零）→ 改革刀才会割到自己人 |
| 黄道周的犹豫是**人**、不是属性检定 | actor 博弈 / LLM 软判在账本约束内演 |
| 玩家**过去的布局**（杨的软线）决定此刻有没有台阶 | 深度：危机能否优雅收场，取决于几回合前埋了什么 |
| 公正处置 → 东林**觉得公正、反挣敬重** | **失称度**：查实真隐田（没罗织）+ 给相称出路（自首补税，非抄家弃市）→ 罪罚相称 → **血债≈0，敬重落满意度（可逆层）** |

## 要命点 = 这套脊柱的存在理由

这 90 分，是在 form-1 **无任何持久账本**、**靠一次漂亮的临场发挥撞出来的**。它的反面，就是社区在玩商业版时抱怨的病——「**前面办的事跟放屁一样**」「已办结的后面还出现」「付费也过不了崇祯三年」：**神来之笔，下一回合 LLM 就忘了、重新翻案、洗没了**（无持久状态 → 推进不能）。

**血债 / 失称度 / 罪与罚账 / seed-guilt / 满意度层 这套脊柱，干的就是把这种 90 分从「撞运气」变成「稳定可复现 + 持久」**：东林那句「觉得你公正」落进满意度（留得住）、血债记 0（因为你公正），**下一回合 LLM 读到这个状态、就接着公正地演下去**，而不是失忆。

**脊柱不创造那场戏（戏是 LLM 演的）——它让戏留得住、能累积，而不是蒸发。** 我们造的，就是让这种 90 分**别再靠运气**。

## 怎么用

设计任何机制时，拿这个时刻当试金石：它**喂不喂得出**这种「涌现的道德两难 + 角色有为难 + 你过去的布局决定此刻的余地 + 公正处置挣来敬重而非记仇」？喂不出，就还差点意思。
