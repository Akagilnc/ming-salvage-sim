## Q1 ✅ 已拍（2026-06-14）：确定性账本只累积、永不判负；结局层单独一个功能
- 用户原话："这个说法是对的。结局层是单独一个功能。"
- 我先前把"确定性 vs 软判"和"判死"错挂成一根轴 → 纠正：
  - **确定性 ≠ 钦定**。因果链(三饷→民变→流寇/血债棘轮)尽管做确定性，是 sim 该有的样子、要有牙。
  - 唯一钦定特例 = **确定性正反馈环 + 无可达破局杠杆**。但每条困境链都有真出路(清隐田/追赃/议和/赈灾) → 不是钦定。
  - **红线一条**：确定性账本只累积压力变量(民怨/流寇/血债↑)，**永不内嵌"判负"那一跳**。
  - **判死 = 单独分层**(结局层，已存在的结局三级判定 叙事→数值→到期 turn≥240，decree.py:1122)，账本碰都不碰；且出路杠杆恒可达 → 判死从不必然、是走投无路的涌现。
- 一句话：**让账有牙(确定性、记得住)，但判死不准写进账，只在结局层涌现、永远留出路。**
