# 0073: 双口径两本账——奏报口径走 0058 进展轨、实况口径走 0054 效果轨，仅实况入 apply

Status: Proposed（2026-07-06 #476 设计闸接缝 B 设计侧自决、双口径硬护栏为 #473 seed 用户已拍；cmr 复核）

双口径落账不新建载体，两条既有轨分饰两本账：**奏报口径**=0058 月度进展记录轨扩成通用奏报记录——所有带执行判定面的案卷可挂（不只长差密令；0058 本有「机械对账差额不以进展记录为真源」句，叙事进展天生是奏报侧）；**实况口径**=真实效果照常落库＋0054 origin 回指案卷＋执行格判决（含 0072 变形值）。变形=同一案卷两轨分叉，暴露三通道（玩家稽核 #461/0058、政敌检举 0077、民变自长 0014 涌现轨）的机器读端=查分叉。硬护栏落在架构位：**仅实况轨可改世界状态、奏报轨永不入 apply**——假进度进不了国库（金手指审计教训同理）；两本全量落库、皆一等公民、打不同 origin 标，「叙事 A、DB B」静默漂移在存储上不可表达（B11 类故障可辨）。皇帝先看到哪本、何时看穿归 #472 情报层（0033/0034 见闻/瞒报既有），本条只管账本。
