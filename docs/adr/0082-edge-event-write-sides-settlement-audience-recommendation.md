# 0082: 边事件写端三口全做——结算·召对·荐人，当场落库

Status: Proposed（决策：2026-07-06 #479 设计闸 grill Q3 用户拍）

大臣↔大臣侧边事件写端三口：**结算口**（extractor 新边事件模块，抓邸报里的互动——联名、使绊、派系动作）、**召对口**（召对判官当场记当面站台/表态/结怨，**与大臣回话并行跑**——判官不依赖回话生成，零额外等待）、**荐人口**（#472/#465 荐人事件落地时同步落两条边）。事件形态与 0079 四字段同构（当事人对/事件类/一句语境/origin），全部当场/当回合落库；大臣侧事件类目枚举归 PRD。**召对口捕获时序（防并行悖论）**：判官每拍读「至当前已完成的对话轮」（玩家消息＋此前各轮回话），本轮回话中**新生**的事件（如答话里当场结成的协作）由下一拍判官或收夜扫尾捕获——仍在召对内、当回合落库（P1 成立），判官派发始终与回话生成并行（P5 成立、零额外等待）。判官带**已判水位**：每拍只判上次水位之后的新完成轮、收夜扫尾只补水位后残段，落库入口对同一对话段落的重复识别**幂等**——同一当面事件多拍重看不重复记账、摘要不酿重。**尾扫时序**：收夜扫尾是收夜流程内的一次**有界尾调用**（末拍答话新生事件时须等该回话完成，可能串行于其后）——「并行零加时」的承诺辖召对内判官拍（P5：不入回话感知时延）；尾扫等待归收夜结算面，与其余收夜步骤照常并行。**撤回联动（0038 白名单第三项，本 PR 即其设计审）**：边事件 origin 含**源轮绑定**；撤回该轮＝删该轮边事件（前像入 0038 轮级撤销日志）＋判官已判水位回退至该轮之前＋该轮在飞判官拍按 0038「终结异步残余」处理（写入前校验目标轮存活）；摘要月末才酿，撤回窗口内无重酿残留。理由：月末 extractor 读的是 simulator 邸报、**召对全文不在其输入里**——「当面」类事件（毕自严当面替洪承畴站台）不当场记即永久丢失（P1）；判官并行＋DB 多写免费正是 P5「严禁拿免费的换最贵的」的正向用例。否决（防重议）：只结算单口；结算＋荐人两口（砍掉的恰是 #479 body 点名的「当面站台」写面）。
