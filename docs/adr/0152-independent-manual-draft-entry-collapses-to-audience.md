## Context

上游在拟诏台留了一条**独立手拟发起口**（「御笔自拟」文本框 + 「新增草案」）：绕开召对揣摩/追问，与召对拟旨并行落桌。它曾是召对拟旨落桌缺陷的逃生口（#1680 / #1716 类；两票均 CLOSED，关闭态不能代替最新真实局成功证据）。

今日真实局（2026-09-06 17:33–17:38，代码基线 `317271211`，局 8016，真实 codex；证据 `scratchpad/qa-1772-precond/`、`1772-evidence-audience-draft-trace.txt`）前置**未成立**：召对路「拟旨：…拨银十五万两解赴关宁军前…」→ `draft_intent grant_allocation`（目标「关宁军前」、目标ID 空）→ 校验「所指对象未明」→ 追问；皇帝答「准」后再抽仍同目标 → 再追问。派单报告（非 trace）：散夜后拟诏台 `directives=0/cased=0/pending=0`；另一措辞手拟（目标「关宁军」）约 20 秒落桌、盖玺、过月。两路同文不同、结构化产物不同。已核代码侧「关宁军」可解析、「关宁军前」不在别名表——两入口准入是否不对称属**待核假说**（#1774），不是本 ADR 事实。

owner 直接原话（2026-09-06，唯一授权来源；冻结 `c-manual-draft-is-audience-wangchengen.md`）：

> 换个思路。所谓手拟，就是招对 王承恩

王承恩已是可召对角色（`content/characters.json`、`minister_dossiers.json`、`events.json` audiences；宣召 diegetic 执行职位）。通用恢复供料与拟旨抽取核可复用，**不另造**王承恩拟旨机制。

## Decision

1. **删除**拟诏台的独立手拟入口（「御笔自拟」文本框 + 「新增草案」）。
2. 皇帝直接下旨走**召对**（既有 A 路）：对王承恩或内阁说「拟旨：……」，大臣照样揣摩、追问。
3. 「**御笔**」概念保留在批红页「**另旨·中旨**」动作；不在拟诏台另立御笔发起口。

**入口范围（本决定定界，不定实现）**

| 面 | 本决定 |
| --- | --- |
| Web 拟诏台「御笔自拟」文本框与「新增草案」控件 | **退出** |
| API `POST /api/directives`（新增手拟草案） | 随 Web 控件退出而**退出** |
| 草稿的读 / 改 / 删接口（本架构内能力，与旧档无关） | **保留** |
| CLI（`ming_sim/cli/terminal.py` 手拟路） | **不在本决定**——CLI 沉浸版 parked，去留交后续设计审定 |
| 共享抽取核 `extract_draft_intent_with_roster_heal` | **不删** |

**不在本决定之内**：取消拟诏台「草稿」区、把拟诏台改成「只剩已发」——owner 原话未拍；#1764 两区（草稿与已发分开、已发覆水难收）不支持取消草稿区。若需取消须另上呈。

## Consequences / 法源边界

**later-wins 修正**

- **御笔强推**（#1772 / 2026-09-06 御批）：御笔强推＝批红页上对无人站台案卷的**一个选择**（皇帝亲担）——选了，案卷即 `backed`、照常颁布；不经手拟、不经召对。**替代**原站台闭环口径中「无人站台后的御笔强推走现有自由下旨通道（typed `target_dossier_id`）」一句；**保持**「复用原案卷追加御笔手敕并把状态改为 `backed`，不另建第二案卷」；背书的批红 `decision_key` 不变。另旨·中旨仍为皇帝独担御笔；日常直接下旨走召对「拟旨：…」（决定 2）。

**保持（本决定对其余法源不出修正案）**

- 删独立手拟入口**不改**召对前缀钮集；口令加速器契约原无「拟诏台御笔自拟契约」。「召王承恩」加速器如采用，属原则实例，不必修正该契约。
- 文书页契约原无保留手拟文本框或草稿区条款——删文本框不构成推翻其拟诏台契约。
- 落桌 ≠ 隐藏 pending 须提前变成可改删草案；**不增加**盖玺确认条件。
- 不因删入口重切已应允旨意、另立桌面真源、或把旧 draft 改名为准旨。
- 召对拟旨继续 `source_chat_turn_id`；另旨·中旨／强推继续 `decision_key`。历史御笔 provenance **不漂移**——不删历史御笔来源、不伪造聊天轮；受影响的原「自由下旨」引用改认另旨·中旨／`decision_key` 轴，不另立 provenance 形。
- 复用现行拟旨路由及抽取，**不另造**王承恩分类器。
- 王承恩等近侍不因承接拟旨而全知。
- 撤回成命／收权分立。删手拟不抹除既有反悔路径。
- 落桌验收**不锁**自由措辞。
- 桌面交接服从核账期准许呈现的事实。

**与在飞／既有契约的边界**

- **#1764**（PR #1768 已合）：草稿／已发两区与已发只读**保留**；本决定不动两区，不取消草稿区。
- **#1769**（总计 3 次补交、跨月原旨留存、真故障区分）：**不动**；不停其施工。
- **草稿区**（#1849 修订，取代原「存量：旧存档的草稿与跨月留存旨继续可读可处理」一条）：草稿的**读／改／删是本架构内的能力，与旧存档兼容无关**——删的是新增发起口，不是这层能力，故读改删一律保留；不把已应允（已发）降回可任意改删草稿；不另造重试链。旧存档兼容依 owner 2026-09-28 口谕（queued_command `64b7aa45-8865-4d2d-9495-dd1925545a08`）「不考虑旧存档兼容，以前不，现在不，以后也不，除非哪天我明确说要考虑才开始考虑」，**不在本架构的保留理由之内**；本条不因此新增任何旧档读取或迁移路径。

## 验收（实现阶段；本 ADR 不定实现细节）

1. **入口**：Web 独立手拟控件已退出；`POST /api/directives` 新增口已退出；草稿读／改／删仍可达（本架构内能力，与旧档无关）；共享抽取核仍在；CLI 手拟路未在本决定下被顺手删除。
2. **召对路两条时序**（两条时序分写；可见盖玺按钮**不作为**所有路径的必需确认；复用既有入口行为测试覆盖失败／恢复；不锁自由措辞）：
   - (a) 对王承恩或内阁说「拟旨：……」→ 揣摩/追问 → **已应允** → 收夜提交成案 → 拟诏台可辨去向 → 盖玺过月；
   - (b) 「拟旨：……」→ 揣摩/追问 → **未表态** → 收夜封窗 → 结束回合默认同意成案 → 过月。
3. **另旨·中旨**仍可执行；无人站台案卷的御笔强推按上文 later-wins 修正：批红页上的一个选择，复用原案卷、`backed`、不另建第二案卷；背书 provenance 走批红 `decision_key` 不变；历史御笔 provenance 不漂移。
4. 「召王承恩」加速器摆位为**可逆呈现取舍**，**不作**本决定前提，也不阻塞决定 1–3。
