# 0152: 独立手拟入口收束为召对（王承恩/内阁「拟旨：…」）

Status: Proposed（#1772；票庭 r4 仅放行本短单决策 ADR + 切片文书；实现 blocked_by #1774，实施票另过庭）

## Context

上游在拟诏台留了一条**独立手拟发起口**（「御笔自拟」文本框 + 「新增草案」）：绕开召对揣摩/追问，与召对拟旨并行落桌。它曾是召对拟旨落桌缺陷的逃生口（#1680 / #1716 类；两票均 CLOSED，关闭态不能代替最新真实局成功证据）。

今日真实局（2026-09-06 17:33–17:38，代码基线 `317271211`，局 8016，真实 codex；证据 `scratchpad/qa-1772-precond/`、`1772-evidence-audience-draft-trace.txt`）前置**未成立**：召对路「拟旨：…拨银十五万两解赴关宁军前…」→ `draft_intent grant_allocation`（目标「关宁军前」、目标ID 空）→ 校验「所指对象未明」→ 追问；皇帝答「准」后再抽仍同目标 → 再追问。派单报告（非 trace）：散夜后拟诏台 `directives=0/cased=0/pending=0`；另一措辞手拟（目标「关宁军」）约 20 秒落桌、盖玺、过月。两路同文不同、结构化产物不同。已核代码侧「关宁军」可解析、「关宁军前」不在别名表——两入口准入是否不对称属**待核假说**（#1774），不是本 ADR 事实。

owner 直接原话（2026-09-06，唯一授权来源；冻结 `c-manual-draft-is-audience-wangchengen.md`）：

> 换个思路。所谓手拟，就是招对 王承恩

> 想直接下旨就在召对里对王承恩或内阁说「拟旨：……」，大臣照样揣摩、追问）；「御笔」这个概念保留在批红页的「另旨·中旨」动作里 / 就是这个意思

王承恩已是可召对角色（`content/characters.json`、`minister_dossiers.json`、`events.json` audiences；0047 宣召 diegetic 执行职位）。通用恢复供料与拟旨抽取核可复用，**不另造**王承恩拟旨机制。

## Decision

1. **删除**拟诏台的独立手拟入口（「御笔自拟」文本框 + 「新增草案」）。
2. 皇帝直接下旨走**召对**（既有 A 路）：对王承恩或内阁说「拟旨：……」，大臣照样揣摩、追问。
3. 「**御笔**」概念保留在批红页「**另旨·中旨**」动作；不在拟诏台另立御笔发起口。

**入口范围（本决定定界，不定实现）**

| 面 | 本决定 |
| --- | --- |
| Web 拟诏台「御笔自拟」文本框与「新增草案」控件 | **退出** |
| API `POST /api/directives`（新增手拟草案） | 随 Web 控件退出而**退出** |
| 存量草稿的读 / 改 / 删接口 | **保留** |
| CLI（`ming_sim/cli/terminal.py` 手拟路） | **不在本决定**——CLI 沉浸版 parked，去留交后续设计审定 |
| 共享抽取核 `extract_draft_intent_with_roster_heal` | **不删** |

**不在本决定之内**：取消拟诏台「草稿」区、把拟诏台改成「只剩已发」——owner 原话未拍；#1764 两区（草稿与已发分开、已发覆水难收）不支持取消草稿区。若需取消须另上呈。

## Consequences / 法源边界

**later-wins 修正**

- **[0093](0093-rescript-loop-triage-draft-six-actions.md)**（#1772 / 2026-09-06 御批）：御笔强推＝批红页上对无人站台案卷的**一个选择**（皇帝亲担）——选了，案卷即 `backed`、照常颁布；不经手拟、不经召对。**替代** 0093「站台闭环现成轨口径」中「无人站台后的御笔强推走现有自由下旨通道（typed `target_dossier_id`）」一句；**保持**「复用原案卷追加御笔手敕并把状态改为 `backed`，不另建第二案卷」；0070 批红 `decision_key` 不变。另旨·中旨仍为皇帝独担御笔；日常直接下旨走召对「拟旨：…」（决定 2）。

**保持（本决定对其余法源不出修正案）**

- **[0047](0047-buttons-are-command-accelerators-composer-contract.md)** 保持：口令加速器同一语义管线；宣召执行者是王承恩这个职位、缺位常在员额顶替；前缀钮密令＋拟旨；任免自然语言；转入诏书草案钮废除。删独立手拟入口**不改**召对前缀钮集；原文无「拟诏台御笔自拟契约」。「召王承恩」加速器如采用，属原则实例，不必修正 0047。
- **[0048](0048-month-end-rescript-as-real-document-page-no-desk-workbench.md)** 保持：一桩一疏真文书页；有选择的 DECISION 进批红；废御案逐条准驳；应允前对话润色／不准、应允后撤回成命；文书视觉语言只用于批红页。原文无保留手拟文本框或草稿区条款——删文本框不构成推翻其拟诏台契约。
- **[0049](0049-close-night-commit-is-approval-no-month-end-decree-review.md)** 保持：夜域已应允；收夜提交即准旨；未表态项结束回合默认同意；收夜封窗；月末无颁诏复审。落桌 ≠ 隐藏 pending 须提前变成可改删草案；**不增加**盖玺确认条件。
- **[0051](0051-decree-ledger-is-night-commit-record-no-second-split.md)** 保持：案卷唯一身份；收夜或结束回合默认同意成案；已应允不入案卷枚举；召对逐旨粒度；四态／判决组合态；载荷继承、效果溯源；留中同 id；密令双轴。不因删入口重切已应允旨意、另立桌面真源、或把旧 draft 改名为准旨。
- **[0070](0070-ledger-endorsement-entries-cosign-backing-imperial-hand.md)** 保持：会签／当面站台／御笔手敕分立；召对来源 `source_chat_turn_id`；批红／御笔来源 `decision_key`，互斥。收束后：召对拟旨继续 `source_chat_turn_id`；另旨·中旨／强推继续 `decision_key`。历史御笔 provenance **不漂移**——不删历史御笔来源、不伪造聊天轮；受影响的原「自由下旨」引用改认另旨·中旨／`decision_key` 轴，不另立 provenance 形。
- **[0006](0006-stage-chat-actions-and-commit-at-decree.md)** 保持：被召者含太监；对话确认、拒绝丢暂存、不回默认同意；提交时点以后出 0038／0049 为准。
- **[0028](0028-audience-secret-order-capture-and-action-classification.md)** 保持：显式分类／上下文取材／no-op·暂存对冲；2026-07-23 结构信号分界；2026-08-28 拟旨 typed 成案修订。复用现行拟旨路由及抽取，**不另造**王承恩分类器。
- **[0033](0033-minister-audience-prompt-characterize-not-constrain.md)** 保持：人物、党派、认同度客观特征化；被召者含太监；零形式约束；输入侧 P4。适用于王承恩供料。
- **[0034](0034-minister-audience-fed-perspectival-knowledge-not-omniscient.md)** 保持：角色见闻、参与即知、永不全知、开局非真空、显式排除优先。近侍不因此全知。
- **[0037](0037-summon-lands-in-ledger-no-dedicated-action-type.md)** 保持：宣召入故事账，不新增 summon 表／动作类型。
- **[0041](0041-retract-word-split-three-referents.md)** 保持：撤回本轮／撤回成命／收权分立。删手拟不抹除既有反悔路径。

- **[0142](0142-no-semantic-parsing-of-llm-prose.md)** 保持：结构事实走显式契约，不从自由散文解析。落桌验收**不锁**自由措辞。

## 验收（实现阶段；本 ADR 不定实现细节）

1. **入口**：Web 独立手拟控件已退出；`POST /api/directives` 新增口已退出；存量草稿读／改／删仍可达；共享抽取核仍在；CLI 手拟路未在本决定下被顺手删除。
2. **召对路两条时序**（0049 原文分写；可见盖玺按钮**不作为**所有路径的必需确认；复用既有入口行为测试覆盖失败／恢复；不锁自由措辞／0142）：
   - (a) 对王承恩或内阁说「拟旨：……」→ 揣摩/追问 → **已应允** → 收夜提交成案 → 拟诏台可辨去向 → 盖玺过月；
   - (b) 「拟旨：……」→ 揣摩/追问 → **未表态** → 收夜封窗 → 结束回合默认同意成案 → 过月。
3. **另旨·中旨**仍可执行；0093 `target_dossier_id` 强推仍可达且复用原案卷；历史御笔 provenance（0070）不漂移。
4. 「召王承恩」加速器摆位为**可逆呈现取舍**，按 0047，**不作**本决定前提，也不阻塞决定 1–3。
