# 重构首期：一个 LLM 演整场召对，可读材料备齐后自主取阅

Status: W2A 施工中（2026-09-09 owner 已拍首期取舍；W1A #1827 / #1830 已于 2026-09-11 落地只读跑证与人物材料目录；W1B #1832–#1834 已由 PR #1865 落地身份隔离、世界材料目录及既有调用接入；W2A #1836–#1839 / #1842 在 PR #1868 分支施工，未合并前不宣告版本落地；本次游戏重构，非独立版本）

首期由一个 LLM 演整场召对，中间层按职责备齐可读材料、由 LLM 需要时自主取阅，而非将全部原文预先塞入上下文，优先还原北极星的连贯演出，不采用每人一个模型或独立导演调用，也不预建长期记忆整理或摘要机制，待实际出现上下文影响后再讨论。
这是重构时多人同场所作的明确取舍：同一次调用可看见各在场人物的材料，由 LLM 维持人物视角，但不把全局实况无差别提供给角色。
本决定不把世界推演和所有辅助处理合成一次调用，原话及被替代的前案见 [召对取舍依据](../design/game-v2-architecture.md#召对取舍依据)，「一次给全」的含义澄清与不做记忆整理的裁定见 [记忆供料保持简单](../design/game-v2-architecture.md#记忆供料保持简单)，读取形态已定（见下）。
读取形态（#1947 v10 替代场景取阅口；不推及世界推演）：场景模型经中间层四个工具自主查人物档案、看殿上名单、改殿上名单、退朝（查人物档案一项由统一读账取代，见 [0162](0162-every-model-reads-one-way-and-speaks-as-a-person.md)）。档案含定性人物字段、查询得出的现任各职与所涉事件（含经手的旨意、所担之旨及背书人和形式），不含世界全知盘面或人物属性数值。账目按 [#1965](https://github.com/Akagilnc/ming-salvage-sim/issues/1965) 现行 G7/G8 规则提供：所有账户名称可见，知情者另得当前实况，不知情者无数无档，取代本段原「只含定性内容」「谁知道什么只按经手即知」在账目上的限制；法源及共用材料边界见 [0034 后出注记](0034-minister-audience-fed-perspectival-knowledge-not-omniscient.md)。其他见闻仍按经手即知。每夜开场附最近一期邸报原文；本夜皇帝原话与戏文按真实多轮消息递入，不压成一段、不做摘要。原 #1819「给一个地方它自己读」的自主取阅法意不变，不再为场景另外维护目录和一套读取工具。见闻、工具次数等硬上限不复活。依据：源卷 `~/.claude/projects/-Users-akagilnc-WorkSpace-Ming-LLM/a45c2e6b-8c9a-4f56-85fb-73324ee40299.jsonl`，owner `ddbdaf45-2545-4329-a9aa-7e1152977ae9`、`a16e2f0c-8362-48cb-aaf7-c48a1c8e9c36`、`74fac3e6-9895-487e-90b0-0c6b9c473353`。
场中承接（#1947 v10）：一轮是皇帝原话与场景模型的整段自由戏文；原文作为召对夜实体上的事件即时提交，输出不改字、不改顺序。场景只维护殿上名单：入殿口核对账本有人、所在京师（beizhili），退下不核；不在京的人加不进殿。当场实况自身不再另设所在地后验核对；异地任职、罢居起复可以当场生效，所在不因此改变。旨意与当场实况归退朝后的整夜转译。

皇帝对谁吩咐要办的事，就由谁拟成正式圣旨念给皇帝，皇帝认可才成旨；没表态就是默拒。召对使用者在**收夜后起一次后台转译**，通读整夜全部已落账轮次；中间层只一进一出。转译只声明皇帝认可的圣旨定稿（定稿全文、来历、涉及的人）与当场实况，不再声明应允、排版或退朝。旨意事件同时记在涉及的人身上，不带交办／拨款载荷，待执行后果由 #1948 月末通用声明落账。当场实况用两票共用的实体字段声明，事件与现状同事务。是待执行旨意还是已发生实况，归模型演绎。任免是在任记录的在任者变更，一员的官职新任只替换同一「官职＋属地」的原任，多员除外（0159「官职、属地与任职」「新官上任」，2026-10-23 改）；首辅的资格及出阁联动以 [#1965 首辅裁定](https://github.com/Akagilnc/ming-salvage-sim/issues/1965) 为准。

说话人、王承恩低语、旨文、旁白与要紧处，由场景模型直接在戏文写【名】【王承恩·低语】【旨】【旁白】与加粗标记；前端照标记排，不改原文，不另等转译。大立绘为当前说话人，王承恩永远小头像；不再设御前主角声明。

转译结果或「接不住」挂在这一夜上；进度只读账本有无终结结果，不另立状态表。跨夜查档读已经落账的现状与履历；「接不住」进入后续夜的输入，只有这条事实，不含重试过程和字段诊断。单层声明重交耗尽是终结结果，不挡后续夜或过月（#1943 对本 ADR 的替代）；调用没返回、传输与代码异常不改称「接不住」。

点退朝按钮直接请求收夜；打字说退朝由场景模型调退朝工具。最后一轮生成完、整轮落账之后，才记收夜，不等转译；该轮模型失败则不落该轮，收夜照记，转译只读已落轮次。说话任务归召对使用者，不随连接终止。收夜前意外中断仍算没收夜，重开回到最后一轮；已收夜而缺结果的夜补转，已落不重落。正常退出先排空，过月先等**所有已收夜**缺结果的夜。过月入口在召对之外，召对唯一出口是退朝，不新增禁点或自动收夜。递话仍由场景模型演，不另起续演调用、意图分类器或代码触发递话 agent。
