# 重构首期：一个 LLM 演整场召对，可读材料备齐后自主取阅

Status: W2A 施工中（2026-09-09 owner 已拍首期取舍；W1A #1827 / #1830 已于 2026-09-11 落地只读跑证与人物材料目录；W1B #1832–#1834 已由 PR #1865 落地身份隔离、世界材料目录及既有调用接入；W2A #1836–#1839 / #1842 在 PR #1868 分支施工，未合并前不宣告版本落地；本次游戏重构，非独立版本）

首期由一个 LLM 演整场召对，中间层按职责备齐可读材料、由 LLM 需要时自主取阅，而非将全部原文预先塞入上下文，优先还原北极星的连贯演出，不采用每人一个模型或独立导演调用，也不预建长期记忆整理或摘要机制，待实际出现上下文影响后再讨论。
这是重构时多人同场所作的明确取舍：同一次调用可看见各在场人物的材料，由 LLM 维持人物视角，但不把全局实况无差别提供给角色。
本决定不把世界推演和所有辅助处理合成一次调用，原话及被替代的前案见 [召对取舍依据](../design/game-v2-architecture.md#召对取舍依据)，「一次给全」的含义澄清与不做记忆整理的裁定见 [记忆供料保持简单](../design/game-v2-architecture.md#记忆供料保持简单)，读取形态已定（见下）。
读取形态（#1947 v6 替代场景取阅口；不推及世界推演）：场景模型经中间层三个工具自主查人物档案、看殿上名单、改殿上名单。档案只含定性人物字段与所涉事件，不含世界全知盘面、属性数值或皇帝独知的材料。每夜开场附最近一期邸报原文；本夜皇帝原话与戏文按真实多轮消息递入，不压成一段、不做摘要。原 #1819「给一个地方它自己读」的自主取阅法意不变，不再为场景另外维护目录和一套读取工具。见闻、工具次数等硬上限不复活。依据：源卷 `~/.claude/projects/-Users-akagilnc-WorkSpace-Ming-LLM/a45c2e6b-8c9a-4f56-85fb-73324ee40299.jsonl`，owner `ddbdaf45-2545-4329-a9aa-7e1152977ae9`、`a16e2f0c-8362-48cb-aaf7-c48a1c8e9c36`、`74fac3e6-9895-487e-90b0-0c6b9c473353`。
场中承接（#1947 v6）：一轮是皇帝原话与场景模型的整段自由戏文；原文作为召对夜实体上的事件即时提交，输出不改字、不改顺序。场景只维护殿上名单：入殿口核对账本有人、所在京师（beizhili），退下不核；不在京的人加不进殿。当场实况自身不再另设所在地后验核对；异地任职、罢居起复可以当场生效，所在不因此改变。名单之外的声明仍归转译。

召对使用者在每轮戏文落账后起**后台转译**，逐轮串行，下一句不等；中间层只一进一出。转译读本轮原话、戏文、本夜历史与已有旨意，声明旨意、应允／驳回、当场实况、分段与可闻性、御前主角以及打字退朝。旨意当场成为账本实体，只带原话、来历、表态；大臣奏请同样当场建。没有暂存清单，也不在收夜时搬账；收夜后未驳回的旨意按已允读取，不另写默认同意事件。待执行后果由 #1948 月末落账；当场实况则用两票共用的实体字段声明立即落账，事件与现状同事务。是待执行旨意还是已发生实况，归模型演绎。人物官职变化罢免同官同地原任，多员除外（0159）。

转译结果或「接不住」挂回原轮；进度只读账本有无终结结果，不另立状态表。查档读已经落账的现状与履历；本夜「接不住」进入后续输入，只有这条事实，不含重试过程和字段诊断。单层声明重交耗尽是终结结果，不挡下一句或过月（#1943 对本 ADR 的替代）；调用没返回、传输与代码异常不改称「接不住」。收夜立即记一笔、不等转译；过月先 join **所有夜**未完成轮次。正常退出先排空，意外中断重开只补无结果的轮次，已落不重落。递话仍由场景模型演，不另起续演调用、意图分类器或代码触发递话 agent。
