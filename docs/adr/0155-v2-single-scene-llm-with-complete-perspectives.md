# V2 首期：一个 LLM 演整场召对，一次提供可见材料

Status: proposed（2026-09-09；owner 已拍首期取舍，设计待评审，未实施；仅适用于 V2）

北极星的一场连续召对原本由一个 LLM 演出，首期采用同一做法，承接回话、插话、人物动作、耳语与场面衔接，不为每个大臣各起模型，也不增设一次独立的导演调用。取舍是优先还原连贯的戏、减少等待，暂不追求模型调用级的人物视野隔离。

一次给全本次职责可见的材料，让 LLM 自己阅读取舍，首期不增加按需检索往返。多人场景仍按人物组织其各自的人设、经历和角色见闻，再交给同一场景 LLM，由它维持人物视角；「给全」不是把全局秘密实况无差别交给所有角色。世界推演的全局视野与场景角色见闻的职责区分仍依 [0153](0153-v2-world-record-and-two-way-mediation.md)。

## 与既有设计的关系

这是对 [0034](0034-minister-audience-fed-perspectival-knowledge-not-omniscient.md) 在 V2 多人同场实现上的明确取舍：不同人物不因此知道相同的世界，但承认同一次模型调用会看见各在场人物的材料，靠演绎保持区别。旧文「全知盘面加自觉克制」的否决，不应误读为禁止这个已拍定的首期方案；本方案也不等于把世界实况全量灌给角色。

选择单模型的原话及其替代的前案见 [召对取舍依据](../design/game-v2-architecture.md#召对取舍依据)。这只决定场景演出，不把世界推演与所有辅助工作强制合为一次调用。
