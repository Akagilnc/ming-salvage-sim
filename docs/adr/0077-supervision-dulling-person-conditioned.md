# 0077: 监督钝化人身条件化——事实硬、裁量软、验收锚补牙，不建钝化数值

Status: Accepted（2026-07-06 随 PR #630 合入；决策：2026-07-06 #476 设计闸 grill Q4 用户拍「事实硬裁量软验收锚」＋追加「钝化必须人身条件化、不许同质」；feel 宪法「不可根治只可管理」为 #473 seed 已拍）

「变形不可根治、只可管理」的机制载体：DB 只机械记**事实**（某路稽核连续在场月数、该类空子暴露史、承办/稽核人任期——操守读 characters.integrity 现成字段），**不建「钝化度」数值字段**（拒假精度、拒引擎侧科技树倒放）；判官读事实软判钝化与空子转移，且**钝化＝人×派系关系的函数、不许同质**：庸常官僚久任合流（速率随操守低、与被稽对象派系纠葛深而快）；同派稽核首日即打折（睁眼闭眼不用「久」）；敌派稽核不钝化、查得狠但每份报告带私货（滑向检举轨）；高操守孤直型（李邦华整顿京营式）**人不钝化——反制转打其人**：架空、断信息、诬告围攻、明升暗调——「不可根治」以守护成本形态保留，用对人真有用、代价从失真换成树敌与护人。政敌免费审计＝检举走候选事件/密奏轨，检举记录带**真伪底**（引擎知真假、皇帝自辨——0073 双口径同款精神）。**成对验收锚**（0057 方法学，判官过不了不收货）：庸吏挂满一年→陋规化必现；孤直型挂满一年→陋规化不得现、针对其人的反制事件必现其一。例证纪年从崇祯朝（《大明王朝1566》剧作标杆只作模式参照、非纪年锚）。
