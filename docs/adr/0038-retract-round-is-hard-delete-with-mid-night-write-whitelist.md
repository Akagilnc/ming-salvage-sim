# 撤回本轮 = 逆转该轮全部效果；夜内直写真实盘面走可枚举白名单

Status: Proposed（2026-07-02 #470 grill 结晶；评审闸在 to-prd 之后；cmr R1 修订：真删→效果逆转）

## 决定

- **「轮」的定义**：一轮 = 从一次玩家发话到下一次玩家发话之间的完整交换，含该窗口内产生的全部账、暂存动作、候选变更、密令落地与对话记录。
- **撤回本轮 = 逆转该轮全部效果**（不止删该轮创建物）：
  - **删该轮创建的**：账本条目、暂存动作、圣旨候选、已正式落地的密令（**含其结构化字段记录**——ADR 0028 的标题/承办人/期限/标签等）、对话轮。
  - **回滚该轮对先前对象的变更**：暂存动作被该轮确认的回到待确认、候选被该轮应允的回到草拟、草稿正文被该轮覆盖的回退上一版、被该轮口头拒绝而删除的暂存行复原。实现形态 = **轮级撤销日志，持久化落库**（夜域附属记录，非内存态——崩溃/重开之后撤回窗口仍有效，restore 后点撤回照样完整逆转；cmr R3），编码归切片。
  - 不加作废标记、不加账本 pending 层、不加状态位——逆转后像没发生过。
- **撤回窗口边界**：只够到最近一轮；**收夜与颁诏封住撤回窗口**——撤回不跨已收的夜、不跨颁诏成案点（颁诏后反悔按 ADR 0006 是新的游戏内命令，不是 undo）。
- **一轮草拟多道旨的口径**：撤回按轮逆转该轮全部产物（该轮草拟的候选一起消失）；只想驳其中一道 → 用对话内逐道准驳，不用撤回。
- **界线**：「落账即史实」（ADR 0036）管**系统层**——重开/崩溃永不回滚账；撤回是**玩家层显式反悔**，是唯一能逆转账的口子。
- **依赖注（接缝约束，已落 #459 body 2026-07-02）**：撤回不追下游见闻，以 #459 的**撤回安全**约束为界——见闻派生须保证「账删则源自该账的见闻随之不可见」：纯读端派生/视图天然满足；#459 若物化（新表）须自带删除/失效传播（形态与机制归 #459 设计，约束不可谈判）。#470 侧删除范围到账为止，不追派生记录。
- **防坑不变式**：夜内对真实盘面的直写是**可枚举白名单**（现状仅「密令应允即落地」一项；拟旨/任免均走待确认暂存、颁诏/过回合才提交——ADR 0006）。新增任何夜内直写必须过设计审，否则撤回逆转不干净。

## 为什么

直删干净的三个结构性事实：夜内无人写真实盘面（ADR 0006 暂存机制现成）；账本是全新自足的表（上游遗留代码不碰它，删行无历史包袱）；见闻为读端派生（#459/#472——删账即自愈；此前提已在「依赖注」显式化）。撤回存在的理由是兜「LLM 演砸了」的质量风险（探针期不让玩家为模型失误买单）。用户 2026-07-02 拍真删、机制设计委托（顾虑=上游遗留代码坑多，由白名单不变式挡住）。**cmr R1（agy+Opus 双厂商并发）抓出「删创建物 ≠ 逆转效果」的四个面**——暂存状态被后轮确认、候选状态被后轮应允、草稿正文被后轮覆盖、暂存行被后轮口头拒绝删除，外加已落地密令的结构化记录残留：撤回的承诺是「像没发生过」，只删创建物兑现不了它，故语义修订为效果逆转 + 轮级撤销日志。

## 否决的备选（防日后重议）

- **只删该轮创建物（本 ADR 的 R0 口径）**：该轮对先前对象的状态变更/覆盖/删除不可逆——撤回确认轮后暂存动作仍是已确认态、被覆盖的草稿正文永久丢失、被拒删的暂存行无法复原，「像没发生过」破功（cmr R1）。
- **冲正/状态位（追加作废标记）**：过滤义务扩散到所有读账处（见闻派生/喂 LLM/呈现），漏一处即「明明撤回了王承恩怎么还记得」；记录留残影。
- **账本 pending 层（实际落时再入）**：推迟落账 = 崩溃丢整轮，违 P1/restore（ADR 0036 恢复精确到最后持久化对话轮的前提是即时落账）。
- **砍掉撤回本轮**：最贴角色保真，但探针期它是兜模型质量风险的（既有 CONTEXT 词条立意），不砍。
