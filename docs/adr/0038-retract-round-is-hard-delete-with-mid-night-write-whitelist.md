# 撤回本轮 = 真删；夜内直写真实盘面走可枚举白名单

Status: Proposed（2026-07-02 #470 grill 结晶；评审闸在 to-prd 之后）

## 决定

- **撤回本轮真删**：删除最近一轮问答产生的全部产物——该轮账本条目、该轮暂存动作（待确认动作）、该轮已正式落地的密令；对话记录里该轮一并删，像没发生过。不加作废标记、不加账本 pending 层、不加状态位。
- **界线**：「落账即史实」（ADR 0036）管**系统层**——重开/崩溃永不回滚账；撤回是**玩家层显式反悔**，是唯一能删账的口子，只够到最近一轮。
- **防坑不变式**：夜内对真实盘面的直写是**可枚举白名单**（现状仅「密令应允即落地」一项；拟旨/任免均走待确认暂存、颁诏/过回合才提交——ADR 0006）。新增任何夜内直写必须过设计审，否则撤回删不干净。

## 为什么

直删干净的三个结构性事实：夜内无人写真实盘面（ADR 0006 暂存机制现成）；账本是全新自足的表（上游遗留代码不碰它，删行无历史包袱）；见闻为读端派生（#459/#472——删账即自愈，不落独立见闻表）。撤回存在的理由是兜「LLM 演砸了」的质量风险（探针期不让玩家为模型失误买单）。用户 2026-07-02 拍真删、机制设计委托（顾虑=上游遗留代码坑多，由白名单不变式挡住）。

## 否决的备选（防日后重议）

- **冲正/状态位（追加作废标记）**：过滤义务扩散到所有读账处（见闻派生/喂 LLM/呈现），漏一处即「明明撤回了王承恩怎么还记得」；记录留残影。
- **账本 pending 层（实际落时再入）**：推迟落账 = 崩溃丢整轮，违 P1/restore（ADR 0036 恢复精确到最后一笔账的前提是即时落账）。
- **砍掉撤回本轮**：最贴角色保真，但探针期它是兜模型质量风险的（既有 CONTEXT 词条立意），不砍。
