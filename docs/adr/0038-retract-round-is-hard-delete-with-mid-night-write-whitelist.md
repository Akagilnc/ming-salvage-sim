# 撤回本轮 = 逆转该轮全部效果；夜内直写真实盘面走可枚举白名单

Status: Proposed（2026-07-02 #470 grill 结晶；评审闸在 to-prd 之后；cmr R1 修订：真删→效果逆转）

## 决定

- **「轮」的定义**：一轮 = 从一次玩家发话到下一次玩家发话之间的完整交换，含该窗口内产生的全部账、暂存动作、候选变更、密令落地与对话记录。
- **撤回本轮 = 逆转该轮全部效果**（不止删该轮创建物）：
  - **删该轮创建的**：账本条目、暂存动作、圣旨候选、已正式落地的密令（**含其全部结构化字段记录**——ADR 0028 的标题/承办人/期限/标签，**及排除名单/知情圈/机构级排除映射 payload**（不论落独立表还是子结构，防幽灵排除——cmr R8））、对话轮。
  - **回滚该轮对先前对象的变更**：暂存动作被该轮确认的回到待确认、候选被该轮应允的回到草拟、草稿正文被该轮覆盖的回退上一版、被该轮口头拒绝而删除的暂存行复原。实现形态 = **轮级撤销日志，持久化落库**（夜域附属记录，非内存态——崩溃/重开之后撤回窗口仍有效，restore 后点撤回照样完整逆转；cmr R3），日志为**前像结构**：删除记被删记录完整前像、覆盖记前值——只记行 ID 复原不出硬删的行（cmr R7 钉），编码归切片。
  - 不加作废标记、不加账本 pending 层、不加状态位——逆转后像没发生过。
- **撤回窗口边界**：只够到最近一轮；**收夜与颁诏封住撤回窗口**——撤回不跨已收的夜、不跨颁诏成案点（颁诏后反悔按 ADR 0006 是新的游戏内命令，不是 undo）。
- **一轮草拟多道旨的口径**：撤回按轮逆转该轮全部产物（该轮草拟的候选一起消失）；只想驳其中一道 → 用对话内逐道准驳，不用撤回。
- **夜内应允提交时序（2026-07-02 用户拍，cmr R4；在召对夜容器下取代 ADR 0006「对话应允=当场 commit」）**：夜内应允 = 暂存标**「已应允」**（夜域状态，撤回可逆转）；**收夜 = 本夜已应允暂存的提交点**（任免/后宫 commit 真实盘面、拟旨候选转 turn_directives 进颁诏界面）——收夜=封窗=提交三合一；**未表态的照旧留暂存至颁诏/过回合默认同意**（ADR 0006「不回→视同准」语义不变）；密令不变（应允即落地，白名单直写项之一——全名单见下「防坑不变式」）。**收夜提交的崩溃契约（cmr R6）**：进入收夜即封窗并持久化「收夜中」相位；提交批处理**幂等续跑**（每项落库即标 committed，同 ADR 0008 纪律）——中途崩溃重开后续跑收齐，半提交终态不可达。**收夜 × 在飞回话（cmr R6）**：收夜（含颁诏顺势收夜）对在飞的大臣回话**先等其完成并入档再执行**（入档 = 对话轮持久化；账可待补、可跨收夜续补——与 ADR 0036 互恰，cmr R7 钉）——「召对退出≠取消」的既有词条语义优先；不取消在飞轮、不允许已收夜后写回。等待带**超时熔断，fail-closed**（线上 R1/R2 Gemini）：在飞生成超时/挂起则**中止收夜**——夜保持开着、响亮报错，玩家在夜内原地重试（同「密令下达失败」语义）或再次退朝；**不强制收下带悬问的夜**（已关的夜无法重试，会留「有问无答」的悬空记录）。
- **撤回终结该轮全部异步残余（cmr R4）**：撤回时同步取消该轮在飞后台生成（回话/读心/抽取），删除或失效该轮的抽取进度、待补标记、重试入口与错误包关联——已撤回的轮不得被补跑复活、不得留孤儿重试；后台任务写入前须校验目标轮仍存活。
- **撤回整套逆转事务原子（cmr R5）**：删创建物 + 回滚变更 + 终结异步残余的全部写操作包在**同一数据库事务**内全有或全无（同 ADR 0008/0036 事务纪律）——撤回中途崩溃不得留下半撤回脏档。
- **界线**：「落账即史实」（ADR 0036）管**系统层**——重开/崩溃永不回滚账；撤回是**玩家层显式反悔**，是唯一能逆转账的口子。
- **依赖注（接缝约束，已落 #459 body 2026-07-02）**：撤回不追下游见闻，以 #459 的**撤回安全**约束为界——见闻派生须保证「账删则源自该账的见闻随之不可见」：纯读端派生/视图天然满足；#459 若物化（新表）须自带删除/失效传播（形态与机制归 #459 设计，约束不可谈判）。#470 侧删除范围到账为止，不追派生记录。
- **防坑不变式**：夜内对真实盘面的直写是**可枚举白名单**（两项，线上 R1 Codex 核真代码补第二项）：①「密令应允即落地」；②**未在册人物入册**（`register_unlisted_person` 现存路径——被宣召的未在册人物须即时建档才能开口，撤回时该轮新入册的人物档案连同 registry/内存注册一并删除，前像日志覆盖）。拟旨/任免均走待确认暂存——已应允的收夜提交、未表态的颁诏/过回合默认同意提交（见上「夜内应允提交时序」）。新增任何夜内直写必须过设计审，否则撤回逆转不干净。

## 为什么

直删干净的三个结构性事实：夜内对真实盘面的直写仅白名单两项、其余全被 ADR 0006 暂存机制挡在夜外；账本是全新自足的表（上游遗留代码不碰它，删行无历史包袱）；见闻为读端派生（#459/#472——删账即自愈；此前提已在「依赖注」显式化）。撤回存在的理由是兜「LLM 演砸了」的质量风险（探针期不让玩家为模型失误买单）。用户 2026-07-02 拍真删、机制设计委托（顾虑=上游遗留代码坑多，由白名单不变式挡住）。**cmr R1（agy+Opus 双厂商并发）抓出「删创建物 ≠ 逆转效果」的四个面**——暂存状态被后轮确认、候选状态被后轮应允、草稿正文被后轮覆盖、暂存行被后轮口头拒绝删除，外加已落地密令的结构化记录残留：撤回的承诺是「像没发生过」，只删创建物兑现不了它，故语义修订为效果逆转 + 轮级撤销日志。

## 否决的备选（防日后重议）

- **只删该轮创建物（本 ADR 的 R0 口径）**：该轮对先前对象的状态变更/覆盖/删除不可逆——撤回确认轮后暂存动作仍是已确认态、被覆盖的草稿正文永久丢失、被拒删的暂存行无法复原，「像没发生过」破功（cmr R1）。
- **保持 ADR 0006 当场 commit + 撤销日志回滚真实盘面**：撤销日志要能逆转任免落库（名册/registry/内存同步全可逆），伸进遗留代码最深处——正是白名单不变式要防的坑（cmr R4，用户否）。
- **保持当场 commit + 应允封窗（应允轮起不可撤）**：撤回兜的恰恰是「说错话/大臣演砸」，确认轮最容易后悔；且推翻「被确认的暂存回到待确认」（cmr R4，用户否）。
- **冲正/状态位（追加作废标记）**：过滤义务扩散到所有读账处（见闻派生/喂 LLM/呈现），漏一处即「明明撤回了王承恩怎么还记得」；记录留残影。
- **账本 pending 层（实际落时再入）**：推迟落账 = 崩溃丢整轮，违 P1/restore（ADR 0036 恢复精确到最后持久化对话轮的前提是即时落账）。
- **砍掉撤回本轮**：最贴角色保真，但探针期它是兜模型质量风险的（既有 CONTEXT 词条立意），不砍。
