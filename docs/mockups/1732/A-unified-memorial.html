#1732 · 取向 A · 统一奏疏牌

所有确认 / 告警 → 同一块画面内奏疏牌

以一枚「奏疏牌」浮层替换全部 window.confirm / alert。 牌面结构固定：事由 · 后果 · 准/驳。高危动作仅在牌内加码（手打解锁），不另起形态。 本页可点按钮打开各场景；文案均为票面原句。

场景：回到主菜单 · 页面内已有确认面板 → 点按钮出奏疏牌（本取向仍弹一次画面内确认；与现状双重不同在于去掉原生框）

回到主菜单

关闭当前游戏会话，回到主菜单。数据库与存档不变；可从主菜单「继续上局」或「加载存档」回到游戏。

游戏菜单

保存存档 加载存档 回到主菜单 重开新局 退出游戏

重开新局

清空主 DB（聊天记录、回合奏报、局势、ledger 全清），重置到开局。 不可撤销。要保留当前局，先到「保存存档」存一份。

本取向把「手打重开」挪进奏疏牌，面板按钮只负责唤起牌面——授权强度不降。
