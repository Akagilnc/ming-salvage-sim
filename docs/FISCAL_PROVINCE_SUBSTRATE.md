## 1. 钱怎么流(codex #1 重写:火耗不再当国库折损)
**关键修正:火耗是「民间多交、被地方截留」的附加,不是「国库收不到」的折损。** 国库收不到 = 逋赋(收不上)+ 漂没(运损),与火耗无关。

```
正赋应征 = 官民田 × 亩率                     (万亩×两/亩·年 → 万两/月)
三饷应征 = 三饷率 × 官民田
── 民侧(火耗在这,不进国库公式)──
火耗额   = 正赋应征 × 火耗率                 ← 民多交、入地方官绅,不进国库
民人均负担 = (正赋+三饷+火耗额) ÷ 民口
── 国库侧 ──
实际征得 = (正赋+三饷应征) × (1 − 逋赋率)    ← 逋赋=收不上(灾/负担率/征收能力)
解运到京 = 实际征得 × (1 − 漂没率)           ← 漂没=运损(腐败/运输能力/押解)
本省可支 = 存留份额;  起运 = 解运到京 − 存留
```
**三口抽水各归各位**:火耗(征收口)加在**民负担**、地方截留,**不直接减国库**(间接:火耗↑→负担↑→逋赋↑);漂没(解运口)减**起运到账**;中饱(拨付口)减**军饷/赈灾到手**。

## 4. 存留/起运优先级(codex #4 钉死)
应征分配按优先级,**短缺时低优先级先被拖欠、累进对应 stock**:
1. 起运定额(中央/边饷 earmark)
2. 本省驻军饷 → 欠则进 `军饷欠`
3. 本省官俸/行政 → 欠进 `官俸欠`
4. 宗禄 → 欠进 `宗禄欠`
5. 赈济/其他

**欠谁爆什么**:军饷欠→**兵变**;宗禄欠→宗藩闹+满意度↓;官俸欠→吏治崩+腐败↑;民欠→逋赋累积+流寇。
(优先级可由旨意调,但调了有政治后果——AI 判。)

## 5. AI ↔ 引擎契约(codex #8/#9/#10 收紧)
- **AI 不提任意 delta。** AI 解析玩家意图 → 映射到**有限 `action_id` + 力度 + 投入资源** → 引擎算真钱/派生/clamp → 返回**结构化原因** → AI 讲人话 + 判软后果。
- **结构化 clamp 返回**:`{reason_code, requested_delta, applied_delta, binding_constraints, blocking_vars}`。引擎原因可测试可复现,AI 只负责叙事。
- **组合动作(codex #10)**:一个 action = **effect 向量**(多个机械效果),不是单 lever。

## 7. 死亡螺旋(因子,加 codex #7 刚性前提)
- AI 耦合:民负担↑+灾 → 民变/逋赋/人口流失↑;`民口`↓ → 人均负担↑ → 下回合更糟。
- 引擎兜底:灾→逋赋率下限。
- **刚性前提(codex #7)**:`民口↓→人均↑` 成立的前提是**税额/军需/加派刚性、不随人口下调** —— 明写:朝廷按册/额派,不按实际生存能力自动减免。

## 8. 设计铁律 v2(codex #11/#12 refine)
1. 压力提供不强制;**硬约束限制「不可能」(灾→逋赋下限),不限制「赢」**;杠杆只调难/慢/代价。
2. 不防爽不防作弊;但**砸钱解决预算 ≠ 自动解决运输/胥吏/粮价/信用/军队组织**。
3. 财政量真钱+标准值看比率;**火耗已分账**(率×正赋=额,进民负担**不进**国库公式)。
4. 引擎不静默 clamp;**原因结构化**(reason_code…),AI 讲人话。
5. 杠杆按机械效果定义不绑名;**且一个 action = effect 向量(组合动作)**。
