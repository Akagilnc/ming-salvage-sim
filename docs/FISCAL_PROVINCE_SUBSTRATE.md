# 省级财政基座 · 草表(draft）

> 「把游戏 LLM 后端当裁判」探针下,省级财政的**全新设计**(砍掉旧黑箱 `_province_efficiency` + flat `tax_per_turn`)。
> 目标:给 AI 当裁判一块**真实、可复现、会反扑**的地。设计决策与取舍见 [ADR 0007](adr/0007-province-fiscal-substrate-ai-judged.md)。
> ⚠️ 所有「值」是**史实量级粗校**,精确账落地时再调;标 ⚠️ 的待精验。样本省=陕西。

## 0. 基座分工(一句话)
**引擎 = 账本 + clamp + 挤压算术(死账);AI = 裁判**(判这回合各状态动多少、软后果怎么爆)。引擎给 AI 的是**带因果的反馈**,不是裸数字。

## 1. 钱怎么流 + 腐败三口抽水

```
征收: 官民田×亩率 + 三饷       ← 火耗(征收口抽,腐败×官俸缺口)
  └→ −逋赋(收不上) = 国库实收(本省)
       └→ 存留: 先付本省出血 ── 解运 ── 漂没(解运口抽,腐败)
            └→ 起运余额 → 太仓/国库   或   净亏空 →(C)中央补+就地拖欠
拨付(军饷/赈灾下发)            ← 中饱(拨付口抽,腐败)
```
**腐败度是一个软系数,在三个口都抽**:火耗(征收)/ 漂没(解运)/ 中饱(拨付)。反腐压腐败 → 三口同小。

## 3. 二级派生指数(引擎每 tick 算,不存)

| 指数 | 公式 |
|---|---|
| `官俸缺口` | 官俸所需 − 官俸法定 |
| **火耗(征收口)** | ≈ 官俸缺口 ×(1 + 腐败溢价) |
| **漂没率(解运口)** | f(腐败度, 路途环节, 有无押解) |
| **中饱率(拨付口)** | f(腐败度, 有无核账) |
| `逋赋率` | f(灾, 负担率, 民变)(AI 软判修正,引擎给灾→下限) |
| `国库实收`(本省) | 官民田×亩率×(1−火耗−逋赋) + 三饷 − 解运漂没 |
| **民人均负担** | (正赋+三饷)×(1+火耗) **÷ 民口** ←人口↓→人均↑(死亡螺旋) |
| **负担率** | 人均负担 ÷ `burden_baseline`(>1 重负 <1 轻;陕西~1.3) |
| `净亏空` | 本省收 − 本省出血 |
| `流寇增长压力` | f(负担率, 灾, 裁驿失业驿卒) |

## 4. 杠杆(新政 = 国策/密令;AI 认意图→机械效果;**名字不锁**)

| 杠杆 | 机械效果 | 阻力 | 玩家可能的说法 |
|---|---|---|---|
| 清丈 | 隐田↓ 官民田↑ | 士绅阻力 + 藩王 | 清丈田亩 / 查隐田 / 核灾蠲赋 |
| 整肃吏治 | 腐败度↓(三口同降) | 慢、最难 | 反腐 / 杀贪官 / 肃清吏治 |
| 派专员押解 | 漂没率↓(临时) | 花人手 | 专员押解 / 防漂没 |
| 清账追赃 | 中饱率↓ | 官僚抗 | 清账 / 追赃 / 会稽 |
| 抬官俸 | 官俸法定↑(出血↑)→缺口↓→火耗↓ | 国库掏不起 | 养廉银 / 加俸禄 / 高薪养廉 |
| 削藩 | 宗禄↓ | 宗室满意度 backlash | 削藩 / 减宗禄 / 限禄 |
| 裁驿 | 驿卒↓ 出血↓ **但** 流寇↑ | dilemma | 裁驿站 / 省驿费 |
| 加/减三饷 | 三饷率;民负担↑→逼反 | dilemma | 加饷 / 练饷 / 免辽饷 |
| 蠲免/赈灾 | 灾影响↓ 逋赋↓ 民心↑ | 花钱 | 蠲免 / 赈济 / 安民 |

## 5. 死亡螺旋(当**一个因子**,不单开子系统)
- **AI 耦合**:民负担↑ + 灾 → 民变/逋赋/人口流失↑;`min_kou`↓ → 人均负担↑ → 下回合更糟。
- **引擎兜底一根钉**:灾年省份 `逋赋率` 有随灾上升的下限(AI 判不掉「大灾还收得上」)。

## 6. AI ↔ 引擎契约(命门)
AI 对任意状态提 delta → 引擎返回 **(实际落地值 + 约束原因)** → AI 据此判 + 叙事。
例:AI「火耗 −5%」→ 引擎「实际 −1%;因火耗已近标准火耗(腐败72+官俸缺口),硬压被胥吏另立名目反弹;真降须先压腐败或抬官俸」。
**引擎永不静默 clamp**(接 [#14](https://github.com/Akagilnc/ming-salvage-sim/issues/14) 不静默吞)。

## 7. 设计铁律(5 条,详见 ADR 0007）
1. 压力是提供的不是强制的 —— 结局开放、破局可真;杠杆只调难/慢/代价,不设「不准赢」硬顶。
2. 不防爽不防作弊 —— 基座做深困境,不逼玩家受苦。
3. 财政量用真钱(万两/月)进预算流;「够不够/重不重」配标准值看比率,不写抽象绝对分数。
4. 引擎从不静默 clamp —— clamp 必带原因返回 AI。
5. 杠杆按机械效果定义,不绑历史名/关键词;AI 做意图→杠杆映射 + 叙事。

## 术语(待并入 CONTEXT.md glossary)
- **三道漏**:税基流失(隐田)/ 征收盘剥(火耗)/ 收不上(逋赋)。
- **火耗 / 漂没 / 中饱**:腐败度在征收口 / 解运口 / 拨付口 抽的三道水。
- **官俸缺口**:官俸所需 − 官俸法定;火耗的根。
- **负担率 / 官俸够不够**:实际 ÷ 标准值 的比率,不是绝对分数。
- **官吏胥役**:政府人员统称(含驿卒)。
- **净亏空**:本省收 − 本省出血,负=亏空。
