## 语义转译仍归 LLM

2026-09-09，owner 针对助手的「也不增加另一个 LLM 来翻译」明确质疑：

> 啥意思，不用llm你怎么翻译？你别告诉我你又想用代码来解析llm的意图

不能把选择统一入口理解为授权代码猜自然语言意图，或禁止中间层使用转译 LLM。语义理解和转译仍由 LLM 承担，代码接明确变更后分派、核算、存储；转译不能擅自重判推演结果。该责任边界修正于 0153，0154 引用它；「推演者不操心底层」与「中间层内部存在 LLM」并不冲突，具体由哪次调用承担尚未定。
