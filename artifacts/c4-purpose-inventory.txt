四、非召对 / 手工编辑链（纠正 r5「只透传」失准）
================================================================

### 4.1 HTTP 入口（web_app.py:5416-5489）

POST `/api/directives`（5416-5450）：
  1. 校验 text 非空；抓 capture_turn
  2. **必调** `capture_manual_directive_payload(text, llm_config, db=, content=)`
  3. 回合未变则 `session.add_directive(text, notes, dossier_payload=捕获结果)`

PATCH `/api/directives/{id}`（5452-5489）：
  1. 读既有 row；text = request.text 或 row.text
  2. existing_mode = read_directive_dossier_payload(row).mode
  3. **同样必调** `capture_manual_directive_payload(text, ..., existing_mode=existing_mode, db=, content=)`
  4. `session.update_directive(id, text, dossier_payload=捕获结果)`

**纠正**：PATCH **不是**「仅透传既有结构化字段」。每次 POST/PATCH 都对
**当前正文**做一次有界 LLM 重抽取（或空载/超时降级 special_decree）。

### 4.2 capture_manual_directive_payload（cli_backend.py:2956-3110）

行为摘要：
- 空 text → 零 LLM，直落 `_manual_special_decree_payload(mode)`（special_decree）
- 非空 → extract_draft_intent_with_roster_heal（有界超时；挂死→special_decree 原文照落）
- draft_action !=「拟旨」→ special_decree
- 否则组装：
  必选：dossier_action_type, target_kind, target_id, mode
  条件挑选（非空才写入）：amount, account, execution_surface, assignee,
    deadline_months, participant_roster, locality_scope, entries,
    target_dossier_id, grant_action, purpose, cadence, region_id,
    transaction_category
  **不挑选 title 字段**（手工旨无独立 title 槽；若成 assignment/referral，
   判后题名回落 payload.target_id——与 _initiative_title_and_body 一致）
  **不挑选 text 字段**（正文真源=directive.text → 成案 decree_text → payload.text）
- dismiss_assignment：补 name=target_id, _office_action=罢免
- grant_allocation 协饷：canonicalize / require 显式字段
- classify_directive_structured_kind：push → 只留 target_dossier_id+mode；
  empty → special_decree；ordinary → assemble_structured_decree 后返回

### 4.3 session / db 写入

session.add_directive（2997-3010）：
  directive_payload_admits_structured_write 闸 → db.add_directive(..., dossier_payload)

session.update_directive（3012-3019）→ db.update_directive_text：
  已成案拒编；_merge_directive_payload(旧 json, 新 capture)：
    ordinary 改草清 target_dossier_id；push 清 triad；再 normalize
  **合并的是「重抽取结果 ⊕ 旧载荷」**，不是「只改 notes 的透传」

成案 _ensure_directive_dossier（19843+）：
  decree_text = directive.text（玩家可见旨文）
  payload = 结构化 capture/normalize 结果
  → create_decree_dossiers；行内核补 payload.text←decree_text（若缺）

判后：
  - 若 action 为 assignment/referral → _initiative_title_and_body
    （title|target_id；body=text|decree_text）
  - 若 special_decree/policy/… narrative → 不写 initiative 题名；
    正文留 decree_text 供 simulator
  - 其它 payload 类型按 §一，不共享 initiative 题名规则

### 4.4 命中与合法留存（本链）

| 环节 | 命中 | 合法留存 |
|---|---|---|
| 重抽取 | 每次 POST/PATCH | 超时/非拟旨 → special_decree，旨文仍落 draft.text |
| 字段挑选 | 上列闭集；无 title | target_id 可作 assignment 题名锚；不从散文截 title |
| 正文 | directive.text → decree_text → payload.text | 旧案/手工无单独 text 字段时的正文唯一槽 |
| 成案后编辑 | get_dossier_for_directive 已存在 → 拒 | 防成案后改结构化身份 |
| 读回 | issue_payloads / list_active_issues | 只读已落库 title/stage_text |
