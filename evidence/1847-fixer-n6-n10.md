## 逐类根因

### N6：原文运输删改
- **根因**：`web_app.py:_humanize_condition` 在未匹配 `character.*` 形式语言时，对任意条件原文执行 `_CONDITION_DISPLAY_REPLACEMENTS` 词表替换；状态投影 `resolve_condition`/`fail_condition` 走此路 → HTTP 呈现与 DB 原文 byte 不等。
- **上轮错误分类**：`evidence/1847-n6-members-classified.tsv` 将该处标 `KEEP_match_or_normalize`（「非原文运输」），与真实来源（账本条件原文）/去向（`GET /api/game/state` 呈现）不符。
- **修法**：删除自由原文 fallback replace；仅保留 `character.*` 形式语言解析；自由原文原样返回。落库/供料运输保留。

### N10：自由措辞决定业务或呈现分类
- **根因 A**：`situation.tsx:groupIssues` 用 `/甲申|贯穿一朝|倾国之大计/` 扫 `fail_condition` 分 long/near；同 id 仅改措辞即换桶。
- **根因 B**：`issues.py:_commitment_fiscal_create_duplicate_reason` 把自由 `reason` 纳入 `_recurring_funding_label_tokens`，并做中文词义剥离后集合交 → 仅改 reason 可翻转 `fiscal_item_written`。
- **边界**：ADR 0027 历史双扣事实保留（账户+科目名去重仍在）；驳回词义猜测；不新增分类字段/溯源/护栏。
- **修法**：删关键词分组（单「局势」列表）；tokens 仅 structured stem（display/key/category/purpose），去掉 reason 与词义剥离词表。
