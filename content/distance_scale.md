# 路程数据

规则与授权见 [ADR 0163](../docs/adr/0163-one-month-timeline-forks-at-once-travel-by-day.md)。

`distance_graph.json` 是唯一作者数据，边的 `cost` 为里。省级节点代表行程起讫；保留原省级路线，浙江另接一条京师端点里程边，以同时保持史书浙江3200里与南京3445里的锚点，不声称还原逐段驿路。普通省际边无逐段史料的标作游戏设定，按京师端点里程校准；不能把史书不同路径的里程混作同一路线。

京师里程据《明史·地理志》：

| 地区 | 里程 | 出处 |
| --- | ---: | --- |
| 南京 | 3445 | 卷40 |
| 山东、山西 | 900、1200 | 卷41 |
| 辽东（宁远一线） | 约930 | 卷41：都司距京1700里、宁远东距都司770里，取差额 |
| 河南、陕西 | 1580、2650 | 卷42 |
| 四川、江西 | 10710、4175 | 卷43 |
| 湖广、浙江 | 5170、3200 | 卷44 |
| 福建、广东、广西 | 6133、7835、7462 | 卷45 |
| 云南、贵州 | 10645、7670 | 卷46 |

原文入口：<https://zh.wikisource.org/wiki/明史/卷40>（其余卷同址改卷号）。境外与没有逐段史料的省际里程是游戏设定，不附会为史实。

`python -m ming build-opening` 在既有模板构建过程中，用 NetworkX 的 `all_pairs_dijkstra_path_length` 计算最短路，最终只落 distance 实体；新开局仍只复制模板。没有中间距离矩阵或独立烘焙脚本。

行速、送达天数、程限和日期运算的实现真源在 `ming/middle/travel.py`；转译字段含义在 `ming/middle/fields.py`。路程不含动身前准备时间。模型用 `read_records` 查询 distance 得各档天数，查询人物得启程日与预计到达日。日只用于行程，游戏月固定30日，不改变按月回合。
