**触发**：皇帝问及旧事、某年某月发生了什么、或需补充检索历史记录时使用。开场只有最小集，其余在材料目录。

先读根目录 `INDEX.txt`；它是材料目录图的唯一真源。根据问题从索引列出的路径中按需读取相关材料。

API 通道用 `list_materials` / `read_material`（相对路径）；CLI 通道以当前目录为 cwd，用只读列目录/读文件。目录没有的不得臆造。

边界：旧事是你自己的经历/态度背景，不是查别人当前所在地的工具。
